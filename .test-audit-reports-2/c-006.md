### HIGH

#### HIGH-1 · Isolation (dim 6) · `tests/test_routes_smoke.py:14`

`test_routes_smoke.py:14` — module-scoped `client` fixture mutates `app.config['TESTING'] = True` with no teardown.

**Consequence:** `TESTING` flag persists on the Flask app singleton after the module finishes. Any test module that runs after `test_routes_smoke` in the same process inherits the flag. Under `pytest-xdist` with in-process workers this is a silent cross-test state bleed. Same root cause as SYNTHESIS big theme #1; this file was not in the prior fix-pass.

**Fix:** Wrap the fixture body in snapshot-restore: save `original = app_module.app.config.get('TESTING')` before setting `True`, and restore in a `finally` clause after `yield`. (`monkeypatch` cannot be used in module-scoped fixtures — the `try/finally` pattern is the correct approach here.)

**Evidence lines:** 11–16

### MED

#### MED-1 · Accuracy (dim 1) · `tests/test_security_headers.py:127–135`

`test_security_headers.py:127` — `TestCspNonceInTemplateContext` class docstring states "The `{{ csp_nonce }}` Jinja global **must match** what's sent in the header." The single test in the class (`test_nonce_exposed_via_context_processor`) verifies only that the rendered nonce is non-empty (`assert rendered`, line 134) and at least 20 chars long (`assert len(rendered) >= 20`, line 135). No assertion compares the nonce value against the `Content-Security-Policy-Report-Only` header.

**Consequence:** A regression where the context processor and the security middleware generate *independent* nonces (e.g., after a refactor of `assign_request_id`) would produce a rendered page with one nonce and a CSP header with a different nonce — every inline script would be blocked silently. This test would still pass because it only checks non-emptiness, not match. The class-level contract is the critical security invariant and it is unverified.

**Fix:** After `assign_request_id()`, inspect `flask.g` for the nonce or issue a test-client request and compare. Concretely: capture the nonce via `from flask import g; nonce_in_g = g.csp_nonce` (or however it is stored), render the template, and assert `rendered == nonce_in_g`. Then issue a real `/health` request and assert the same value appears in `Content-Security-Policy-Report-Only`.

**Evidence lines:** 124–135

#### MED-2 · Splitting (dim 11) · `tests/test_security_headers.py:47–53` and `110–116`

Two tests iterate over feature/directive lists inside a single test body:

- `test_permissions_policy_disables_sensors` (line 47): `for feature in ('camera', 'microphone', 'geolocation', 'payment', 'usb', 'interest-cohort', 'browsing-topics'): assert f'{feature}=()' in pp` — 7 assertions, first failure hides the remaining 6.
- `test_csp_includes_core_directives` (line 110): `for directive in ('default-src', 'script-src', 'style-src', 'img-src', 'font-src', 'connect-src', 'frame-ancestors', 'base-uri', 'form-action'): assert directive in csp` — 9 assertions, first failure hides the remaining 8.

**Consequence:** If a refactor accidentally drops two CSP directives, the test reports only the first missing one. The developer fixes it and re-runs, hits the second failure. For security-relevant header contracts, seeing all failures at once reduces the risk of "fix one, miss another" partial-regression.

**Fix:** Convert each loop to `@pytest.mark.parametrize`. For the permissions-policy test:

```python
@pytest.mark.parametrize("feature", [
    'camera', 'microphone', 'geolocation', 'payment',
    'usb', 'interest-cohort', 'browsing-topics',
])
def test_permissions_policy_disables_feature(self, client, feature):
    pp = client.get('/health').headers['Permissions-Policy']
    assert f'{feature}=()' in pp, f"{feature} not opt-out in Permissions-Policy"
```

The CSP directives test follows the same shape.

**Evidence lines:** 47–53, 110–116

### LOW

#### LOW-1 · Duplication (dim 10) · `tests/test_scan_library_rom_path.py:35–37`

`test_scan_library_rom_path.py:35–37` — `_REPO_ROOT = os.path.dirname(...)` + `sys.path.insert(0, _REPO_ROOT)` boilerplate replicates what `tests/_util.REPO_ROOT` now provides.

`tests/_util.py` was extracted specifically to eliminate this pattern (SYNTHESIS theme #3). `conftest.py` re-exports `REPO_ROOT` and inserts it into `sys.path` at session start, so by the time any test module imports, the path is already set. The local boilerplate in this file is now dead duplication.

**Consequence:** If the repo-root computation changes, it must be updated in two places. The `import os` and `import sys` at lines 29–30 exist solely to support this boilerplate; removing it eliminates two imports.

**Fix:** Remove lines 27–37 (`from __future__ import annotations`, `import os`, `import sys`, `import pytest`, `_REPO_ROOT = ...`, `if _REPO_ROOT not in sys.path: sys.path.insert(...)`) and replace with:

```python
from __future__ import annotations
import pytest
from tests._util import REPO_ROOT
```

Then replace `os.path.join(_REPO_ROOT, 'scraper', 'scan_roms.py')` at line 156 and `os.path.join(_REPO_ROOT, 'services', 'rom_scanner.py')` at line 169 with `os.path.join(REPO_ROOT, ...)` — keeping `import os` since `os.path.join` is still used. Or use `REPO_ROOT / 'scraper' / 'scan_roms.py'` with `pathlib.Path`.

**Evidence lines:** 29–37

#### LOW-3 · Accuracy (dim 1) · `tests/test_slow_query_log.py:71`

`test_slow_query_log.py:71` — `assert '...' in msg` is the only truncation assertion in `test_long_sql_is_truncated`. The comment on line 70 states "Truncated to 500 chars + ellipsis sentinel" but the 500-char cap is never verified.

**Consequence:** If the truncation cap regresses from 500 to 5000 chars, or is removed entirely (message emits the full 1000-char SQL), the test still passes as long as any `...` appears anywhere in the log message. The documented contract is unverified.

**Fix:** Assert an upper bound on the SQL portion length. Example:

```python
assert '...' in msg
assert len(msg) < 700   # 500-char SQL cap + overhead for label fields
```

Or, more precisely, extract the SQL substring from the structured log message and assert its length directly.
