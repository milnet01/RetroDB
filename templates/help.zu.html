Ukufaka

Izidingo Zohlelo

  • Python 3.8+ ene-pip
  • Isiphequluli sewebhu (Chrome, Firefox, Safari, Edge)
  • Uhlelo Lokusebenza: Linux, Windows 10/11, noma macOS

Ukufaka Okusheshayo

  1. Khipha i-ZIP ye-RetroDB uyifake kwidayirekthri oyikhethayo
  2. Vula i-terminal/command prompt kuleyo dayirekthri
  3. Sebenzisa: python install.py
  4. Qalisa iseva:
    • Linux: ./start.sh
    • Windows: chofoza kabili i-start.bat
    • macOS: chofoza kabili i-start.command
  5. Vula i-http://localhost:5000 kusiphequluli sakho

Isifaki se-GUI

Ku-Linux, ungasebenzisa futhi i-./setup.sh ukuqalisa isihloko sokufaka esibonakalayo. Sihlola i-Python/pip/tkinter ngokuzenzakalelayo, bese sikuhola kuzo zonke izinyathelo zokusetha ngelogi yenqubekela phambili ebonakalayo.

Okwenziwa yi-install.py

  • Ihlola ukuthi i-Python 3.8+ ne-pip ziyatholakala
  • Ifaka izinto ezidingekayo ze-Python ezisuka ku-requirements.txt
  • Idala i-config.py isuselwa kuthempulethi yesibonelo
  • Idala amadayirekthri adingekayo (i-database, amalogi, izikhwama zemidiya)
  • Yakha amaphakethe e-CSS ne-JS

Amanothi Eplatifomu

Linux

  • Kuhlolwe ku-Ubuntu, Fedora, openSUSE, ne-Arch Linux
  • Amathuluzi e-ROM adinga: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) noma okufanayo kwesabiwo sakho
  • Uma usebenzisa i-Python yohlelo, isifaki siphatha i---break-system-packages ngokuzenzakalelayo
  • Ukusheshisa kwe-GPU ye-ROCm kusekelwe kuma-GPU e-AMD (Real-ESRGAN ukukhulisa isithombe)

  • Landa i-Python ku-python.org (khetha "Add to PATH" ngesikhathi sokufaka)

  • Sebenzisa i-start.bat ukuqalisa, noma sebenzisa i-python app.py usuka ku-Command Prompt

macOS

  • I-Python 3 ingafakwa nge-Homebrew: brew install python3
  • Amathuluzi e-ROM: brew install p7zip unrar rom-tools
  • Chofoza kabili i-start.command ku-Finder ukuqalisa
  • Ukusheshisa kwe-CoreML kusekelwe kwi-Apple Silicon (Real-ESRGAN ukukhulisa isithombe)

Umhlahlandlela Wokusetha i-API Key

Ama-API key awakhethekile kodwa avumela ukukhwephulwa kwe-metadata ecebile nezici ezengeziwe. Wazisethe ku-Settings → Scraping → API Keys.

Ama-scraper we-Metadata

TheGamesDB

  1. Yiya ku-api.thegamesdb.net/key.php
  2. Cela ama-API key (mahhala, avunywa ngesandla) — uzothola i-key Public ne-Private
  3. Faka womabili ama-key ku-Settings → API Keys → TheGamesDB
  4. I-key Public (umkhawulo wesivinini nge-IP ngayinye) isetshenziswa njenge-key eyinhloko yokukhwephula
  5. I-key Private (ichibi elabelwana ngenyanga) isetshenziswa njengokuweleza uma i-key ye-public yehluleka

IGDB (nge-Twitch)

  1. Dala i-akhawunti ye-Twitch ku-twitch.tv
  2. Yiya ku-dev.twitch.tv/console
  3. Bhalisa uhlelo olusha (noma yiliphi igama, noma yiliphi isigaba, http://localhost njenge-OAuth redirect)
  4. Kopisha i-Client ID bese ukhiqiza i-Client Secret
  5. Faka womabili ku-Settings → API Keys → IGDB

RAWG.io

  1. Yiya ku-rawg.io/apidocs
  2. Chofoza "Get API Key" bese udala i-akhawunti
  3. Kopisha i-API key yakho ku-dashboard
  4. Yifake ku-Settings → API Keys → RAWG

Isigaba samahhala: izicelo ezingu-20,000 ngenyanga

ScreenScraper

  1. Dala i-akhawunti ku-screenscraper.fr
  2. Faka igama lakho lomsebenzisi nephasiwedi ku-Settings → API Keys → ScreenScraper

Qaphela: i-ScreenScraper inemikhawulo yezicelo yansuku zonke encike ezingeni le-akhawunti yakho. Ukufaka isandla kwi-database kwandisa imikhawulo yakho.

  • Notifications — Izintandokazi zesikhathi sokuphela kwesaziso (impumelelo, ulwazi, isexwayiso, iphutha — ngalinye lisethwa ngokuzimela)
  • Controllers — Phatha umtapo we-controller, setha ama-controller azenzakalelayo nge-system ngayinye, engeza ama-controller angokwezifiso. Ama-controller azenzakalelayo abhala phezu kwamanani e-scraper/AI ngesikhathi sokulanda i-metadata.

  • Troubleshooting — Sula i-bulk scrape ejamile, sula ulayini wokuvumelanisa i-RA, sula ukuvuselelwa kwe-PSN, sula ukukhiqizwa kwe-museum, qala kabusha i-server

AI Fill

Ukuthi Yenzani

I-AI Fill isebenzisa i-large language model (Gemini, OpenAI, noma Claude) ukugcwalisa ngobuhlakani i-metadata yomdlalo engekho noma engaphelele. Ihlakaniphile kunokukhwephula okujwayelekile ngoba isebenzisa ulwazi olusemongweni ngomdlalo ukuze inikeze idatha enembile ama-scraper angeke abe nayo.

Indlela Yokusebenzisa

  1. Vula i-modal yemininingwane yomdlalo (noma ikhasi eliphelele lemininingwane)
  2. Chofoza "AI Fill" (kudinga i-AI API key emisiwe ku-Settings)
  3. I-AI ihlaziya isihloko somdlalo ne-system, bese igcwalisa izinkambu ezingekho
  4. Buyekeza imiphumela — izinshintsho zigcinwa ngokuzenzakalelayo

Okungahlinzekwa yi-AI Fill

  • I-genre, incazelo, umenzi, umshicileli, idethi yokukhishwa
  • Abadlali, ama-modes okudlala (Single-Player, Multi-Player, Co-op, njll.)
  • Ulwazi lomkhankaso nesakhiwo somdlalo
  • Zonke izinhlelo ezingu-8 zesilinganiso seminyaka (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Isifunda, i-franchise, imidlalo efanayo
  • Ukusekelwa kwe-controller, uhlobo lokugcina
  • I-perspective (First-Person, Top-Down, Side-Scroller, njll.), i-dimension (2D, 3D)
  • Ulwazi lohlobo, amaphuzu abagxeki nabasebenzisi

Umqondo Wokugcwalisa Okuhlakaniphile

  • Izinkambu ezingenalutho zihlala zigcwaliswa
  • Idatha yomsebenzisi ekhona ayibhalwa phezu kwayo neze
  • Imidlalo efanayo ihlala ivuselelwa (idatha ye-AI ithenjwa kakhulu kule nkambu)
  • Izilinganiso ezimephwe ngokuphambana — Uma uhlelo olulodwa lwesilinganiso lwaziwa, izilinganiso ezingenalutho kwezinye izinhlelo zigcwaliswa ngokuzenzakalelayo kusetshenziswa ukumepha okuphambana kwezinga lokuvuthwa
  • Isihloko sokuhlunga sikhiqizwa ngokuzenzakalelayo uma sigcwaliswa
  • Inkambu Abadlali yenza ababanzi babe sezingeni (isb. "1-4" iba ngu-4)

Ukulinganisa i-Genre

I-AI Fill isebenzisa izinhlobo ze-genre ezisemthethweni ezinamagama afakwe uhlonze:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Izidingo

Okungenani i-API key eyodwa yomhlinzeki we-AI kufanele imiswe ku-Settings → Scraping → API Keys. Izinga le-model elishibhile (Gemini Flash Lite, GPT-4o Mini, noma Claude Haiku) lisebenza kahle ku-metadata.

Security & Disclaimer

Izindlela Ezinhle Zokuphepha

  • Shintsha iphasiwedi ezenzakalelayo — Iphasiwedi ye-admin ezenzakalelayo (admin) kufanele ishintshwe ngokushesha ekungeneni kokuqala. Sebenzisa iphasiwedi eqinile enezinhlamvu okungenani ezingu-8.
  • Sebenzisa i-HTTPS reverse proxy — I-RetroDB ayihlinzeki nge-TLS/SSL ngokwayo. Yibeke ngemuva kwe-reverse proxy (isb. Nginx, Caddy, Traefik) ne-HTTPS evuliwe ukuze ubethele i-traffic phakathi kwamakhasimende neseva.
  • Khawulela ukufinyelela kwenethiwekhi — Gwema ukuveza i-RetroDB ngokuqondile ku-inthanethi yomphakathi. Sebenzisa i-VPN noma khawulela ukufinyelela kunethiwekhi yakho yendawo. Uma ukufinyelela kude kudingeka, sebenzisa i-reverse proxy ene-authentication.
  • Gcina ama-backup njalo — Sebenzisa isici se-backup esakhelwe ngaphakathi ku-Settings ukwenza ama-backup e-database ngezikhathi ezithile. Gcina ama-backup endaweni ehlukene nohlelo.
  • Gcina i-RetroDB ibuyekeziwe — Bheka ukukhishwa okusha njalo. Ukulungiswa kokuphepha nokuthuthukiswa kufakwe ezibuyekezweni.
  • Vikela ama-API key akho — Ama-API key agcinwa ku-data/scraper_settings.json. Qinisekisa ukuthi leli fayela alifinyeleleki ngokuvamile. Ungalokothi wabelane ngo-config.py wakho noma amafayela e-token.

Izici Zokuphepha Ezakhelwe Ngaphakathi

  • Uku-hash kwephasiwedi — Amaphasiwedi e-admin a-hash-wa nge-PBKDF2 (awagcinwa ngombhalo osobala)
  • Ukukhawulelwa kwezinga lokungena — Ukuvikelwa kwe-brute-force endaweni yokungena
  • Ukuqinisekiswa kwendlela — Yonke imisebenzi yamafayela isebenzisa izisizi ze-safe_path ne-safe_filename ukuvimbela ukuhlaselwa kwe-directory traversal
  • Ama-parameterized query — Yonke ama-query e-database asebenzisa ama-parameterized statement ukuvimbela i-SQL injection
  • Ukuvikelwa kwe-XSS — Amabhokisi e-modal asebenzisa ukwakhiwa kwe-DOM okuphephile; okufakwa umsebenzisi kuya-escape-wa
  • Ukuvikelwa kwe-decompression bomb yezithombe — Inani eliphezulu lama-pixel ezithombe likhawulelwe ukuvimbela ukuphela kwenkumbulo ngenxa yezithombe ezinobungozi
