Instalacja

Wymagania systemowe

  • Python 3.8+ z pip
  • Przeglądarka internetowa (Chrome, Firefox, Safari, Edge)
  • System operacyjny: Linux, Windows 10/11 lub macOS

Szybka instalacja

  1. Rozpakuj plik ZIP RetroDB do wybranego katalogu
  2. Otwórz terminal/wiersz poleceń w tym katalogu
  3. Uruchom: python install.py
  4. Uruchom serwer:
    • Linux: ./start.sh
    • Windows: kliknij dwukrotnie start.bat
    • macOS: kliknij dwukrotnie start.command
  5. Otwórz http://localhost:5000 w przeglądarce

Instalator graficzny

W systemie Linux możesz też uruchomić ./setup.sh, aby uruchomić kreatora instalacji z interfejsem graficznym. Automatycznie sprawdza dostępność Pythona/pip/tkinter, a następnie przeprowadza Cię przez każdy krok konfiguracji z wizualnym dziennikiem postępu.

Co robi install.py

  • Sprawdza dostępność Pythona 3.8+ i pip
  • Instaluje zależności Pythona z pliku requirements.txt
  • Tworzy plik config.py na podstawie szablonu przykładowego
  • Tworzy wymagane katalogi (baza danych, dzienniki, foldery multimediów)
  • Buduje pakiety CSS i JS

Pierwsze kroki

Konfiguracja pierwszego uruchomienia

Przy pierwszym uruchomieniu RetroDB pokazuje kreatora konfiguracji, który przeprowadzi Cię przez:

  1. Konto administratora — utwórz nazwę użytkownika i hasło
  2. Ścieżkę biblioteki — ustaw katalog ROM-ów
  3. Integrację z ES-DE — opcjonalne połączenie list gier i multimediów ES-DE
  4. Klucze API — opcjonalne dodanie kluczy API scraperów

Po ukończeniu kreatora kliknij „Skanuj bibliotekę” w Panelu głównym, aby wykryć swoje ROM-y.

Szybki przewodnik po pracy

  1. Skanuj bibliotekę, aby zaimportować ROM-y
  2. Przeglądaj według systemu lub zobacz wszystkie gry w Bibliotece
  3. Pobieraj metadane pojedynczo lub użyj masowego pobierania
  4. Organizuj za pomocą tagów, list i listy życzeń
  5. Śledź swoje postępy dzięki statusowi ukończenia i osiągnięciom

Struktura biblioteki ROM-ów

RetroDB oczekuje, że Twoje ROM-y będą zorganizowane w folderach systemowych w ścieżce biblioteki:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Każdy folder systemowy powinien zawierać plik ES-DE systeminfo.txt, który definiuje obsługiwane rozszerzenia plików. RetroDB odczytuje go podczas skanowania, aby określić, które pliki są prawidłowymi ROM-ami dla danego systemu.

Wskazówka: Jeśli masz już dane pobrane przez ES-DE, RetroDB może je zaimportować! Skonfiguruj ścieżki ES-DE w Ustawieniach → Integracja ES-DE lub podczas kreatora konfiguracji.

Uwagi dotyczące platform

Linux

  • Testowane na Ubuntu, Fedorze, openSUSE i Arch Linux
  • Narzędzia ROM wymagają: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) lub odpowiednika dla Twojej dystrybucji
  • Jeśli używasz systemowego Pythona, instalator automatycznie obsługuje --break-system-packages
  • Obsługiwane przyspieszenie GPU ROCm dla kart AMD (skalowanie obrazów Real-ESRGAN)

Windows

  • Pobierz Pythona ze strony python.org (zaznacz „Add to PATH” podczas instalacji)
  • Narzędzia ROM: zainstaluj 7-Zip, WinRAR i MAME (dla chdman)
  • Użyj start.bat, aby uruchomić, lub uruchom python app.py z wiersza poleceń

macOS

  • Python 3 można zainstalować przez Homebrew: brew install python3
  • Narzędzia ROM: brew install p7zip unrar rom-tools
  • Kliknij dwukrotnie start.command w Finderze, aby uruchomić
  • Obsługiwane przyspieszenie CoreML dla Apple Silicon (skalowanie obrazów Real-ESRGAN)

Nawigacja

Sekcje paska bocznego

Główne

  • Panel główny — wynik kondycji kolekcji, przegląd statystyk, status API, ostatnio grane/dodane/pobrane gry, odzyskiwanie zadań

  • Biblioteka — wszystkie gry z nieskończonym przewijaniem, zaawansowanym filtrowaniem (uwzględnianie/wykluczanie), wyszukiwaniem i sortowaniem
  • Analityka — wykresy i statystyki kolekcji w 12 zakładkach z opcjami eksportu

Trofea i osiągnięcia

  • Trofea RPCS3 — lokalnie zdobyte trofea PS3 z emulatora RPCS3
  • Trofea PSN — synchronizacja trofeów PlayStation Network przez API PSN
  • Osiągnięcia — śledzenie postępów RetroAchievements według systemu
  • Osiągnięcia Steam — śledzenie osiągnięć Steam ze szczegółami dla każdej gry
  • Osiągnięcia Xbox — śledzenie osiągnięć i gamerscore Xbox

  • Tagi — niestandardowe, kolorowe tagi gier
  • Listy — nazwane, wyselekcjonowane listy gier z kolejnością ustalaną metodą przeciągnij i upuść
  • Lista życzeń — śledź gry, które chcesz zdobyć, z poziomami priorytetu
  • Trofea kolekcjonera — kamienie milowe grywalizacji dla Twojej kolekcji

Narzędzia

  • Raporty ROM — walidacja nazewnictwa ROM-ów i zgodność ze standardami
  • Import gier — import z CLZ, Steam, Xbox i PSN
  • Narzędzia ROM — skaner archiwów, konwerter/weryfikator CHD, wyszukiwarka duplikatów, organizator gier wielopłytowych, deduplikacja zrzutów ekranu, zmiana rozmiaru obrazów

Konfiguracja

  • Przeglądarka dzienników — przeglądaj dzienniki aplikacji we wszystkich kategoriach

Informacje

Jak to działa

  • Motywy nadpisują zmienne kolorów CSS — wszystkie elementy interfejsu dostosowują się automatycznie
  • Efekty tła obejmują automatyczne wykrywanie poziomu sprzętu (wysoki/średni/niski) z przyspieszeniem GPU, gdy jest dostępne, i awaryjnym trybem CPU dla słabszych urządzeń
  • Efekty wstrzymują się, gdy karta nie jest widoczna, aby oszczędzać zasoby
  • Stan dymu Cyberpunk zachowuje się między nawigacjami stron dla płynnych przejść
  • Subtelna nakładka linii skanowania w stylu CRT dostosowuje się do palety kolorów każdego motywu
  • Twoja preferencja motywu jest zapisywana w przeglądarce i zachowywana między sesjami

Ikony powiadomień, wskaźniki statusu zadań i ikony akcji automatycznie dostosowują się do bieżącego motywu. Na przykład ikona sukcesu może pokazywać zielony znacznik na Cyberpunk, ale inny symbol na Matrix, aby pasował do estetyki zieleni na czerni.

Panel główny

Wynik kondycji kolekcji

Okrągły pierścień postępu pokazuje ogólną kondycję Twojej kolekcji w procentach, oznaczoną kolorem według jakości:

  • Zielony (80%+) — doskonałe pokrycie metadanych

  • Czerwony (<40%) — znaczące luki w metadanych

Poniższe mini-pierścienie pokazują kompletność okładek, kompletność opisów i pokrycie osiągnięć.

Przegląd statystyk

Karty z widokiem na pierwszy rzut oka pokazujące:

  • Łączna liczba systemów — liczba platform w Twojej bibliotece
  • Łączna liczba gier — łączna liczba gier (bez płyt bonusowych)
  • Brakujące metadane — gry jeszcze nie pobrane
  • Kompletne — gry z pobranymi metadanymi

Sekcje ostatniej aktywności

Przewijalne sekcje pokazujące Twoją ostatnią aktywność (każda pojawia się tylko wtedy, gdy istnieją odpowiednie gry):

  • Aktualnie grane — gry oznaczone jako „W trakcie”
  • Ostatnio dodane — najnowsze gry dodane do biblioteki
  • Ostatnio przeglądane — gry, które ostatnio otwierałeś
  • Ostatnio pobrane — gry z ostatnio pobranymi metadanymi

Szybkie akcje

  • Skanuj bibliotekę — skanuj katalogi ROM-ów w poszukiwaniu nowych gier
  • Losowa gra — wybierz losową grę z biblioteki

Status API

Pokazuje status połączenia wszystkich skonfigurowanych scraperów i API. Niedostępne lub błędnie skonfigurowane API wyświetlają baner ostrzegawczy z odnośnikiem do Ustawień.

Odzyskiwanie zadań

Jeśli RetroDB zostanie zrestartowane podczas działania zadań w tle (masowe pobieranie, synchronizacja RA, zmiana rozmiaru obrazów itp.), przerwane zadania pojawiają się w banerze odzyskiwania. Opcje:

  • Wznów — uruchom ponownie pojedyncze przerwane zadanie
  • Wznów wszystkie — uruchom ponownie wszystkie przerwane zadania
  • Odrzuć — usuń pojedyncze zadanie z listy odzyskiwania
  • Odrzuć wszystkie — usuń wszystkie przerwane zadania

Przeglądarka systemów

Siatka systemów

Strona Systemy pokazuje wszystkie platformy w Twojej bibliotece jako karty w responsywnym układzie siatki typu masonry. Każda karta wyświetla:

  • Logo systemu (można dostosować w Ustawienia → Personalizacja → Logotypy)
  • Liczbę ROM-ów i liczbę niepobranych
  • Odznakę typu systemu — konsola, przenośna, komputer, automat arcade lub silnik
  • Odznaki funkcji — obsługa RetroAchievements, lokalne trofea (RPCS3)

Okno modalne specyfikacji systemu

Kliknij przycisk informacji na dowolnej karcie systemu, aby zobaczyć szczegółowe specyfikacje sprzętowe:

  • Obraz sprzętu (zdjęcie konsoli/systemu)
  • Producent i data wydania
  • CPU, GPU, RAM, VRAM
  • Rozdzielczość, głębia kolorów, chip dźwiękowy
  • Typ nośnika (kartridż, płyta itd.)

Filtrowanie i wyszukiwanie

  • Wyszukiwanie tekstowe — filtruj według nazwy systemu lub nazwy folderu
  • Filtr typu — konsola, przenośna, komputer, automat arcade, silnik
  • Filtr funkcji — obsługa RetroAchievements, lokalne trofea
  • Pasek wyników filtrowania pokazuje „X z Y systemów”
  • Filtry są zachowywane po przeładowaniu strony dzięki pamięci sesji

Lista gier dla poszczególnych systemów

Kliknij dowolną kartę systemu, aby zobaczyć jego gry. Lista gier danego systemu ma te same funkcje co pełna strona Biblioteki — nieskończone przewijanie, wyszukiwanie, wszystkie opcje filtrowania, zaznaczanie masowe i sortowanie. Nagłówek systemu pokazuje nazwę systemu, liczbę gier i odznakę typu systemu.

Przewodnik konfiguracji kluczy API

Klucze API są opcjonalne, ale umożliwiają bogatsze pobieranie metadanych i dodatkowe funkcje. Skonfiguruj je w Ustawienia → Pobieranie metadanych → Klucze API.

Scrapery metadanych

TheGamesDB

  1. Przejdź do api.thegamesdb.net/key.php
  2. Poproś o klucze API (darmowe, zatwierdzane ręcznie) — otrzymasz klucz Publiczny i Prywatny
  3. Wprowadź oba klucze w Ustawienia → Klucze API → TheGamesDB
  4. Klucz publiczny (limit na adres IP) jest używany jako główny klucz do pobierania
  5. Klucz prywatny (współdzielona pula miesięczna) jest używany jako zapasowy, gdy klucz publiczny zawiedzie

IGDB (przez Twitch)

  1. Utwórz konto Twitch na twitch.tv
  2. Przejdź do dev.twitch.tv/console
  3. Zarejestruj nową aplikację (dowolna nazwa, dowolna kategoria, http://localhost jako przekierowanie OAuth)
  4. Skopiuj Client ID i wygeneruj Client Secret
  5. Wprowadź oba w Ustawienia → Klucze API → IGDB

RAWG.io

  1. Przejdź do rawg.io/apidocs
  2. Kliknij „Get API Key” i utwórz konto
  3. Skopiuj swój klucz API z panelu
  4. Wprowadź go w Ustawienia → Klucze API → RAWG

Darmowy poziom: 20 000 żądań/miesiąc

ScreenScraper

  1. Utwórz konto na screenscraper.fr
  2. Wprowadź nazwę użytkownika i hasło w Ustawienia → Klucze API → ScreenScraper

Uwaga: ScreenScraper ma dzienne limity żądań zależne od poziomu konta. Współtworzenie bazy danych zwiększa Twoje limity.

Osiągnięcia i trofea

RetroAchievements

  1. Utwórz konto na retroachievements.org
  2. Przejdź do Ustawienia → Klucze API na swoim profilu
  3. Skopiuj swój klucz API
  4. Wprowadź nazwę użytkownika i klucz API w Ustawienia → Konto → RetroAchievements

Steam Web API

  1. Przejdź do steamcommunity.com/dev/apikey
  2. Zarejestruj się po klucz Steam Web API (wymaga konta Steam)
  3. Wprowadź swój klucz API i Steam ID (lub adres URL vanity) w Ustawieniach

Używane do importu biblioteki Steam i śledzenia osiągnięć.

Xbox Live

Uwierzytelnianie Xbox używa OAuth2 — klucz API nie jest potrzebny. Zaloguj się kontem Microsoft bezpośrednio z zakładki Import gier → Xbox. Tokeny są buforowane automatycznie i odświeżane w razie potrzeby.

PlayStation Network (PSN)

PSN używa uwierzytelniania przez ciasteczko NPSSO. Zobacz sekcję Trofea, aby poznać szczegółowe instrukcje konfiguracji.

Ustawienia

Ustawienia są zorganizowane w 6 zakładkach, każda z wieloma podsekcjami.

Zakładka Konto

  • Mój profil — przesyłanie/usuwanie awatara, nazwa wyświetlana, informacje o roli, zmiana hasła
  • RetroAchievements — nazwa użytkownika i klucz API do integracji z RA
  • PSN — ciasteczko NPSSO do synchronizacji trofeów PlayStation Network
  • Strefa czasowa — ustaw strefę czasową do wyświetlania dat w całej aplikacji
  • Użytkownicy — zarządzanie użytkownikami: dodawanie, edycja, usuwanie użytkowników i przypisywanie ról (tylko administrator)

Zakładka Biblioteka

  • Ścieżki — ścieżka biblioteki ROM-ów, lokalizacja bazy danych
  • Wyświetlanie — wybór motywu, styl okładki (2D/3D), preferowany system ocen wiekowych, liczba elementów na stronę
  • Nazewnictwo ROM-ów — umiejscowienie przedimka (wiodący/końcowy „The”), lista opcji regionów, domyślny region, konwencje nazewnictwa
  • Kopia zapasowa — tworzenie i przywracanie kopii zapasowych bazy danych

Zakładka Pobieranie metadanych

  • ES-DE — ścieżki list gier i multimediów ES-DE do importu danych lokalnych
  • Scraper — włączanie/wyłączanie poszczególnych scraperów, kolejność priorytetu metodą przeciągnij i upuść, ustawienia limitów zapytań dla każdego scrapera
  • Klucze API — wszystkie dane uwierzytelniające scraperów (TGDB, IGDB, RAWG, ScreenScraper), wybór dostawcy AI i modelu (Gemini, OpenAI, Claude)

Zakładka Dane

  • Statystyki — przegląd statystyk biblioteki (łączna liczba gier, systemów, wykorzystanie miejsca)
  • Trofea — konfiguracja ścieżki trofeów RPCS3 do lokalnego skanowania trofeów PS3
  • Listy rozwijane — dostosuj opcje regionów i inne wartości list rozwijanych używane w całej aplikacji
  • Normalizacja — reguły normalizacji gatunków i trybów — dodaj niestandardowe mapowania, aby ujednolicić dane wyjściowe scraperów

Zakładka Personalizacja

  • Powiadomienia — preferencje czasu wygaśnięcia powiadomień (sukces, informacja, ostrzeżenie, błąd — każde konfigurowalne niezależnie)
  • Kontrolery — zarządzaj biblioteką kontrolerów, ustaw domyślne kontrolery dla każdego systemu, dodaj niestandardowe kontrolery. Domyślne kontrolery nadpisują wartości pobrane/z AI podczas pobierania metadanych.
  • Logotypy — personalizacja logo systemów — importuj logotypy systemów lub odśwież domyślne

Zakładka System

  • Konserwacja — optymalizacja bazy danych (VACUUM/ANALYZE), czyszczenie osieroconych multimediów, czyszczenie brakujących ROM-ów, czyszczenie pobranych danych, czyszczenie importów CLZ, masowa standaryzacja obrazów
  • Serwer — konfiguracja serwera (host, port, tryb debugowania)
  • Rejestrowanie — ustawienia poziomu dziennika dla różnych kategorii
  • Rozwiązywanie problemów — czyszczenie zablokowanego masowego pobierania, czyszczenie kolejki synchronizacji RA, czyszczenie odświeżania PSN, czyszczenie generowania muzeum, restart serwera
Wskazówka: Wyłączone scrapery nie będą wywoływać ostrzeżeń „API offline” w Panelu głównym. Jeśli nie używasz jakiegoś scrapera, wyłącz go w Ustawienia → Pobieranie metadanych → Scraper, zamiast usuwać klucz API.

Pobieranie hybrydowe

RetroDB automatycznie łączy dane z wielu źródeł, aby zmaksymalizować pokrycie metadanych:

  • Metadane tekstowe z dostępnego źródła o najwyższym priorytecie
  • Obrazy i multimedia ze źródeł drugorzędnych, gdy główne źródło ich nie posiada
  • Automatyczne uzupełnianie luk między scraperami dla maksymalnego pokrycia
  • Tytuł sortowania jest generowany automatycznie z tytułu gry podczas pobierania

Obsługa multimediów

  • Pola multimediów (okładka, okładka 3D, zrzuty ekranu, fanart, wideo, instrukcja) nigdy nie są zastępowane podczas zwykłego pobierania — są uzupełniane tylko wtedy, gdy są puste
  • Zrzuty ekranu są zawsze dołączane, nigdy nie są zastępowane
  • Aby ponownie pobrać multimedia, najpierw wyczyść istniejący obraz w oknie edycji, a następnie pobierz ponownie
  • Tryb Pełne ponowne pobranie nadpisuje tę zasadę i zastępuje wszystko
  • Nieaktualne odniesienia do multimediów (plik usunięty, ale nazwa pliku wciąż w bazie danych) są automatycznie czyszczone przed pobieraniem, aby umożliwić pobranie świeżych multimediów
  • Pobrane obrazy są automatycznie standaryzowane do docelowych rozmiarów (zobacz Standaryzacja obrazów)

Priorytet scraperów

Skonfiguruj, które scrapery uruchamiają się jako pierwsze i które są włączone/wyłączone w Ustawienia → Pobieranie metadanych → Scraper. Przeciągnij i upuść, aby zmienić kolejność priorytetu. Wyłączone scrapery nie będą próbowane podczas pobierania i nie wywołają ostrzeżeń o statusie API w Panelu głównym.

Ograniczanie liczby żądań

Każdy scraper ma konfigurowalne limity żądań, aby zapobiec ograniczaniu przez API. Domyślne opóźnienia są ustawione zachowawczo. Zmniejszaj opóźnienia na własne ryzyko — przekroczenie limitów żądań API może skutkować tymczasową blokadą przez daną usługę.

Masowe pobieranie metadanych

Rozpoczynanie masowego pobierania

  1. Przejdź do dowolnej strony Systemu lub Biblioteki
  2. Kliknij „Wybierz”, aby przejść do trybu zaznaczania
  3. Zaznacz gry pojedynczo lub użyj szybkiego wyboru:
    • Zaznacz wszystkie — wszystkie widoczne gry
    • Zaznacz niepobrane — tylko gry bez metadanych
  4. Wybierz tryb: Uzupełnij brakujące lub Pełne ponowne pobranie
  5. Kliknij „Pobierz zaznaczone”

Sterowanie

  • Wstrzymaj / Wznów — wstrzymaj lub kontynuuj pobieranie
  • Anuluj — zatrzymaj całkowicie
  • W tle — zminimalizuj i kontynuuj przeglądanie, podczas gdy pobieranie działa

Powiadomienie toast

Podczas działania w tle trwałe powiadomienie toast pokazuje postęp na wszystkich stronach:

  • Nazwa bieżącej gry, licznik postępu i statystyki wyniku (sukces, niepowodzenie, pominięto)
  • Kontrolki wstrzymania/anulowania dostępne z każdej strony
  • Kliknij powiadomienie toast, aby wrócić do okna pobierania

System kolejki

Wiele masowych pobrań kolejkuje się automatycznie:

  • Rozpocznij nowe pobieranie, gdy inne już trwa — trafia do kolejki
  • Kolejka jest widoczna w powiadomieniu toast wraz z liczbą oczekujących zadań
  • Zadania przetwarzane są automatycznie w kolejności
  • Użyj Menedżera kolejki, aby przeglądać, zmieniać kolejność lub anulować zadania w kolejce

Opcje pobierania

  • Uzupełnij tylko brakujące — uzupełnia tylko puste pola metadanych, zachowując istniejące dane
  • Pełne ponowne pobranie — zastępuje wszystkie pola, w tym multimedia (pobiera nowe obrazy i filmy)
  • Sprawdź RetroAchievements — dodatkowo sprawdź zestawy osiągnięć RetroAchievements podczas pobierania

Odzyskiwanie zadań

Jeśli RetroDB zostanie zrestartowane podczas działania zadania, przerwane zadania pojawiają się w banerze odzyskiwania w Panelu głównym. Kliknij „Wznów” przy pojedynczych zadaniach lub „Wznów wszystkie”, aby je zrestartować. Powiadomienie toast z postępem pojawia się natychmiast po wznowieniu.

Uzupełnianie AI

Co to robi

Uzupełnianie AI używa dużego modelu językowego (Gemini, OpenAI lub Claude), aby inteligentnie uzupełnić brakujące lub niekompletne metadane gry. Jest sprytniejsze niż zwykłe pobieranie, ponieważ wykorzystuje wiedzę kontekstową o grze, aby dostarczyć dokładne dane, których scrapery mogą nie posiadać.

Jak używać

  1. Otwórz okno szczegółów gry (lub pełną stronę szczegółów)
  2. Kliknij „Uzupełnij AI” (wymaga skonfigurowanego klucza API AI w Ustawieniach)
  3. AI analizuje tytuł gry i system, a następnie uzupełnia brakujące pola
  4. Przejrzyj wyniki — zmiany są zapisywane automatycznie

Co może dostarczyć Uzupełnianie AI

  • Gatunek, opis, producenta, wydawcę, datę wydania
  • Liczbę graczy, tryby gry (jednoosobowy, wieloosobowy, kooperacja itd.)
  • Informacje o kampanii i strukturę gry
  • Wszystkie 8 systemów ocen wiekowych (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Region, serię, podobne gry
  • Obsługę kontrolerów, typ zapisu
  • Perspektywę (pierwszoosobowa, z góry, przewijana z boku itd.), wymiar (2D, 3D)
  • Informacje o edycji, oceny krytyków i użytkowników

Logika inteligentnego uzupełniania

  • Puste pola są zawsze uzupełniane
  • Istniejące dane użytkownika nigdy nie są nadpisywane
  • Podobne gry są zawsze odświeżane (dane AI są bardziej wiarygodne w tym polu)
  • Wzajemnie mapowane oceny — jeśli znany jest jeden system oceny, puste oceny w innych systemach są automatycznie uzupełniane za pomocą mapowania poziomów dojrzałości
  • Tytuł sortowania jest generowany automatycznie po uzupełnieniu
  • Pole Liczba graczy normalizuje zakresy (np. „1-4” staje się 4)

Normalizacja gatunków

Uzupełnianie AI używa kanonicznych form gatunków z nazwami łączonymi myślnikami:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Wymagania

W Ustawienia → Pobieranie metadanych → Klucze API musi być skonfigurowany co najmniej jeden klucz API dostawcy AI. Najtańszy poziom modelu (Gemini Flash Lite, GPT-4o Mini lub Claude Haiku) sprawdza się dobrze przy metadanych.

Filtrowanie i wyszukiwanie

Wyszukiwanie

Wyszukiwanie filtruje gry według tytułu (i tytułu sortowania). Naciśnij /, aby ustawić fokus na pole wyszukiwania. Wyniki aktualizują się w czasie rzeczywistym z opóźnieniem 300ms.

Filtr źródła

Filtruj gry według źródła importu:

  • Pliki ROM — gry z Twojej biblioteki ROM-ów
  • Importy CLZ — fizyczne gry zaimportowane z CLZ
  • Importy Steam — gry zaimportowane ze Steam
  • Importy Xbox — gry zaimportowane z Xbox
  • Importy PSN — gry zaimportowane z PlayStation Network

Przyciski filtrów

Każdy filtr otwiera okno modalne pokazujące wszystkie unikalne wartości w Twojej bibliotece wraz z liczbami. Filtry obsługują dwa tryby:

  • Uwzględnij (IS) — pokaż tylko gry pasujące do wybranej wartości
  • Wyklucz (IS NOT) — ukryj gry pasujące do wybranej wartości

Przełączaj między trybem uwzględniania a wykluczania za pomocą przełącznika w oknie filtra.

Opcje sortowania

  • Tytuł — alfabetycznie według tytułu sortowania (bez rozróżniania wielkości liter)
  • Data wydania — porządek chronologiczny (od najwcześniejszej)
  • Platforma — pogrupowane według nazwy systemu

Nawigacja alfabetyczna

Przeskocz do gier zaczynających się na daną literę. Litery bez pasujących gier są wyszarzone. Cyfry i symbole są grupowane pod #.

Nieskończone przewijanie

Gry ładują się w partiach po 100 podczas przewijania. Nowe strony ładują się automatycznie, gdy zbliżasz się do dołu. Zmiana filtrów lub wyszukiwania natychmiast resetuje i przeładowuje wyniki.

Zachowanie stanu

Twoje bieżące filtry, wyszukiwana fraza i pozycja przewijania są zapisywane w pamięci sesji. Są przywracane, gdy wrócisz na stronę lub ją odświeżysz.

Szczegóły gry

Okno szczegółów gry

Kliknięcie dowolnej karty gry otwiera okno szczegółów z buforowanym szybkim podglądem. Okno pokazuje:

  • Okładkę (2D i 3D), tło fanart
  • Opis i informacje o wydaniu
  • Odznaki producenta, wydawcy, gatunku
  • Liczbę graczy, tryby gry, strukturę gry
  • Obraz oceny wiekowej (z Twojego preferowanego systemu, z zapasowym mapowaniem krzyżowym)
  • Galerię zrzutów ekranu z nawigacją klawiaturą (← →)
  • Zwiastun wideo (jeśli dostępny)
  • Szacowany czas gry z HLTB (główny wątek, główny wątek + dodatki, ukończenie 100%)
  • Status i postęp RetroAchievements
  • Podobne gry (klikalne odnośniki)
  • Szczegóły obsługi kontrolerów
  • Tagi przypisane do gry
  • Rozmiar pliku i ścieżkę ROM-u

Pełna strona szczegółów gry

Kliknij odnośnik tytułu gry lub przejdź przez ścieżkę nawigacji, aby zobaczyć pełną stronę szczegółów gry. Dodatkowe funkcje na pełnej stronie obejmują:

  • Nagłówek z tłem fanart z nawigacją w postaci ścieżki
  • Odznaki importu platformy — pokazuje Import CLZ, Import Steam, Import Xbox lub Import PSN z logotypami platform, gdy ma to zastosowanie
  • Wskaźnik płyty bonusowej — pokazuje odznakę i odnośnik „Część:” do gry nadrzędnej z miniaturą
  • Przycisk usuwania — usuwa grę z bazy danych (z potwierdzeniem)
  • Przycisk czyszczenia — czyści wszystkie pobrane metadane, zachowując wpis ROM-u

Okno edycji

Kliknij Edytuj (lub naciśnij e), aby otworzyć okno edycji, zorganizowane w sekcje:

  • Tożsamość — tytuł, tytuł sortowania (generowany automatycznie, ale edytowalny), seria, edycja
  • Informacje o wydaniu — data wydania, region (z konfigurowalnej listy rozwijanej)
  • Rozgrywka — gatunek (tagi wielokrotnego wyboru), tryby, struktura gry, liczba graczy, producent, wydawca
  • Techniczne — kontrolery (wielokrotny wybór), typ zapisu, perspektywa (wiele wartości), wymiar (wiele wartości)
  • Oceny wiekowe — wszystkie 8 systemów ocen z oficjalnymi obrazami ocen i automatycznym mapowaniem krzyżowym. Zmiana jednej oceny automatycznie uzupełnia puste oceny w innych systemach.
  • Oceny — ocena krytyków, ocena użytkowników
  • Opis — tekst opisu gry
  • Niestandardowe obrazy — prześlij niestandardową okładkę (2D), okładkę 3D i fanart. Wyczyść istniejące obrazy, aby umożliwić ponowne pobieranie.
  • Wideo / zwiastun — prześlij lub połącz zwiastun wideo

Szybkie akcje

  • Edytuj — otwórz okno edycji (e)
  • Pobierz — pobierz metadane ze źródeł scraperów (s)
  • Uzupełnij AI — uzupełnij brakujące pola za pomocą AI (wymaga klucza API AI)
  • Sprawdź RA — wyszukaj zestaw osiągnięć RetroAchievements
  • Wyszukiwanie HLTB — znajdź szacowany czas gry z HowLongToBeat

Status ukończenia

Śledź swoje postępy za pomocą tych statusów (pokazywanych jako odznaki na kartach gier):

  • Nierozpoczęta — jeszcze nie graną
  • W trakcie — aktualnie grana
  • Grana — grana, ale nieukończona
  • Ukończona — ukończono grę główną
  • 100% — ukończono wszystko

Porównanie gier

Co to robi

Porównanie obok siebie metadanych dwóch gier w widoku tabelarycznym. Przydatne do sprawdzania jakości metadanych, wykrywania duplikatów lub porównywania wersji tej samej gry na różnych systemach.

Jak używać

  1. Przejdź do Porównania (dostępnego ze strony Biblioteki)
  2. Wyszukaj i wybierz pierwszą grę
  3. Wyszukaj i wybierz drugą grę
  4. Przejrzyj tabelę porównania — różnice są podświetlone

Porównywane pola

System, producent, wydawca, data wydania, gatunek, seria, region, liczba graczy, tryby, perspektywa, wymiar, wszystkie 8 ocen wiekowych, ocena użytkowników, ocena krytyków, szacowany czas gry, obsługa kontrolerów, typ zapisu, rozmiar pliku, podobne gry, opis i więcej.

Kolekcje (Tagi, Listy, Lista życzeń)

Tagi

Twórz niestandardowe, kolorowe tagi, aby organizować swoje gry. Tagi działają jak etykiety — każda gra może mieć wiele tagów, a każdy tag może zawierać wiele gier.

  • Twórz tagi z niestandardowymi nazwami i kolorami ze strony Tagi
  • Przypisuj tagi do gier za pomocą okna szczegółów gry
  • Kliknij dowolny tag, aby przeglądać wszystkie gry z tym tagiem
  • Edytuj lub usuwaj tagi ze strony zarządzania tagami

Nazwane listy

Twórz wyselekcjonowane listy gier z niestandardową kolejnością. Listy działają jak playlisty — kontrolujesz dokładną kolejność gier.

  • Twórz listy z nazwą, opisem i ikoną ze strony Listy
  • Dodawaj gry do list za pomocą okna szczegółów gry lub strony listy
  • Przeciągnij i upuść, aby zmienić kolejność gier w liście
  • Sortuj według niestandardowej kolejności lub alfabetycznie

Lista życzeń

Śledź gry, które chcesz zdobyć, fizyczne lub cyfrowe.

  • Dodawaj gry ręcznie z tytułem, systemem, notatkami i priorytetem (1–5)
  • Pozycje z listy życzeń mogą zostać powiązane z istniejącymi grami w bibliotece, jeśli zostaną znalezione
  • Sortowane według priorytetu (najwyższy pierwszy), a następnie daty dodania
Wskazówka: Używaj tagów do etykiet przekrojowych (np. „Ulubione”, „Kanapowa kooperacja”, „Do nadrobienia”), a list do konkretnych, wyselekcjonowanych kolekcji (np. „Top 10 gier SNES”, „Gry do streamowania”).

Import gier

Importuj kolekcje gier ze źródeł zewnętrznych. Dostęp przez Import gier na pasku bocznym. Wszystkie typy importu są zebrane na jednej stronie z zakładkami.

Import gier CLZ

Importuj swoją fizyczną kolekcję gier z CLZ Games.

  1. Wyeksportuj swoją kolekcję CLZ Games jako PDF
  2. Przejdź do Import gier → zakładka CLZ
  3. Prześlij plik PDF
  4. Przejrzyj przetworzone gry
  5. Wybierz, które gry zaimportować

Importy CLZ są śledzone osobno od gier ROM (przy użyciu przedrostka clz_import/), co pozwala katalogować zarówno kolekcje fizyczne, jak i cyfrowe. Importy CLZ można całkowicie wyczyścić z Ustawienia → System → Konserwacja.

Import Steam

Importuj swoją bibliotekę gier Steam i śledź osiągnięcia.

Trofea PS3 / PSN

Lokalne trofea RPCS3

Śledź trofea zdobyte w grach PS3 za pomocą emulatora RPCS3.

  1. Ustaw ścieżkę trofeów RPCS3 w Ustawienia → Dane → Trofea
  2. Kliknij „Skanuj trofea”, aby zaimportować zdobyte trofea
  3. Przeglądaj listy trofeów i szczegóły poszczególnych trofeów w sekcji Trofea RPCS3

RPCS3 odczytuje dane XML trofeów z Twojego katalogu użytkownika RPCS3 i automatycznie dopasowuje gry do Twojej biblioteki.

Trofea PSN API

Synchronizuj dane trofeów PlayStation Network ze swojego konta PSN.

  1. Uzyskaj swoje ciasteczko NPSSO (zobacz poniżej)
  2. Wprowadź je w Ustawienia → Konto → PSN
  3. Twoja biblioteka trofeów PSN jest pobierana przez API PlayStation
  4. Przeglądaj postęp trofeów dla każdej gry z liczbą zdobytych/łącznych
  5. Szczegóły poszczególnych trofeów obejmują opis, rzadkość i znaczniki czasu odblokowania

Uwierzytelnianie PSN (ciasteczko NPSSO)

PSN używa specjalnego ciasteczka uwierzytelniającego zwanego tokenem NPSSO. Aby je uzyskać:

  1. Otwórz przeglądarkę internetową i zaloguj się na store.playstation.com
  2. Po zalogowaniu przejdź do: https://ca.account.sony.com/api/v1/ssocookie
  3. Strona wyświetli JSON zawierający Twój token NPSSO
  4. Skopiuj wartość npsso i wklej ją w Ustawienia → Konto → PSN

Po uwierzytelnieniu RetroDB bezpiecznie buforuje tokeny dostępu we własnej bazie danych (per użytkownik) i odświeża je automatycznie — nie musisz wklejać NPSSO ponownie przy każdej synchronizacji. Sesja pozostaje ważna przez około dwa miesiące, a RetroDB odnawia ją teraz automatycznie w tle, więc przy normalnym użytkowaniu rzadko będziesz potrzebować nowego NPSSO.

Szczegóły trofeów

  • Typy trofeów: brązowe, srebrne, złote, platynowe
  • Ikony trofeów są pobierane i buforowane lokalnie
  • Procent ukończenia dla każdej gry
  • Znaczniki czasu odblokowania dla każdego zdobytego trofeum

Synchronizacja masowa

Synchronizuj wszystkie trofea gier PSN naraz za pomocą zadania w tle. Postęp jest pokazywany w powiadomieniu toast. Ograniczanie liczby żądań (2,5s między żądaniami) zapobiega ograniczaniu przez API PSN.

Muzeum

Czym jest

Interaktywna encyklopedia systemów gier zorganizowana według generacji. Poznaj historię, specyfikacje i godne uwagi gry dla każdej platformy w Twojej kolekcji.

Strona główna

Strona główna Muzeum pokazuje oś czasu systemów gier pogrupowanych według generacji (1.–9. generacja, konsole przenośne, automaty arcade, komputery). Każda karta systemu pokazuje obraz sprzętu i liczbę gier z Twojej biblioteki.

Strony szczegółów systemu

Kliknij dowolny system, aby zobaczyć jego stronę muzealną, która obejmuje:

  • Obraz sprzętu — zdjęcie konsoli/systemu
  • Specyfikacje techniczne — CPU, GPU, RAM, rozdzielczość, typ nośnika
  • Historia — narracja generowana przez AI o rozwoju, premierze i dziedzictwie systemu
  • Top 10 gier — najbardziej godne uwagi tytuły systemu (na podstawie ocen krytyków i sugestii AI)
  • Galeria kontrolerów — obrazy kontrolerów systemu z opisami

Generowanie treści przez AI

Treści Muzeum są generowane za pomocą AI (Gemini, OpenAI lub Claude). Możesz wygenerować treść dla:

  • Pojedynczego systemu — kliknij „Generuj” na stronie muzealnej dowolnego systemu
  • Generowania masowego — wygeneruj treść dla wszystkich systemów naraz ze strony głównej (działa jako zadanie w tle z postępem w powiadomieniu toast)

Obrazy kontrolerów

Obrazy kontrolerów można dodać za pomocą:

  • Wyszukiwania obrazów — wyszukaj zdjęcia kontrolerów za pomocą Bing Image Search. Wyniki są uszeregowane według trafności (nazwa kontrolera + producent + warianty systemu).
  • Ręcznego przesyłania — prześlij własne obrazy kontrolerów
  • Usuwania tła — automatycznie usuń tło za pomocą lokalnej AI (biblioteka rembg), aby uzyskać przezroczyste obrazy kontrolerów na dowolnym tle
  • Propagacji obrazów — gdy znaleziony zostanie obraz kontrolera, jest on automatycznie współdzielony z tym samym kontrolerem na innych systemach (kontrolery pokrewne)
  • Pobierania masowego — pobierz obrazy dla wszystkich kontrolerów w systemie naraz

Wszystkie obrazy kontrolerów są standaryzowane do docelowego rozmiaru i zapisywane w formacie WebP.

Wskazówka: Do generowania treści wymagany jest klucz API AI. Muzeum korzysta z tego samego dostawcy AI, który jest skonfigurowany w Ustawienia → Pobieranie metadanych → Klucze API.

Raporty ROM

Co to robi

Sprawdza nazwy plików ROM pod kątem standardowych konwencji nazewnictwa i identyfikuje potencjalne problemy. Dostęp przez Raporty ROM na pasku bocznym.

Typy raportów

ZakładkaCo sprawdza
Nazwy niestandardoweROM-y z nazwami plików, które nie pasują do konwencji nazewnictwa. Pokazuje bieżącą nazwę pliku, wykryte problemy i sugerowaną poprawioną nazwę.
Niezgodności nazwROM-y, w których nazwa pliku nie pasuje do pobranego tytułu metadanych. Pokazuje bieżącą nazwę pliku vs pobrany tytuł, region, rok i producenta.

Co jest sprawdzane

  • Nieprawidłowe znaki w nazwach plików (: ? * / " < > | \)
  • Brakujące lub nieprawidłowe tagi regionu (np. (USA), (Europe))
  • Brakujące tagi roku
  • Niezgodności nazwy pliku z tytułem w bazie danych

Raporty można sortować według systemu, nazwy pliku i typu problemu. Używaj ich, aby utrzymać bibliotekę ROM-ów zorganizowaną i spójnie nazwaną.

Narzędzia ROM

Uzyskaj dostęp do centrum Narzędzi ROM z paska bocznego. Każde narzędzie działa jako zadanie w tle z aktualizacjami postępu w czasie rzeczywistym, obsługą wstrzymania/wznowienia i rejestrowaniem.

Skaner archiwów

Rozpakuj archiwa ROM (ZIP, 7Z, RAR) z opcjami:

  • Rekurencyjnego skanowania podkatalogów
  • Usuwania niechcianych plików po rozpakowaniu
  • Automatycznego generowania list odtwarzania M3U dla gier wielopłytowych

Wymaga: 7z lub unzip

Konwerter CHD

Konwertuj obrazy płyt (ISO, BIN/CUE, GDI) do skompresowanego formatu CHD. Oszczędza znaczną ilość miejsca, zachowując pełną kompatybilność z emulatorami.

Wymaga: chdman (z mame-tools)

Weryfikacja CHD

Weryfikuj integralność plików CHD za pomocą walidacji hasza. Identyfikuje uszkodzone lub niekompletne konwersje.

Wymaga: chdman

Wyszukiwarka duplikatów

Znajdź zduplikowane ROM-y według hasza lub nazwy pliku, z opcjami priorytetyzacji według tagów regionu.

Brak zależności zewnętrznych

Organizator gier wielopłytowych

Organizuj gry wielopłytowe w podkatalogi i generuj listy odtwarzania M3U dla emulatorów, które je obsługują. Przydatne dla systemów takich jak PlayStation i Saturn.

Brak zależności zewnętrznych

Deduplikacja zrzutów ekranu

Znajdź i usuń zduplikowane zrzuty ekranu w bibliotece gier, aby zwolnić miejsce.

  • Dokładny hasz (MD5) — identyfikuje tylko identyczne pliki
  • Podobieństwo wizualne — porównanie hasza percepcyjnego z konfigurowalnym progiem (1–20, niższy = ściślejsze dopasowanie)

Skanuje stopniowo z na żywo aktualizowanymi statystykami pokazującymi liczbę przeskanowanych gier, liczbę duplikatów i miejsce możliwe do odzyskania. Wyniki są grupowane według gry i systemu. Możesz wybrać, który plik zachować w każdej grupie duplikatów, lub użyć „Wybierz największy”, aby automatycznie zachować wersję o najwyższej rozdzielczości.

Brak zależności zewnętrznych

Zmiana rozmiaru obrazów

Standaryzuj multimedia gier do spójnych docelowych rozmiarów. Zobacz Standaryzacja obrazów, aby poznać pełne szczegóły.

Brak zależności zewnętrznych (skalowanie AI oparte na Pythonie)

Uzupełnianie tytułów alternatywnych

Przeszukaj bibliotekę w poszukiwaniu gier, których pole tytuły alternatywne jest puste, i uzupełnij je z IGDB / TGDB / ScreenScraper. Przydatne po zaimportowaniu dużego katalogu lub migracji z innego narzędzia, które nie przechowywało tytułów regionalnych/japońskich/podtytułów. Działa w tle; postęp jest pokazany na karcie narzędzia.

Wymaga co najmniej jednego klucza API scrapera (IGDB / TGDB / ScreenScraper)

Masowe wyszukiwanie HLTB

Uruchom wyszukiwanie HowLongToBeat dla każdej gry bez szacowanego czasu gry. Każde dopasowanie jest oceniane według tytułu + platformy + roku wydania; dopasowania o wysokiej pewności są zapisywane automatycznie. Wszystko poniżej progu pewności (lub z niezgodnymi platformami) trafia do przeglądu przez człowieka.

Brak zależności zewnętrznych (używa dołączonego offline zbioru danych HLTB)

Oczekujący przegląd HLTB

Kolejka przeglądu dla niejednoznacznych dopasowań wykrytych przez Masowe wyszukiwanie HLTB. Każdy oczekujący wiersz pokazuje grę źródłową obok kandydata HLTB (tytuł, platforma, rok wydania, pewność). Zatwierdź, odrzuć lub wybierz inne dopasowanie dla każdego wiersza. Karta narzędzia przeglądu pojawia się w centrum Narzędzi ROM tylko wtedy, gdy istnieje co najmniej jedno oczekujące dopasowanie.

  • Zakładki filtrów dla dopasowań o niskiej pewności, alternatywnym tytule i niezgodności platformy.
  • Zatwierdź zapisuje szacowany czas gry; Odrzuć usuwa kandydata i utrzymuje kolejkę wyszukiwania w czystości.

Ustawienia narzędzi

Skonfiguruj ścieżki, lokalizacje narzędzi, typy archiwów i preferencje współdzielone przez wszystkie narzędzia ROM.

Wskazówka: Wszystkie narzędzia ROM obsługują wstrzymanie/wznowienie i działają w tle. Postęp i wyniki są rejestrowane i widoczne w Przeglądarce dzienników. Status narzędzia (dostępne vs wymaga instalacji) jest pokazany na każdej karcie narzędzia.

Normalizacja

Co to robi

Normalizuje wartości gatunku i trybu gry do spójnych form kanonicznych. Dzieje się to automatycznie podczas pobierania i Uzupełniania AI, a można to też zastosować ręcznie do istniejącej biblioteki.

Dlaczego to ważne

Różne scrapery używają różnych nazw dla tej samej rzeczy. Normalizacja zapewnia spójność w całej Twojej bibliotece:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Reguły niestandardowe

Możesz dodać niestandardowe reguły normalizacji w Ustawienia → Dane → Normalizacja. Reguły niestandardowe nadpisują wbudowane mapowania, pozwalając Ci zdefiniować własne preferowane nazwy gatunków i trybów. Reguły są przechowywane w bazie danych.

Podgląd i zastosowanie

Przed zastosowaniem normalizacji możesz zobaczyć podgląd, które gry zostaną dotknięte i jakie zmiany zostaną wprowadzone. Pozwala to na przegląd przed zatwierdzeniem zmian w bibliotece.

Standaryzacja obrazów

Co to robi

Standaryzuje wszystkie multimedia gier do spójnych docelowych rozmiarów, aby uzyskać jednolity wygląd w całej bibliotece. Obrazy w przedziale 80–120% docelowego rozmiaru są pomijane.

Jak to działa

  • Powiększanie — obrazy mniejsze niż docelowy rozmiar są powiększane za pomocą Real-ESRGAN x4 (super-rozdzielczość AI przez ONNX Runtime) w celu wysokiej jakości powiększenia, a następnie zmieniany jest ich rozmiar do dokładnego celu
  • Pomniejszanie — obrazy większe niż docelowy rozmiar są pomniejszane za pomocą filtrowania Lanczos dla ostrych wyników
  • Pasmo progowe — obrazy w przedziale 80–120% celu pozostają nietknięte, aby uniknąć niepotrzebnego przetwarzania

Jak uruchomić

  1. Przejdź do Ustawienia → System → Konserwacja lub Narzędzia ROM → Zmiana rozmiaru obrazów
  2. Kliknij „Start”, aby rozpocząć masową standaryzację
  3. Zadanie działa w tle z postępem w powiadomieniu toast pokazującym bieżący plik i statystyki
  4. Obrazy są też automatycznie standaryzowane podczas pobierania (nowe pobrania są standaryzowane natychmiast)

Obsługa sprzętu

Model Real-ESRGAN automatycznie wykrywa Twój sprzęt i używa najlepszego dostępnego dostawcy:

  • CUDA — przyspieszenie GPU NVIDIA
  • ROCm — przyspieszenie GPU AMD (z automatycznym nadpisaniem wersji gfx dla serii RX 6000)
  • CoreML — przyspieszenie Apple Silicon
  • CPU — tryb awaryjny dla systemów bez obsługi GPU

Plik modelu ONNX jest pobierany automatycznie z Hugging Face przy pierwszym użyciu i buforowany lokalnie.

Konserwacja

Operacje konserwacyjne są dostępne w Ustawienia → System → Konserwacja. Pomagają utrzymać bibliotekę czystą i zoptymalizowaną.

Skanowanie biblioteki

  • Skanuj bibliotekę — skanuj katalogi ROM-ów w poszukiwaniu nowych gier. Wykrywa foldery systemowe i obsługiwane typy plików za pomocą list rozszerzeń ES-DE systeminfo.txt. Dostępne też z Panelu głównego.

Operacje czyszczenia

  • Czyszczenie brakujących ROM-ów — usuwa wpisy w bazie danych dla gier, których pliki ROM już nie istnieją na dysku. Przydatne po zreorganizowaniu lub usunięciu plików ROM.
  • Czyszczenie osieroconych multimediów — znajduje i usuwa pliki obrazów na dysku (okładki, zrzuty ekranu, fanart), które nie mają odpowiadającego odniesienia w bazie danych. Podgląd przed usunięciem dla potwierdzenia.
  • Czyszczenie pobranych danych — usuwa wszystkie pobrane metadane z gier, zachowując wpisy plików ROM. Przydatne przy rozpoczynaniu pobierania od nowa. Podgląd pokazuje dotknięte gry przed wykonaniem.
  • Czyszczenie importów CLZ — usuwa wszystkie rekordy importu CLZ Games (wpisy zawierające tylko metadane, bez plików ROM).

Optymalizacja bazy danych

  • Optymalizuj bazę danych — uruchamia VACUUM i ANALYZE SQLite, aby odzyskać miejsce z usuniętych rekordów i zaktualizować statystyki planera zapytań. Zalecane po dużych usunięciach lub operacjach czyszczenia.

Masowa standaryzacja obrazów

Standaryzuj wszystkie obrazy gier do docelowych rozmiarów. Zobacz Standaryzacja obrazów po szczegóły.

Zarządzanie serwerem

  • Restart serwera — łagodny restart aplikacji (czyszczenie i zakończenie). Dostępne w Ustawienia → System → Rozwiązywanie problemów.

Kopia zapasowa i przywracanie

Tworzenie kopii zapasowych

  1. Przejdź do Ustawienia → Biblioteka → Kopia zapasowa
  2. Kliknij „Utwórz kopię zapasową”
  3. Kopia zapasowa jest zapisywana w folderze backups/ z nazwą pliku zawierającą znacznik czasu

Co jest zawarte w kopii zapasowej

Kopia zapasowa obejmuje całą bazę danych SQLite (roms.db), która zawiera wszystkie metadane gier, konta użytkowników, ustawienia, dane trofeów, postęp osiągnięć, tagi, listy i pozycje z listy życzeń.

Co NIE jest zawarte w kopii zapasowej

Pliki multimediów (okładki, zrzuty ekranu, fanart, filmy, instrukcje) NIE są zawarte w kopii zapasowej bazy danych, ponieważ można je pobrać ponownie przez pobieranie metadanych. Rozważ osobne wykonanie kopii zapasowej katalogu static/images/, jeśli masz niestandardowe przesłane pliki.

Przywracanie

  1. Znajdź kopię zapasową na liście kopii
  2. Kliknij „Przywróć”
  3. Potwierdź akcję
Ostrzeżenie: Przywrócenie kopii zapasowej nadpisuje bieżącą bazę danych. Utwórz świeżą kopię zapasową przed przywróceniem starszej!

Aktualizacja RetroDB

Jak aktualizować

  1. Pobierz nowe wydanie RetroDB
  2. Wykonaj kopię zapasową tych plików (zawierają Twoje dane osobiste):
    • config.py (Twoje ścieżki i klucze API)
    • data/settings.json (Twoje preferencje interfejsu)
    • data/scraper_settings.json (Twoja konfiguracja scraperów)
    • data/rom_tools_config.json (Twoje preferencje narzędzi ROM)
    • folder database/ (baza danych Twojej biblioteki gier oraz zapisane tokeny logowania PSN/Xbox)
  3. Rozpakuj nową wersję na istniejącą instalację
  4. Uruchom python install.py, aby zainstalować nowe zależności
  5. Zrestartuj serwer

Pliki bezpieczne do nadpisania

Wszystkie pliki kodu źródłowego (.py, .html, .css, .js) można bezpiecznie nadpisać. Instalator nie nadpisze Twoich osobistych plików konfiguracyjnych.

Pliki do zachowania

Nigdy nie usuwaj ani nie nadpisuj: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Migracje bazy danych

RetroDB automatycznie obsługuje zmiany schematu bazy danych przy uruchomieniu. Nowe kolumny i tabele są dodawane w razie potrzeby bez utraty danych. Nie musisz robić nic specjalnego — po prostu uruchom nową wersję, a baza danych zostanie zaktualizowana automatycznie.

Rozwiązywanie problemów

Typowe problemy

„Nie znaleziono rozszerzeń dla systemu”

Folder systemowy potrzebuje prawidłowego pliku ES-DE systeminfo.txt, który definiuje obsługiwane rozszerzenia plików ROM. Upewnij się, że struktura katalogu ROM-ów pasuje do standardów ES-DE.

„Połączenie z API nie powiodło się”

  • Sprawdź swoje połączenie internetowe
  • Zweryfikuj klucze API w Ustawienia → Pobieranie metadanych → Klucze API
  • Poczekaj, jeśli limit żądań został osiągnięty (niektóre API mają dzienne/godzinne limity)
  • Sprawdź, czy scraper jest włączony (wyłączone scrapery pokazują „Wyłączony” w statusie Panelu głównego)
  • Sprawdź Przeglądarkę dzienników w poszukiwaniu szczegółowych komunikatów błędów

„Masowe pobieranie zablokowane”

Przejdź do Ustawienia → System → Rozwiązywanie problemów → „Wyczyść zablokowane masowe pobieranie”. Resetuje to stan zadania bez wpływu na Twoje dane.

„Kolejka synchronizacji RA zablokowana”

Wyczyść kolejkę synchronizacji RetroAchievements z Ustawienia → System → Rozwiązywanie problemów.

„Synchronizacja PSN zablokowana”

Wyczyść zadanie odświeżania PSN z Ustawienia → System → Rozwiązywanie problemów.

„Generowanie Muzeum zablokowane”

Wyczyść zadanie generowania muzeum z Ustawienia → System → Rozwiązywanie problemów.

„Błędy bazy danych”

  1. Utwórz kopię zapasową, jeśli to możliwe (Ustawienia → Biblioteka → Kopia zapasowa)
  2. Spróbuj Ustawienia → System → Konserwacja → Optymalizuj bazę danych
  3. Sprawdź uprawnienia plików w katalogu database/
  4. Ostateczność: przywróć z kopii zapasowej lub usuń bazę danych i przeskanuj ponownie

„Obrazy nie zapisują się”

Sprawdź uprawnienia zapisu w katalogach multimediów: chmod -R 755 static/images/

„Strona wolna lub niereagująca”

  • Duże kolekcje mogą potrzebować czasu na załadowanie — nieskończone przewijanie ładuje w partiach po 100
  • Spróbuj odświeżyć stronę, aby wyczyścić zgromadzoną pamięć
  • Sprawdź konsolę przeglądarki pod kątem błędów JavaScript
  • Spróbuj przełączyć się na motyw z lżejszym efektem tła (np. Amber lub Elite)
  • Efekty tła automatycznie wykrywają sprzęt; słabsze urządzenia używają awaryjnego trybu CPU przy zmniejszonej liczbie klatek

Baner „Przerwane zadania” w Panelu głównym

Jeśli RetroDB zostanie zrestartowane podczas działania zadań, pojawiają się one w banerze odzyskiwania. Kliknij „Wznów” pojedynczo lub „Wznów wszystkie”, aby je zrestartować. Kliknij „Odrzuć” lub „Odrzuć wszystkie”, aby je usunąć.

„Uwierzytelnianie PSN nie powiodło się”

  • Tokeny NPSSO wygasają — wygeneruj nowy z ca.account.sony.com/api/v1/ssocookie
  • Upewnij się, że jesteś zalogowany na store.playstation.com przed odwiedzeniem adresu URL ciasteczka
  • RetroDB buforuje Twoją sesję PSN przez około dwa miesiące i teraz automatycznie odnawia ją w tle; jeśli mimo to wygaśnie, po prostu wklej nowy NPSSO w Ustawienia → Konto → PSN

„Uwierzytelnianie Xbox nie powiodło się”

  • Uwierzytelnij się ponownie, klikając „Zaloguj się” w zakładce Import gier → Xbox
  • Tokeny Xbox są buforowane w data/xbox_tokens.json i odświeżane automatycznie

„Błędy powiększania obrazów”

  • Model ONNX Real-ESRGAN jest pobierany przy pierwszym użyciu — upewnij się, że masz dostęp do internetu
  • Przyspieszenie GPU wymaga zgodnych sterowników (CUDA dla NVIDIA, ROCm dla AMD)
  • Jeśli GPU zawiedzie, system automatycznie przechodzi na przetwarzanie CPU

Wskazówki dotyczące wydajności

  • Aktualizuj przeglądarkę dla najlepszej wydajności
  • Zamknij inne karty przeglądarki podczas pracy z bardzo dużymi kolekcjami
  • Używaj filtrów systemu, aby zmniejszyć liczbę wyświetlanych gier naraz
  • Uruchamiaj Optymalizację bazy danych okresowo po dużych operacjach (pobieranie, czyszczenie, importy)
  • Efekty motywów tła automatycznie wykrywają sprzęt; słabsze urządzenia używają awaryjnego trybu CPU

Bezpieczeństwo i zastrzeżenia

Najlepsze praktyki bezpieczeństwa

  • Zmień domyślne hasło — domyślne hasło administratora (admin) powinno zostać zmienione natychmiast po pierwszym zalogowaniu. Używaj silnego hasła składającego się z co najmniej 8 znaków.
  • Używaj serwera proxy HTTPS — RetroDB samo w sobie nie zapewnia TLS/SSL. Umieść je za serwerem proxy (np. Nginx, Caddy, Traefik) z włączonym HTTPS, aby szyfrować ruch między klientami a serwerem.
  • Ogranicz dostęp sieciowy — unikaj wystawiania RetroDB bezpośrednio do publicznego internetu. Użyj VPN lub ogranicz dostęp do swojej sieci lokalnej. Jeśli potrzebny jest dostęp zdalny, użyj serwera proxy z uwierzytelnianiem.
  • Wykonuj regularne kopie zapasowe — użyj wbudowanej funkcji kopii zapasowej w Ustawieniach, aby tworzyć okresowe kopie zapasowe bazy danych. Przechowuj kopie zapasowe w innej lokalizacji niż aplikacja.
  • Aktualizuj RetroDB — regularnie sprawdzaj nowe wydania. Poprawki bezpieczeństwa i ulepszenia są zawarte w aktualizacjach.
  • Chroń swoje klucze API — klucze API są przechowywane w data/scraper_settings.json. Upewnij się, że ten plik nie jest publicznie dostępny. Nigdy nie udostępniaj swojego pliku config.py ani plików tokenów.

Wbudowane funkcje bezpieczeństwa

  • Haszowanie haseł — hasła administratora są haszowane za pomocą PBKDF2 (nigdy nie są przechowywane w postaci jawnego tekstu)
  • Ograniczanie prób logowania — ochrona przed atakami typu brute-force na punkcie końcowym logowania
  • Walidacja ścieżek — wszystkie operacje na plikach używają pomocników safe_path i safe_filename, aby zapobiec atakom przechodzenia katalogów
  • Zapytania parametryzowane — wszystkie zapytania do bazy danych używają instrukcji parametryzowanych, aby zapobiec wstrzykiwaniu SQL
  • Ochrona przed XSS — okna modalne używają bezpiecznej konstrukcji DOM; dane wejściowe użytkownika są odpowiednio przekształcane (escaping)
  • Ochrona przed bombami dekompresji obrazów — maksymalna liczba pikseli obrazu jest ograniczona, aby zapobiec wyczerpaniu pamięci przez złośliwe obrazy
