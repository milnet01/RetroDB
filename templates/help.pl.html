Instalacja

Wymagania systemowe

  • Python 3.12+ z pip
  • Przeglądarka internetowa (Chrome, Firefox, Safari, Edge)
  • System operacyjny: Linux, Windows 10/11 lub macOS

Szybka instalacja

  1. Rozpakuj plik ZIP RetroDB do wybranego katalogu
  2. Otwórz terminal/wiersz poleceń w tym katalogu
  3. Uruchom: python install.py
  4. Uruchom serwer:
    • Linux: ./start.sh
    • Windows: kliknij dwukrotnie start.bat
    • macOS: kliknij dwukrotnie start.command
  5. Otwórz http://localhost:5000 w przeglądarce

Instalator graficzny

W systemie Linux możesz też uruchomić ./setup.sh, aby uruchomić kreatora instalacji z interfejsem graficznym. Automatycznie sprawdza dostępność Pythona/pip/tkinter, a następnie przeprowadza Cię przez każdy krok konfiguracji z wizualnym dziennikiem postępu.

Co robi install.py

  • Sprawdza dostępność Pythona 3.12+ i pip
  • Instaluje zależności Pythona z pliku requirements.txt
  • Tworzy plik config.py na podstawie szablonu przykładowego
  • Tworzy wymagane katalogi (baza danych, dzienniki, foldery multimediów)
  • Buduje pakiety CSS i JS

Pierwsze kroki

Konfiguracja pierwszego uruchomienia

Przy pierwszym uruchomieniu RetroDB pokazuje kreatora konfiguracji, który przeprowadzi Cię przez:

  1. Konto administratora — utwórz nazwę użytkownika i hasło
  2. Ścieżkę biblioteki — ustaw katalog ROM-ów
  3. Integracja z ES-DE — opcjonalne połączenie list gier i multimediów ES-DE
  4. Klucze API — opcjonalne dodanie kluczy API scraperów

Po ukończeniu kreatora kliknij „Skanuj bibliotekę” w Panelu głównym, aby wykryć swoje ROM-y.

Szybki przewodnik po pracy

  1. Skanuj bibliotekę, aby zaimportować ROM-y
  2. Przeglądaj według systemu lub zobacz wszystkie gry w Bibliotece
  3. Pobieraj metadane pojedynczo lub użyj masowego pobierania
  4. Organizuj za pomocą tagów, list i listy życzeń
  5. Śledź swoje postępy dzięki statusowi ukończenia i osiągnięciom

Struktura biblioteki ROM-ów

RetroDB oczekuje, że Twoje ROM-y będą zorganizowane w folderach systemowych w ścieżce biblioteki:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA) (Disc 1).chd
    Final Fantasy VII (USA) (Disc 2).chd

Trzymaj pliki ROM bezpośrednio w folderze systemu. Pliki w podfolderach są pomijane, z wyjątkiem PS3.

Każdy folder systemowy powinien zawierać plik ES-DE systeminfo.txt, który definiuje obsługiwane rozszerzenia plików. RetroDB odczytuje go podczas skanowania, aby określić, które pliki są prawidłowymi ROM-ami dla danego systemu.

Wskazówka: Jeśli masz już dane pobrane przez ES-DE, RetroDB może je zaimportować! Skonfiguruj ścieżki ES-DE w Ustawieniach → Integracja ES-DE lub podczas kreatora konfiguracji.

Uwagi dotyczące platform

Linux

  • Testowane na Ubuntu, Fedorze, openSUSE i Arch Linux
  • Narzędzia ROM wymagają: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) lub odpowiednika dla Twojej dystrybucji
  • Jeśli systemowy Python nie pozwala instalować pakietów, instalator tworzy dla RetroDB własny folder Pythona (.venv) i nie zmienia systemowego Pythona
  • Obsługiwane przyspieszenie GPU ROCm dla kart AMD (skalowanie obrazów Real-ESRGAN)

Windows

  • Pobierz Pythona ze strony python.org (zaznacz „Add to PATH” podczas instalacji)
  • Narzędzia ROM: zainstaluj 7-Zip, WinRAR i MAME (dla chdman)
  • Użyj start.bat, aby uruchomić, lub uruchom python app.py z wiersza poleceń

macOS

  • Python 3 można zainstalować przez Homebrew: brew install python3
  • Narzędzia ROM: brew install p7zip unrar rom-tools
  • Kliknij dwukrotnie start.command w Finderze, aby uruchomić
  • Obsługiwane przyspieszenie CoreML dla Apple Silicon (skalowanie obrazów Real-ESRGAN)

Nawigacja

Wyszukiwanie wszędzie

Pole wyszukiwania pod Twoją nazwą na pasku bocznym jest na każdej stronie. Wpisz co najmniej dwie litery, aby zobaczyć pasujące konsole i do ośmiu pasujących gier. Sekcje paska bocznego

Główne

  • Panel główny — wynik kondycji kolekcji, przegląd statystyk, status API, ostatnio grane/dodane/pobrane gry, odzyskiwanie zadań
  • Biblioteka — wszystkie gry z nieskończonym przewijaniem, zaawansowanym filtrowaniem (uwzględnianie/wykluczanie), wyszukiwaniem i sortowaniem
  • Systemy — przeglądaj platformy z liczbą gier, obrazami systemów, specyfikacjami, filtrowaniem według typu i funkcji
  • Osiągnięcia — Jedna strona na wszystkie Twoje trofea i osiągnięcia, z osobną kartą dla RetroAchievements, RPCS3, PSN, Steam i Xbox. Otwiera się na ostatnio używanej karcie.
  • Analityka — wykresy i statystyki kolekcji w 12 zakładkach z opcjami eksportu

Moja kolekcja

  • Tagi — niestandardowe, kolorowe tagi gier
  • Listy — nazwane, wyselekcjonowane listy gier z kolejnością ustalaną metodą przeciągnij i upuść
  • Lista życzeń — śledź gry, które chcesz zdobyć, z poziomami priorytetu
  • Trofea kolekcjonera — kamienie milowe grywalizacji dla Twojej kolekcji

Narzędzia

  • Narzędzia ROM — skaner archiwów, konwerter/weryfikator CHD, wyszukiwarka duplikatów, organizator gier wielopłytowych, deduplikacja zrzutów ekranu, zmiana rozmiaru obrazów, Raporty ROM
  • Importy gier — import z CLZ, Steam, Xbox i PSN

Konfiguracja

  • Ustawienia — cała konfiguracja aplikacji, w zakładkach z podsekcjami
  • Przeglądarka dzienników — przeglądaj dzienniki aplikacji we wszystkich kategoriach

Informacje

  • Muzeum — interaktywna encyklopedia systemów gier z treścią generowaną przez AI
  • Pomoc — ta strona dokumentacji
  • Dziennik zmian — historia wersji

Motywy

RetroDB oferuje 7 motywów wizualnych, każdy z unikalną paletą kolorów i animowanym efektem tła. Zmień motyw w Ustawienia → Biblioteka → Wyświetlanie. Tło zatrzymuje się, gdy nie korzystasz z RetroDB: gdy jego okno nie jest na wierzchu albo po minucie bez użycia myszy i klawiatury. Aby zatrzymać je na tym komputerze, wyłącz Ruchome tło przy motywach.

Jak to działa

  • Motywy nadpisują zmienne kolorów CSS — wszystkie elementy interfejsu dostosowują się automatycznie
  • Efekty tła obejmują automatyczne wykrywanie poziomu sprzętu (wysoki/średni/niski) z przyspieszeniem GPU, gdy jest dostępne, i awaryjnym trybem CPU dla słabszych urządzeń
  • Efekty wstrzymują się, gdy karta nie jest widoczna, aby oszczędzać zasoby
  • Stan dymu Cyberpunk zachowuje się między nawigacjami stron dla płynnych przejść
  • Subtelna nakładka linii skanowania w stylu CRT dostosowuje się do palety kolorów każdego motywu
  • Twój motyw jest zapisywany na Twoim koncie, więc towarzyszy Ci w każdej przeglądarce, w której się zalogujesz

Ikony dostosowane do motywu

Ikony powiadomień, wskaźniki statusu zadań i ikony akcji automatycznie dostosowują się do bieżącego motywu. Na przykład ikona sukcesu może pokazywać zielony znacznik na Cyberpunk, ale inny symbol na Matrix, aby pasował do estetyki zieleni na czerni.

Status API

Pokazuje status połączenia wszystkich skonfigurowanych scraperów i API. Gdy skonfigurowane API jest niedostępne, pojawia się baner ostrzegawczy z odnośnikiem do Ustawień.

Odzyskiwanie zadań

Jeśli RetroDB zostanie zrestartowane podczas działania zadań w tle (masowe pobieranie, synchronizacja RA, zmiana rozmiaru obrazów itp.), przerwane zadania pojawiają się w banerze odzyskiwania. Opcje:

  • Wznów — uruchom ponownie pojedyncze przerwane zadanie
  • Wznów wszystko — uruchom ponownie wszystkie przerwane zadania
  • Odrzuć — usuń pojedyncze zadanie z listy odzyskiwania
  • Odrzuć wszystko — usuń wszystkie przerwane zadania

Przeglądarka systemów

Siatka systemów

Strona Systemy pokazuje wszystkie platformy w Twojej bibliotece jako karty w responsywnym układzie siatki typu masonry. Każda karta wyświetla:

  • Logo systemu (można dostosować w Ustawienia → Personalizacja → Logotypy)
  • Liczbę ROM-ów i liczbę niepobranych
  • Odznakę typu systemu — konsola, przenośna, komputer, automat arcade lub silnik
  • Odznaki funkcji — obsługa RetroAchievements, lokalne trofea (RPCS3)

Okno modalne specyfikacji systemu

Kliknij przycisk informacji na dowolnej karcie systemu, aby zobaczyć szczegółowe specyfikacje sprzętowe:

  • Obraz sprzętu (zdjęcie konsoli/systemu)
  • Producent i data wydania
  • CPU, GPU, RAM, VRAM
  • Rozdzielczość, głębia kolorów, chip dźwiękowy
  • Typ nośnika (kartridż, płyta itd.)

Filtrowanie i wyszukiwanie

  • Wyszukiwanie tekstowe — filtruj według nazwy systemu lub nazwy folderu
  • Filtr typu — konsola, przenośna, komputer, automat arcade, silnik
  • Filtr funkcji — obsługa RetroAchievements, lokalne trofea
  • Pasek wyników filtrowania pokazuje „X z Y systemów”
  • Filtry są zachowywane po przeładowaniu strony dzięki pamięci sesji

Lista gier dla poszczególnych systemów

Kliknij dowolną kartę systemu, aby zobaczyć jego gry. Lista gier danego systemu ma te same funkcje co pełna strona Biblioteki — nieskończone przewijanie, wyszukiwanie, wszystkie opcje filtrowania, zaznaczanie masowe i sortowanie. Nagłówek systemu pokazuje nazwę systemu, liczbę gier i odznakę typu systemu.

Przewodnik konfiguracji kluczy API

Klucze API są opcjonalne, ale umożliwiają bogatsze pobieranie metadanych i dodatkowe funkcje. Skonfiguruj je w Ustawienia → Pobieranie danych → Klucze API.

Scrapery metadanych

TheGamesDB

  1. Przejdź do api.thegamesdb.net/key.php
  2. Poproś o klucze API (darmowe, zatwierdzane ręcznie) — otrzymasz klucz Publiczny i Prywatny
  3. W Ustawienia → Pobieranie danych → Klucze API wpisz klucz publiczny w polu TheGamesDB — Klucz główny, a klucz prywatny w polu TheGamesDB — Klucz zapasowy
  4. Klucz główny jest używany najpierw; każde połączenie z internetem ma własny limit
  5. Klucz zapasowy jest używany, gdy klucz główny się wyczerpie; pozwala na około 6000 zapytań miesięcznie

IGDB (przez Twitch)

  1. Utwórz konto Twitch na twitch.tv
  2. Przejdź do dev.twitch.tv/console
  3. Zarejestruj nową aplikację (dowolna nazwa, dowolna kategoria, http://localhost jako przekierowanie OAuth)
  4. Skopiuj Client ID i wygeneruj Client Secret
  5. Wprowadź oba w Ustawienia → Klucze API → IGDB

RAWG.io

  1. Przejdź do rawg.io/apidocs
  2. Kliknij „Get API Key” i utwórz konto
  3. Skopiuj swój klucz API z panelu
  4. Wprowadź go w Ustawienia → Klucze API → RAWG

Darmowy poziom: 20 000 żądań/miesiąc

ScreenScraper

  1. Utwórz konto na screenscraper.fr
  2. Wprowadź nazwę użytkownika i hasło w Ustawienia → Klucze API → ScreenScraper

Uwaga: ScreenScraper ma dzienne limity żądań zależne od poziomu konta. Współtworzenie bazy danych zwiększa Twoje limity.

Osiągnięcia i trofea

RetroAchievements

  1. Utwórz konto na retroachievements.org
  2. Przejdź do Ustawienia → Klucze API na swoim profilu
  3. Skopiuj swój klucz API
  4. Wprowadź nazwę użytkownika i klucz API w Ustawienia → Konto → RetroAchievements

Steam Web API

  1. Przejdź do steamcommunity.com/dev/apikey
  2. Zarejestruj się po klucz Steam Web API (wymaga konta Steam)
  3. Wprowadź swój klucz API i Steam ID (lub adres URL vanity) w Ustawieniach

Używane do importu biblioteki Steam i śledzenia osiągnięć.

Xbox Live

Xbox łączy się z RetroDB przez OpenXBL, darmową usługę. Każdy używa własnego klucza: zaloguj się na xbl.io kontem Xbox, skopiuj swój klucz API i wklej go w Ustawienia → Konto → Mój profil → Xbox. Zapisz mój profil sprawdza klucz i pokazuje Twój gamertag. Darmowy klucz pozwala na 150 zapytań na godzinę.

PlayStation Network (PSN)

PSN używa uwierzytelniania przez ciasteczko NPSSO. Zobacz sekcję Trofea, aby poznać szczegółowe instrukcje konfiguracji.

Dostawcy AI (dla Uzupełniania AI i Muzeum)

Do generowania metadanych przez Uzupełnianie AI i treści Muzeum potrzebny jest jeden dostawca AI. Wybierz spośród:

Każdy dostawca oferuje kilka modeli. Ten oznaczony jako Zalecane sprawdza się dobrze przy metadanych i treściach muzeum; strona każdego dostawcy podaje aktualne ceny. Skonfiguruj preferowanego dostawcę i klucz API w Ustawienia → Pobieranie danych → Klucze API.

Ustawienia

Ustawienia są zorganizowane w zakładkach, każda z podsekcjami. Administratorzy widzą też zakładkę Emulatory, która otwiera własną stronę.

Każda osoba widzi tylko te ustawienia, które może zmienić jej rola. Przeglądający lub gracz widzi zakładkę Konto. Edytor widzi też Płyty bonusowe i Kontrolery. Wszystko inne jest dla administratorów.

Zakładka Konto

  • Mój profil — Twój awatar, Twój folder trofeów RPCS3 oraz Twoje własne konta RetroAchievements, PlayStation Network, Xbox i Steam. Twoja nazwa użytkownika i klucz API (web) RetroAchievements pokazują Twoje osiągnięcia; zalogowanie hasłem odblokowuje osiągnięcia podczas gry. Jeden przycisk Zapisz mój profil zapisuje całą kartę i sprawdza nowy token PlayStation lub nowy klucz Xbox. Zmień hasło prosi o nowe hasło dwa razy; musi mieć co najmniej 12 znaków.
  • Motyw i język — Twój motyw, Twój język i ruchome tło
  • Powiadomienia — Jak długo każdy rodzaj komunikatu zostaje na ekranie, tylko dla Ciebie
  • Strefa czasowa — ustaw strefę czasową do wyświetlania dat w całej aplikacji
  • Użytkownicy — zarządzanie użytkownikami: dodawanie, edycja, usuwanie użytkowników i przypisywanie ról (tylko administrator)

Zakładka Biblioteka

  • Ścieżki — Folder biblioteki ROM-ów, foldery gamelist i multimediów ES-DE oraz domowy folder trofeów RPCS3, z jednym przyciskiem Zapisz
  • Wyświetlanie — Styl okładki (2D/3D) i preferowany system klasyfikacji wiekowej, dla wszystkich
  • Nazewnictwo ROM-ów — umiejscowienie przedimka (wiodący/końcowy „The”), lista opcji regionów, domyślny region, konwencje nazewnictwa
  • Płyty bonusowe — Znajdź płyty bonusowe i połącz je z ich grami
  • Kopia zapasowa — tworzenie i przywracanie kopii zapasowych bazy danych

Zakładka Pobieranie metadanych

  • Scraper — Włączaj i wyłączaj scrapery oraz przeciągaj je w kolejności, w jakiej są próbowane. Filtrowanie dopasowań przy pobieraniu zbiorczym ustala, jak bardzo wynik musi pasować: Ścisłe przyjmuje tylko dokładne tytuły, Normalne (domyślne) bliski tytuł na właściwym systemie, a Luźne także tytuły częściowe. Ustawienie z wcześniejszej wersji pokazuje się jako Własne, dopóki nie wybierzesz innego.
  • Klucze API — Wszystkie dane dostępowe scraperów (TheGamesDB, IGDB, RAWG, ScreenScraper), wybór dostawcy AI i modelu (Gemini, OpenAI, Claude) oraz domowe klucze RetroAchievements i Steam. Własny klucz RetroAchievements danej osoby z Mój profil jest używany najpierw, a domowy tylko u kogoś, kto własnego nie ma. Domowy klucz Steam służy tylko administratorowi bez własnego klucza.

Zakładka Dane

  • Listy rozwijane — Dostosuj wartości oferowane na listach, takich jak gatunek, perspektywa i typ zapisu
  • Normalizacja — reguły normalizacji gatunków i trybów — dodaj niestandardowe mapowania, aby ujednolicić dane wyjściowe scraperów

Zakładka Personalizacja

  • Kontrolery — Otwórz Kontrolery prowadzi na stronę Kontrolery. Tam ustawiasz domyślne kontrolery każdego systemu, dodajesz własne i edytujesz bibliotekę kontrolerów. Domyślne kontrolery zastępują wartości pobrane/z AI podczas pobierania metadanych.
  • Logo — Odśwież logo systemów kopiuje nowe logo z Twojego folderu ES-DE, a potem pokazuje, które systemy nadal ich nie mają

Zakładka System

  • Konserwacja — Czyszczenie brakujących ROM-ów, usuwanie importów CLZ lub pobranych danych, usuwanie plików multimediów, których żadna gra nie używa, usuwanie powiązań z nieistniejącymi plikami multimediów, optymalizacja bazy danych i obliczanie rozmiarów plików
  • Aktualizacje — Sprawdź, pobierz i zainstaluj nową wersję
  • Serwer — Restart lub wyłączenie RetroDB, port, którego używa (adres zmienia się po restarcie) i miejsce jego bazy danych
  • Dziennik — Ustawienia poziomu dziennika dla różnych kategorii oraz pliki dziennika

Emulatory i granie

Administratorzy konfigurują emulatory w Ustawienia → Emulatory. Dodaj folder, w którym znajdują się Twoje emulatory, do Foldery emulatorów. RetroDB znajduje tam każdy emulator (AppImage, przenośny skrypt lub zainstalowany Flatpak) i łączy go z systemami, które uruchamia. Tabela przypisań pokazuje każdy system raz, z listą do wyboru jego emulatora, oraz to, czy ten emulator działa i czy pliki BIOS są na miejscu. RetroDB tylko odczytuje pliki BIOS; nigdy ich nie kopiuje ani nie pobiera.

Gry, których emulator działa, mają przycisk Graj na stronie gry, na kartach Biblioteki i na stronach systemów.

Nie masz jeszcze emulatora? Naciśnij Pobierz RetroArch w sekcji Graj w RetroDB na tej samej stronie. RetroDB pobiera oficjalny RetroArch z libretro, sprawdza pobrany plik i konfiguruje go jako RetroArch (RetroDB), z własnymi ustawieniami i zapisami, oddzielnie od RetroArch, którego już używasz. Następnie przy pierwszym graniu pobiera najlepszy rdzeń dla każdego systemu. W grze wielopłytowej Następny dysk działa bez żadnej konfiguracji. Gdy taka gra jest uruchomiona, a w systemach Windows i macOS gdy uruchomiona jest dowolna gra, RetroArch nasłuchuje poleceń RetroDB na porcie sieciowym.

W przypadku DuckStation, PCSX2 i RPCS3 RetroDB ustawia też dla każdej gry skalę rozdzielczości i proporcje obrazu, w osobnym pliku ustawień gry samego emulatora, oraz to, czy gra uruchamia się na pełnym ekranie. Wartości dla całego systemu zmienisz przyciskiem Ustawienia w tabeli przypisań, a dla jednej gry w panelu Ustawienia emulatora na jej stronie. Są zapisywane po naciśnięciu Graj. Ustawienie zmienione w samym emulatorze zawsze ma pierwszeństwo: RetroDB od tej pory go nie rusza. Uruchom każdy emulator raz przed graniem, aby utworzył swój folder ustawień.

Kody

W sekcji Kody na tej samej stronie naciśnij Pobierz, aby ściągnąć darmowe, publiczne paczki kodów, albo zaimportuj folder z kodami, który już masz. RetroDB kopiuje pliki i nigdy nie zmienia Twojego folderu; zaimportuj ponownie, aby dodać nowe pliki. Strona gry pokazuje wtedy panel Kody dla gier uruchamianych w RetroArch (RetroDB), DuckStation lub PCSX2, z przełącznikiem wł./wył. dla każdego kodu. W RetroArch (RetroDB) włączone kody zadziałają, gdy następnym razem naciśniesz Graj, a przełącznik zmieniony w trakcie gry we własnym menu RetroArch zostaje zachowany. W DuckStation i PCSX2 przełączniki są zapisywane bezpośrednio w ustawieniach emulatora dla tej gry, więc zmiana wprowadzona w samym emulatorze też pojawia się w panelu. RetroDB nigdy nie nadpisuje pliku kodów, który emulator już ma. Włączony kod wstrzymuje tryb hardcore RetroAchievements; DuckStation i PCSX2 pomijają kody w trybie hardcore.

Dla gier arcade uruchamianych w MAME pobierz w przeglądarce „MAME XML Cheats Collection” z mamecheat.co.uk, a potem zaimportuj folder, w którym się znajduje. RetroDB zostawia ją spakowaną, jak prosi o to jej plik readme, i raz odczytuje z niej nazwy kodów każdej gry, pobierając w tym celu z internetu narzędzie 7-Zip. Strona gry pokazuje wtedy kody tej gry, z przełącznikiem przy każdym zwykłym kodzie włącz/wyłącz, a MAME uruchamia się z włączonymi kodami. Kod, który przyjmuje wartość albo działa tylko raz, nie ma przełącznika: ustaw go podczas gry, naciskając Tab, potem Plugin Options, potem Cheat. Przełączniki zmienione w ten sposób pojawią się na stronie gry po zamknięciu MAME. Zaimportowanie nowszej kolekcji zastępuje starą.

Gry arcade z RetroAchievements uruchamiają się w RetroArch (RetroDB) z rdzeniem FinalBurn Neo, bo RetroAchievements nie obsługuje MAME; pozostałe zostają w MAME. Naciśnij Pobierz przy Kody arcade FinalBurn Neo na tej samej stronie, a strona każdej takiej gry pokaże jej kody. FinalBurn Neo wyłącza wszystkie kody przy każdym starcie gry, więc lista nie ma przełączników: podczas gry naciśnij F1, aby otworzyć menu RetroArch, potem wybierz Core Options, potem Cheat. Gdy gra działa, RetroDB kładzie swój plik z kodami w folderze systemowym RetroArch, chyba że jest tam już plik o takiej nazwie, i usuwa go, gdy gra się kończy. Aby zagrać w jedną z tych gier w MAME, wybierz MAME w Uruchom, Zastąpienie emulatora, w jej oknie edycji.

Pobieranie metadanych

Pobieranie dla pojedynczej gry

  1. Otwórz okno szczegółów dowolnej gry (kliknij kartę gry)
  2. Kliknij „Pobierz dane”
  3. W razie potrzeby zmodyfikuj tytuł wyszukiwania
  4. Wybierz właściwy wynik spośród dopasowań
  5. Kliknij „Zastosuj”

Pobieranie hybrydowe

RetroDB automatycznie łączy dane z wielu źródeł, aby zmaksymalizować pokrycie metadanych:

  • Metadane tekstowe z dostępnego źródła o najwyższym priorytecie
  • Obrazy i multimedia ze źródeł drugorzędnych, gdy główne źródło ich nie posiada
  • Automatyczne uzupełnianie luk między scraperami dla maksymalnego pokrycia
  • Tytuł sortowania jest generowany automatycznie z tytułu gry podczas pobierania
  • Źródło jest przeszukiwane tylko wtedy, gdy obsługuje system gry, i tylko w tym systemie: RAWG nie ma Intellivision, więc gry na Intellivision nie są wyszukiwane w RAWG, gdzie pasowałyby tylko do gier z innych platform
  • Gdy AI jest włączona, podaje też oficjalny tytuł gry wydanej w regionie jej ROM-u, a gra otrzymuje tę nazwę, zarówno przy pobieraniu danych jednej gry, jak i przy masowym pobieraniu (zobacz Uzupełnianie AI)

Obsługa multimediów

  • Pola multimediów (okładka, okładka 3D, tył pudełka, zrzuty ekranu, fanart, logo, wideo, instrukcja) nigdy nie są zastępowane podczas zwykłego pobierania — są uzupełniane tylko wtedy, gdy są puste
  • Zrzuty ekranu są zawsze dołączane, nigdy nie są zastępowane
  • Aby ponownie pobrać multimedia, najpierw wyczyść istniejący obraz w oknie edycji, a następnie pobierz ponownie
  • Tryb Pełne ponowne pobranie nadpisuje tę zasadę i zastępuje wszystko
  • Nieaktualne odniesienia do multimediów (plik usunięty, ale nazwa pliku wciąż w bazie danych) są automatycznie czyszczone przed pobieraniem, aby umożliwić pobranie świeżych multimediów
  • Pobrane obrazy są automatycznie standaryzowane do docelowych rozmiarów (zobacz Standaryzacja obrazów)

Zachowanie tytułu

Gdy wpiszesz nowy tytuł w oknie edycji i zapiszesz, pobieranie danych już go nie zmienia, także Pełne ponowne pobranie. Pole Zachowaj ten tytuł przy pobieraniu danych w oknie edycji pokazuje, czy tytuł jest zachowany; odznacz je, aby scrapery znów mogły zmienić nazwę gry. Resetuj na stronie gry również pozwala scraperom znów zmienić jej nazwę, a Wyczyść pobrane dane w sekcji Konserwacja pozostawia zachowane tytuły bez zmian.

Priorytet scraperów

Skonfiguruj, które scrapery uruchamiają się jako pierwsze i które są włączone/wyłączone w Ustawienia → Pobieranie danych → Scraper. Przeciągnij i upuść, aby zmienić kolejność priorytetu. Wyłączone scrapery nie będą próbowane podczas pobierania i nie wywołają ostrzeżeń o statusie API w Panelu głównym.

Ograniczanie liczby żądań

RetroDB samo rozkłada w czasie swoje żądania do każdej usługi; nie ma nic do ustawienia. Gdy usługa zgłasza, że osiągnięto jej limit, RetroDB przestaje ją pytać do czasu, który ona poda, i mówi o tym (patrz Rozwiązywanie problemów).

Masowe pobieranie danych

Rozpoczynanie masowego pobierania

  1. Przejdź do dowolnej strony Systemu lub Biblioteki
  2. Kliknij „Wybierz”, aby przejść do trybu zaznaczania. Narzędzia zaznaczania pojawiają się na pasku u dołu okna.
  3. Zaznacz gry pojedynczo lub użyj szybkiego wyboru:
    • Zaznacz wszystko — wszystkie widoczne gry
    • Zaznacz bez pobranych danych — tylko gry bez metadanych
  4. Wybierz tryb: Uzupełnij braki lub Pełne ponowne pobranie
  5. Kliknij „Pobierz dane dla zaznaczonych”
  6. Kliknij „Gotowe”, aby wyjść z trybu zaznaczania

Sterowanie

  • Wstrzymaj / Wznów — wstrzymaj lub kontynuuj pobieranie
  • Anuluj — zatrzymaj całkowicie
  • Tło — zminimalizuj i kontynuuj przeglądanie, podczas gdy pobieranie działa

Powiadomienie toast

Podczas działania w tle trwałe powiadomienie toast pokazuje postęp na wszystkich stronach:

  • Nazwa bieżącej gry, licznik postępu i statystyki wyniku (sukces, niepowodzenie, pominięto)
  • Kontrolki wstrzymania/anulowania dostępne z każdej strony
  • Kliknij powiadomienie toast, aby wrócić do okna pobierania

System kolejki

Wiele masowych pobrań kolejkuje się automatycznie:

  • Rozpocznij nowe pobieranie, gdy inne już trwa — trafia do kolejki
  • Kolejka jest widoczna w powiadomieniu toast wraz z liczbą oczekujących zadań
  • Zadania przetwarzane są automatycznie w kolejności
  • Użyj Menedżera kolejki, aby przeglądać, zmieniać kolejność lub anulować zadania w kolejce

Opcje pobierania

  • Uzupełnij tylko brakujące — uzupełnia tylko puste pola metadanych, zachowując istniejące dane
  • Pełne ponowne pobranie — zastępuje wszystkie pola, w tym multimedia (pobiera nowe obrazy i filmy)
  • Zachowaj istniejące multimedia — Przy pełnym ponownym pobraniu zachowaj grafiki, filmy i instrukcje już zapisane na dysku zamiast pobierać je ponownie. Nowe zrzuty ekranu są nadal dodawane.
  • Sprawdź RetroAchievements — dodatkowo sprawdź zestawy osiągnięć RetroAchievements podczas pobierania

Odzyskiwanie zadań

Jeśli RetroDB zostanie zrestartowane podczas działania zadania, przerwane zadania pojawiają się w banerze odzyskiwania w Panelu głównym. Kliknij „Wznów” przy pojedynczych zadaniach lub „Wznów wszystko”, aby je zrestartować. Powiadomienie toast z postępem pojawia się natychmiast po wznowieniu.

Uzupełnianie AI

Co to robi

Uzupełnianie AI używa dużego modelu językowego (Gemini, OpenAI lub Claude), aby inteligentnie uzupełnić brakujące lub niekompletne metadane gry. Jest sprytniejsze niż zwykłe pobieranie, ponieważ wykorzystuje wiedzę kontekstową o grze, aby dostarczyć dokładne dane, których scrapery mogą nie posiadać.

Jak używać

  1. Otwórz okno szczegółów gry (lub pełną stronę szczegółów)
  2. Kliknij „Uzupełnianie AI” (wymaga skonfigurowanego klucza API AI w Ustawieniach)
  3. AI analizuje tytuł gry i system, a następnie uzupełnia brakujące pola
  4. Przejrzyj wyniki — zmiany są zapisywane automatycznie

Wiele gier naraz

Aby uzupełnić cały system, otwórz Narzędzia ROM → Masowe uzupełnianie AI i użyj karty Uzupełnij puste pola przez AI. Włącz pola, które chcesz uzupełnić; liczone są tylko gry, w których któreś z nich jest puste, a mniej pól kosztuje mniej. Wybierz system lub Wszystkie systemy i naciśnij Uzupełnij przez AI. Uruchamia to Uzupełnianie AI dla każdej gry i zapisuje odpowiedzi od razu w grze. Pasek postępu na karcie i powiadomienie Uzupełniania AI pokazują, jak daleko zaszło, a podczas działania możesz opuścić stronę. Gry, które przeszły już Uzupełnianie AI, są pomijane, więc drugi przebieg robi tylko resztę; włącz Uwzględnij gry, które Uzupełnianie AI już przetworzyło, aby uzupełnić w nich także pole, na przykład sprzedane egzemplarze. Przebieg sam się zatrzymuje, gdy AI przestaje odpowiadać, na przykład gdy klucz zostanie odrzucony albo konto nie ma środków. Dostawca AI pobiera opłatę za każdą grę.

Co może dostarczyć Uzupełnianie AI

  • Gatunek, opis, producenta, wydawcę, datę wydania
  • Liczbę graczy, tryby gry (jednoosobowy, wieloosobowy, kooperacja itd.)
  • Informacje o kampanii i strukturę gry
  • Wszystkie systemy ocen wiekowych (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd, CADPA)
  • Region, serię, podobne gry
  • Obsługę kontrolerów, typ zapisu
  • Perspektywę (pierwszoosobowa, z góry, przewijana z boku itd.), wymiar (2D, 3D)
  • Informacje o edycji, oceny krytyków i użytkowników

Logika inteligentnego uzupełniania

  • Puste pola są zawsze uzupełniane
  • Istniejące dane użytkownika nigdy nie są nadpisywane
  • Podobne gry są zawsze odświeżane (dane AI są bardziej wiarygodne w tym polu)
  • Wzajemnie mapowane oceny — jeśli znany jest jeden system oceny, puste oceny w innych systemach są automatycznie uzupełniane za pomocą mapowania poziomów dojrzałości
  • Tytuł sortowania jest generowany automatycznie po uzupełnieniu
  • Oficjalny tytuł — AI podaje też oficjalny tytuł gry wydanej w regionie jej ROM-u, a gra otrzymuje tę nazwę, w Uzupełnianiu AI i za każdym razem, gdy AI uzupełnia luki podczas pobierania danych. Stara nazwa zostaje zachowana jako tytuł alternatywny. Tytuł wpisany przez Ciebie lub zachowany opcją Zachowaj ten tytuł przy pobieraniu danych nigdy nie jest zmieniany
  • Pole Gracze normalizuje zakresy (np. „1-4” staje się 4)

Normalizacja gatunków

Uzupełnianie AI używa kanonicznych form gatunków z nazwami łączonymi myślnikami:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Wymagania

W Ustawienia → Pobieranie danych → Klucze API musi być skonfigurowany co najmniej jeden klucz API dostawcy AI. Najtańszy poziom modelu (Gemini Flash Lite, GPT-4o Mini lub Claude Haiku) sprawdza się dobrze przy metadanych.

Filtrowanie i wyszukiwanie

Szukaj

Wyszukiwanie filtruje gry według tytułu (i tytułu sortowania). Naciśnij /, aby ustawić fokus na pole wyszukiwania. Wyniki aktualizują się w czasie rzeczywistym z opóźnieniem 300ms.

Filtr źródła

Filtruj gry według źródła importu:

  • Pliki ROM — gry z Twojej biblioteki ROM-ów
  • Importy CLZ — fizyczne gry zaimportowane z CLZ
  • Importy Steam — gry zaimportowane ze Steam
  • Importy Xbox — gry zaimportowane z Xbox
  • Importy PSN — gry zaimportowane z PlayStation Network

Przyciski filtrów

Każdy filtr otwiera okno modalne pokazujące wszystkie unikalne wartości w Twojej bibliotece wraz z liczbami. Filtry obsługują dwa tryby:

  • Uwzględnij (IS) — pokaż tylko gry pasujące do wybranej wartości
  • Wyklucz (IS NOT) — ukryj gry pasujące do wybranej wartości

Przełączaj między trybem uwzględniania a wykluczania za pomocą przełącznika w oknie filtra.

W filtrach Gatunek, Seria, Wydawca, Deweloper, Tryb gry, Perspektywa i Wymiar zaznacz dowolną liczbę wartości i naciśnij Zastosuj. Gra jest widoczna, jeśli ma którąkolwiek z zaznaczonych wartości; w trybie wykluczania gra jest ukryta, jeśli ma którąkolwiek z nich. Każda wartość dostaje własny znacznik nad grami, a jego × usuwa tylko tę wartość. Filtry Ocena i Źródło przyjmują jedną wartość i działają, gdy tylko ją klikniesz.

Opcje sortowania

Wybierz kolejność z listy Sortuj według, obok liczby gier:

  • Nazwa — alfabetycznie według tytułu sortowania (bez rozróżniania wielkości liter)

  • Ostatnio dodane — najpierw gry dodane do biblioteki jako ostatnie

Nawigacja alfabetyczna

Przeskocz do gier zaczynających się na daną literę. Litery bez pasujących gier są wyszarzone. Cyfry i symbole są grupowane pod #.

Nieskończone przewijanie

Gry ładują się w partiach po 100 podczas przewijania. Nowe strony ładują się automatycznie, gdy zbliżasz się do dołu. Zmiana filtrów lub wyszukiwania natychmiast resetuje i przeładowuje wyniki.

Zachowanie stanu

Twoje bieżące filtry, wyszukiwana fraza i pozycja przewijania są zapisywane w pamięci sesji. Są przywracane, gdy wrócisz na stronę lub ją odświeżysz.

Szczegóły gry

Okno szczegółów gry

Kliknięcie dowolnej karty gry otwiera okno szczegółów z buforowanym szybkim podglądem. Okno pokazuje:

Pełna strona szczegółów gry

Kliknij odnośnik tytułu gry lub przejdź przez ścieżkę nawigacji, aby zobaczyć pełną stronę szczegółów gry. Dodatkowe funkcje na pełnej stronie obejmują:

  • Nagłówek z tłem fanart z nawigacją w postaci ścieżki
  • Logo gry — logo gry jest widoczne nad jej tytułem, który pozostaje tekstem. Gra bez okładki pokazuje logo w miejscu pudełka. Pobieranie danych uzupełnia loga z ES-DE, ScreenScraper, TheGamesDB, IGDB i Steam; masowe pobieranie z opcją Uzupełnij braki uzupełnia je dla gier pobranych wcześniej
  • Tył pudełka — gdy gra ma tył pudełka, na okładce jest przycisk Tył. Naciśnij go, aby zobaczyć tył, i naciśnij Przód, aby wrócić. Kliknij tył, aby go powiększyć. Pobieranie danych uzupełnia tyły z ES-DE, ScreenScraper i TheGamesDB za każdym razem, gdy pobierane są dane gry
  • Odznaki importu platformy — pokazuje Import CLZ, Import Steam, Import Xbox lub Import PSN z logotypami platform, gdy ma to zastosowanie
  • Wskaźnik płyty bonusowej — pokazuje odznakę i odnośnik „Część:” do gry nadrzędnej z miniaturą
  • Przycisk usuwania — usuwa grę z bazy danych (z potwierdzeniem)
  • Przycisk czyszczenia — czyści wszystkie pobrane metadane, zachowując wpis ROM-u

Okno edycji

Kliknij Edytuj (lub naciśnij e), aby otworzyć okno edycji, zorganizowane w sekcje:

  • Tożsamość — tytuł, tytuł sortowania (generowany automatycznie, ale edytowalny), seria, edycja
  • Informacje o wydaniu — data wydania, region (z konfigurowalnej listy rozwijanej)
  • Rozgrywka — gatunek (tagi wielokrotnego wyboru), tryby, struktura gry, liczba graczy, producent, wydawca
  • Techniczne — kontrolery (wielokrotny wybór), typ zapisu, perspektywa (wiele wartości), wymiar (wiele wartości)
  • Oceny wiekowe — wszystkie systemy ocen z oficjalnymi obrazami ocen i automatycznym mapowaniem krzyżowym. Zmiana jednej oceny automatycznie uzupełnia puste oceny w innych systemach.
  • Oceny — ocena krytyków, ocena użytkowników
  • Opis — tekst opisu gry
  • Własne obrazy — prześlij niestandardową okładkę (2D), okładkę 3D, tył pudełka, fanart i logo. Wyczyść istniejące obrazy, aby umożliwić ponowne pobieranie.
  • Importuj pudełko 3D — również w sekcji Własne obrazy. Zapisuje się od razu, bez Zapisz zmiany. Wybierz plik .box.json zapisany przez Slipcase razem z jego obrazami (można wybrać cały folder). Slipcase 1.4.0 lub nowszy zapisuje ten plik obok każdego wyeksportowanego obrazu. RetroDB zachowuje ścianki pudełka dla tej gry; kliknięcie okładki pokazuje wtedy pudełko w 3D, które można przeciągać lub obracać klawiszami strzałek. Twoja okładka 3D się nie zmienia. Gdy gra ma już ścianki, RetroDB zapyta przed ich zastąpieniem, a Usuń je kasuje.
  • Wideo / zwiastun — prześlij lub połącz zwiastun wideo

Szybkie akcje

  • Pobierz dane — pobierz metadane ze źródeł scraperów (s)

Kolekcje (Tagi, Listy, Lista życzeń)

Tagi

Twórz niestandardowe, kolorowe tagi, aby organizować swoje gry. Tagi działają jak etykiety — każda gra może mieć wiele tagów, a każdy tag może zawierać wiele gier.

  • Twórz tagi z niestandardowymi nazwami i kolorami ze strony Tagi
  • Przypisuj tagi do gier za pomocą okna szczegółów gry
  • Kliknij dowolny tag, aby przeglądać wszystkie gry z tym tagiem
  • Edytuj lub usuwaj tagi ze strony zarządzania tagami

Nazwane listy

Twórz wyselekcjonowane listy gier z niestandardową kolejnością. Listy działają jak playlisty — kontrolujesz dokładną kolejność gier.

  • Twórz listy z nazwą, opisem i ikoną ze strony Listy
  • Dodawaj gry do list za pomocą okna szczegółów gry lub strony listy
  • Przeciągnij i upuść, aby zmienić kolejność gier w liście
  • Sortuj według niestandardowej kolejności lub alfabetycznie

Lista życzeń

Śledź gry, które chcesz zdobyć, fizyczne lub cyfrowe.

  • Dodawaj gry ręcznie z tytułem, systemem, notatkami i priorytetem (1–5)
  • Pozycje z listy życzeń mogą zostać powiązane z istniejącymi grami w bibliotece, jeśli zostaną znalezione
  • Sortowane według priorytetu (najwyższy pierwszy), a następnie daty dodania
Wskazówka: Używaj tagów do etykiet przekrojowych (np. „Ulubione”, „Kanapowa kooperacja”, „Do nadrobienia”), a list do konkretnych, wyselekcjonowanych kolekcji (np. „Top 10 gier SNES”, „Gry do streamowania”).

Importy gier

Importuj kolekcje gier ze źródeł zewnętrznych. Dostęp przez Importy gier na pasku bocznym. Wszystkie typy importu są zebrane na jednej stronie z zakładkami.

Import gier CLZ

Importuj swoją fizyczną kolekcję gier z CLZ Games.

  1. Wyeksportuj swoją kolekcję CLZ Games jako PDF
  2. Przejdź do Importy gier → zakładka CLZ
  3. Prześlij plik PDF
  4. Przejrzyj przetworzone gry
  5. Wybierz, które gry zaimportować

Importy CLZ są śledzone osobno od gier ROM (przy użyciu przedrostka clz_import/), co pozwala katalogować zarówno kolekcje fizyczne, jak i cyfrowe. Importy CLZ można całkowicie wyczyścić z Ustawienia → System → Konserwacja.

Import Steam

Importuj swoją bibliotekę gier Steam i śledź osiągnięcia.

  1. Skonfiguruj swój klucz Steam Web API i Steam ID w Ustawieniach
  2. Przejdź do Importy gier → zakładka Steam
  3. Kliknij „Pobierz bibliotekę”, aby pobrać swoje gry ze Steam
  4. Wybierz gry do zaimportowania Gra, która jest już na Twojej liście Windows pod tą samą nazwą, zostaje połączona ze Steam, a nie dodana drugi raz
  5. Zaimportowane gry są oznaczane ich Steam App ID do śledzenia osiągnięć
  6. W tle każda gra uzupełnia puste dane ze swojej strony w sklepie Steam, a Twoje osiągnięcia i czas gry są pobierane. Strona gry pokazuje Twój czas gry. Pobierz dane gry, aby uzyskać gatunek i datę wydania: te ze Steam są zbyt ogólne albo są datą pojawienia się gry na Steam

Import Xbox

Importuj gry Xbox z historii swojego konta za pomocą własnego klucza OpenXBL.

  1. Zapisz swój klucz OpenXBL w Ustawienia → Mój profil → Xbox (zobacz Klucze API powyżej)
  2. Przejdź do Importy gier → zakładka Xbox i kliknij Pobierz bibliotekę
  3. Wybierz gry do zaimportowania z wykrywaniem duplikatów. Aplikacje i gry tylko na telefon są pomijane.
  4. Zaimportowane gry są oznaczane ich Xbox Title ID do śledzenia osiągnięć

Import PSN

Importuj swoją bibliotekę gier PlayStation Network.

  1. Przejdź do Importy gier → zakładka PSN
  2. Wprowadź swoje ciasteczko NPSSO (zobacz Trofea → Uwierzytelnianie PSN, aby dowiedzieć się, jak je uzyskać)
  3. Kliknij „Pobierz bibliotekę”, aby pobrać swoje gry z PSN
  4. Wybierz gry do zaimportowania

Po zaimportowaniu

  • Zaimportowane gry pojawiają się w Twojej Bibliotece z odznakami specyficznymi dla platformy
  • Użyj masowego pobierania, aby pobrać metadane dla zaimportowanych gier
  • Śledzenie osiągnięć/trofeów jest automatycznie powiązane ze źródłową platformą
  • Zaimportowane gry można filtrować w Bibliotece za pomocą filtra Źródło
Wskazówka: Po zaimportowaniu gier z dowolnej platformy możesz pobrać dla nich metadane za pomocą masowego pobierania, tak jak w przypadku gier ROM. Zaimportowane gry mogą też śledzić osiągnięcia ze swoich odpowiednich platform.

RetroAchievements

Konfiguracja

  1. Utwórz konto na retroachievements.org
  2. Wygeneruj klucz API w ustawieniach swojego profilu
  3. Wprowadź nazwę użytkownika i klucz API w Ustawienia → Konto → RetroAchievements

Aby zdobywać osiągnięcia podczas gry w RetroArch (RetroDB), DuckStation lub PCSX2, wpisz raz swoje hasło RetroAchievements w sekcji Zdobywaj osiągnięcia w RetroArch, DuckStation i PCSX2 na tej samej stronie. Trafia ono wyłącznie do RetroAchievements i nie jest przechowywane; RetroDB zachowuje zwrócony token logowania, po jednym na użytkownika RetroDB. Jeśli chcesz, zaznacz tam Tryb hardcore. Jeśli logowanie do osiągnięć przestanie działać, na przykład po zresetowaniu klucza na stronie RetroAchievements, wyloguj się i zaloguj ponownie. Gdy naciśniesz Graj w DuckStation lub PCSX2, RetroDB zapisuje Twoje logowanie we własnym pliku ustawień tego emulatora, gdzie pozostaje, dopóki się nie wylogujesz lub nie zagra inny użytkownik RetroDB. Logowanie wykonane we własnym menu emulatora pozostaje nietknięte. RetroDB nie może zalogować DuckStation na Macu.

Strona osiągnięć

  • Zakładki systemów — przeglądaj osiągnięcia według platformy (pamięta ostatnio przeglądaną zakładkę)
  • Nawigacja alfabetyczna — przeskocz do gier według pierwszej litery w obrębie każdej zakładki systemu
  • Odśwież postęp — synchronizuj swój postęp osiągnięć z RetroAchievements
  • Statystyki ogólne — zdobyte osiągnięcia i punkty we wszystkich systemach
  • Postęp poszczególnych gier — zobacz procent ukończenia dla każdej gry z paskami postępu

Kolejka synchronizacji

Wiele synchronizacji systemów może zostać zakolejkowanych:

  • Kliknij „Odśwież postęp” na dowolnym systemie, aby rozpocząć lub zakolejkować synchronizację
  • Jeśli synchronizacja już trwa, nowe żądania są kolejkowane automatycznie
  • Kolejka przetwarza się automatycznie po zakończeniu bieżącej synchronizacji
  • Powiadomienie toast pokazuje bieżący postęp i liczbę w kolejce

Znajdowanie gier z osiągnięciami

  • Filtr biblioteki — użyj filtra „Ma RA”, aby pokazać tylko gry z osiągnięciami
  • Sprawdź RA — w oknach szczegółów gry kliknij, aby wyszukać zestaw osiągnięć
  • Masowe pobieranie — włącz opcję „Sprawdź RA”, aby znaleźć osiągnięcia podczas pobierania
  • Zadanie odświeżania RA — przeskanuj wszystkie gry w systemie, aby określić, które obsługują RA

Szczegóły na poziomie gry

Kliknij dowolną grę na stronie osiągnięć, aby zobaczyć szczegółowe informacje o osiągnięciach dla danej gry, w tym nazwy poszczególnych osiągnięć, opisy, wartości punktowe i status zdobycia.

Uwaga: „Odśwież postęp” synchronizuje Twój postęp dla gier, które już mają powiązane RetroAchievements. Aby znaleźć NOWE zestawy osiągnięć, użyj „Sprawdź RA” w oknach szczegółów gry lub włącz tę opcję podczas masowego pobierania.

Strona główna osiągnięć

How Long to Beat

Użycie

  1. Otwórz stronę gry i znajdź How Long to Beat albo otwórz jej okno Edytuj
  2. Pole wyszukiwania zawiera tytuł gry. Zmień go, jeśli HowLongToBeat zna grę pod inną nazwą
  3. Kliknij „Wyszukaj HLTB”
  4. Sprawdź jedyne pokazane dopasowanie wraz z platformą i stopniem zgodności, a następnie kliknij Zapisz. Anuluj niczego nie zachowuje

Jeśli pole nadal zawiera własny tytuł gry, wyszukiwanie sprawdza też inne znane tytuły tej gry. Tekst wpisany przez Ciebie jest wyszukiwany dokładnie tak, jak go wpisano.

Kategorie czasu

  • Główny wątek fabularny — czas ukończenia podstawowej fabuły
  • Główna + dodatki — z zawartością poboczną
  • Kompletacjonista — ukończenie wszystkiego

Gdzie pojawiają się dane HLTB

  • Okno szczegółów gry — szacowany czas gry pokazany w informacjach o grze
  • Pełna strona szczegółów gry — te same informacje o czasie gry
  • Analityka → zakładka Czas gry — analiza czasu gry w całej kolekcji
  • Porównaj gry — porównanie czasu gry obok siebie
Wskazówka: Dane HLTB są też pokazane w Analityce w zakładce Czas gry, dając Ci szacunki dla całej kolekcji.

Trofea PS3 / PSN

Lokalne trofea RPCS3

Śledź trofea zdobyte w grach PS3 za pomocą emulatora RPCS3.

  1. Ustaw ścieżkę trofeów RPCS3 w Ustawienia → Dane → Trofea
  2. Kliknij „Skanuj trofea”, aby zaimportować zdobyte trofea
  3. Przeglądaj listy trofeów i szczegóły poszczególnych trofeów na karcie RPCS3 w sekcji Osiągnięcia

RPCS3 odczytuje dane XML trofeów z Twojego katalogu użytkownika RPCS3 i automatycznie dopasowuje gry do Twojej biblioteki.

Trofea PSN API

Synchronizuj dane trofeów PlayStation Network ze swojego konta PSN.

  1. Uzyskaj swoje ciasteczko NPSSO (zobacz poniżej)
  2. Wprowadź je w Ustawienia → Konto → PSN
  3. Twoja biblioteka trofeów PSN jest pobierana przez API PlayStation
  4. Przeglądaj postęp trofeów dla każdej gry z liczbą zdobytych/łącznych
  5. Szczegóły poszczególnych trofeów obejmują opis, rzadkość i znaczniki czasu odblokowania

Uwierzytelnianie PSN (ciasteczko NPSSO)

PSN używa specjalnego ciasteczka uwierzytelniającego zwanego tokenem NPSSO. Aby je uzyskać:

  1. Otwórz przeglądarkę internetową i zaloguj się na store.playstation.com
  2. Po zalogowaniu przejdź do: https://ca.account.sony.com/api/v1/ssocookie
  3. Strona wyświetli JSON zawierający Twój token NPSSO
  4. Skopiuj wartość npsso i wklej ją w Ustawienia → Konto → PSN

Po uwierzytelnieniu RetroDB bezpiecznie buforuje tokeny dostępu we własnej bazie danych (per użytkownik) i odświeża je automatycznie — nie musisz wklejać NPSSO ponownie przy każdej synchronizacji. Gdy sesja Sony wygaśnie, RetroDB sam zaloguje się ponownie przy użyciu zapisanego NPSSO. Nowy NPSSO jest potrzebny tylko wtedy, gdy Sony odrzuci zapisany; poinformują Cię o tym wtedy Ustawienia → Konto oraz Panel.

Szczegóły trofeów

  • Typy trofeów: brązowe, srebrne, złote, platynowe
  • Ikony trofeów są pobierane i buforowane lokalnie
  • Procent ukończenia dla każdej gry
  • Znaczniki czasu odblokowania dla każdego zdobytego trofeum

Synchronizacja masowa

Synchronizuj wszystkie trofea gier PSN naraz za pomocą zadania w tle. Postęp jest pokazywany w powiadomieniu toast. Ograniczanie liczby żądań (2,5s między żądaniami) zapobiega ograniczaniu przez API PSN.

Czym są

System grywalizacji, który przyznaje trofea na podstawie kamieni milowych Twojej kolekcji. W miarę dodawania gier, pobierania metadanych i ukańczania gier, trofea odblokowują się automatycznie.

Muzeum

Czym jest

Interaktywna encyklopedia systemów gier zorganizowana według generacji. Poznaj historię, specyfikacje i godne uwagi gry dla każdej platformy w Twojej kolekcji.

Strona główna

Strona główna Muzeum pokazuje oś czasu systemów gier pogrupowanych według generacji (1.–9. generacja, konsole przenośne, automaty arcade, komputery). Każda karta systemu pokazuje obraz sprzętu i liczbę gier z Twojej biblioteki.

Strony szczegółów systemu

Kliknij dowolny system, aby zobaczyć jego stronę muzealną, która obejmuje:

  • Obraz sprzętu — zdjęcie konsoli/systemu
  • Specyfikacje techniczne — CPU, GPU, RAM, rozdzielczość, typ nośnika
  • Historia — narracja generowana przez AI o rozwoju, premierze i dziedzictwie systemu
  • 10 najlepszych gier — najbardziej godne uwagi tytuły systemu (na podstawie ocen krytyków i sugestii AI)
  • Galeria kontrolerów — obrazy kontrolerów systemu z opisami

Generowanie treści przez AI

Treści Muzeum są generowane za pomocą AI (Gemini, OpenAI lub Claude). Możesz wygenerować treść dla:

  • Pojedynczego systemu — kliknij „Generuj” na stronie muzealnej dowolnego systemu
  • Generowania masowego — wygeneruj treść dla wszystkich systemów naraz ze strony głównej (działa jako zadanie w tle z postępem w powiadomieniu toast)

Obrazy kontrolerów

Obrazy kontrolerów można dodać za pomocą:

  • Wyszukiwania obrazów — wyszukaj zdjęcia kontrolerów za pomocą Bing Image Search. Wyniki są uszeregowane według trafności (nazwa kontrolera + producent + warianty systemu).
  • Ręcznego przesyłania — prześlij własne obrazy kontrolerów
  • Usuwania tła — automatycznie usuń tło za pomocą lokalnej AI (biblioteka rembg), aby uzyskać przezroczyste obrazy kontrolerów na dowolnym tle
  • Propagacji obrazów — gdy znaleziony zostanie obraz kontrolera, jest on automatycznie współdzielony z tym samym kontrolerem na innych systemach (kontrolery pokrewne)
  • Pobierania masowego — pobierz obrazy dla wszystkich kontrolerów w systemie naraz

Wszystkie obrazy kontrolerów są standaryzowane do docelowego rozmiaru i zapisywane w formacie WebP.

Wskazówka: Do generowania treści wymagany jest klucz API AI. Muzeum korzysta z tego samego dostawcy AI, który jest skonfigurowany w Ustawienia → Pobieranie danych → Klucze API.

Raporty ROM

Co to robi

Sprawdza nazwy plików ROM pod kątem standardowych konwencji nazewnictwa i identyfikuje potencjalne problemy. Otwórz Narzędzia ROM na pasku bocznym, a następnie wybierz kartę Raporty ROM.

Typy raportów

ZakładkaCo sprawdza
Niestandardowe nazwyROM-y z nazwami plików, które nie pasują do konwencji nazewnictwa. Pokazuje bieżącą nazwę pliku, wykryte problemy i sugerowaną poprawioną nazwę.
Niezgodności nazwROM-y, w których nazwa pliku nie pasuje do pobranego tytułu metadanych. Pokazuje bieżącą nazwę pliku vs pobrany tytuł, region, rok i producenta.

Co jest sprawdzane

  • Nieprawidłowe znaki w nazwach plików (: ? * / " < > | \)
  • Brakujące lub nieprawidłowe tagi regionu (np. (USA), (Europe))
  • Brakujące tagi roku
  • Niezgodności nazwy pliku z tytułem w bazie danych

Raporty można sortować według systemu, nazwy pliku i typu problemu. Używaj ich, aby utrzymać bibliotekę ROM-ów zorganizowaną i spójnie nazwaną.

Narzędzia ROM

Uzyskaj dostęp do centrum Narzędzi ROM z paska bocznego. Każde narzędzie działa jako zadanie w tle z aktualizacjami postępu w czasie rzeczywistym, obsługą wstrzymania/wznowienia i rejestrowaniem.

Skaner archiwów

Rozpakuj archiwa ROM (ZIP, 7Z, RAR) z opcjami:

  • Rekurencyjnego skanowania podkatalogów
  • Usuwania niechcianych plików po rozpakowaniu
  • Automatycznego generowania list odtwarzania M3U dla gier wielopłytowych

Wymaga: 7z lub unzip

Konwerter CHD

Konwertuj obrazy płyt (ISO, BIN/CUE, GDI) do skompresowanego formatu CHD. Oszczędza znaczną ilość miejsca, zachowując pełną kompatybilność z emulatorami.

Wymaga: chdman (z mame-tools)

Weryfikacja CHD

Weryfikuj integralność plików CHD za pomocą walidacji hasza. Identyfikuje uszkodzone lub niekompletne konwersje.

Wymaga: chdman

Wyszukiwarka duplikatów

Znajdź zduplikowane ROM-y według hasza lub nazwy pliku, z opcjami priorytetyzacji według tagów regionu. W trybie nazw plików połączone wersje regionalne jednej gry nie są zgłaszane jako duplikaty; w trybie hash identyczne pliki są zgłaszane zawsze.

Nie wymaga żadnych zależności

Wersje regionalne

Tylko dla edytorów. RetroDB sugeruje gry, które wyglądają na jedną grę z różnych regionów: tę samą grę w IGDB lub ScreenScraper, ten sam tytuł z innym tagiem regionu albo pasującą nazwę regionalną. Odznacz każdą grę, która nie pasuje, i kliknij „Połącz zaznaczone gry” albo kliknij „Nie wersje”, aby ta grupa nigdy więcej nie była sugerowana. Nic nie zostanie połączone, dopóki tego nie potwierdzisz. Najpierw uruchom Uzupełnij tytuły alternatywne w sekcji Konserwacja: uzupełnia to identyfikatory IGDB i ScreenScraper, z których korzystają sugestie.

Nie wymaga żadnych zależności

MAME Names

Tylko dla administratorów. MAME znajduje grę po dokładnej nazwie pliku, więc zachowaj krótkie nazwy, takie jak dyger.zip. Wybierz listę MAME (plik DAT pasujący do Twoich ROM-ów lub wynik polecenia mame -listxml) i naciśnij „Nadaj nazwy grom MAME”. Każda gra dostaje swoją prawdziwą nazwę, rok i producenta, a pliki pozostają nietknięte. Tytuł, który zmieniłeś samodzielnie, zostaje zachowany. Dodaj plik catver.ini, aby filtrować listę według kategorii. Zestawy BIOS są ukryte na liście, ale zostają na dysku, ponieważ potrzebują ich inne gry. Potem pobierz dane, aby scrapery mogły znaleźć każdą grę.

Wymaga: pliku listy MAME

Masowe uzupełnianie AI

Tylko dla edytorów. Uruchamia Uzupełnianie AI dla całego systemu, dla pól, które włączysz (zob. Uzupełnianie AI → Wiele gier naraz).

Wymaga: dostawcy AI w Ustawienia → Pobieranie danych

Organizator wielopłytowy

Organizuj gry wielopłytowe w podkatalogi i generuj listy odtwarzania M3U dla emulatorów, które je obsługują. Przydatne dla systemów takich jak PlayStation i Saturn.

Nie wymaga żadnych zależności

Deduplikacja zrzutów ekranu

Znajdź i usuń zduplikowane zrzuty ekranu w bibliotece gier, aby zwolnić miejsce.

  • Dokładny hasz (MD5) — identyfikuje tylko identyczne pliki
  • Podobieństwo wizualne — porównanie hasza percepcyjnego z konfigurowalnym progiem (1–20, niższy = ściślejsze dopasowanie)

Skanuje stopniowo z na żywo aktualizowanymi statystykami pokazującymi liczbę przeskanowanych gier, liczbę duplikatów i miejsce możliwe do odzyskania. Wyniki są grupowane według gry i systemu. Możesz wybrać, który plik zachować w każdej grupie duplikatów, lub użyć „Zachowaj największe”, aby automatycznie zachować wersję o najwyższej rozdzielczości. Jeśli opuścisz stronę w trakcie skanowania lub po nim, wyniki będą na Ciebie czekać po powrocie przez 30 minut od zakończenia skanowania, chyba że RetroDB zostanie ponownie uruchomiony. Pozostałe strony narzędzi ROM, które skanują lub konwertują, działają tak samo.

Nie wymaga żadnych zależności

Zmiana rozmiaru obrazów

Standaryzuj multimedia gier do spójnych docelowych rozmiarów. Zobacz Standaryzacja obrazów, aby poznać pełne szczegóły.

Nie wymaga żadnych zależności (skalowanie AI oparte na Pythonie)

Uzupełnij tytuły alternatywne

Przejdź przez każdą grę z pobranymi danymi i pobierz jej tytuły alternatywne z IGDB / TGDB / ScreenScraper, oznaczone regionem, z którego pochodzi każda nazwa. Nazwy, które już masz, otrzymują swój region. Przydatne po zaimportowaniu dużego katalogu lub migracji z innego narzędzia, które nie przechowywało tytułów regionalnych/japońskich/podtytułów. Działa w tle; postęp jest pokazany na karcie narzędzia.

Wymaga co najmniej jednego klucza API scrapera (IGDB / TGDB / ScreenScraper)

Napraw regiony okładek i instrukcji

Starsze pobrania z ScreenScraper brały pierwsze pudełko, pudełko 3D i instrukcję z alfabetycznej listy regionów, więc gra z USA mogła pokazywać europejskie pudełko lub mieć portugalską instrukcję. To narzędzie ponownie wyszukuje każdą z tych gier. Gdy inny region lepiej pasuje do gry, pobiera ten plik i usuwa stary. Pudełka i instrukcje z innych źródeł pozostają nietknięte, podobnie jak gry, których plik już pasuje. Karta otwiera stronę narzędzia. Tam przyciski Wstrzymaj, Wznów i Zatrzymaj sterują uruchomieniem, a What changed pokazuje każdą grę, dla której narzędzie podmieniło plik, wraz z jej obecnym pudełkiem i regionem, z którego pochodzi każdy nowy plik. Późniejsze uruchomienie zajmie się resztą.

Wymaga konta ScreenScraper. Zużywa Twój dzienny limit ScreenScraper

Napraw regiony na podstawie nazw plików

Nazwa pliku ROM mówi, która to kopia, więc znacznik taki jak (USA) decyduje teraz o regionie i AI nie jest pytane. Starsze pobrania pozwalały AI zgadywać jako pierwszemu, więc plik (USA) mógł być oznaczony jako Japonia. To narzędzie nadaje tym grom region z nazwy pliku. Zmienia tylko regiony uzupełnione przez AI, także taki, który później poprawiłeś ręcznie tak, że różni się od nazwy pliku.

Nie wymaga żadnych zależności

Uporządkuj daty wydania

Starsze pobrania zapisywały datę, z której znany był tylko rok, jako 1 stycznia lub 31 grudnia, tak jakby dzień był znany. To narzędzie skraca te daty do roku lub miesiąca, aby późniejsze pobranie mogło uzupełnić prawdziwą datę. Data, której nie uzupełniło żadne pobranie, pozostaje bez zmian.

Nie wymaga żadnych zależności

Sprawdź zapisane czasy gry

Starsze wyszukiwania mogły zapisać czas gry kontynuacji albo innej gry o tej samej nazwie na innym systemie. To narzędzie wysyła takie dopasowania na stronę przeglądu HowLongToBeat i żadna gra się nie zmienia, dopóki nie zdecydujesz. Tam Zatwierdź zachowuje czas, a Odrzuć go czyści. Niektóre dopasowania są w porządku: HowLongToBeat nie wymienia każdego systemu, na który gra została wydana.

Nie wymaga żadnych zależności

Uporządkuj gatunki, perspektywy i tryby

Źródła nazywają to samo różnie, więc jeden gatunek mógł występować jako RPG i jako Role Playing Game, a filtr pomijał gry. Pobieranie danych używa teraz jednego zestawu nazw, tych z list filtrów. To narzędzie przekształca to, co zapisały starsze pobrania. Słowa, które nie mają miejsca na tych listach, takie jak Arcade czy Indie, są usuwane. Słowa należące do innego pola, takie jak FPV, są tam przenoszone, jeśli to pole jest puste. Liczba graczy sprzeczna z trybami gry jest poprawiana, a stare liczby 1 z RAWG są czyszczone, aby mogła je uzupełnić prawdziwa liczba. Wartość, którą sam dodałeś do listy rozwijanej, zostaje. Uruchom potem masowe pobieranie z opcją Uzupełnij braki, aby uzupełnić to, co pozostało puste.

Nie wymaga żadnych zależności

Wyczyść obrazy RAWG z okładek

RAWG nie ma okładek. Starsze pobrania zapisywały jego obraz tła, często zrzut ekranu, jako okładkę, a ponieważ pobieranie wypełnia tylko puste okładki, ten obraz blokował prawdziwą. To narzędzie usuwa te obrazy i zostawia okładki puste. Okładki z innych źródeł i cały fanart zostają. Te gry nie pokazują okładki, dopóki pobieranie jej nie znajdzie, więc uruchom potem masowe pobieranie z opcją Uzupełnij braki.

Nie wymaga żadnych zależności

Masowe wyszukiwanie HLTB

Uruchom wyszukiwanie HowLongToBeat dla każdej gry bez szacowanego czasu gry. Każde dopasowanie jest oceniane według tytułu + platformy + roku wydania; dopasowania o wysokiej pewności są zapisywane automatycznie. Wszystko poniżej progu pewności (lub z niezgodnymi platformami) trafia do przeglądu przez człowieka.

Wyszukuje każdą grę na stronie HowLongToBeat, więc potrzebny jest dostęp do internetu

HLTB oczekujące na przegląd

Kolejka przeglądu dla niejednoznacznych dopasowań wykrytych przez Masowe wyszukiwanie HLTB. Każdy oczekujący wiersz pokazuje grę źródłową obok kandydata HLTB (tytuł, platforma, rok wydania, pewność). Zatwierdź, odrzuć lub wybierz inne dopasowanie dla każdego wiersza. Karta narzędzia przeglądu pojawia się w centrum Narzędzi ROM tylko wtedy, gdy istnieje co najmniej jedno oczekujące dopasowanie.

  • Zakładki filtrów dla dopasowań o niskiej pewności, alternatywnym tytule i niezgodności platformy.
  • Zatwierdź zapisuje szacowany czas gry; Odrzuć usuwa kandydata i utrzymuje kolejkę wyszukiwania w czystości.

Ustawienia narzędzi

Skonfiguruj ścieżki, lokalizacje narzędzi, typy archiwów i preferencje współdzielone przez wszystkie narzędzia ROM.

Wskazówka: Wszystkie narzędzia ROM obsługują wstrzymanie/wznowienie i działają w tle. Postęp i wyniki są rejestrowane i widoczne w Przeglądarce dzienników. Status narzędzia (dostępne vs wymaga instalacji) jest pokazany na każdej karcie narzędzia.

Normalizacja

Co to robi

Normalizuje wartości gatunku i trybu gry do spójnych form kanonicznych. Dzieje się to automatycznie podczas pobierania i Uzupełniania AI, a można to też zastosować ręcznie do istniejącej biblioteki.

Dlaczego to ważne

Różne scrapery używają różnych nazw dla tej samej rzeczy. Normalizacja zapewnia spójność w całej Twojej bibliotece:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Reguły niestandardowe

Możesz dodać niestandardowe reguły normalizacji w Ustawienia → Dane → Normalizacja. Reguły niestandardowe nadpisują wbudowane mapowania, pozwalając Ci zdefiniować własne preferowane nazwy gatunków i trybów. Reguły są przechowywane w bazie danych.

Podgląd i zastosowanie

Przed zastosowaniem normalizacji możesz zobaczyć podgląd, które gry zostaną dotknięte i jakie zmiany zostaną wprowadzone. Pozwala to na przegląd przed zatwierdzeniem zmian w bibliotece.

Nazwy pisane na dwa sposoby

Przyciski Franczyza, Wydawca i Deweloper wyświetlają nazwy pisane różnymi wielkimi literami, takie jak Doom i DOOM. Wybierany jest zapis użyty w największej liczbie gier; wybierz inny, jeśli wolisz, a potem naciśnij Zastosuj. Jeśli późniejsze pobieranie danych lub Uzupełnianie AI przyniesie nazwę zapisaną innymi wielkimi literami, użyje zapisu z Twojej biblioteki.

W sekcjach Wydawca i Deweloper lista Nazwy, które mogą oznaczać jedną firmę pokazuje nazwy takie jak Eidos i Eidos Interactive. Nic nie jest zaznaczone, bo podobne nazwy mogą oznaczać różne firmy: Atari Games i Atari, Inc. to dwie firmy. W wierszu wybierz nazwę do zachowania, zaznacz nazwy, które oznaczają tę samą firmę, i naciśnij Scal. Zaznaczone nazwy zmieniają się na zachowaną zarówno w Wydawcy, jak i w Deweloperze, a jeśli późniejsze pobieranie danych lub Uzupełnianie AI przyniesie scaloną nazwę, użyje zachowanej.

Standaryzacja obrazów

Co to robi

Standaryzuje wszystkie multimedia gier do spójnych docelowych rozmiarów, aby uzyskać jednolity wygląd w całej bibliotece. Obrazy w przedziale 80–120% docelowego rozmiaru są pomijane.

Jak to działa

  • Powiększanie — obrazy mniejsze niż docelowy rozmiar są powiększane za pomocą Real-ESRGAN x4 (super-rozdzielczość AI przez ONNX Runtime) w celu wysokiej jakości powiększenia, a następnie zmieniany jest ich rozmiar do dokładnego celu
  • Pomniejszanie — obrazy większe niż docelowy rozmiar są pomniejszane za pomocą filtrowania Lanczos dla ostrych wyników
  • Pasmo progowe — obrazy w przedziale 80–120% celu pozostają nietknięte, aby uniknąć niepotrzebnego przetwarzania

Obsługa sprzętu

Model Real-ESRGAN automatycznie wykrywa Twój sprzęt i używa najlepszego dostępnego dostawcy:

  • ROCm — przyspieszenie GPU AMD (z automatycznym nadpisaniem wersji gfx dla serii RX 6000)
  • CoreML — przyspieszenie Apple Silicon
  • CPU — tryb awaryjny dla systemów bez obsługi GPU

Konserwacja

Operacje konserwacyjne są dostępne w Ustawienia → System → Konserwacja. Pomagają utrzymać bibliotekę czystą i zoptymalizowaną.

Skanowanie biblioteki

  • Skanuj bibliotekę — skanuj katalogi ROM-ów w poszukiwaniu nowych gier. Wykrywa foldery systemowe i obsługiwane typy plików za pomocą list rozszerzeń ES-DE systeminfo.txt. Dostępne też z Panelu głównego.

Operacje czyszczenia

  • Wyczyść brakujące ROM-y — usuwa wpisy w bazie danych dla gier, których pliki ROM już nie istnieją na dysku. Przydatne po zreorganizowaniu lub usunięciu plików ROM.
  • Czyszczenie osieroconych multimediów — znajduje i usuwa pliki obrazów na dysku (okładki, zrzuty ekranu, fanart), które nie mają odpowiadającego odniesienia w bazie danych. Podgląd przed usunięciem dla potwierdzenia.
  • Wyczyść pobrane dane — Usuwa to, co pobieranie wypełniło w pobranych grach, razem z powiązaniami z ich obrazami i filmami, aby można było pobrać wszystko od zera. Gry zostają, a ich tytuły wracają do nazw plików (zablokowany tytuł zostaje). Pliki obrazów i filmów zostają na dysku, chyba że zaznaczysz Usuń też pliki obrazów i filmów. Podgląd pokazuje, ilu gier dotyczy.
  • Wyczyść importy CLZ — usuwa wszystkie rekordy importu CLZ Games (wpisy zawierające tylko metadane, bez plików ROM).

Optymalizacja bazy danych

  • Optymalizuj bazę danych — uruchamia VACUUM i ANALYZE SQLite, aby odzyskać miejsce z usuniętych rekordów i zaktualizować statystyki planera zapytań. Zalecane po dużych usunięciach lub operacjach czyszczenia.

Co jest zawarte w kopii zapasowej

Kopia zapasowa obejmuje całą bazę danych SQLite (roms.db), która zawiera wszystkie metadane gier, konta użytkowników, ustawienia, dane trofeów, postęp osiągnięć, tagi, listy i pozycje z listy życzeń.

Pliki multimediów (okładki, zrzuty ekranu, fanart, filmy, instrukcje) NIE są zawarte w kopii zapasowej bazy danych, ponieważ można je pobrać ponownie przez pobieranie metadanych. Rozważ osobne wykonanie kopii zapasowej katalogu static/images/, jeśli masz niestandardowe przesłane pliki.

Aktualizacja RetroDB

Wersja 4.0 to ostatnia duża wersja internetowa RetroDB. Nowe wersje będą aplikacją na komputery z systemem Windows, Linux i macOS oraz aplikacją na Androida i otworzą Twoją dotychczasową bibliotekę. Wersja internetowa pozostaje dostępna i nadal otrzymuje poprawki błędów, a od czasu do czasu także nowe funkcje.

Jak aktualizować

  1. Pobierz nowe wydanie RetroDB
  2. Wykonaj kopię zapasową tych plików (zawierają Twoje dane osobiste):
    • config.py (Twoje ścieżki i klucze API)
    • data/settings.json (Twoje preferencje interfejsu)
    • data/scraper_settings.json (Twoja konfiguracja scraperów)
    • data/rom_tools_config.json (Twoje preferencje narzędzi ROM)
    • folder database/ (baza danych Twojej biblioteki gier oraz zapisane tokeny logowania PSN/Xbox)
  3. Rozpakuj nową wersję na istniejącą instalację
  4. Uruchom python install.py, aby zainstalować nowe zależności
  5. Zrestartuj serwer

Pliki bezpieczne do nadpisania

Wszystkie pliki kodu źródłowego (.py, .html, .css, .js) można bezpiecznie nadpisać. Instalator nie nadpisze Twoich osobistych plików konfiguracyjnych.

Pliki do zachowania

Nigdy nie usuwaj ani nie nadpisuj: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Migracje bazy danych

RetroDB automatycznie obsługuje zmiany schematu bazy danych przy uruchomieniu. Nowe kolumny i tabele są dodawane w razie potrzeby bez utraty danych. Nie musisz robić nic specjalnego — po prostu uruchom nową wersję, a baza danych zostanie zaktualizowana automatycznie.

Rozwiązywanie problemów

Problemy są pogrupowane według funkcji. Wpisz słowo z komunikatu, który widzisz, w polu wyszukiwania u góry tej strony, aby od razu do niego przejść. Większość komunikatów zostawia też wpis w Przeglądarce dzienników (tylko dla administratorów), który mówi więcej.

Długie zadania

Zadanie wygląda na zawieszone

Masowe pobieranie danych, synchronizacje osiągnięć, odświeżanie PSN, zmiana rozmiaru obrazów i uzupełnianie AI pokazują powiadomienie o postępie w rogu ekranu. Jego przyciski wstrzymują, zatrzymują lub anulują zadanie. Masowe pobieranie danych zatrzymuje się między dwiema grami, więc trwająca gra kończy się najpierw; to może zająć minutę. Jeśli zadanie nadal trwa, uruchom RetroDB ponownie: Ustawienia → System → Sterowanie serwerem → Uruchom serwer ponownie.

Baner „Przerwane zadania” w Panelu

Zadanie, które trwało lub czekało, gdy RetroDB się zatrzymało, pojawia się tutaj. Wznów kontynuuje je od miejsca, w którym ostatnio zapisało postęp. Odrzuć porzuca je. Wznów wszystko i Odrzuć wszystko robią to samo dla każdego zadania z listy.

Dodawanie gier

„Ścieżka ROM-ów nie jest skonfigurowana”

Ustaw folder, w którym leżą foldery systemów, w Ustawienia → Biblioteka → Ścieżki → Ścieżka biblioteki ROM, a potem naciśnij Skanuj bibliotekę.

Skanowanie nie znajduje nowych gier albo brakuje systemu

  • Każdy folder systemu potrzebuje pliku ES-DE systeminfo.txt z listą rozszerzeń plików. Folder bez niego jest pomijany; Przeglądarka dzienników pokazuje dla niego No extensions found. Foldery PS3 go nie potrzebują.
  • Pliki muszą leżeć bezpośrednio w folderze systemu. Pliki w podfolderze są pomijane, z wyjątkiem PS3.
  • Plik, którego rozszerzenia nie ma na liście, jest pomijany.
  • Przeniesiony lub zmieniony plik jest dodawany jako nowa gra. Ustawienia → System → Wyczyść brakujące ROM-y usuwa stary wpis.

Pobieranie danych

"No results found. Try a different search term."

  • Skróć tytuł w polu wyszukiwania albo spróbuj angielskiej nazwy.
  • Sprawdź, czy źródła są włączone i pokazują Online w Ustawienia → Pobieranie danych → Scraper.
  • Źródło, które osiągnęło limit, nic nie zwraca do czasu, który podało (patrz niżej).

Dane lub obrazy należą do innej gry

  • Masowe pobieranie danych szuka według nazwy pliku ROM, więc źle nazwany plik znajduje złą grę. Zmień nazwę pliku albo pobierz dane gry na jej własnej stronie z lepszym tytułem wyszukiwania i wybierz właściwy wynik.
  • W oknie Edytuj grę zaznacz Zachowaj ten tytuł przy pobieraniu danych, aby kolejne pobrania nie ruszały nazwy.
  • Przy wielu grach wybierz Ścisłe w Ustawienia → Pobieranie danych → Scraper → Filtrowanie dopasowań przy pobieraniu zbiorczym.

Pobieranie danych nie zastępuje złego obrazu

Pobieranie danych wypełnia tylko puste obrazy, a zrzuty ekranu są tylko dodawane. Usuń obraz w oknie Edytuj grę, a potem pobierz dane ponownie. Masowe Pełne ponowne pobranie zastępuje obrazy, chyba że zaznaczono Zachowaj istniejące multimedia. Usunięty przez Ciebie zrzut ekranu nie jest dodawany ponownie.

„… informuje, że osiągnięto limit” lub „… odrzucił klucz API”

RetroDB nie pyta tej usługi do czasu podanego w komunikacie. Odrzucony klucz popraw w Ustawienia → Pobieranie danych → Klucze API i naciśnij Zapisz klucze API; zapis kończy też od razu każdą taką przerwę. Ponowne uruchomienie również je kończy.

Źródło pokazuje powód zamiast „Online”

Powód wskazuje problem, na przykład „No API key” lub „Invalid API key”. Wpisz lub popraw klucz w Ustawienia → Pobieranie danych → Klucze API (tylko administratorzy) i naciśnij Zapisz klucze API. Zapisany klucz widać jako gwiazdki; zostaw pole w spokoju, aby go zachować, albo wyczyść je i wpisz nowy klucz.

Masowe pobieranie danych

Masowe pobieranie danych się zawiesiło

Naciśnij Anuluj w oknie Masowe pobieranie danych; kliknij powiadomienie o postępie, aby je otworzyć. Pobierana właśnie gra kończy się najpierw. Jeśli zadanie nadal trwa, zobacz Zadanie wygląda na zawieszone.

Większość gier jest „Pominięta”

  • Uzupełnij braki pomija grę, którą masowe pobieranie danych zakończyło w ciągu ostatnich 24 godzin.
  • Gra, której pobranie nie znalazło nic nowego, też liczy się jako pominięta.
  • Aby pobrać je ponownie teraz, użyj Pełne ponowne pobranie; zaznacz Zachowaj istniejące multimedia, aby zachować swoje obrazy.

Wiele gier ma „Niepowodzenie”

Niepowodzenie zwykle oznacza, że żaden wynik nie był dość bliski, aby go zapisać. Wybierz Luźne w Ustawienia → Pobieranie danych → Scraper → Filtrowanie dopasowań przy pobieraniu zbiorczym i sprawdź nazwy plików. Przeglądarka dzienników wymienia każdą grę, dla której nie znaleziono dopasowania.

"A scrape for … is already running"

Ten system jest już pobierany w tym samym trybie. Poczekaj na to albo anuluj. Pobieranie dla innego systemu czeka w kolejce i startuje samo.

Uzupełnianie AI

„AI nie zwróciło żadnych danych. Sprawdź klucz API i ustawienia dostawcy.”

W Ustawienia → Pobieranie danych → Klucze API wybierz Dostawca metadanych AI, wpisz jego klucz, naciśnij Zapisz klucze API, a potem Testuj zapisany klucz AI. Jeśli usługa AI odmówiła, komunikat podaje zamiast tego powód, na przykład brak środków.

„AI nie znalazło brakujących pól do uzupełnienia”

To nie błąd: gra nie ma nic pustego, co uzupełnianie AI mogłoby wypełnić.

Masowe uzupełnianie AI zatrzymało się samo

Zatrzymuje się, gdy trzy gry z rzędu nie dostaną odpowiedzi. Sprawdź klucz przyciskiem Testuj zapisany klucz AI, a potem uruchom je ponownie. Gry już uzupełnione zachowują to, co dostały.

Obrazy

Po pobraniu danych brakuje obrazów

Obraz, którego pobranie się nie powiedzie, jest pomijany bez komunikatu; Przeglądarka dzienników mówi dlaczego. Sprawdź, czy RetroDB może zapisywać w swoim folderze multimediów (static/images/, chyba że go przeniesiono). W systemie Linux lub macOS polecenie chmod -R u+rwX static/images/ daje Twojemu kontu prawo zapisu bez oznaczania obrazów jako programów.

Powiększanie nie działa

  • Pierwsze powiększanie pobiera model Real-ESRGAN, więc potrzebny jest dostęp do internetu.
  • Karta graficzna potrzebuje działających sterowników (CUDA dla NVIDIA, ROCm dla AMD). Jeśli karta zawiedzie, powiększanie przechodzi na procesor.
  • Jeśli powiększanie w ogóle nie może działać, RetroDB powiększa obrazy zwykłą metodą (Lanczos). logs/upscale_worker.log mówi dlaczego.

Granie

Gra otwiera się na innym komputerze

Graj uruchamia emulator na komputerze, na którym działa RetroDB, a nie na urządzeniu, na którym naciśnięto przycisk.

„Nie znaleziono programu emulatora w PATH”

Na stronie Emulatory, w sekcji Zarejestrowane emulatory, edytuj emulator i wpisz w polu Lokalizacja programu, gdzie leży program. Albo dodaj folder, w którym leży, w sekcji Foldery emulatorów. Dla RetroArch użyj Wykryj automatycznie na karcie RetroArch, a potem Zapisz.

„Brak skonfigurowanego emulatora dla systemu …” lub „Emulator … jest wyłączony”

Wybierz emulator dla systemu w sekcji Przypisanie do systemów na stronie Emulatory albo włącz emulator w sekcji Zarejestrowane emulatory. Gra ustawiona na emulator, który już nie istnieje: wyczyść ten wybór w jej oknie Edytuj grę.

„… nie ustawiono dla niego rdzenia RetroArch” lub „Nie znaleziono rdzenia RetroArch”

Na stronie Emulatory sprawdź, czy karta RetroArch wskazuje folder z Twoimi rdzeniami (Wykryj automatycznie go uzupełnia), a potem naciśnij Zapisz. Brakujący rdzeń zainstaluj własnym pobieraczem rdzeni RetroArch. Albo wybierz inny emulator dla systemu w sekcji Przypisanie do systemów.

„Nie znaleziono pliku ROM” lub „Ścieżka ROM-u leży poza skonfigurowanymi folderami skanowania”

Plik został przeniesiony lub usunięty od ostatniego skanowania albo leży poza Twoim folderem ROM. Połóż go z powrotem w folderze systemu i zeskanuj bibliotekę ponownie.

„Ta gra jest już uruchomiona”

Zamknij okno emulatora albo przyjmij propozycję jego zamknięcia i ponownego uruchomienia.

„Nie można pobrać rdzenia …”

Granie w RetroDB pobiera brakujący rdzeń przy pierwszym graniu, chyba że na stronie Emulatory wyłączono Pobierz brakujący rdzeń po naciśnięciu „Graj”. Sprawdź połączenie z internetem i naciśnij Graj ponownie albo naciśnij Zainstaluj rdzenie dla moich systemów na stronie Emulatory.

Kody

„Nie znaleziono kodów dla tej gry.”

Pobierz pakiet kodów dla emulatora na karcie Kody na stronie Emulatory albo zaimportuj tam folder z własnymi kodami. Kody działają w odtwarzaczu, DuckStation, PCSX2 i MAME. W przypadku MAME zaimportuj kolekcję kodów z mamecheat.co.uk.

Włączony kod nic nie robi

Kody są stosowane przy następnym naciśnięciu Graj. Włączony kod wyłącza tryb hardcore RetroAchievements na czas gry.

„Uruchom … raz, aby utworzył swoje ustawienia, a potem zagraj ponownie.”

DuckStation lub PCSX2 nie utworzył jeszcze folderu ustawień. Uruchom emulator raz samodzielnie, a potem naciśnij Graj ponownie.

Osiągnięcia i trofea

Synchronizacja RetroAchievements się zawiesiła lub czeka

Naraz działa jedno zadanie RetroAchievements; reszta czeka w kolejce w powiadomieniu o postępie. Jego przycisk zatrzymania kończy trwające zadanie, a każde czekające zadanie ma przycisk Usuń z kolejki.

„RetroAchievements nie jest skonfigurowane”

Zapisz nazwę użytkownika RetroAchievements i klucz web API w Ustawienia → Konto → Mój profil → Ustawienia RetroAchievements.

„RetroAchievements nie zalogowało cię”

Logowanie na czas gry wymaga hasła RetroAchievements, a nie klucza API. Zaczyna działać przy następnym naciśnięciu Graj.

„Nie znaleziono gier. Sprawdź, czy Twój profil Steam i szczegóły gier są ustawione jako publiczne.”

Na stronie Steam ustaw swój profil i szczegóły jego gier jako publiczne. Klucz Steam i 17-cyfrowy identyfikator Steam wpisz w Ustawienia → Konto → Mój profil → Steam.

„OpenXBL nie przyjął tego klucza”

  • Skopiuj klucz ponownie z xbl.io i wklej go w Ustawienia → Konto → Mój profil → Xbox.
  • „Osiągnięto godzinny limit OpenXBL” oznacza, że klucz zużył w tej godzinie swoje 150 żądań. Zsynchronizuj ponownie później; synchronizacja zacznie od gier, które nie zostały jeszcze zsynchronizowane.

„Uwierzytelnianie PSN nie powiodło się”

  • Sony nie przyjmuje już zapisanego tokenu NPSSO. Pobierz nowy według kroków w Ustawienia → Konto → Mój profil → PlayStation Network, a potem naciśnij Zapisz mój profil.
  • RetroDB samo podtrzymuje logowanie, dopóki Sony przyjmuje token. Aby zastąpić token, który nadal działa, najpierw wyloguj się z PlayStation.

Synchronizacja trofeów PSN się zawiesiła

Odświeżanie PSN ma przyciski zatrzymania w powiadomieniu o postępie. Pełna synchronizacja trofeów ich nie ma; kończy ją ponowne uruchomienie RetroDB.

Wszystkie Trofea kolekcjonera pokazują się jako niezdobyte

Naciśnij Odśwież postęp na stronie Trofea kolekcjonera. Samo otwarcie strony ich nie liczy.

„Nie znaleziono dopasowania HLTB dla …”

Wpisz w polu wyszukiwania tytuł, którego używa HowLongToBeat, i wyszukaj ponownie. Jeśli HowLongToBeat zgłosiło zbyt wiele żądań, RetroDB czeka 15 minut przed ponownym zapytaniem, a do tego czasu wyszukiwanie niczego nie znajdzie.

Muzeum i narzędzia ROM

„Nie skonfigurowano dostawcy AI”

Muzeum pisze swoje strony za pomocą dostawcy AI ustawionego w Ustawienia → Pobieranie danych → Klucze API. Skonfiguruj go i wygeneruj ponownie.

Generowanie muzeum się zawiesiło

Naciśnij Anuluj pod paskiem postępu na stronie Muzeum.

„Nie znaleziono chdman. Zainstaluj narzędzia MAME.”

Zainstaluj narzędzia MAME, które zawierają chdman, albo ustaw jego lokalizację w Narzędzia ROM → Ustawienia.

„Te wyniki skanowania wygasły. Zeskanuj ponownie, a potem usuń.”

Uruchom skanowanie ponownie, a potem usuwaj z nowych wyników.

Konta i logowanie

„Zbyt wiele prób logowania. Spróbuj ponownie później.”

Po pięciu błędnych hasłach w ciągu pięciu minut poczekaj pięć minut i spróbuj ponownie.

Zapomniane hasło

Nie ma resetu przez e-mail. Administrator ustawia nowe hasło w Ustawienia → Konto → Zarządzanie użytkownikami. Jeśli jedyny administrator zapomni swojego, przywróć kopię zapasową zrobioną, gdy hasło było znane.

"Nie masz uprawnień do wykonania tej czynności"

Twoja rola nie obejmuje tej funkcji. Administrator może zmienić Twoją rolę w Ustawienia → Konto → Zarządzanie użytkownikami.

Baza danych, kopie zapasowe i aktualizacje

Błędy bazy danych

  1. Jeśli to możliwe, zrób kopię zapasową (Ustawienia → Biblioteka → Kopia zapasowa)
  2. Spróbuj Ustawienia → System → Konserwacja → Optymalizuj bazę danych. Może się nie udać, gdy zadanie zapisuje; poczekaj, aż zadania się skończą, i spróbuj ponownie.
  3. Sprawdź uprawnienia do plików w katalogu database/
  4. Ostateczność: przywróć z kopii zapasowej

„Zadanie w tle jest w toku. Poczekaj na jego zakończenie przed przywróceniem.”

Pozwól zadaniu się zakończyć albo zatrzymaj je z jego powiadomienia o postępie, a potem przywróć. Po przywróceniu uruchom RetroDB ponownie.

„Ta kopia RetroDB jest klonem git. Zaktualizuj ją poleceniem git pull.”

Aktualizator instaluje tylko na pobranym wydaniu. Kopię utworzoną przez git aktualizuje się poleceniem git pull.

Aktualizacja się nie powiodła

Nieudane pobieranie niczego nie instaluje; naciśnij Pobierz aktualizację ponownie. Nieudana instalacja sama przywraca starą wersję i mówi dlaczego. Szczegóły są w logs/update.log.

Strony i szybkość

Strona działa wolno lub nie odpowiada

  • Duże kolekcje mogą się ładować dłużej — nieskończone przewijanie ładuje po 100 pozycji
  • Odśwież stronę, aby wyczyścić zgromadzoną pamięć
  • Sprawdź konsolę przeglądarki pod kątem błędów JavaScript
  • Przełącz się na motyw z lżejszym efektem canvas (np. Amber lub Elite)
  • Efekty canvas wykrywają sprzęt automatycznie; słabsze urządzenia używają procesora z niższą liczbą klatek na sekundę

Wskazówki dotyczące wydajności

  • Aktualizuj przeglądarkę, aby działała jak najlepiej
  • Zamknij inne karty przeglądarki podczas pracy z bardzo dużymi kolekcjami
  • Używaj filtrów systemów, aby ograniczyć liczbę jednocześnie wyświetlanych gier
  • Uruchamiaj Optymalizuj bazę danych co jakiś czas po dużych operacjach (pobieranie danych, czyszczenie, importy)

Bezpieczeństwo i zastrzeżenia

Najlepsze praktyki bezpieczeństwa

  • Zmień domyślne hasło — domyślne hasło administratora (admin) powinno zostać zmienione natychmiast po pierwszym zalogowaniu. Używaj silnego hasła składającego się z co najmniej 12 znaków.
  • Używaj serwera proxy HTTPS — RetroDB samo w sobie nie zapewnia TLS/SSL. Umieść je za serwerem proxy (np. Nginx, Caddy, Traefik) z włączonym HTTPS, aby szyfrować ruch między klientami a serwerem.
  • Ogranicz dostęp sieciowy — unikaj wystawiania RetroDB bezpośrednio do publicznego internetu. Użyj VPN lub ogranicz dostęp do swojej sieci lokalnej. Jeśli potrzebny jest dostęp zdalny, użyj serwera proxy z uwierzytelnianiem.
  • Wykonuj regularne kopie zapasowe — użyj wbudowanej funkcji kopii zapasowej w Ustawieniach, aby tworzyć okresowe kopie zapasowe bazy danych. Przechowuj kopie zapasowe w innej lokalizacji niż aplikacja.
  • Aktualizuj RetroDB — regularnie sprawdzaj nowe wydania. Poprawki bezpieczeństwa i ulepszenia są zawarte w aktualizacjach.
  • Chroń swoje klucze API — klucze API są przechowywane w data/scraper_settings.json. Upewnij się, że ten plik nie jest publicznie dostępny. Nigdy nie udostępniaj swojego pliku config.py ani plików tokenów.

Wbudowane funkcje bezpieczeństwa

  • Haszowanie haseł — Hasła są hashowane za pomocą PBKDF2 (nigdy nie są przechowywane jako zwykły tekst)
  • Ograniczanie prób logowania — ochrona przed atakami typu brute-force na punkcie końcowym logowania
  • Walidacja ścieżek — wszystkie operacje na plikach używają pomocników safe_path i safe_filename, aby zapobiec atakom przechodzenia katalogów
  • Zapytania parametryzowane — wszystkie zapytania do bazy danych używają instrukcji parametryzowanych, aby zapobiec wstrzykiwaniu SQL
  • Ochrona przed XSS — okna modalne używają bezpiecznej konstrukcji DOM; dane wejściowe użytkownika są odpowiednio przekształcane (escaping)
  • Ochrona przed bombami dekompresji obrazów — maksymalna liczba pikseli obrazu jest ograniczona, aby zapobiec wyczerpaniu pamięci przez złośliwe obrazy
