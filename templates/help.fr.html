Installation

Configuration requise

  • Python 3.8+ avec pip
  • Navigateur web (Chrome, Firefox, Safari, Edge)
  • Système d'exploitation : Linux, Windows 10/11 ou macOS

Installation rapide

  1. Extrayez le fichier ZIP de RetroDB dans le répertoire de votre choix
  2. Ouvrez un terminal/une invite de commande dans ce répertoire
  3. Exécutez : python install.py
  4. Démarrez le serveur :
    • Linux : ./start.sh
    • Windows : double-cliquez sur start.bat
    • macOS : double-cliquez sur start.command
  5. Ouvrez http://localhost:5000 dans votre navigateur

Installateur graphique

Sous Linux, vous pouvez aussi exécuter ./setup.sh pour lancer un assistant d'installation graphique. Il vérifie automatiquement la présence de Python/pip/tkinter, puis vous guide à travers chaque étape de configuration avec un journal de progression visuel.

Ce que fait install.py

  • Vérifie que Python 3.8+ et pip sont disponibles
  • Installe les dépendances Python depuis requirements.txt
  • Crée config.py à partir du modèle d'exemple
  • Crée les répertoires requis (base de données, journaux, dossiers de médias)
  • Génère les paquets CSS et JS

Premiers pas

Configuration initiale

Au premier lancement, RetroDB affiche un assistant de configuration qui vous guide à travers :

  1. Compte administrateur — Créez votre nom d'utilisateur et votre mot de passe
  2. Chemin de la bibliothèque — Définissez votre répertoire de ROM
  3. Intégration ES-DE — Liez éventuellement les gamelists et médias ES-DE
  4. Clés API — Ajoutez éventuellement des clés API de récupération

Une fois l'assistant terminé, cliquez sur « Analyser la bibliothèque » sur le Tableau de bord pour découvrir vos ROM.

Flux de démarrage rapide

  1. Analysez votre bibliothèque pour importer les ROM
  2. Parcourez par système ou affichez tous les jeux dans la Bibliothèque
  3. Récupérez les métadonnées individuellement ou utilisez la récupération en masse
  4. Organisez avec des étiquettes, des listes et une liste de souhaits
  5. Suivez votre progression grâce au statut d'achèvement et aux succès

Structure de la bibliothèque de ROM

RetroDB s'attend à ce que vos ROM soient organisées dans des dossiers de système au sein du chemin de votre bibliothèque :

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Chaque dossier de système doit contenir un fichier ES-DE systeminfo.txt qui définit les extensions de fichiers prises en charge. RetroDB le lit lors de l'analyse pour identifier quels fichiers sont des ROM valides pour chaque système.

Astuce : Si vous avez déjà récupéré des données avec ES-DE, RetroDB peut les importer ! Configurez les chemins ES-DE dans Paramètres → Intégration ES-DE, ou pendant l'assistant de configuration.

Notes par plateforme

Linux

  • Testé sur Ubuntu, Fedora, openSUSE et Arch Linux
  • Les Outils ROM nécessitent : sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) ou l'équivalent pour votre distribution
  • Si vous utilisez le Python du système, l'installateur gère automatiquement --break-system-packages
  • Accélération GPU ROCm prise en charge pour les GPU AMD (agrandissement d'images Real-ESRGAN)

Windows

  • Téléchargez Python depuis python.org (cochez « Add to PATH » lors de l'installation)
  • Outils ROM : installez 7-Zip, WinRAR et MAME (pour chdman)
  • Utilisez start.bat pour démarrer, ou exécutez python app.py depuis l'invite de commande

macOS

  • Python 3 peut être installé via Homebrew : brew install python3
  • Outils ROM : brew install p7zip unrar rom-tools
  • Double-cliquez sur start.command dans le Finder pour démarrer
  • Accélération CoreML prise en charge pour Apple Silicon (agrandissement d'images Real-ESRGAN)

Comment ça fonctionne

  • Les thèmes remplacent les variables de couleur CSS — tous les éléments de l'interface s'adaptent automatiquement
  • Les effets sur canevas incluent une détection automatique du niveau matériel (élevé/moyen/faible) avec accélération GPU lorsqu'elle est disponible et repli sur le CPU pour les appareils moins puissants
  • Les effets se mettent en pause lorsque l'onglet n'est pas visible afin d'économiser les ressources
  • L'état de la fumée Cyberpunk persiste lors des navigations entre pages pour des transitions fluides
  • Une superposition subtile de lignes de balayage façon CRT s'adapte à la palette de couleurs de chaque thème
  • Votre préférence de thème est enregistrée dans le navigateur et persiste d'une session à l'autre

Reprise des tâches

Si RetroDB redémarre alors que des tâches en arrière-plan sont en cours (récupération en masse, synchronisation RA, redimensionnement d'images, etc.), les tâches interrompues apparaissent dans une bannière de reprise. Options :

Guide de configuration des clés API

Les clés API sont facultatives mais permettent une récupération riche des métadonnées et des fonctionnalités supplémentaires. Configurez-les dans Paramètres → Récupération → Clés API.

Scrapers de métadonnées

TheGamesDB

  1. Rendez-vous sur api.thegamesdb.net/key.php
  2. Demandez des clés API (gratuites, approuvées manuellement) — vous recevrez une clé publique et une clé privée
  3. Saisissez les deux clés dans Paramètres → Clés API → TheGamesDB
  4. La clé publique (limite de débit par IP) est utilisée comme clé principale pour la récupération
  5. La clé privée (pool mensuel partagé) sert de solution de repli si la clé publique échoue

IGDB (via Twitch)

  1. Créez un compte Twitch sur twitch.tv
  2. Rendez-vous sur dev.twitch.tv/console
  3. Enregistrez une nouvelle application (nom au choix, catégorie au choix, http://localhost comme redirection OAuth)
  4. Copiez le Client ID et générez un Client Secret
  5. Saisissez les deux dans Paramètres → Clés API → IGDB

RAWG.io

  1. Rendez-vous sur rawg.io/apidocs
  2. Cliquez sur « Get API Key » et créez un compte
  3. Copiez votre clé API depuis le tableau de bord
  4. Saisissez-la dans Paramètres → Clés API → RAWG

Niveau gratuit : 20 000 requêtes/mois

ScreenScraper

  1. Créez un compte sur screenscraper.fr
  2. Saisissez votre nom d'utilisateur et votre mot de passe dans Paramètres → Clés API → ScreenScraper

Remarque : ScreenScraper impose des limites de requêtes quotidiennes selon le niveau de votre compte. Contribuer à la base de données augmente vos limites.

Succès et trophées

RetroAchievements

  1. Créez un compte sur retroachievements.org
  2. Rendez-vous sur Paramètres → Clés API sur votre profil
  3. Copiez votre clé API
  4. Saisissez votre nom d'utilisateur et votre clé API dans Paramètres → Compte → RetroAchievements

API Web Steam

  1. Rendez-vous sur steamcommunity.com/dev/apikey

Paramètres

Les paramètres sont organisés en 6 onglets, chacun comportant plusieurs sous-sections.

Onglet Compte

  • Mon profil — Téléversement/suppression d'avatar, nom d'affichage, infos sur le rôle, changement de mot de passe
  • RetroAchievements — Nom d'utilisateur et clé API pour l'intégration RA
  • PSN — Cookie NPSSO pour la synchronisation des trophées PlayStation Network
  • Fuseau horaire — Définissez votre fuseau horaire pour l'affichage des dates dans toute l'application
  • Utilisateurs — Gestion des utilisateurs : ajouter, modifier, supprimer des utilisateurs et attribuer des rôles (administrateur uniquement)

Onglet Bibliothèque

  • Chemins — Chemin de la bibliothèque de ROM, emplacement de la base de données
  • Affichage — Sélection du thème, style de jaquette (2D/3D), système de classification d'âge préféré, éléments par page
  • Nommage des ROM — Placement de l'article (« The » au début/à la fin), liste des options de région, région par défaut, conventions de nommage
  • Sauvegarde — Créer et restaurer des sauvegardes de la base de données

Onglet Récupération

  • ES-DE — Chemins des gamelists et médias ES-DE pour l'import de données locales
  • Scraper — Activer/désactiver les scrapers individuels, classement par priorité en glisser-déposer, réglages de limite de débit par scraper
  • Clés API — Tous les identifiants de scrapers (TGDB, IGDB, RAWG, ScreenScraper), sélection du fournisseur d'IA et choix du modèle (Gemini, OpenAI, Claude)

Onglet Données

  • Statistiques — Aperçu des statistiques de la bibliothèque (total des jeux, systèmes, utilisation du stockage)
  • Trophées — Configuration du chemin des trophées RPCS3 pour l'analyse des trophées PS3 locaux
  • Listes déroulantes — Personnalisez les options de région et autres valeurs de listes déroulantes utilisées dans l'application
  • Normalisation — Règles de normalisation des genres et des modes — ajoutez des correspondances personnalisées pour standardiser la sortie des scrapers

Onglet Personnalisation

  • Notifications — Préférences de délai des notifications (succès, info, avertissement, erreur — chacune configurable indépendamment)
  • Manettes — Gérez la bibliothèque de manettes, définissez les manettes par défaut par système, ajoutez des manettes personnalisées. Les manettes par défaut remplacent les valeurs récupérées/IA lors de la récupération des métadonnées.
  • Logos — Personnalisation des logos de systèmes — importez des logos de systèmes ou réinitialisez-les aux valeurs par défaut

Onglet Système

  • Maintenance — Optimisation de la base de données (VACUUM/ANALYZE), nettoyage des médias orphelins, nettoyage des ROM manquantes, effacement des données récupérées, effacement des imports CLZ, standardisation d'images en masse
  • Serveur — Configuration du serveur (hôte, port, mode débogage)
  • Journalisation — Réglages du niveau de journal pour différentes catégories
  • Dépannage — Débloquer une récupération en masse bloquée, vider la file de synchronisation RA, vider l'actualisation PSN, vider la génération du musée, redémarrer le serveur
Astuce : Les scrapers désactivés ne déclencheront pas d'avertissements « API hors ligne » sur le Tableau de bord. Si vous n'utilisez pas un scraper, désactivez-le dans Paramètres → Récupération → Scraper plutôt que de supprimer la clé API.

Récupération hybride

RetroDB combine automatiquement les données de plusieurs sources pour maximiser la couverture des métadonnées :

  • Métadonnées textuelles depuis la source disponible la plus prioritaire
  • Images et médias depuis des sources secondaires lorsque la source principale ne les possède pas
  • Comblement automatique des lacunes à travers les scrapers pour une couverture maximale
  • Le titre de tri est généré automatiquement à partir du titre du jeu lors de la récupération

Gestion des médias

  • Les champs médias (jaquette, jaquette 3D, captures d'écran, fanart, vidéo, manuel) ne sont jamais remplacés lors d'une récupération normale — ils sont uniquement remplis lorsqu'ils sont vides
  • Les captures d'écran sont toujours ajoutées, jamais remplacées
  • Pour retélécharger un média, effacez d'abord l'image existante dans la fenêtre d'édition, puis relancez la récupération
  • Le mode Récupération complète remplace ce comportement et écrase tout
  • Les références de médias obsolètes (fichier supprimé mais nom toujours en base) sont effacées automatiquement avant la récupération afin que de nouveaux médias puissent être téléchargés
  • Les images téléchargées sont automatiquement standardisées à des tailles cibles (voir Standardisation des images)

Priorité des scrapers

Configurez quels scrapers s'exécutent en premier et lesquels sont activés/désactivés dans Paramètres → Récupération → Scraper. Glissez-déposez pour réorganiser la priorité. Les scrapers désactivés ne seront pas sollicités lors de la récupération et ne déclencheront pas d'avertissements d'état des API sur le Tableau de bord.

Limitation de débit

Chaque scraper dispose de limites de débit configurables pour éviter la limitation des API. Les délais par défaut sont définis de manière prudente. Réduisez les délais à vos risques et périls — dépasser les limites de débit des API peut entraîner des bannissements temporaires du service concerné.

Récupération en masse

Démarrer une récupération en masse

  1. Rendez-vous sur n'importe quelle page Système ou Bibliothèque
  2. Cliquez sur « Sélectionner » pour entrer en mode sélection
  3. Sélectionnez les jeux individuellement ou utilisez la sélection rapide :
    • Tout sélectionner — Tous les jeux visibles
    • Sélectionner les non récupérés — Uniquement les jeux sans métadonnées
  4. Choisissez le mode : Compléter les manquantes ou Récupération complète
  5. Cliquez sur « Récupérer la sélection »

Contrôles

  • Pause / Reprendre — Mettre en pause ou poursuivre la récupération
  • Annuler — Arrêter complètement
  • Arrière-plan — Réduire et continuer à naviguer pendant que la récupération s'exécute

Notification toast

Lorsqu'elle s'exécute en arrière-plan, une notification toast persistante affiche la progression sur toutes les pages :

  • Nom du jeu en cours, compteur de progression et statistiques de résultat (réussis, échoués, ignorés)
  • Contrôles Pause/Annuler disponibles depuis n'importe quelle page
  • Cliquez sur le toast pour revenir à la fenêtre de récupération

Système de file d'attente

Plusieurs récupérations en masse se mettent automatiquement en file d'attente :

  • Démarrez une nouvelle récupération pendant qu'une autre est en cours — elle est mise en file d'attente
  • La file d'attente s'affiche dans le toast avec le nombre de tâches en attente
  • Les tâches sont traitées automatiquement dans l'ordre
  • Utilisez le Gestionnaire de file d'attente pour afficher, réorganiser ou annuler les tâches en attente

Options de récupération

  • Compléter les manquantes uniquement — Ne remplit que les champs de métadonnées vides, en préservant les données existantes
  • Récupération complète — Remplace tous les champs, y compris les médias (télécharge de nouvelles images et vidéos)
  • Vérifier RetroAchievements — Vérifie également la présence de jeux de succès RetroAchievements lors de la récupération

Reprise des tâches

Si RetroDB est redémarré alors qu'une tâche est en cours, les tâches interrompues apparaissent dans une bannière de reprise sur le Tableau de bord. Cliquez sur « Reprendre » pour des tâches individuelles ou sur « Tout reprendre » pour toutes les relancer. Le toast de progression apparaît immédiatement après la reprise.

Remplissage IA

Ce que cela fait

Le Remplissage IA utilise un grand modèle de langage (Gemini, OpenAI ou Claude) pour compléter intelligemment les métadonnées de jeu manquantes ou incomplètes. Il est plus malin que la récupération classique car il s'appuie sur une connaissance contextuelle du jeu pour fournir des données précises que les scrapers peuvent ne pas avoir.

Comment l'utiliser

  1. Ouvrez la fenêtre de détails d'un jeu (ou la page de détails complète)
  2. Cliquez sur « Remplissage IA » (nécessite une clé API d'IA configurée dans les Paramètres)
  3. L'IA analyse le titre du jeu et le système, puis remplit les champs manquants
  4. Examinez les résultats — les modifications sont enregistrées automatiquement

Ce que le Remplissage IA peut fournir

  • Genre, description, développeur, éditeur, date de sortie
  • Joueurs, modes de jeu (Solo, Multijoueur, Coopératif, etc.)
  • Informations de campagne et structure du jeu
  • Les 8 systèmes de classification d'âge (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Région, franchise, jeux similaires
  • Prise en charge des manettes, type de sauvegarde
  • Perspective (Première personne, Vue de dessus, Défilement latéral, etc.), dimension (2D, 3D)
  • Informations d'édition, notes de la critique et des utilisateurs

Logique de remplissage intelligente

  • Les champs vides sont toujours remplis
  • Les données utilisateur existantes ne sont jamais écrasées
  • Les jeux similaires sont toujours actualisés (les données de l'IA sont plus fiables pour ce champ)
  • Classifications par correspondance croisée — Si un système de classification est connu, les classifications vides des autres systèmes sont remplies automatiquement par correspondance croisée des niveaux de maturité
  • Le titre de tri est généré automatiquement lors du remplissage
  • Le champ Joueurs normalise les plages (par ex. « 1-4 » devient 4)

Normalisation des genres

Le Remplissage IA utilise des formes canoniques de genre avec des noms à trait d'union :

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Prérequis

Au moins une clé API de fournisseur d'IA doit être configurée dans Paramètres → Récupération → Clés API. Le niveau de modèle le moins cher (Gemini Flash Lite, GPT-4o Mini ou Claude Haiku) fonctionne bien pour les métadonnées.

Synchronisez vos données de trophées PlayStation Network depuis votre compte PSN.

  1. Obtenez votre cookie NPSSO (voir ci-dessous)
  2. Saisissez-le dans Paramètres → Compte → PSN
  3. Votre bibliothèque de trophées PSN est récupérée via l'API PlayStation
  4. Consultez la progression des trophées par jeu avec les compteurs obtenus/total

PSN utilise un cookie d'authentification spécial appelé jeton NPSSO. Pour l'obtenir :

  1. Ouvrez un navigateur web et connectez-vous à store.playstation.com
  2. Une fois connecté, accédez à : https://ca.account.sony.com/api/v1/ssocookie
  3. La page affichera du JSON contenant votre jeton NPSSO
  4. Copiez la valeur npsso et collez-la dans Paramètres → Compte → PSN

Trophées de collectionneur

De quoi s'agit-il

Un système de gamification qui décerne des trophées selon les jalons de votre collection. À mesure que vous ajoutez des jeux, récupérez des métadonnées et terminez des jeux, les trophées se débloquent automatiquement.

Niveaux de trophées

NiveauExemples
BronzeAjouter le premier jeu, atteindre 10 jeux, première récupération, 5 systèmes, premier achèvement
Argent100 jeux, 50 récupérés, 10 systèmes, 10 achèvements, 500 jeux
Or1 000 jeux, 100 % de couverture des métadonnées, 20 systèmes, 50 achèvements
Platine5 000 jeux, 100 achèvements, 30 systèmes et plus

Comment ça fonctionne

  • La progression est suivie automatiquement selon les statistiques de votre bibliothèque
  • Visitez la page Trophées de collectionneur pour voir votre progression vers chaque trophée
  • Cliquez sur « Actualiser » pour mettre à jour la progression après avoir effectué des modifications
  • Les trophées obtenus s'affichent avec leur date de déblocage
  • Les barres de progression indiquent à quel point vous êtes proche du prochain jalon

Musée

De quoi s'agit-il

Une encyclopédie interactive des systèmes de jeu organisée par génération. Découvrez l'histoire, les spécifications et les jeux notables de chaque plateforme de votre collection.

Page d'accueil

La page d'accueil du Musée affiche une chronologie des systèmes de jeu regroupés par génération (1re–9e génération, Portables, Arcade, Ordinateurs). Chaque carte de système affiche l'image du matériel et le nombre de jeux de votre bibliothèque.

Pages de détails des systèmes

Cliquez sur n'importe quel système pour afficher sa page de musée, qui comprend :

  • Image du matériel — Photo de la console/du système
  • Spécifications techniques — Processeur, GPU, RAM, résolution, type de support
  • Histoire — Récit généré par IA sur le développement, le lancement et l'héritage du système
  • Top 10 des jeux — Les titres les plus notables du système (issus des notes de la critique et des suggestions de l'IA)
  • Galerie de manettes — Images des manettes du système avec descriptions

Génération de contenu par IA

Le contenu du Musée est généré à l'aide de l'IA (Gemini, OpenAI ou Claude). Vous pouvez générer du contenu pour :

  • Un seul système — Cliquez sur « Générer » sur la page de musée de n'importe quel système
  • Génération en masse — Générez du contenu pour tous les systèmes en une fois depuis la page d'accueil (s'exécute comme une tâche en arrière-plan avec progression par toast)

Images de manettes

Les images de manettes peuvent être ajoutées via :

  • Recherche d'images — Recherchez des photos de manettes à l'aide de Bing Image Search. Les résultats sont classés par pertinence (nom de la manette + fabricant + variations de système).
  • Téléversement manuel — Téléversez vos propres images de manettes
  • Suppression de l'arrière-plan — Supprimez automatiquement les arrière-plans à l'aide d'une IA locale (bibliothèque rembg) pour des images de manettes transparentes sur n'importe quel fond
  • Propagation d'image — Lorsqu'une image de manette est trouvée, elle est automatiquement partagée avec la même manette sur d'autres systèmes (manettes sœurs)
  • Récupération en masse — Récupérez les images de toutes les manettes d'un système en une fois

Toutes les images de manettes sont standardisées à la taille cible et enregistrées au format WebP.

Astuce : Une clé API d'IA est requise pour la génération de contenu. Le Musée utilise le même fournisseur d'IA configuré dans Paramètres → Récupération → Clés API.

Rapports ROM

Ce que cela fait

Valide les noms de fichiers ROM par rapport aux conventions de nommage standard et identifie les problèmes potentiels. Accédez-y via Rapports ROM dans la barre latérale.

Types de rapports

OngletCe qu'il vérifie
Noms non standardROM dont les noms de fichiers ne respectent pas les conventions de nommage. Affiche le nom de fichier actuel, les problèmes détectés et le nom corrigé suggéré.
Incohérences de nomsROM dont le nom de fichier ne correspond pas au titre des métadonnées récupérées. Affiche le nom de fichier actuel par rapport au titre récupéré, à la région, à l'année et au développeur.

Ce qui est vérifié

  • Caractères invalides dans les noms de fichiers (: ? * / " < > | \)
  • Étiquettes de région manquantes ou incorrectes (par ex. (USA), (Europe))
  • Étiquettes d'année manquantes
  • Incohérences entre le nom de fichier et le titre en base de données

Les rapports sont triables par système, nom de fichier et type de problème. Utilisez-les pour garder votre bibliothèque de ROM organisée et nommée de façon cohérente.

Outils ROM

Accédez au pôle Outils ROM depuis la barre latérale. Chaque outil s'exécute comme une tâche en arrière-plan avec mises à jour de progression en temps réel, prise en charge de la pause/reprise et journalisation.

Scanner d'archives

Extrayez les archives de ROM (ZIP, 7Z, RAR) avec des options pour :

  • Analyse récursive des sous-répertoires
  • Suppression des fichiers indésirables après l'extraction
  • Génération automatique de playlists M3U pour les jeux multi-disques

Requiert : 7z ou unzip

Convertisseur CHD

Convertissez les images de disque (ISO, BIN/CUE, GDI) au format compressé CHD. Permet d'économiser un espace de stockage significatif tout en conservant une compatibilité complète avec les émulateurs.

Requiert : chdman (de mame-tools)

Vérification CHD

Vérifiez l'intégrité des fichiers CHD avec validation par hachage. Identifie les conversions corrompues ou incomplètes.

Requiert : chdman

Détecteur de doublons

Trouvez les ROM en double par hachage ou par nom de fichier, avec des options pour prioriser selon les étiquettes de région.

Aucune dépendance externe

Organisateur multi-disques

Organisez les jeux multi-disques en sous-répertoires et générez des playlists M3U pour les émulateurs qui les prennent en charge. Utile pour des systèmes comme la PlayStation et la Saturn.

Aucune dépendance externe

Déduplication de captures d'écran

Trouvez et supprimez les captures d'écran en double dans votre bibliothèque de jeux pour libérer de l'espace de stockage.

  • Hachage exact (MD5) — Identifie uniquement les fichiers identiques
  • Similarité visuelle — Comparaison par hachage perceptuel avec seuil configurable (1–20, plus bas = correspondance plus stricte)

Analyse progressivement avec des statistiques en direct affichant les jeux analysés, le nombre de doublons et l'espace récupérable. Les résultats sont regroupés par jeu et par système. Vous pouvez choisir quel fichier conserver dans chaque groupe de doublons, ou utiliser « Sélectionner le plus grand » pour conserver automatiquement la version de plus haute résolution.

Aucune dépendance externe

Redimensionneur d'images

Standardisez les médias de jeu à des tailles cibles cohérentes. Consultez Standardisation des images pour tous les détails.

Aucune dépendance externe (agrandissement IA basé sur Python)

Compléter les titres alternatifs

Balayez la bibliothèque à la recherche de jeux dont le champ titres alternatifs est vide et remplissez-le depuis IGDB / TGDB / ScreenScraper. Utile après l'import d'un grand catalogue ou la migration depuis un autre outil qui ne stockait pas les sous-titres régionaux / japonais. S'exécute en arrière-plan ; la progression est affichée sur la carte de l'outil.

Requiert au moins une clé API de scraper (IGDB / TGDB / ScreenScraper)

Recherche HLTB en masse

Lancez une recherche HowLongToBeat pour chaque jeu sans estimation de durée. Chaque correspondance est notée selon le titre + la plateforme + l'année de sortie ; les correspondances de haute confiance sont enregistrées automatiquement. Tout ce qui se situe sous le seuil de confiance (ou avec des plateformes conflictuelles) est mis de côté pour révision humaine.

Aucune dépendance externe (utilise le jeu de données HLTB hors ligne fourni)

Révision HLTB en attente

File de révision pour les correspondances ambiguës soulevées par la Recherche HLTB en masse. Chaque ligne en attente affiche le jeu source aux côtés du candidat HLTB (titre, plateforme, année de sortie, confiance). Approuvez, rejetez ou choisissez une correspondance différente par ligne. La carte de l'outil de révision n'apparaît dans le pôle Outils ROM que lorsqu'il y a au moins une correspondance en attente.

  • Onglets de filtre pour les correspondances à faible confiance, à titre alternatif et à incohérence de plateforme.
  • Approuver écrit l'estimation de durée ; Rejeter abandonne le candidat et garde la file de recherche propre.

Réglages des outils

Configurez les chemins, les emplacements des outils, les types d'archives et les préférences partagées par tous les outils ROM.

Astuce : Tous les outils ROM prennent en charge la pause/reprise et s'exécutent en arrière-plan. La progression et les résultats sont journalisés et consultables dans la Visionneuse de journaux. L'état de l'outil (disponible vs installation requise) est affiché sur chaque carte d'outil.

Normalisation

Ce que cela fait

Normalise les valeurs de genre et de mode de jeu vers des formes canoniques cohérentes. Cela se produit automatiquement lors de la récupération et du Remplissage IA, et peut aussi être appliqué manuellement à votre bibliothèque existante.

Pourquoi c'est important

Différents scrapers utilisent des noms différents pour la même chose. La normalisation garantit la cohérence dans toute votre bibliothèque :

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Règles personnalisées

Vous pouvez ajouter des règles de normalisation personnalisées dans Paramètres → Données → Normalisation. Les règles personnalisées remplacent les correspondances intégrées, vous permettant de définir vos propres noms préférés de genres et de modes. Les règles sont stockées dans la base de données.

Aperçu et application

Avant d'appliquer la normalisation, vous pouvez prévisualiser quels jeux seront affectés et quelles modifications seront effectuées. Cela vous permet de vérifier avant de valider les changements dans votre bibliothèque.

Standardisation des images

Ce que cela fait

Standardise tous les médias de jeu à des tailles cibles cohérentes pour un rendu uniforme dans toute votre bibliothèque. Les images comprises entre 80 et 120 % de la taille cible sont ignorées.

Comment ça fonctionne

  • Agrandissement — Les images plus petites que la taille cible sont agrandies à l'aide de Real-ESRGAN x4 (super-résolution par IA via ONNX Runtime) pour un agrandissement de haute qualité, puis redimensionnées à la taille cible exacte
  • Réduction — Les images plus grandes que la taille cible sont réduites à l'aide du filtrage Lanczos pour des résultats nets
  • Bande de seuil — Les images comprises entre 80 et 120 % de la cible sont laissées intactes pour éviter un retraitement inutile

Tailles cibles

Type de médiaCibleMéthode
Jaquette1080 px de hauteurLa largeur s'adapte proportionnellement
Jaquette 3D1080 px de hauteurLa largeur s'adapte proportionnellement (préserve la transparence)
Captures d'écran1080 px de hauteurLa largeur s'adapte proportionnellement
Manettes1280 px sur le côté le plus longPréserve la transparence (RGBA)
Matériel1280 px sur le côté le plus longPréserve la transparence (RGBA)
FanartIgnoréNon standardisé (laissé à la taille d'origine)

Comment l'exécuter

  1. Rendez-vous sur Paramètres → Système → Maintenance ou Outils ROM → Redimensionneur d'images
  2. Cliquez sur « Démarrer » pour lancer la standardisation en masse
  3. La tâche s'exécute en arrière-plan avec une progression par toast affichant le fichier en cours et les statistiques
  4. Les images sont également standardisées automatiquement lors de la récupération (les nouveaux téléchargements sont standardisés immédiatement)

Prise en charge matérielle

Le modèle Real-ESRGAN détecte automatiquement votre matériel et utilise le meilleur fournisseur disponible :

  • CUDA — Accélération GPU NVIDIA
  • ROCm — Accélération GPU AMD (avec substitution automatique de la version gfx pour la série RX 6000)
  • CoreML — Accélération Apple Silicon
  • CPU — Solution de repli pour les systèmes sans prise en charge GPU

Le fichier de modèle ONNX est téléchargé automatiquement depuis Hugging Face lors de la première utilisation et mis en cache localement.

Maintenance

Les opérations de maintenance sont disponibles dans Paramètres → Système → Maintenance. Elles aident à garder votre bibliothèque propre et optimisée.

Analyse de la bibliothèque

  • Analyser la bibliothèque — Analysez vos répertoires de ROM à la recherche de nouveaux jeux. Détecte les dossiers de système et les types de fichiers pris en charge à l'aide des listes d'extensions ES-DE systeminfo.txt. Également disponible depuis le Tableau de bord.

Opérations de nettoyage

  • Nettoyer les ROM manquantes — Supprimez les entrées de base de données des jeux dont les fichiers ROM n'existent plus sur le disque. Utile après réorganisation ou suppression de fichiers ROM.
  • Nettoyage des médias orphelins — Trouvez et supprimez les fichiers image sur le disque (jaquettes, captures d'écran, fanart) qui n'ont aucune référence correspondante en base de données. Prévisualisez avant de supprimer pour confirmer.
  • Effacer les données récupérées — Supprimez toutes les métadonnées récupérées des jeux tout en conservant les entrées de fichiers ROM. Utile pour repartir de zéro avec la récupération. L'aperçu montre les jeux affectés avant l'exécution.
  • Effacer les imports CLZ — Supprimez tous les enregistrements d'import CLZ Games (entrées de métadonnées uniquement, sans fichiers ROM).

Optimisation de la base de données

  • Optimiser la base de données — Exécute VACUUM et ANALYZE de SQLite pour récupérer l'espace de stockage des enregistrements supprimés et mettre à jour les statistiques du planificateur de requêtes. Recommandé après de grandes suppressions ou des opérations de nettoyage.

Standardisation d'images en masse

Standardisez toutes les images de jeu à des tailles cibles. Consultez Standardisation des images pour les détails.

Gestion du serveur

  • Redémarrer le serveur — Redémarrage gracieux de l'application (nettoyage et arrêt). Disponible dans Paramètres → Système → Dépannage.

Sauvegarde et restauration

Créer des sauvegardes

  1. Rendez-vous sur Paramètres → Bibliothèque → Sauvegarde
  2. Cliquez sur « Créer une sauvegarde »
  3. La sauvegarde est enregistrée dans le dossier backups/ avec un nom de fichier horodaté

Ce qui est sauvegardé

La sauvegarde inclut l'intégralité de la base de données SQLite (roms.db), qui contient toutes les métadonnées de jeu, les comptes utilisateurs, les paramètres, les données de trophées, la progression des succès, les étiquettes, les listes et les éléments de la liste de souhaits.

Ce qui N'EST PAS sauvegardé

Les fichiers médias (jaquettes, captures d'écran, fanart, vidéos, manuels) ne sont PAS inclus dans la sauvegarde de la base de données car ils peuvent être retéléchargés par récupération. Envisagez de sauvegarder votre répertoire static/images/ séparément si vous avez des téléversements personnalisés.

Restaurer

  1. Trouvez la sauvegarde dans la liste des sauvegardes
  2. Cliquez sur « Restaurer »
  3. Confirmez l'action
Avertissement : Restaurer une sauvegarde écrase votre base de données actuelle. Créez une nouvelle sauvegarde avant d'en restaurer une plus ancienne !

Mettre à jour RetroDB

Comment mettre à jour

  1. Téléchargez la nouvelle version de RetroDB
  2. Sauvegardez ces fichiers (ils contiennent vos données personnelles) :
    • config.py (vos chemins et clés API)
    • data/settings.json (vos préférences d'interface)
    • data/scraper_settings.json (votre configuration de scrapers)
    • data/rom_tools_config.json (vos préférences d'outils ROM)
    • data/psn_tokens.json (vos jetons d'authentification PSN)
    • data/xbox_tokens.json (vos jetons d'authentification Xbox)
    • Dossier database/ (la base de données de votre bibliothèque de jeux)
  3. Extrayez la nouvelle version par-dessus l'installation existante
  4. Exécutez python install.py pour installer les nouvelles dépendances éventuelles
  5. Redémarrez le serveur

Fichiers que l'on peut écraser sans risque

Tous les fichiers de code source (.py, .html, .css, .js) peuvent être écrasés sans risque. L'installateur n'écrasera pas vos fichiers de configuration personnels.

Fichiers à conserver

Ne supprimez ni n'écrasez jamais : config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Migrations de base de données

RetroDB gère automatiquement les changements de schéma de base de données au démarrage. De nouvelles colonnes et tables sont ajoutées au besoin sans perte de données. Vous n'avez rien de particulier à faire — démarrez simplement la nouvelle version et la base de données est mise à jour automatiquement.

Dépannage

Problèmes courants

« Aucune extension trouvée pour le système »

Le dossier du système nécessite un fichier ES-DE systeminfo.txt valide qui définit les extensions de fichiers ROM prises en charge. Assurez-vous que la structure de votre répertoire de ROM correspond aux standards ES-DE.

« Échec de la connexion à l'API »

  • Vérifiez votre connexion internet
  • Vérifiez les clés API dans Paramètres → Récupération → Clés API
  • Patientez si vous êtes limité en débit (certaines API ont des plafonds quotidiens/horaires)
  • Vérifiez si le scraper est activé (les scrapers désactivés affichent « Désactivé » dans l'état du Tableau de bord)
  • Consultez la Visionneuse de journaux pour des messages d'erreur détaillés

« Récupération en masse bloquée »

Rendez-vous sur Paramètres → Système → Dépannage → « Débloquer la récupération en masse ». Ceci réinitialise l'état de la tâche sans affecter vos données.

« File de synchronisation RA bloquée »

Videz la file de synchronisation RetroAchievements depuis Paramètres → Système → Dépannage.

« Synchronisation PSN bloquée »

Videz la tâche d'actualisation PSN depuis Paramètres → Système → Dépannage.

« Génération du musée bloquée »

Videz la tâche de génération du musée depuis Paramètres → Système → Dépannage.

« Erreurs de base de données »

  1. Créez une sauvegarde si possible (Paramètres → Bibliothèque → Sauvegarde)
  2. Essayez Paramètres → Système → Maintenance → Optimiser la base de données
  3. Vérifiez les permissions de fichiers sur le répertoire database/
  4. En dernier recours : restaurez depuis une sauvegarde ou supprimez la base de données et relancez l'analyse

« Les images ne s'enregistrent pas »

Vérifiez les permissions d'écriture sur les répertoires de médias : chmod -R 755 static/images/

« Page lente ou ne répondant pas »

  • Les grandes collections peuvent mettre du temps à se charger — le défilement infini charge par lots de 100
  • Essayez d'actualiser la page pour libérer la mémoire accumulée
  • Vérifiez la console du navigateur pour des erreurs JavaScript
  • Essayez de passer à un thème avec un effet de canevas plus léger (par ex. Amber ou Elite)
  • Les effets sur canevas détectent automatiquement le matériel ; les appareils moins puissants utilisent le repli CPU à une fréquence d'images réduite

Bannière « Tâches interrompues » sur le Tableau de bord

Si RetroDB redémarre alors que des tâches sont en cours, elles apparaissent dans une bannière de reprise. Cliquez sur « Reprendre » individuellement ou sur « Tout reprendre » pour les relancer. Cliquez sur « Ignorer » ou « Tout ignorer » pour les effacer.

« Échec de l'authentification PSN »

  • Les jetons NPSSO expirent — générez-en un nouveau depuis ca.account.sony.com/api/v1/ssocookie
  • Assurez-vous d'être connecté à store.playstation.com avant de visiter l'URL du cookie
  • Les jetons mis en cache dans data/psn_tokens.json durent environ 2 mois

« Échec de l'authentification Xbox »

  • Réauthentifiez-vous en cliquant sur « Se connecter » dans l'onglet Imports de jeux → Xbox
  • Les jetons Xbox sont mis en cache dans data/xbox_tokens.json et actualisés automatiquement

« Erreurs d'agrandissement d'images »

  • Le modèle ONNX Real-ESRGAN est téléchargé lors de la première utilisation — assurez-vous d'avoir un accès internet
  • L'accélération GPU nécessite des pilotes compatibles (CUDA pour NVIDIA, ROCm pour AMD)
  • Si le GPU échoue, le système bascule automatiquement sur le traitement CPU

Conseils de performance

  • Gardez votre navigateur à jour pour de meilleures performances
  • Fermez les autres onglets du navigateur lorsque vous travaillez avec de très grandes collections
  • Utilisez les filtres de système pour réduire le nombre de jeux affichés à la fois
  • Exécutez Optimiser la base de données régulièrement après de grandes opérations (récupération, nettoyage, imports)
  • Les effets de thème sur canevas détectent automatiquement le matériel ; les appareils moins puissants utilisent le repli CPU

Sécurité et avertissement

Bonnes pratiques de sécurité

  • Changez le mot de passe par défaut — Le mot de passe administrateur par défaut (admin) doit être changé immédiatement à la première connexion. Utilisez un mot de passe fort d'au moins 8 caractères.
  • Utilisez un proxy inverse HTTPS — RetroDB ne fournit pas le TLS/SSL par lui-même. Placez-le derrière un proxy inverse (par ex. Nginx, Caddy, Traefik) avec HTTPS activé pour chiffrer le trafic entre les clients et le serveur.
  • Restreignez l'accès réseau — Évitez d'exposer RetroDB directement à l'internet public. Utilisez un VPN ou restreignez l'accès à votre réseau local. Si un accès distant est nécessaire, utilisez un proxy inverse avec authentification.
  • Conservez des sauvegardes régulières — Utilisez la fonction de sauvegarde intégrée dans les Paramètres pour créer des sauvegardes périodiques de la base de données. Stockez les sauvegardes dans un emplacement distinct de l'application.
  • Gardez RetroDB à jour — Vérifiez régulièrement la présence de nouvelles versions. Les correctifs de sécurité et les améliorations sont inclus dans les mises à jour.
  • Protégez vos clés API — Les clés API sont stockées dans data/scraper_settings.json. Assurez-vous que ce fichier n'est pas accessible publiquement. Ne partagez jamais votre config.py ni vos fichiers de jetons.

Fonctionnalités de sécurité intégrées

  • Hachage des mots de passe — Les mots de passe administrateur sont hachés avec PBKDF2 (jamais stockés en clair)
  • Limitation de débit de connexion — Protection contre la force brute sur le point d'accès de connexion
  • Validation des chemins — Toutes les opérations sur fichiers utilisent les assistants safe_path et safe_filename pour empêcher les attaques par traversée de répertoire
  • Requêtes paramétrées — Toutes les requêtes de base de données utilisent des instructions paramétrées pour empêcher les injections SQL
  • Protection XSS — Les fenêtres modales utilisent une construction DOM sûre ; les entrées utilisateur sont échappées
  • Protection contre les bombes de décompression d'images — Le nombre maximal de pixels d'image est limité pour empêcher l'épuisement de la mémoire par des images malveillantes
