Installation

System Requirements

  • Python 3.8+ with pip
  • Web browser (Chrome, Firefox, Safari, Edge)
  • Operating System: Linux, Windows 10/11, or macOS

Quick Install

  1. Extract the RetroDB ZIP to a directory of your choice
  2. Open a terminal/command prompt in that directory
  3. Run: python install.py
  4. Start the server:
    • Linux: ./start.sh
    • Windows: double-click start.bat
    • macOS: double-click start.command
  5. Open http://localhost:5000 in your browser

GUI Installer

On Linux, you can also run ./setup.sh to launch a graphical installer wizard. It checks for Python/pip/tkinter automatically, then walks you through every setup step with a visual progress log.

What install.py Does

  • Verifies Python 3.8+ and pip are available
  • Installs Python dependencies from requirements.txt
  • Creates config.py from the example template
  • Creates required directories (database, logs, media folders)
  • Builds the CSS and JS bundles

Getting Started

First-Time Setup

On first launch, RetroDB shows a Setup Wizard that guides you through:

  1. Admin Account — Create your username and password
  2. Library Path — Set your ROM directory
  3. ES-DE Integration — Optionally link ES-DE gamelists and media
  4. API Keys — Optionally add scraper API keys

After completing the wizard, click "Scan Library" on the Dashboard to discover your ROMs.

Quick Start Workflow

  1. Scan your library to import ROMs
  2. Browse by system or view all games in Library
  3. Scrape metadata individually or use bulk scrape
  4. Organize with tags, lists, and wishlist
  5. Track your progress with completion status and achievements

ROM Library Structure

RetroDB expects your ROMs to be organized in system folders within your library path:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Each system folder should contain an ES-DE systeminfo.txt file that defines supported file extensions. RetroDB reads this during scanning to identify which files are valid ROMs for each system.

Tip: If you've already scraped with ES-DE, RetroDB can import that data! Configure ES-DE paths in Settings → ES-DE Integration, or during the setup wizard.

Platform Notes

Linux

  • Tested on Ubuntu, Fedora, openSUSE, and Arch Linux
  • ROM Tools require: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) or equivalent for your distro
  • If using system Python, the installer handles --break-system-packages automatically
  • ROCm GPU acceleration supported for AMD GPUs (Real-ESRGAN image upscaling)

Windows

  • Download Python from python.org (check "Add to PATH" during install)
  • ROM Tools: Install 7-Zip, WinRAR, and MAME (for chdman)
  • Use start.bat to launch, or run python app.py from Command Prompt

macOS

  • Python 3 can be installed via Homebrew: brew install python3
  • ROM Tools: brew install p7zip unrar rom-tools
  • Double-click start.command in Finder to launch
  • CoreML acceleration supported for Apple Silicon (Real-ESRGAN image upscaling)

API Key Setup Guide

API keys are optional but enable rich metadata scraping and additional features. Configure them in Settings → Scraping → API Keys.

Metadata Scrapers

TheGamesDB

  1. Go to api.thegamesdb.net/key.php
  2. Request API keys (free, approved manually) — you'll receive a Public and Private key
  3. Enter both keys in Settings → API Keys → TheGamesDB
  4. The Public key (per-IP rate limit) is used as the primary key for scraping
  5. The Private key (shared monthly pool) is used as a fallback if the public key fails

IGDB (via Twitch)

  1. Create a Twitch account at twitch.tv
  2. Go to dev.twitch.tv/console
  3. Register a new application (any name, any category, http://localhost as OAuth redirect)
  4. Copy the Client ID and generate a Client Secret
  5. Enter both in Settings → API Keys → IGDB

RAWG.io

  1. Go to rawg.io/apidocs
  2. Click "Get API Key" and create an account
  3. Copy your API key from the dashboard
  4. Enter it in Settings → API Keys → RAWG

Free tier: 20,000 requests/month

ScreenScraper

  1. Create an account at screenscraper.fr
  2. Enter your username and password in Settings → API Keys → ScreenScraper

Note: ScreenScraper has daily request limits based on your account level. Contributing to the database increases your limits.

Achievements & Trophies

RetroAchievements

  1. Create an account at retroachievements.org
  2. Go to Settings → API Keys on your profile
  3. Copy your API key
  4. Enter your username and API key in Settings → Account → RetroAchievements

Steam Web API

  1. Go to steamcommunity.com/dev/apikey
  2. Register for a Steam Web API key (requires a Steam account)
  3. Enter your API key and Steam ID (or vanity URL) in Settings

Used for Steam library import and achievement tracking.

Xbox Live

Xbox authentication uses OAuth2 — no API key is needed. Sign in with your Microsoft account directly from the Game Imports → Xbox tab. Tokens are cached automatically and refreshed as needed.

PlayStation Network (PSN)

PSN uses NPSSO cookie authentication. See the Trophies section for detailed setup instructions.

  2. Click "Scrape"

  4. Select the correct result from the matches
  5. Click "Apply"

Hybrid Scraping

RetroDB automatically combines data from multiple sources to maximize metadata coverage:

  • Text metadata from the highest-priority available source
  • Images and media from secondary sources when the primary doesn't have them
  • Automatic gap-filling across scrapers for maximum coverage
  • Sort title is auto-generated from the game title during scraping

Media Handling

  • Media fields (boxart, 3D boxart, screenshots, fanart, video, manual) are never replaced during normal scraping — only filled when empty
  • Screenshots are always appended, never replaced
  • To re-download media, clear the existing image in the edit modal first, then re-scrape
  • Full Re-scrape mode overrides this and replaces everything
  • Stale media references (file deleted but filename still in DB) are automatically cleared before scraping so fresh media can be downloaded
  • Downloaded images are automatically standardized to target sizes (see Image Standardization)

Scraper Priority

Configure which scrapers run first and which are enabled/disabled in Settings → Scraping → Scraper. Drag-and-drop to reorder priority. Disabled scrapers won't be tried during scraping and won't trigger API status warnings on the Dashboard.

Rate Limiting

Each scraper has configurable rate limits to prevent API throttling. Default delays are set conservatively. Reduce delays at your own risk — exceeding API rate limits may result in temporary bans from the respective service.

Bulk Scraping

Starting a Bulk Scrape

  1. Go to any System or Library page
  2. Click "Select" to enter selection mode
  3. Select games individually or use quick select:
    • Select All — All visible games
    • Select Unscraped — Only games without metadata
  4. Choose mode: Fill Missing or Full Re-scrape
  5. Click "Scrape Selected"

Controls

  • Pause / Resume — Pause or continue scraping
  • Cancel — Stop completely
  • Background — Minimize and continue browsing while scraping runs

Toast Notification

When running in background, a persistent toast shows progress on all pages:

  • Current game name, progress count, and outcome stats (success, failed, skipped)
  • Pause/Cancel controls available from any page
  • Click the toast to return to the scrape modal

Queue System

Multiple bulk scrapes queue automatically:

  • Start a new scrape while one is running — it queues
  • Queue shows in toast with count of pending jobs
  • Jobs process automatically in order
  • Use Queue Manager to view, reorder, or cancel queued jobs

Scrape Options

  • Fill Missing Only — Only fill empty metadata fields, preserving existing data
  • Full Re-scrape — Replace all fields including media (downloads fresh images and videos)
  • Check RetroAchievements — Also check for RetroAchievements achievement sets during scraping

Job Recovery

If RetroDB is restarted while a job is running, interrupted jobs appear in a recovery banner on the Dashboard. Click "Resume" on individual jobs or "Resume All" to restart them. The progress toast appears immediately after resuming.

AI Fill

What It Does

AI Fill uses a large language model (Gemini, OpenAI, or Claude) to intelligently fill missing or incomplete game metadata. It's smarter than regular scraping because it uses contextual knowledge about the game to provide accurate data that scrapers may not have.

How to Use

  1. Open a game's detail modal (or full detail page)
  2. Click "AI Fill" (requires an AI API key configured in Settings)
  3. AI analyzes the game title and system, then fills in missing fields
  4. Review the results — changes are saved automatically

What AI Fill Can Provide

  • Genre, description, developer, publisher, release date
  • Players, play modes (Single-Player, Multi-Player, Co-op, etc.)
  • Campaign info and game structure
  • All 8 age rating systems (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Region, franchise, similar games
  • Controller support, save type
  • Perspective (First-Person, Top-Down, Side-Scroller, etc.), dimension (2D, 3D)
  • Edition info, critic and user scores

Smart Fill Logic

  • Empty fields are always filled
  • Existing user data is never overwritten
  • Similar games are always refreshed (AI data is more reliable for this field)
  • Cross-mapped ratings — If one rating system is known, empty ratings in other systems are automatically filled using maturity tier cross-mapping
  • Sort title is auto-generated when filled
  • Players field normalizes ranges (e.g. "1-4" becomes 4)

Genre Normalization

AI Fill uses canonical genre forms with hyphenated names:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Requirements

At least one AI provider API key must be configured in Settings → Scraping → API Keys. The cheapest model tier (Gemini Flash Lite, GPT-4o Mini, or Claude Haiku) works well for metadata.

Filtering & Search

Search

Search filters games by title (and sort title). Press / to focus the search box. Results update in real-time with a 300ms debounce.

Source Filter

Filter games by import source:

  • ROM Files — Games from your ROM library
  • CLZ Imports — Physical games imported from CLZ
  • Steam Imports — Games imported from Steam
  • Xbox Imports — Games imported from Xbox
  • PSN Imports — Games imported from PlayStation Network

Each filter opens a modal showing all unique values in your library with counts. Filters support two modes:

  • Include (IS) — Show only games matching the selected value
  • Exclude (IS NOT) — Hide games matching the selected value

  • Title — Alphabetical by sort title (case-insensitive)

Collections (Tags, Lists, Wishlist)

Tags

Create custom color-coded tags to organize your games. Tags work like labels — each game can have multiple tags, and each tag can contain multiple games.

  • Create tags with custom names and colors from the Tags page
  • Assign tags to games via the game detail modal
  • Click any tag to browse all games with that tag
  • Edit or delete tags from the Tags management page

Named Lists

Create curated game lists with custom ordering. Lists are like playlists — you control the exact order of games.

  • Create lists with a name, description, and icon from the Lists page
  • Add games to lists via the game detail modal or list page
  • Drag-and-drop to reorder games within a list
  • Sort by custom order or alphabetically

Wishlist

Track games you want to acquire, whether physical or digital.

  • Add games manually with title, system, notes, and priority (1–5)
  • Wishlist items can be linked to existing library games if found
  • Sorted by priority (highest first), then date added
Tip: Use tags for cross-cutting labels (e.g. "Favorites", "Couch Co-op", "Backlog") and lists for specific curated collections (e.g. "Top 10 SNES Games", "Games to Stream").

Image Standardization

What It Does

Standardizes all game media to consistent target sizes for a uniform look throughout your library. Images within 80–120% of the target size are skipped.

How It Works

  • Upscaling — Images smaller than the target size are upscaled using Real-ESRGAN x4 (AI super-resolution via ONNX Runtime) for high-quality enlargement, then resized to the exact target
  • Downscaling — Images larger than the target size are downscaled using Lanczos filtering for sharp results
  • Threshold band — Images within 80–120% of the target are left untouched to avoid unnecessary reprocessing

Target Sizes

Media TypeTargetMethod
Boxart1080px heightWidth scales proportionally
3D Boxart1080px heightWidth scales proportionally (preserves transparency)
Screenshots1080px heightWidth scales proportionally
Controllers1280px longest edgePreserves transparency (RGBA)
Hardware1280px longest edgePreserves transparency (RGBA)
FanartSkippedNot standardized (left at original size)

How to Run

  1. Go to Settings → System → Maintenance or ROM Tools → Image Resizer
  2. Click "Start" to begin bulk standardization
  3. The job runs in the background with toast progress showing current file and stats
  4. Images are also auto-standardized during scraping (new downloads are standardized immediately)

Hardware Support

The Real-ESRGAN model auto-detects your hardware and uses the best available provider:

  • CUDA — NVIDIA GPU acceleration
  • ROCm — AMD GPU acceleration (with automatic gfx version override for RX 6000 series)
  • CoreML — Apple Silicon acceleration
  • CPU — Fallback for systems without GPU support

The ONNX model file is downloaded automatically from Hugging Face on first use and cached locally.

Troubleshooting

Common Issues

"No extensions found for system"

The system folder needs a valid ES-DE systeminfo.txt file that defines supported ROM file extensions. Ensure your ROM directory structure matches ES-DE standards.

"API Connection Failed"

  • Check your internet connection
  • Verify API keys in Settings → Scraping → API Keys
  • Wait if rate limited (some APIs have daily/hourly caps)
  • Check if the scraper is enabled (disabled scrapers show "Disabled" in Dashboard status)
  • Check the Log Viewer for detailed error messages

"Bulk Scrape Stuck"

Go to Settings → System → Troubleshooting → "Clear Stuck Bulk Scrape". This resets the job state without affecting your data.

"RA Sync Queue Stuck"

Clear the RetroAchievements sync queue from Settings → System → Troubleshooting.

"PSN Sync Stuck"

Clear the PSN refresh job from Settings → System → Troubleshooting.

"Museum Generation Stuck"

Clear the museum generation job from Settings → System → Troubleshooting.

"Database Errors"

  1. Create a backup if possible (Settings → Library → Backup)
  2. Try Settings → System → Maintenance → Optimize Database
  3. Check file permissions on the database/ directory
  4. Last resort: restore from a backup or delete the database and re-scan

"Images Not Saving"

Check write permissions on the media directories: chmod -R 755 static/images/

"Page Slow or Unresponsive"

  • Large collections may take time to load — infinite scroll loads in batches of 100
  • Try refreshing the page to clear accumulated memory
  • Check browser console for JavaScript errors
  • Try switching to a theme with a lighter canvas effect (e.g. Amber or Elite)
  • Canvas effects auto-detect hardware; lower-end devices use CPU fallback at reduced frame rate

"Interrupted Jobs" Banner on Dashboard

If RetroDB restarts while jobs are running, they appear in a recovery banner. Click "Resume" individually or "Resume All" to restart them. Click "Dismiss" or "Dismiss All" to clear them.

"PSN Authentication Failed"

  • NPSSO tokens expire — generate a new one from ca.account.sony.com/api/v1/ssocookie
  • Make sure you're logged into store.playstation.com before visiting the cookie URL
  • Cached tokens in data/psn_tokens.json last approximately 2 months

"Xbox Authentication Failed"

  • Re-authenticate by clicking "Sign In" on the Game Imports → Xbox tab
  • Xbox tokens are cached in data/xbox_tokens.json and refreshed automatically

"Image Upscaling Errors"

  • The Real-ESRGAN ONNX model is downloaded on first use — ensure internet access
  • GPU acceleration requires compatible drivers (CUDA for NVIDIA, ROCm for AMD)
  • If GPU fails, the system falls back to CPU processing automatically

Performance Tips

  • Keep your browser up to date for best performance
  • Close other browser tabs when working with very large collections
  • Use system filters to reduce games displayed at once
  • Run Optimize Database periodically after large operations (scraping, cleanup, imports)
  • Canvas theme effects auto-detect hardware; lower-end devices use CPU fallback

Security & Disclaimer

Security Best Practices

  • Change the default password — The default admin password (admin) should be changed immediately on first login. Use a strong password of at least 8 characters.
  • Use an HTTPS reverse proxy — RetroDB does not provide TLS/SSL on its own. Place it behind a reverse proxy (e.g. Nginx, Caddy, Traefik) with HTTPS enabled to encrypt traffic between clients and the server.
  • Restrict network access — Avoid exposing RetroDB directly to the public internet. Use a VPN or restrict access to your local network. If remote access is needed, use a reverse proxy with authentication.
  • Keep regular backups — Use the built-in backup feature under Settings to create periodic database backups. Store backups in a separate location from the application.
  • Keep RetroDB updated — Check for new releases regularly. Security fixes and improvements are included in updates.
  • Protect your API keys — API keys are stored in data/scraper_settings.json. Ensure this file is not publicly accessible. Never share your config.py or token files.

Built-in Security Features

  • Password hashing — Admin passwords are hashed with PBKDF2 (never stored in plain text)
  • Login rate limiting — Brute-force protection on the login endpoint
  • Path validation — All file operations use safe_path and safe_filename helpers to prevent directory traversal attacks
  • Parameterized queries — All database queries use parameterized statements to prevent SQL injection
  • XSS protection — Modal dialogs use safe DOM construction; user input is escaped
  • Image decompression bomb protection — Maximum image pixel count is limited to prevent memory exhaustion from malicious images
