Instalación

Requisitos del sistema

  • Python 3.12+ con pip
  • Navegador web (Chrome, Firefox, Safari, Edge)
  • Sistema operativo: Linux, Windows 10/11 o macOS

Instalación rápida

  1. Extrae el ZIP de RetroDB en un directorio de tu elección
  2. Abre una terminal o símbolo del sistema en ese directorio
  3. Ejecuta: python install.py
  4. Inicia el servidor:
    • Linux: ./start.sh
    • Windows: haz doble clic en start.bat
    • macOS: haz doble clic en start.command
  5. Abre http://localhost:5000 en tu navegador

Instalador gráfico

En Linux, también puedes ejecutar ./setup.sh para lanzar un asistente de instalación gráfico. Comprueba automáticamente la presencia de Python/pip/tkinter y luego te guía por cada paso de la configuración con un registro de progreso visual.

Qué hace install.py

  • Verifica que Python 3.12+ y pip estén disponibles
  • Instala las dependencias de Python desde requirements.txt
  • Crea config.py a partir de la plantilla de ejemplo
  • Crea los directorios necesarios (base de datos, registros, carpetas de medios)
  • Compila los paquetes de CSS y JS

Primeros pasos

Configuración inicial

En el primer arranque, RetroDB muestra un asistente de configuración que te guía por:

  1. Cuenta de administrador — Crea tu nombre de usuario y contraseña
  2. Ruta de la biblioteca — Define tu directorio de ROMs
  3. Integración con ES-DE — Vincula opcionalmente las listas de juegos y los medios de ES-DE
  4. Claves de API — Añade opcionalmente claves de API de scraping

Tras completar el asistente, haz clic en «Escanear biblioteca» en el Panel para descubrir tus ROMs.

Flujo de inicio rápido

  1. Escanea tu biblioteca para importar las ROMs
  2. Explora por sistema o ve todos los juegos en la Biblioteca
  3. Haz scraping de los metadatos de forma individual o usa el scraping masivo
  4. Organiza con etiquetas, listas y lista de deseos
  5. Sigue tu progreso con el estado de finalización y los logros

Estructura de la biblioteca de ROMs

RetroDB espera que tus ROMs estén organizadas en carpetas de sistema dentro de la ruta de tu biblioteca:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA) (Disc 1).chd
    Final Fantasy VII (USA) (Disc 2).chd

Guarda los archivos ROM directamente en la carpeta del sistema. Los archivos en subcarpetas se omiten, salvo en PS3.

Cada carpeta de sistema debe contener un archivo systeminfo.txt de ES-DE que defina las extensiones de archivo admitidas. RetroDB lo lee durante el escaneo para identificar qué archivos son ROMs válidas para cada sistema.

Consejo: Si ya has hecho scraping con ES-DE, ¡RetroDB puede importar esos datos! Configura las rutas de ES-DE en Ajustes → Integración con ES-DE, o durante el asistente de configuración.

Notas por plataforma

Linux

  • Probado en Ubuntu, Fedora, openSUSE y Arch Linux
  • Las herramientas de ROM requieren: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) o el equivalente para tu distribución
  • Si usas el Python del sistema, el instalador gestiona --break-system-packages automáticamente
  • Aceleración por GPU con ROCm admitida para GPUs AMD (escalado de imágenes con Real-ESRGAN)

Windows

  • Descarga Python desde python.org (marca «Add to PATH» durante la instalación)
  • Herramientas de ROM: instala 7-Zip, WinRAR y MAME (para chdman)
  • Usa start.bat para iniciar, o ejecuta python app.py desde el símbolo del sistema

macOS

  • Python 3 se puede instalar con Homebrew: brew install python3
  • Herramientas de ROM: brew install p7zip unrar rom-tools
  • Haz doble clic en start.command en Finder para iniciar
  • Aceleración con CoreML admitida para Apple Silicon (escalado de imágenes con Real-ESRGAN)

Cómo funciona

Un anillo de progreso circular muestra la salud general de tu colección como porcentaje, codificada por color según la calidad:

Recuperación de tareas

Si RetroDB se reinicia mientras se ejecutan tareas en segundo plano (scraping masivo, sincronización con RA, redimensión de imágenes, etc.), las tareas interrumpidas aparecen en un banner de recuperación. Opciones:

  • Descartar — Quita una tarea individual de la lista de recuperación

Guía de configuración de claves de API

Las claves de API son opcionales, pero permiten un scraping rico de metadatos y funciones adicionales. Configúralas en Ajustes → Scraping → Claves de API.

Scrapers de metadatos

TheGamesDB

  1. Ve a api.thegamesdb.net/key.php
  2. Solicita claves de API (gratuitas, aprobadas manualmente) — recibirás una clave pública y una privada
  3. En Ajustes → Scrapeo → Claves de API, pon la clave pública en TheGamesDB — Clave principal y la clave privada en TheGamesDB — Clave de reserva
  4. La clave principal se usa primero; cada conexión a internet tiene su propio cupo
  5. La clave de reserva se usa cuando la clave principal se agota; permite unas 6000 solicitudes al mes

IGDB (mediante Twitch)

  1. Crea una cuenta de Twitch en twitch.tv
  2. Ve a dev.twitch.tv/console
  3. Registra una aplicación nueva (cualquier nombre, cualquier categoría, http://localhost como redirección de OAuth)
  4. Copia el Client ID y genera un Client Secret
  5. Introduce ambos en Ajustes → Claves de API → IGDB

RAWG.io

  1. Ve a rawg.io/apidocs
  2. Haz clic en «Get API Key» y crea una cuenta
  3. Copia tu clave de API desde el panel
  4. Introdúcela en Ajustes → Claves de API → RAWG

Nivel gratuito: 20 000 solicitudes al mes

ScreenScraper

  1. Crea una cuenta en screenscraper.fr
  2. Introduce tu nombre de usuario y contraseña en Ajustes → Claves de API → ScreenScraper

Nota: ScreenScraper tiene límites diarios de solicitudes según el nivel de tu cuenta. Contribuir a la base de datos aumenta tus límites.

Logros y trofeos

RetroAchievements

  1. Crea una cuenta en retroachievements.org
  2. Ve a Ajustes → Claves de API en tu perfil
  3. Copia tu clave de API
  4. Introduce tu nombre de usuario y clave de API en Ajustes → Cuenta → RetroAchievements

API web de Steam

  1. Ve a steamcommunity.com/dev/apikey
  2. Regístrate para obtener una clave de la API web de Steam (requiere una cuenta de Steam)
  3. Introduce tu clave de API y tu Steam ID (o URL personalizada) en Ajustes

Se usa para la importación de la biblioteca de Steam y el seguimiento de logros.

Xbox Live

Xbox se conecta con RetroDB a través de OpenXBL, un servicio gratuito. Cada persona usa su propia clave: inicia sesión en xbl.io con tu cuenta de Xbox, copia tu clave de API y pégala en Ajustes → Cuenta → Mi perfil → Xbox. Guardar mi perfil comprueba la clave y muestra tu gamertag. La clave gratuita permite 150 solicitudes por hora.

PlayStation Network (PSN)

PSN usa la autenticación por cookie NPSSO. Consulta la sección Trofeos para instrucciones de configuración detalladas.

Ajustes

Los ajustes están organizados en pestañas, cada una con subsecciones. Los administradores también ven una pestaña Emuladores, que abre su propia página.

Cada persona ve solo los ajustes que su rol puede cambiar. Un espectador o jugador ve la pestaña Cuenta. Un editor ve además Discos extra y Mandos. Todo lo demás es para administradores.

Pestaña Cuenta

  • Mi perfil — Tu avatar, tu carpeta de trofeos de RPCS3 y tus propias cuentas de RetroAchievements, PlayStation Network, Xbox y Steam. Tu nombre de usuario y tu clave de API web de RetroAchievements muestran tus logros; iniciar sesión con tu contraseña desbloquea logros mientras juegas. Un solo botón Guardar mi perfil guarda la tarjeta y comprueba un token de PlayStation o una clave de Xbox nuevos. Cambiar contraseña pide la contraseña nueva dos veces; necesita al menos 12 caracteres.
  • Tema e idioma — Tu tema, tu idioma y el fondo en movimiento
  • Notificaciones — Cuánto tiempo se queda en pantalla cada tipo de mensaje, solo para ti
  • Zona horaria — Define tu zona horaria para mostrar las fechas en toda la aplicación
  • Usuarios — Gestión de usuarios: añadir, editar, eliminar usuarios y asignar roles (solo administrador)

Pestaña Biblioteca

  • Rutas — La carpeta de la biblioteca de ROMs, las carpetas de listas de juegos y de medios de ES-DE, y la carpeta de trofeos de RPCS3 de la casa, con un solo Guardar
  • Visualización — Estilo de carátula (2D/3D) y sistema de clasificación por edad preferido, para todos
  • Nomenclatura de ROM — Colocación del artículo (artículo «The» al inicio o al final), lista de opciones de región, región predeterminada, convenciones de nomenclatura
  • Discos extra — Busca discos extra y vincúlalos a sus juegos
  • Copia de seguridad — Crea y restaura copias de seguridad de la base de datos

Pestaña Scraping

  • Scraper — Activa o desactiva scrapers y arrástralos al orden en que se prueban. Filtro de coincidencias en el scrapeo masivo define cuánto debe parecerse un resultado: Estricto acepta solo títulos exactos, Normal (el predeterminado) un título parecido en el sistema correcto, y Flexible también títulos parciales. Un ajuste hecho en una versión anterior aparece como Personalizado hasta que elijas otro.
  • Claves de API — Todas las credenciales de scrapers (TheGamesDB, IGDB, RAWG, ScreenScraper), selección de proveedor de IA y elección de modelo (Gemini, OpenAI, Claude), y las claves de RetroAchievements y Steam de la casa. La clave de RetroAchievements propia de una persona en Mi perfil se usa primero, y la de la casa solo para quien no tiene ninguna. La clave de Steam de la casa solo sirve a un administrador sin clave propia.

Pestaña Datos

  • Menús desplegables — Personaliza los valores que ofrecen listas como género, perspectiva y tipo de guardado
  • Normalización — Reglas de normalización de géneros y modos — añade asignaciones personalizadas para estandarizar la salida de los scrapers

Pestaña Personalización

  • Mandos — Abrir Mandos lleva a la página Mandos. Ahí defines los mandos predeterminados de cada sistema, añades los tuyos y editas la biblioteca de mandos. Los mandos predeterminados sobrescriben los valores obtenidos por scraping/IA durante la obtención de metadatos.
  • Logotipos — Actualizar logotipos del sistema copia los logotipos nuevos de tu carpeta de ES-DE y luego muestra qué sistemas aún no tienen ninguno

Pestaña Sistema

  • Mantenimiento — Limpiar ROMs faltantes, borrar importaciones de CLZ o datos scrapeados, eliminar los archivos de medios que ningún juego usa, quitar los vínculos a archivos de medios que ya no existen, optimizar la base de datos y calcular los tamaños de archivo
  • Actualizaciones — Buscar, descargar e instalar una versión nueva
  • Servidor — Reiniciar o apagar RetroDB, el puerto que usa (la dirección cambia tras Reiniciar) y dónde está su base de datos
  • Registro — Ajustes del nivel de registro para distintas categorías, y los archivos de registro

Emuladores y Jugar

Los administradores configuran los emuladores en Ajustes → Emuladores. Añade la carpeta donde están tus emuladores a Carpetas de emuladores. RetroDB encuentra allí cada emulador (un AppImage, un script portátil o un Flatpak instalado) y lo vincula con los sistemas que ejecuta. La tabla de asignación muestra, para cada sistema, si su emulador funciona y si sus archivos BIOS están en su sitio. RetroDB solo lee los archivos BIOS; nunca los copia ni los descarga.

Los juegos cuyo emulador funciona reciben un botón Jugar en la página del juego, en las tarjetas de la Biblioteca y en las páginas de sistema.

¿Aún no tienes emulador? Pulsa Obtener RetroArch en Jugar en RetroDB, en la misma página. RetroDB descarga el RetroArch oficial de libretro, comprueba la descarga y lo configura como RetroArch (RetroDB), con sus propios ajustes y partidas guardadas, separado de cualquier RetroArch que ya uses. Después descarga el mejor núcleo para cada sistema la primera vez que juegas. En un juego de varios discos, Siguiente disco funciona sin ninguna configuración. Mientras se ejecuta un juego así, y en Windows y macOS mientras se ejecuta cualquier juego, RetroArch escucha las órdenes de RetroDB en un puerto de red.

Para DuckStation, PCSX2 y RPCS3, RetroDB también define para cada juego la escala de resolución y la relación de aspecto, en el propio archivo de ajustes por juego del emulador, y si el juego se inicia a pantalla completa. Cambia los valores de todo un sistema con el botón Ajustes de la tabla de asignación, o de un solo juego en el panel Ajustes del emulador de su página. Se escriben cuando pulsas Jugar. Un ajuste que cambies dentro del propio emulador siempre prevalece: RetroDB no lo toca a partir de entonces. Ejecuta cada emulador una vez antes de jugar para que cree su carpeta de ajustes.

Trucos

En Trucos, en esa misma página, pulsa Descargar para obtener los paquetes de trucos públicos y gratuitos, o importa una carpeta de trucos que ya tengas. RetroDB copia los archivos y nunca cambia tu carpeta; vuelve a importar para recoger archivos nuevos. La página del juego muestra entonces un panel Trucos para los juegos que se juegan en RetroArch (RetroDB), DuckStation o PCSX2, con un interruptor de activar/desactivar para cada truco. En RetroArch (RetroDB) los trucos que actives se aplican la próxima vez que pulses Jugar, y un interruptor que cambies en el propio menú de RetroArch durante la partida se conserva. En DuckStation y PCSX2 los interruptores se guardan directamente en los ajustes del emulador para ese juego, así que un cambio hecho dentro del emulador también se ve en el panel. RetroDB nunca sobrescribe un archivo de trucos que el emulador ya tenga. Un truco activado pausa el modo hardcore de RetroAchievements; DuckStation y PCSX2 ignoran los trucos en modo hardcore.

Para los juegos arcade que se juegan en MAME, descarga la "MAME XML Cheats Collection" de mamecheat.co.uk en tu navegador y luego importa la carpeta que la contiene. RetroDB la mantiene comprimida, como pide su léame, y lee de ella una sola vez los nombres de los trucos de cada juego; para ello descarga de internet la herramienta 7-Zip. La página del juego lista entonces los trucos de ese juego, con un interruptor para cada truco simple de activado/desactivado, y MAME arranca con los que están activados. Un truco que toma un valor, o que actúa una sola vez, no tiene interruptor: ajústalo mientras juegas pulsando Tab, luego Plugin Options y luego Cheat. Los interruptores que cambies ahí aparecen en la página del juego después de cerrar MAME. Importar una colección más nueva reemplaza la anterior.

Los juegos arcade con RetroAchievements se juegan en RetroArch (RetroDB) con el núcleo FinalBurn Neo, porque RetroAchievements no admite MAME; el resto sigue en MAME. Pulsa Descargar junto a Trucos arcade de FinalBurn Neo en la misma página, y la página de cada uno de esos juegos lista sus trucos. FinalBurn Neo desactiva todos los trucos cada vez que arranca un juego, así que la lista no tiene interruptores: mientras juegas, pulsa F1 para abrir el menú de RetroArch, luego elige Core Options y después Cheat. Mientras el juego está en marcha, RetroDB pone su archivo de trucos en la carpeta del sistema de RetroArch, salvo que ya haya allí un archivo con ese nombre, y lo quita cuando el juego se cierra. Para jugar uno de estos juegos en MAME, elige MAME en Iniciar, Sustituir emulador, en su ventana de edición.

Scraping híbrido

RetroDB combina automáticamente datos de varias fuentes para maximizar la cobertura de metadatos:

  • Metadatos de texto de la fuente disponible de mayor prioridad
  • Imágenes y medios de fuentes secundarias cuando la principal no los tiene
  • Relleno automático de lagunas entre scrapers para la máxima cobertura
  • El título de ordenación se genera automáticamente a partir del título del juego durante el scraping
  • Una fuente solo se consulta cuando incluye el sistema del juego, y solo en ese sistema: RAWG no tiene Intellivision, así que los juegos de Intellivision no se buscan en RAWG, donde solo coincidirían con juegos de otras plataformas
  • Con la IA activada, también da el título oficial del juego tal como salió en la región de su ROM, y el juego se renombra con él, tanto en el scraping de un solo juego como en el Scraping masivo (consulta Relleno con IA)

Gestión de medios

  • Los campos de medios (carátula, carátula 3D, parte trasera de la caja, capturas, fanart, logo, vídeo, manual) nunca se reemplazan durante el scraping normal — solo se rellenan cuando están vacíos
  • Las capturas siempre se añaden, nunca se reemplazan
  • Para volver a descargar medios, borra primero la imagen existente en el modal de edición y luego vuelve a hacer scraping
  • El modo Re-scrapeo completo anula esto y reemplaza todo
  • Las referencias de medios obsoletas (archivo eliminado pero nombre de archivo todavía en la BD) se borran automáticamente antes del scraping para poder descargar medios nuevos
  • Las imágenes descargadas se estandarizan automáticamente a los tamaños objetivo (consulta Estandarización de imágenes)

Conservar un título

Cuando escribes un título nuevo en la ventana de edición y guardas, el scraping ya no lo cambia, ni siquiera el Re-scrapeo completo. La casilla Conservar este título al scrapear de la ventana de edición muestra si un título se conserva; desmárcala para que los scrapers puedan volver a renombrar el juego. Restablecer en la página de un juego también permite que los scrapers lo renombren, y Borrar datos scrapeados en Mantenimiento deja como están los títulos conservados.

Prioridad de los scrapers

Configura qué scrapers se ejecutan primero y cuáles están activados/desactivados en Ajustes → Scraping → Scraper. Arrastra y suelta para reordenar la prioridad. Los scrapers desactivados no se intentarán durante el scraping y no provocarán advertencias de estado de API en el Panel.

Límite de tasa

RetroDB espacia por sí solo sus solicitudes a cada servicio; no hay nada que configurar. Cuando un servicio indica que se alcanzó su límite, RetroDB deja de consultarlo hasta la hora que da el servicio, y lo avisa (consulta Solución de problemas).

Scraping masivo

Iniciar un scraping masivo

  1. Ve a cualquier página de Sistema o de Biblioteca
  2. Haz clic en «Seleccionar» para entrar en el modo de selección. Las herramientas de selección aparecen en una barra a lo largo de la parte inferior de la ventana.
  3. Selecciona juegos individualmente o usa la selección rápida:
    • Seleccionar todo — Todos los juegos visibles
    • Seleccionar sin scrapear — Solo los juegos sin metadatos
  4. Elige el modo: Rellenar ausentes o Re-scrapeo completo
  5. Haz clic en «Scrapear seleccionados»
  6. Haz clic en «Hecho» para salir del modo de selección

Controles

  • Pausar / Reanudar — Pausa o continúa el scraping
  • Cancelar — Detener por completo
  • Segundo plano — Minimiza y sigue navegando mientras el scraping se ejecuta

Notificación emergente

Cuando se ejecuta en segundo plano, una notificación persistente muestra el progreso en todas las páginas:

  • Nombre del juego actual, recuento de progreso y estadísticas de resultado (éxito, fallidos, omitidos)
  • Controles de pausa/cancelación disponibles desde cualquier página
  • Haz clic en la notificación para volver al modal de scraping

Sistema de cola

Varios scrapings masivos se ponen en cola automáticamente:

  • Inicia un nuevo scraping mientras hay uno en marcha — se pone en cola
  • La cola se muestra en la notificación con el recuento de tareas pendientes
  • Las tareas se procesan automáticamente en orden
  • Usa el Gestor de colas para ver, reordenar o cancelar las tareas en cola

Opciones de scraping

  • Rellenar solo ausentes — Rellena solo los campos de metadatos vacíos, conservando los datos existentes
  • Re-scrapeo completo — Reemplaza todos los campos, incluidos los medios (descarga imágenes y vídeos nuevos)
  • Conservar los medios existentes — Con el Re-scrapeo completo, conserva las ilustraciones, los vídeos y los manuales que ya están en el disco en lugar de descargarlos de nuevo. Las capturas nuevas se siguen añadiendo.
  • Comprobar RetroAchievements — Comprueba también la existencia de conjuntos de logros de RetroAchievements durante el scraping

Recuperación de tareas

Si RetroDB se reinicia mientras se ejecuta una tarea, las tareas interrumpidas aparecen en un banner de recuperación en el Panel. Haz clic en «Reanudar» en tareas individuales o en «Reanudar todo» para reiniciarlas. La notificación de progreso aparece de inmediato tras reanudar.

Relleno con IA

Qué hace

El Relleno con IA usa un modelo de lenguaje grande (Gemini, OpenAI o Claude) para rellenar de forma inteligente los metadatos de juego que faltan o están incompletos. Es más inteligente que el scraping normal porque usa conocimiento contextual sobre el juego para aportar datos precisos que los scrapers quizá no tengan.

Cómo usarlo

  1. Abre el modal de detalles de un juego (o la página de detalles completa)
  2. Haz clic en «Relleno con IA» (requiere una clave de API de IA configurada en Ajustes)
  3. La IA analiza el título del juego y el sistema, y luego rellena los campos que faltan
  4. Revisa los resultados — los cambios se guardan automáticamente

Muchos juegos a la vez

Para rellenar un sistema entero, abre Herramientas ROM → Rellenado masivo con AI y usa la tarjeta Rellenar campos vacíos con IA. Activa los campos que quieres rellenar; solo se cuentan los juegos con alguno de ellos vacío, y menos campos cuestan menos. Elige un sistema, o Todos los sistemas, y pulsa Rellenar con IA. Ejecuta Rellenar con AI en cada juego y guarda las respuestas directamente en el juego. Una barra de progreso en la tarjeta y un cuadro de aviso de Rellenar con AI muestran cuánto lleva, y puedes salir de la página mientras se ejecuta. Los juegos que ya han pasado por Rellenar con AI se omiten, así que una segunda pasada solo hace el resto; activa Incluir juegos que Rellenar con AI ya ha procesado para rellenar también un campo en ellos, como las copias vendidas. La pasada se detiene sola si la IA deja de responder, por ejemplo cuando se rechaza la clave o la cuenta no tiene saldo. Tu proveedor de IA cobra por cada juego.

Qué puede aportar el Relleno con IA

  • Género, descripción, desarrollador, distribuidor, fecha de lanzamiento
  • Jugadores, modos de juego (Un jugador, Multijugador, Cooperativo, etc.)
  • Información de campaña y estructura del juego
  • Todos los sistemas de clasificación por edad (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd, CADPA)
  • Región, franquicia, juegos similares
  • Compatibilidad con mandos, tipo de guardado
  • Perspectiva (Primera persona, Cenital, Lateral, etc.), dimensión (2D, 3D)
  • Información de edición, puntuaciones de crítica y de usuarios

Lógica de relleno inteligente

  • Los campos vacíos siempre se rellenan
  • Los datos del usuario existentes nunca se sobrescriben
  • Los juegos similares siempre se actualizan (los datos de la IA son más fiables para este campo)
  • Clasificaciones cruzadas — Si se conoce un sistema de clasificación, las clasificaciones vacías de otros sistemas se rellenan automáticamente mediante la correspondencia cruzada por nivel de madurez
  • El título de ordenación se genera automáticamente al rellenar
  • Título oficial — la IA también da el título oficial del juego tal como salió en la región de su ROM, y el juego se renombra con él, en el Relleno con IA y siempre que la IA rellena huecos durante el scraping. El nombre anterior se conserva como título alternativo. Un título que escribiste tú, o que conservaste con Conservar este título al scrapear, nunca se renombra
  • El campo Jugadores normaliza los rangos (p. ej. «1-4» pasa a 4)

Normalización de géneros

El Relleno con IA usa formas canónicas de género con nombres separados por guiones:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Requisitos

Debe haber al menos una clave de API de un proveedor de IA configurada en Ajustes → Scraping → Claves de API. El nivel de modelo más económico (Gemini Flash Lite, GPT-4o Mini o Claude Haiku) funciona bien para los metadatos.

Filtros y búsqueda

Búsqueda

La búsqueda filtra los juegos por título (y título de ordenación). Pulsa / para enfocar el cuadro de búsqueda. Los resultados se actualizan en tiempo real con un retardo de 300 ms.

Filtro de origen

Filtra los juegos por origen de importación:

  • Archivos de ROM — Juegos de tu biblioteca de ROMs
  • Importaciones de CLZ — Juegos físicos importados desde CLZ
  • Importaciones de Steam — Juegos importados desde Steam
  • Importaciones de Xbox — Juegos importados desde Xbox
  • Importaciones de PSN — Juegos importados desde PlayStation Network

Botones de filtro

Cada filtro abre un modal que muestra todos los valores únicos de tu biblioteca con sus recuentos. Los filtros admiten dos modos:

  • Incluir (ES) — Muestra solo los juegos que coinciden con los valores seleccionados
  • Excluir (NO ES) — Oculta los juegos que coinciden con los valores seleccionados

Alterna entre el modo incluir y excluir con el interruptor del modal de filtro.

En los filtros Género, Serie, Distribuidora, Desarrolladora, Modo de juego, Perspectiva y Dimensión, marca tantos valores como quieras y pulsa Aplicar. Un juego se muestra si tiene alguno de los valores marcados; en el modo excluir, un juego se oculta si tiene alguno de ellos. Cada valor tiene su propia etiqueta encima de los juegos, y su × quita solo ese valor. Los filtros Clasificación y Fuente admiten un solo valor y se aplican en cuanto haces clic en él.

Desplazamiento infinito

Los juegos se cargan en lotes de 100 a medida que te desplazas. Las nuevas páginas se cargan automáticamente cuando te acercas al final. Cambiar los filtros o la búsqueda reinicia y recarga los resultados al instante.

Persistencia del estado

Tus filtros actuales, el término de búsqueda, el orden y la posición de desplazamiento se guardan en el almacenamiento de sesión. Se restauran al volver a la página o al recargar.

Autenticación de PSN (cookie NPSSO)

PSN usa una cookie de autenticación especial llamada token NPSSO. Para obtenerla:

  1. Abre un navegador web e inicia sesión en store.playstation.com
  2. Una vez con la sesión iniciada, ve a: https://ca.account.sony.com/api/v1/ssocookie
  3. La página mostrará un JSON que contiene tu token NPSSO
  4. Copia el valor npsso y pégalo en Ajustes → Cuenta → PSN

Una vez autenticado, RetroDB guarda los tokens de acceso de forma segura en su propia base de datos (por usuario) y los renueva automáticamente — no tienes que volver a pegar el NPSSO en cada sincronización. Cuando la sesión de Sony termina, RetroDB vuelve a iniciar sesión por sí solo con tu NPSSO guardado. Solo necesitas un NPSSO nuevo cuando Sony rechaza el guardado; Ajustes → Cuenta y el Panel te lo indicarán entonces.

Sin dependencias externas

Versiones regionales

Solo para editores. RetroDB sugiere juegos que parecen un mismo juego de distintas regiones: el mismo juego de IGDB o ScreenScraper, el mismo título con otra etiqueta de región o un nombre regional que coincide. Desmarca cualquier juego que no corresponda y haz clic en «Vincular juegos marcados», o haz clic en «No son versiones» para que ese grupo no se vuelva a sugerir nunca. No se vincula nada hasta que lo confirmes. Ejecuta primero Completar títulos alternativos en Mantenimiento: rellena los ids de IGDB y ScreenScraper que usan las sugerencias.

Sin dependencias externas

Nombres de MAME

Solo para administradores. MAME encuentra un juego por su nombre de archivo exacto, así que conserva los nombres cortos, como dyger.zip. Elige la lista de MAME (un DAT que coincida con tus ROMs, o la salida de mame -listxml) y pulsa «Nombrar juegos de MAME». Cada juego recibe su nombre real, su año y su fabricante, y los archivos no se tocan. Un título que cambiaste tú se conserva. Añade un catver.ini para filtrar la lista por categoría. Los conjuntos BIOS se ocultan de la lista pero se quedan en el disco, porque otros juegos los necesitan. Haz scraping después, para que los scrapers puedan encontrar cada juego.

Requiere: un archivo de lista de MAME

Normaliza los valores de género y modo de juego a formas canónicas coherentes. Esto ocurre automáticamente durante el scraping y el Relleno con IA, y también se puede aplicar manualmente a tu biblioteca existente.

Distintos scrapers usan nombres diferentes para lo mismo. La normalización garantiza la coherencia en toda tu biblioteca:

  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash

  • board game, card game → Board-Card

Nombres escritos de dos maneras

Los botones Franquicia, Distribuidora y Desarrolladora listan nombres escritos con mayúsculas distintas, como Doom y DOOM. Se elige la grafía que tienen más juegos; elige otra si lo prefieres y pulsa Aplicar. Un scrapeo o Relleno con IA posterior que traiga el nombre con otras mayúsculas usa la grafía de tu biblioteca.

Bajo Distribuidora y Desarrolladora, Nombres que pueden ser una misma empresa lista nombres como Eidos y Eidos Interactive. No hay nada marcado, porque los nombres parecidos pueden ser empresas distintas: Atari Games y Atari, Inc. son dos. En una fila, elige el nombre que se queda, marca los nombres que son la misma empresa y pulsa Fusionar. Los nombres marcados pasan al que se conserva tanto en Distribuidora como en Desarrolladora, y un scrapeo o Relleno con IA posterior que traiga un nombre fusionado usa el conservado.

Estandarización de imágenes

Qué hace

Estandariza todos los medios de los juegos a tamaños objetivo coherentes para un aspecto uniforme en toda tu biblioteca. Las imágenes que están dentro del 80–120% del tamaño objetivo se omiten.

Cómo funciona

  • Escalado hacia arriba — Las imágenes más pequeñas que el tamaño objetivo se escalan con Real-ESRGAN x4 (superresolución por IA mediante ONNX Runtime) para un agrandamiento de alta calidad, y luego se redimensionan al tamaño objetivo exacto
  • Escalado hacia abajo — Las imágenes más grandes que el tamaño objetivo se reducen con filtrado Lanczos para resultados nítidos
  • Banda de umbral — Las imágenes dentro del 80–120% del objetivo se dejan intactas para evitar reprocesamientos innecesarios

  2. Haz clic en «Iniciar» para comenzar la estandarización masiva

  4. Las imágenes también se autoestandarizan durante el scraping (las nuevas descargas se estandarizan de inmediato)

Compatibilidad de hardware

El modelo Real-ESRGAN detecta automáticamente tu hardware y usa el mejor proveedor disponible:

  • CUDA — Aceleración por GPU de NVIDIA
  • ROCm — Aceleración por GPU de AMD (con anulación automática de la versión gfx para la serie RX 6000)
  • CoreML — Aceleración de Apple Silicon
  • CPU — Reserva para sistemas sin compatibilidad con GPU

El archivo del modelo ONNX se descarga automáticamente de Hugging Face en el primer uso y se almacena en caché localmente.

Actualizar RetroDB

La versión 4.0 es la última versión web de RetroDB. Las nuevas versiones serán una aplicación de escritorio para Windows, Linux y macOS, y una aplicación para Android. Abrirán tu biblioteca actual. Hasta entonces, la versión 4.0 solo recibirá correcciones de seguridad y de errores que causen pérdida de datos.

Cómo actualizar

  1. Descarga la nueva versión de RetroDB
  2. Respalda estos archivos (contienen tus datos personales):
    • config.py (tus rutas y claves de API)
    • data/settings.json (tus preferencias de interfaz)
    • data/scraper_settings.json (tu configuración de scrapers)
    • data/rom_tools_config.json (tus preferencias de herramientas de ROM)

  4. Ejecuta python install.py para instalar las nuevas dependencias
  5. Reinicia el servidor

El escalado no parece funcionar

  • El primer escalado descarga el modelo Real-ESRGAN, así que necesita acceso a Internet.
  • Una GPU necesita controladores que funcionen (CUDA para NVIDIA, ROCm para AMD). Si la GPU falla, el escalado pasa a la CPU.
  • Si el escalador no puede ejecutarse en absoluto, RetroDB amplía las imágenes de la forma sencilla (Lanczos). logs/upscale_worker.log dice por qué.

Jugar

El juego se abre en otro ordenador

Jugar inicia el emulador en el ordenador donde se ejecuta RetroDB, no en el dispositivo en el que pulsaste el botón.

"No se encontró el programa del emulador en el PATH"

En la página Emuladores, en Emuladores registrados, edita el emulador e indica dónde está el programa en Ubicación del programa. O añade la carpeta que lo contiene en Carpetas de emuladores. Para RetroArch, usa Detectar automáticamente en la tarjeta de RetroArch y luego Guardar.

"No hay ningún emulador configurado para el sistema …" o "El emulador … está desactivado"

Elige un emulador para el sistema en Asignación por sistema en la página Emuladores, o activa el emulador en Emuladores registrados. Si un juego está fijado a un emulador que ya no existe, borra esa elección en su ventana Editar juego.

"… no tiene ningún núcleo de RetroArch asignado" o "No se encontró el núcleo de RetroArch"

En la página Emuladores, comprueba que la tarjeta de RetroArch apunte a la carpeta que contiene tus núcleos (Detectar automáticamente la rellena) y pulsa Guardar. Instala un núcleo que falte con el descargador de núcleos del propio RetroArch. O elige otro emulador para el sistema en Asignación por sistema.

"Archivo ROM no encontrado" o "La ruta de la ROM está fuera de las carpetas de escaneo configuradas"

El archivo se movió o se eliminó desde el último escaneo, o está fuera de tu carpeta de ROMs. Devuélvelo a la carpeta del sistema y vuelve a escanear la biblioteca.

"Este juego ya está en ejecución"

Cierra la ventana del emulador, o acepta la oferta de cerrarla y empezar de nuevo.

"No se pudo descargar el núcleo de …"

Jugar en RetroDB descarga un núcleo que falte la primera vez que juegas, salvo que Descargar un núcleo que falte al pulsar «Jugar» esté desactivado en la página Emuladores. Comprueba la conexión a Internet y pulsa Jugar de nuevo, o pulsa Instalar núcleos para mis sistemas en la página Emuladores.

Trucos

"No se encontraron trucos para este juego."

Descarga el paquete de trucos del emulador en la tarjeta Trucos de la página Emuladores, o importa allí una carpeta con tus propios trucos. Los trucos funcionan en el reproductor, DuckStation, PCSX2 y MAME. Para MAME, importa la colección de trucos de mamecheat.co.uk.

Un truco activado no hace nada

Los trucos se aplican la próxima vez que pulses Jugar. Un truco activado desactiva el modo hardcore de RetroAchievements mientras juegas.

"Ejecuta … una vez para que cree sus ajustes y vuelve a jugar."

DuckStation o PCSX2 aún no ha creado su carpeta de ajustes. Inicia el emulador una vez por separado y luego pulsa Jugar de nuevo.

Logros y trofeos

Una sincronización de RetroAchievements está atascada o en espera

Solo se ejecuta una tarea de RetroAchievements a la vez; las demás esperan en la cola en el aviso de progreso. Su botón de detener termina la tarea en curso, y cada tarea en espera tiene un botón Quitar de la cola.

"RetroAchievements no está configurado"

Guarda tu nombre de usuario de RetroAchievements y tu clave de API web en Ajustes → Cuenta → Mi perfil → Ajustes de RetroAchievements.

"RetroAchievements no ha iniciado tu sesión"

Iniciar sesión para jugar necesita tu contraseña de RetroAchievements, no la clave de API. Surte efecto la próxima vez que pulses Jugar.

"No se encontraron juegos. Comprueba que tu perfil de Steam y los detalles de los juegos estén configurados como públicos."

En el sitio web de Steam, pon tu perfil y los detalles de sus juegos como Público. Tu clave de Steam y tu ID de Steam de 17 dígitos van en Ajustes → Cuenta → Mi perfil → Steam.

"OpenXBL no aceptó esa clave"

  • Vuelve a copiar la clave desde xbl.io y pégala en Ajustes → Cuenta → Mi perfil → Xbox.
  • "Se alcanzó el límite por hora de OpenXBL" significa que la clave ha usado sus 150 solicitudes de esta hora. Vuelve a sincronizar más tarde; empieza por los juegos que aún no se han sincronizado.

"Falló la autenticación de PSN"

  • Sony ya no acepta tu token NPSSO guardado. Consigue uno nuevo con los pasos de Ajustes → Cuenta → Mi perfil → PlayStation Network y pulsa después Guardar mi perfil.
  • RetroDB mantiene la sesión por sí solo mientras Sony acepte el token. Para reemplazar un token que aún funciona, cierra primero la sesión de PlayStation.

Una sincronización de trofeos de PSN está atascada

Una actualización de PSN tiene botones de detener en su aviso de progreso. Una sincronización completa de trofeos no los tiene; reiniciar RetroDB la termina.

Los Trofeos de coleccionista aparecen todos como no obtenidos

Pulsa Actualizar progreso en la página Trofeos de coleccionista. Abrir la página no los cuenta.

"No se encontró ninguna coincidencia de HLTB para …"

Escribe en el cuadro de búsqueda el título que usa HowLongToBeat y vuelve a buscar. Si HowLongToBeat dijo que había recibido demasiadas solicitudes, RetroDB espera 15 minutos antes de volver a preguntar, y hasta entonces una búsqueda no encuentra nada.

Base de datos, copias de seguridad y actualizaciones

Errores de base de datos

  1. Crea una copia de seguridad si es posible (Ajustes → Biblioteca → Copia de seguridad)
  2. Prueba Ajustes → Sistema → Mantenimiento → Optimizar base de datos. Puede fallar mientras una tarea está escribiendo; espera a que terminen las tareas y vuelve a intentarlo.
  3. Comprueba los permisos de archivo del directorio database/
  4. Último recurso: restaurar desde una copia de seguridad

"Hay una tarea en segundo plano en ejecución. Espera a que termine antes de restaurar."

Deja que la tarea termine, o detenla desde su aviso de progreso, y luego restaura. Después de restaurar, reinicia RetroDB.

El actualizador solo instala sobre una versión descargada. Una copia hecha con git se actualiza con git pull.

Una descarga fallida no instala nada; pulsa Descargar actualización de nuevo. Una instalación fallida devuelve la versión anterior por sí sola y dice por qué. Los detalles están en logs/update.log.

Páginas y velocidad

Página lenta o sin respuesta

  • Las colecciones grandes pueden tardar en cargar — el desplazamiento infinito carga en lotes de 100
  • Prueba a actualizar la página para liberar la memoria acumulada
  • Revisa la consola del navegador en busca de errores de JavaScript
  • Prueba a cambiar a un tema con un efecto de lienzo más ligero (p. ej., Amber o Elite)
  • Los efectos de lienzo detectan el hardware automáticamente; los dispositivos más modestos usan una alternativa por CPU con una tasa de fotogramas reducida

Consejos de rendimiento

  • Mantén tu navegador actualizado para obtener el mejor rendimiento
  • Cierra otras pestañas del navegador cuando trabajes con colecciones muy grandes
  • Usa los filtros de sistema para mostrar menos juegos a la vez
  • Ejecuta Optimizar base de datos periódicamente después de operaciones grandes (scrapeo, limpieza, importaciones)

Seguridad y exención de responsabilidad

Buenas prácticas de seguridad

  • Cambia la contraseña predeterminada — La contraseña de administrador predeterminada (admin) debe cambiarse de inmediato en el primer inicio de sesión. Usa una contraseña fuerte de al menos 12 caracteres.
  • Usa un proxy inverso con HTTPS — RetroDB no proporciona TLS/SSL por sí mismo. Colócalo detrás de un proxy inverso (p. ej. Nginx, Caddy, Traefik) con HTTPS activado para cifrar el tráfico entre los clientes y el servidor.
  • Restringe el acceso de red — Evita exponer RetroDB directamente a la internet pública. Usa una VPN o restringe el acceso a tu red local. Si necesitas acceso remoto, usa un proxy inverso con autenticación.
  • Mantén copias de seguridad periódicas — Usa la función de copia de seguridad integrada en Ajustes para crear copias periódicas de la base de datos. Guarda las copias en una ubicación distinta de la de la aplicación.
  • Mantén RetroDB actualizado — Comprueba si hay nuevas versiones con regularidad. Las correcciones de seguridad y las mejoras se incluyen en las actualizaciones.
  • Protege tus claves de API — Las claves de API se almacenan en data/scraper_settings.json. Asegúrate de que este archivo no sea accesible públicamente. Nunca compartas tu config.py ni tus archivos de tokens.

Funciones de seguridad integradas

  • Hash de contraseñas — Las contraseñas se cifran con hash mediante PBKDF2 (nunca se almacenan en texto plano)
  • Límite de tasa en el inicio de sesión — Protección contra ataques de fuerza bruta en el punto de inicio de sesión
  • Validación de rutas — Todas las operaciones de archivo usan los ayudantes safe_path y safe_filename para evitar ataques de traversía de directorios
  • Consultas parametrizadas — Todas las consultas a la base de datos usan sentencias parametrizadas para evitar inyecciones SQL
  • Protección XSS — Los diálogos modales usan construcción segura del DOM; la entrada del usuario se escapa
  • Protección contra bombas de descompresión de imágenes — El número máximo de píxeles de imagen está limitado para evitar el agotamiento de memoria por imágenes maliciosas
