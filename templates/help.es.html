Instalación

Requisitos del sistema

  • Python 3.8+ con pip
  • Navegador web (Chrome, Firefox, Safari, Edge)
  • Sistema operativo: Linux, Windows 10/11 o macOS

Instalación rápida

  1. Extrae el ZIP de RetroDB en un directorio de tu elección
  2. Abre una terminal o símbolo del sistema en ese directorio
  3. Ejecuta: python install.py
  4. Inicia el servidor:
    • Linux: ./start.sh
    • Windows: haz doble clic en start.bat
    • macOS: haz doble clic en start.command
  5. Abre http://localhost:5000 en tu navegador

Instalador gráfico

En Linux, también puedes ejecutar ./setup.sh para lanzar un asistente de instalación gráfico. Comprueba automáticamente la presencia de Python/pip/tkinter y luego te guía por cada paso de la configuración con un registro de progreso visual.

Qué hace install.py

  • Verifica que Python 3.8+ y pip estén disponibles
  • Instala las dependencias de Python desde requirements.txt
  • Crea config.py a partir de la plantilla de ejemplo
  • Crea los directorios necesarios (base de datos, registros, carpetas de medios)
  • Compila los paquetes de CSS y JS

Primeros pasos

Configuración inicial

En el primer arranque, RetroDB muestra un asistente de configuración que te guía por:

  1. Cuenta de administrador — Crea tu nombre de usuario y contraseña
  2. Ruta de la biblioteca — Define tu directorio de ROMs
  3. Integración con ES-DE — Vincula opcionalmente las listas de juegos y los medios de ES-DE
  4. Claves de API — Añade opcionalmente claves de API de scraping

Tras completar el asistente, haz clic en «Escanear biblioteca» en el Panel para descubrir tus ROMs.

Flujo de inicio rápido

  1. Escanea tu biblioteca para importar las ROMs
  2. Explora por sistema o ve todos los juegos en la Biblioteca
  3. Haz scraping de los metadatos de forma individual o usa el scraping masivo
  4. Organiza con etiquetas, listas y lista de deseos
  5. Sigue tu progreso con el estado de finalización y los logros

Estructura de la biblioteca de ROMs

RetroDB espera que tus ROMs estén organizadas en carpetas de sistema dentro de la ruta de tu biblioteca:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Cada carpeta de sistema debe contener un archivo systeminfo.txt de ES-DE que defina las extensiones de archivo admitidas. RetroDB lo lee durante el escaneo para identificar qué archivos son ROMs válidas para cada sistema.

Consejo: Si ya has hecho scraping con ES-DE, ¡RetroDB puede importar esos datos! Configura las rutas de ES-DE en Ajustes → Integración con ES-DE, o durante el asistente de configuración.

Notas por plataforma

Linux

  • Probado en Ubuntu, Fedora, openSUSE y Arch Linux
  • Las herramientas de ROM requieren: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) o el equivalente para tu distribución
  • Si usas el Python del sistema, el instalador gestiona --break-system-packages automáticamente
  • Aceleración por GPU con ROCm admitida para GPUs AMD (escalado de imágenes con Real-ESRGAN)

Windows

  • Descarga Python desde python.org (marca «Add to PATH» durante la instalación)
  • Herramientas de ROM: instala 7-Zip, WinRAR y MAME (para chdman)
  • Usa start.bat para iniciar, o ejecuta python app.py desde el símbolo del sistema

macOS

  • Python 3 se puede instalar con Homebrew: brew install python3
  • Herramientas de ROM: brew install p7zip unrar rom-tools
  • Haz doble clic en start.command en Finder para iniciar
  • Aceleración con CoreML admitida para Apple Silicon (escalado de imágenes con Real-ESRGAN)

Panel

Puntuación de salud de la colección

Un anillo de progreso circular muestra la salud general de tu colección como porcentaje, codificada por color según la calidad:

  • Verde (80% o más) — Excelente cobertura de metadatos
  • Cian (60–79%) — Buena cobertura con algunas lagunas
  • Naranja (40–59%) — Cobertura moderada, considera el scraping masivo
  • Rojo (<40%) — Lagunas importantes de metadatos

Los miniaillos de desglose de abajo muestran la integridad de las carátulas, la integridad de las descripciones y la cobertura de logros.

Estado de las API

Muestra el estado de conexión de todos los scrapers y las API configurados. Las API desconectadas o mal configuradas muestran un banner de advertencia con un enlace a Ajustes.

Recuperación de tareas

Si RetroDB se reinicia mientras se ejecutan tareas en segundo plano (scraping masivo, sincronización con RA, redimensión de imágenes, etc.), las tareas interrumpidas aparecen en un banner de recuperación. Opciones:

  • Reanudar — Reinicia una tarea interrumpida individual
  • Reanudar todo — Reinicia todas las tareas interrumpidas
  • Descartar — Quita una tarea individual de la lista de recuperación
  • Descartar todo — Quita todas las tareas interrumpidas

Guía de configuración de claves de API

Las claves de API son opcionales, pero permiten un scraping rico de metadatos y funciones adicionales. Configúralas en Ajustes → Scraping → Claves de API.

Scrapers de metadatos

TheGamesDB

  1. Ve a api.thegamesdb.net/key.php
  2. Solicita claves de API (gratuitas, aprobadas manualmente) — recibirás una clave pública y una privada
  3. Introduce ambas claves en Ajustes → Claves de API → TheGamesDB
  4. La clave pública (límite de tasa por IP) se usa como clave principal para el scraping
  5. La clave privada (cuota mensual compartida) se usa como reserva si la clave pública falla

IGDB (mediante Twitch)

  1. Crea una cuenta de Twitch en twitch.tv
  2. Ve a dev.twitch.tv/console
  3. Registra una aplicación nueva (cualquier nombre, cualquier categoría, http://localhost como redirección de OAuth)
  4. Copia el Client ID y genera un Client Secret
  5. Introduce ambos en Ajustes → Claves de API → IGDB

RAWG.io

  1. Ve a rawg.io/apidocs
  2. Haz clic en «Get API Key» y crea una cuenta
  3. Copia tu clave de API desde el panel
  4. Introdúcela en Ajustes → Claves de API → RAWG

Nivel gratuito: 20 000 solicitudes al mes

ScreenScraper

  1. Crea una cuenta en screenscraper.fr
  2. Introduce tu nombre de usuario y contraseña en Ajustes → Claves de API → ScreenScraper

Nota: ScreenScraper tiene límites diarios de solicitudes según el nivel de tu cuenta. Contribuir a la base de datos aumenta tus límites.

Logros y trofeos

RetroAchievements

  1. Crea una cuenta en retroachievements.org
  2. Ve a Ajustes → Claves de API en tu perfil
  3. Copia tu clave de API
  4. Introduce tu nombre de usuario y clave de API en Ajustes → Cuenta → RetroAchievements

API web de Steam

  1. Ve a steamcommunity.com/dev/apikey
  2. Regístrate para obtener una clave de la API web de Steam (requiere una cuenta de Steam)
  3. Introduce tu clave de API y tu Steam ID (o URL personalizada) en Ajustes

Se usa para la importación de la biblioteca de Steam y el seguimiento de logros.

Xbox Live

La autenticación de Xbox usa OAuth2 — no se necesita ninguna clave de API. Inicia sesión con tu cuenta de Microsoft directamente desde la pestaña Importación de juegos → Xbox. Los tokens se almacenan en caché automáticamente y se renuevan según sea necesario.

PlayStation Network (PSN)

PSN usa la autenticación por cookie NPSSO. Consulta la sección Trofeos para instrucciones de configuración detalladas.

Ajustes

Los ajustes están organizados en 6 pestañas, cada una con varias subsecciones.

Pestaña Cuenta

  • Mi perfil — Subir/quitar avatar, nombre visible, información del rol, cambio de contraseña
  • RetroAchievements — Nombre de usuario y clave de API para la integración con RA
  • PSN — Cookie NPSSO para la sincronización de trofeos de PlayStation Network
  • Zona horaria — Define tu zona horaria para mostrar las fechas en toda la aplicación
  • Usuarios — Gestión de usuarios: añadir, editar, eliminar usuarios y asignar roles (solo administrador)

Pestaña Biblioteca

  • Rutas — Ruta de la biblioteca de ROMs, ubicación de la base de datos
  • Pantalla — Selección de tema, estilo de carátula (2D/3D), sistema de clasificación por edad preferido, elementos por página
  • Nomenclatura de ROM — Colocación del artículo (artículo «The» al inicio o al final), lista de opciones de región, región predeterminada, convenciones de nomenclatura
  • Copia de seguridad — Crea y restaura copias de seguridad de la base de datos

Pestaña Scraping

  • ES-DE — Rutas de listas de juegos y medios de ES-DE para la importación de datos locales
  • Scraper — Activa/desactiva scrapers individuales, ordenación de prioridad mediante arrastrar y soltar, ajustes de límite de tasa por scraper
  • Claves de API — Todas las credenciales de scrapers (TGDB, IGDB, RAWG, ScreenScraper), selección de proveedor de IA y elección de modelo (Gemini, OpenAI, Claude)

Pestaña Datos

  • Estadísticas — Resumen de estadísticas de la biblioteca (total de juegos, sistemas, uso de almacenamiento)
  • Trofeos — Configuración de la ruta de trofeos de RPCS3 para el escaneo de trofeos locales de PS3
  • Desplegables — Personaliza las opciones de región y otros valores desplegables usados en toda la aplicación
  • Normalización — Reglas de normalización de géneros y modos — añade asignaciones personalizadas para estandarizar la salida de los scrapers

Pestaña Personalización

  • Notificaciones — Preferencias de tiempo de espera de las notificaciones (éxito, información, advertencia, error — cada una configurable de forma independiente)
  • Mandos — Gestiona la biblioteca de mandos, define mandos predeterminados por sistema, añade mandos personalizados. Los mandos predeterminados sobrescriben los valores obtenidos por scraping/IA durante la obtención de metadatos.
  • Logotipos — Personalización de logotipos de sistema — importa logotipos de sistema o restablécelos a los predeterminados

Pestaña Sistema

  • Mantenimiento — Optimización de la base de datos (VACUUM/ANALYZE), limpieza de medios huérfanos, limpieza de ROMs ausentes, borrado de datos scrapeados, borrado de importaciones de CLZ, estandarización masiva de imágenes
  • Servidor — Configuración del servidor (host, puerto, modo de depuración)
  • Registro — Ajustes del nivel de registro para distintas categorías
  • Solución de problemas — Limpiar scraping masivo atascado, limpiar cola de sincronización de RA, limpiar actualización de PSN, limpiar generación del museo, reiniciar el servidor
Consejo: Los scrapers desactivados no provocan advertencias de «API desconectada» en el Panel. Si no usas un scraper, desactívalo en Ajustes → Scraping → Scraper en lugar de eliminar la clave de API.

Scraping híbrido

RetroDB combina automáticamente datos de varias fuentes para maximizar la cobertura de metadatos:

  • Metadatos de texto de la fuente disponible de mayor prioridad
  • Imágenes y medios de fuentes secundarias cuando la principal no los tiene
  • Relleno automático de lagunas entre scrapers para la máxima cobertura
  • El título de ordenación se genera automáticamente a partir del título del juego durante el scraping

Gestión de medios

  • Los campos de medios (carátula, carátula 3D, capturas, fanart, vídeo, manual) nunca se reemplazan durante el scraping normal — solo se rellenan cuando están vacíos
  • Las capturas siempre se añaden, nunca se reemplazan
  • Para volver a descargar medios, borra primero la imagen existente en el modal de edición y luego vuelve a hacer scraping
  • El modo Re-scraping completo anula esto y reemplaza todo
  • Las referencias de medios obsoletas (archivo eliminado pero nombre de archivo todavía en la BD) se borran automáticamente antes del scraping para poder descargar medios nuevos
  • Las imágenes descargadas se estandarizan automáticamente a los tamaños objetivo (consulta Estandarización de imágenes)

Prioridad de los scrapers

Configura qué scrapers se ejecutan primero y cuáles están activados/desactivados en Ajustes → Scraping → Scraper. Arrastra y suelta para reordenar la prioridad. Los scrapers desactivados no se intentarán durante el scraping y no provocarán advertencias de estado de API en el Panel.

Límite de tasa

Cada scraper tiene límites de tasa configurables para evitar la limitación de las API. Los retardos predeterminados están definidos de forma conservadora. Reduce los retardos bajo tu propia responsabilidad — superar los límites de tasa de las API puede provocar bloqueos temporales del servicio correspondiente.

Scraping masivo

Iniciar un scraping masivo

  1. Ve a cualquier página de Sistema o de Biblioteca
  2. Haz clic en «Seleccionar» para entrar en el modo de selección
  3. Selecciona juegos individualmente o usa la selección rápida:
    • Seleccionar todo — Todos los juegos visibles
    • Seleccionar sin scrapear — Solo los juegos sin metadatos
  4. Elige el modo: Rellenar lo que falta o Re-scraping completo
  5. Haz clic en «Hacer scraping de la selección»

Controles

  • Pausar / Reanudar — Pausa o continúa el scraping
  • Cancelar — Detener por completo
  • Segundo plano — Minimiza y sigue navegando mientras el scraping se ejecuta

Notificación emergente

Cuando se ejecuta en segundo plano, una notificación persistente muestra el progreso en todas las páginas:

  • Nombre del juego actual, recuento de progreso y estadísticas de resultado (éxito, fallidos, omitidos)
  • Controles de pausa/cancelación disponibles desde cualquier página
  • Haz clic en la notificación para volver al modal de scraping

Sistema de cola

Varios scrapings masivos se ponen en cola automáticamente:

  • Inicia un nuevo scraping mientras hay uno en marcha — se pone en cola
  • La cola se muestra en la notificación con el recuento de tareas pendientes
  • Las tareas se procesan automáticamente en orden
  • Usa el Gestor de colas para ver, reordenar o cancelar las tareas en cola

Opciones de scraping

  • Rellenar solo lo que falta — Rellena solo los campos de metadatos vacíos, conservando los datos existentes
  • Re-scraping completo — Reemplaza todos los campos, incluidos los medios (descarga imágenes y vídeos nuevos)
  • Comprobar RetroAchievements — Comprueba también la existencia de conjuntos de logros de RetroAchievements durante el scraping

Recuperación de tareas

Si RetroDB se reinicia mientras se ejecuta una tarea, las tareas interrumpidas aparecen en un banner de recuperación en el Panel. Haz clic en «Reanudar» en tareas individuales o en «Reanudar todo» para reiniciarlas. La notificación de progreso aparece de inmediato tras reanudar.

Relleno con IA

Qué hace

El Relleno con IA usa un modelo de lenguaje grande (Gemini, OpenAI o Claude) para rellenar de forma inteligente los metadatos de juego que faltan o están incompletos. Es más inteligente que el scraping normal porque usa conocimiento contextual sobre el juego para aportar datos precisos que los scrapers quizá no tengan.

Cómo usarlo

  1. Abre el modal de detalles de un juego (o la página de detalles completa)
  2. Haz clic en «Relleno con IA» (requiere una clave de API de IA configurada en Ajustes)
  3. La IA analiza el título del juego y el sistema, y luego rellena los campos que faltan
  4. Revisa los resultados — los cambios se guardan automáticamente

Qué puede aportar el Relleno con IA

  • Género, descripción, desarrollador, distribuidor, fecha de lanzamiento
  • Jugadores, modos de juego (Un jugador, Multijugador, Cooperativo, etc.)
  • Información de campaña y estructura del juego
  • Los 8 sistemas de clasificación por edad (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Región, franquicia, juegos similares
  • Compatibilidad con mandos, tipo de guardado
  • Perspectiva (Primera persona, Cenital, Lateral, etc.), dimensión (2D, 3D)
  • Información de edición, puntuaciones de crítica y de usuarios

Lógica de relleno inteligente

  • Los campos vacíos siempre se rellenan
  • Los datos del usuario existentes nunca se sobrescriben
  • Los juegos similares siempre se actualizan (los datos de la IA son más fiables para este campo)
  • Clasificaciones cruzadas — Si se conoce un sistema de clasificación, las clasificaciones vacías de otros sistemas se rellenan automáticamente mediante la correspondencia cruzada por nivel de madurez
  • El título de ordenación se genera automáticamente al rellenar
  • El campo Jugadores normaliza los rangos (p. ej. «1-4» pasa a 4)

Normalización de géneros

El Relleno con IA usa formas canónicas de género con nombres separados por guiones:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Requisitos

Debe haber al menos una clave de API de un proveedor de IA configurada en Ajustes → Scraping → Claves de API. El nivel de modelo más económico (Gemini Flash Lite, GPT-4o Mini o Claude Haiku) funciona bien para los metadatos.

Autenticación de PSN (cookie NPSSO)

PSN usa una cookie de autenticación especial llamada token NPSSO. Para obtenerla:

  1. Abre un navegador web e inicia sesión en store.playstation.com
  2. Una vez con la sesión iniciada, ve a: https://ca.account.sony.com/api/v1/ssocookie
  3. La página mostrará un JSON que contiene tu token NPSSO
  4. Copia el valor npsso y pégalo en Ajustes → Cuenta → PSN

Una vez autenticado, los tokens se almacenan en caché localmente en data/psn_tokens.json y se renuevan automáticamente. Los tokens en caché siguen siendo válidos durante unos 2 meses.

Trofeos de coleccionista

Qué es

Un sistema de gamificación que otorga trofeos según los hitos de tu colección. A medida que añades juegos, haces scraping de metadatos y completas juegos, los trofeos se desbloquean automáticamente.

Niveles de trofeo

NivelEjemplos
BronceAñadir el primer juego, alcanzar los 10 juegos, primer scraping, 5 sistemas, primera finalización
Plata100 juegos, 50 scrapeados, 10 sistemas, 10 finalizaciones, 500 juegos
Oro1000 juegos, 100% de cobertura de metadatos, 20 sistemas, 50 finalizaciones
Platino5000 juegos, 100 finalizaciones, más de 30 sistemas

Cómo funciona

  • El progreso se sigue automáticamente según las estadísticas de tu biblioteca
  • Visita la página de Trofeos de coleccionista para ver tu progreso hacia cada trofeo
  • Haz clic en «Actualizar» para actualizar el progreso tras hacer cambios
  • Los trofeos obtenidos se muestran con su fecha de desbloqueo
  • Las barras de progreso muestran cuánto te falta para el siguiente hito

Museo

Qué es

Una enciclopedia interactiva de sistemas de videojuegos organizada por generación. Aprende sobre la historia, las especificaciones y los juegos destacados de cada plataforma de tu colección.

Página principal

La página principal del Museo muestra una línea temporal de sistemas de videojuegos agrupados por generación (1.ª–9.ª gen, Portátiles, Arcade, Ordenadores). Cada tarjeta de sistema muestra la imagen del hardware y el recuento de juegos de tu biblioteca.

Páginas de detalle del sistema

Haz clic en cualquier sistema para ver su página de museo, que incluye:

  • Imagen del hardware — Foto de la consola/sistema
  • Especificaciones técnicas — CPU, GPU, RAM, resolución, tipo de soporte
  • Historia — Relato generado por IA sobre el desarrollo, lanzamiento y legado del sistema
  • Top 10 de juegos — Los títulos más destacados del sistema (a partir de puntuaciones de la crítica y sugerencias de la IA)
  • Galería de mandos — Imágenes de los mandos del sistema con descripciones

Generación de contenido con IA

El contenido del Museo se genera con IA (Gemini, OpenAI o Claude). Puedes generar contenido para:

  • Un solo sistema — Haz clic en «Generar» en la página de museo de cualquier sistema
  • Generación masiva — Genera contenido para todos los sistemas de una vez desde la página principal (se ejecuta como tarea en segundo plano con progreso en notificación)

Imágenes de mandos

Las imágenes de mandos se pueden añadir mediante:

  • Búsqueda de imágenes — Busca fotos de mandos con Bing Image Search. Los resultados se ordenan por relevancia (nombre del mando + fabricante + variaciones del sistema).
  • Subida manual — Sube tus propias imágenes de mandos
  • Eliminación de fondo — Elimina automáticamente los fondos con IA local (biblioteca rembg) para obtener imágenes de mandos transparentes sobre cualquier fondo
  • Propagación de imágenes — Cuando se encuentra la imagen de un mando, se comparte automáticamente con el mismo mando en otros sistemas (mandos hermanos)
  • Obtención masiva — Obtén imágenes para todos los mandos de un sistema de una vez

Todas las imágenes de mandos se estandarizan al tamaño objetivo y se guardan en formato WebP.

Consejo: Se requiere una clave de API de IA para la generación de contenido. El Museo usa el mismo proveedor de IA configurado en Ajustes → Scraping → Claves de API.

Informes de ROM

Qué hace

Valida los nombres de archivo de las ROM frente a las convenciones de nomenclatura estándar e identifica posibles problemas. Accede mediante Informes de ROM en la barra lateral.

Tipos de informe

PestañaQué comprueba
Nombres no estándarROMs con nombres de archivo que no cumplen las convenciones de nomenclatura. Muestra el nombre de archivo actual, los problemas detectados y el nombre corregido sugerido.
Discrepancias de nombreROMs cuyo nombre de archivo no coincide con el título de los metadatos scrapeados. Muestra el nombre de archivo actual frente al título scrapeado, la región, el año y el desarrollador.

Qué se comprueba

  • Caracteres no válidos en los nombres de archivo (: ? * / " < > | \)
  • Etiquetas de región ausentes o incorrectas (p. ej. (USA), (Europe))
  • Etiquetas de año ausentes
  • Discrepancias entre el nombre de archivo y el título de la base de datos

Los informes se pueden ordenar por sistema, nombre de archivo y tipo de problema. Úsalos para mantener tu biblioteca de ROMs organizada y con nombres coherentes.

Herramientas de ROM

Accede al centro de Herramientas de ROM desde la barra lateral. Cada herramienta se ejecuta como tarea en segundo plano con actualizaciones de progreso en tiempo real, compatibilidad con pausa/reanudación y registro.

Escáner de archivos comprimidos

Extrae archivos comprimidos de ROM (ZIP, 7Z, RAR) con opciones para:

  • Escaneo recursivo de subdirectorios
  • Eliminación de archivos no deseados tras la extracción
  • Generación automática de listas de reproducción M3U para juegos de varios discos

Requiere: 7z o unzip

Conversor de CHD

Convierte imágenes de disco (ISO, BIN/CUE, GDI) al formato CHD comprimido. Ahorra mucho almacenamiento manteniendo la compatibilidad total con los emuladores.

Requiere: chdman (de mame-tools)

Verificación de CHD

Verifica la integridad de los archivos CHD con validación por hash. Identifica conversiones corruptas o incompletas.

Requiere: chdman

Buscador de duplicados

Encuentra ROMs duplicadas por hash o nombre de archivo, con opciones para priorizar por etiquetas de región.

Sin dependencias externas

Organizador de multidisco

Organiza los juegos de varios discos en subdirectorios y genera listas de reproducción M3U para los emuladores que las admiten. Útil para sistemas como PlayStation y Saturn.

Sin dependencias externas

Deduplicación de capturas

Encuentra y elimina capturas duplicadas en toda tu biblioteca de juegos para liberar espacio de almacenamiento.

  • Hash exacto (MD5) — Identifica solo los archivos idénticos
  • Similitud visual — Comparación por hash perceptual con umbral configurable (1–20, menor = coincidencia más estricta)

Escanea de forma progresiva con estadísticas en vivo que muestran juegos escaneados, recuento de duplicados y espacio recuperable. Los resultados se agrupan por juego y sistema. Puedes seleccionar qué archivo conservar en cada grupo de duplicados, o usar «Seleccionar el más grande» para conservar automáticamente la versión de mayor resolución.

Sin dependencias externas

Redimensionador de imágenes

Estandariza los medios de los juegos a tamaños objetivo coherentes. Consulta Estandarización de imágenes para todos los detalles.

Sin dependencias externas (escalado con IA basado en Python)

Rellenar títulos alternativos

Recorre la biblioteca en busca de juegos cuyo campo de títulos alternativos esté vacío y lo rellena desde IGDB / TGDB / ScreenScraper. Útil tras importar un catálogo grande o migrar desde otra herramienta que no almacenaba títulos regionales/japoneses/subtítulos. Se ejecuta en segundo plano; el progreso se muestra en la tarjeta de la herramienta.

Requiere al menos una clave de API de scraper (IGDB / TGDB / ScreenScraper)

Búsqueda masiva en HLTB

Ejecuta una búsqueda en HowLongToBeat para cada juego al que le falte una estimación de tiempo de juego. Cada coincidencia se puntúa por título + plataforma + año de lanzamiento; las coincidencias de alta confianza se guardan automáticamente. Cualquiera por debajo del umbral de confianza (o con plataformas en conflicto) se aparta para revisión manual.

Sin dependencias externas (usa el conjunto de datos sin conexión de HLTB incluido)

Revisión pendiente de HLTB

Cola de revisión para las coincidencias ambiguas surgidas de la Búsqueda masiva en HLTB. Cada fila pendiente muestra el juego de origen junto al candidato de HLTB (título, plataforma, año de lanzamiento, confianza). Aprueba, rechaza o elige una coincidencia distinta en cada fila. La tarjeta de la herramienta de revisión solo aparece en el centro de Herramientas de ROM cuando hay al menos una coincidencia pendiente.

  • Pestañas de filtro para coincidencias de baja confianza, de título alternativo y de discrepancia de plataforma.
  • Aprobar escribe la estimación de tiempo de juego; Rechazar descarta el candidato y mantiene limpia la cola de búsqueda.

Ajustes de herramientas

Configura rutas, ubicaciones de herramientas, tipos de archivo comprimido y preferencias compartidas entre todas las herramientas de ROM.

Consejo: Todas las herramientas de ROM admiten pausa/reanudación y se ejecutan en segundo plano. El progreso y los resultados se registran y se pueden ver en el Visor de registros. El estado de la herramienta (disponible frente a requiere instalación) se muestra en cada tarjeta de herramienta.

Normalización

Qué hace

Normaliza los valores de género y modo de juego a formas canónicas coherentes. Esto ocurre automáticamente durante el scraping y el Relleno con IA, y también se puede aplicar manualmente a tu biblioteca existente.

Por qué importa

Distintos scrapers usan nombres diferentes para lo mismo. La normalización garantiza la coherencia en toda tu biblioteca:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Reglas personalizadas

Puedes añadir reglas de normalización personalizadas en Ajustes → Datos → Normalización. Las reglas personalizadas anulan las asignaciones integradas, lo que te permite definir tus propios nombres preferidos de género y modo. Las reglas se almacenan en la base de datos.

Vista previa y aplicación

Antes de aplicar la normalización, puedes previsualizar qué juegos se verán afectados y qué cambios se harán. Esto te permite revisar antes de confirmar los cambios en tu biblioteca.

Estandarización de imágenes

Qué hace

Estandariza todos los medios de los juegos a tamaños objetivo coherentes para un aspecto uniforme en toda tu biblioteca. Las imágenes que están dentro del 80–120% del tamaño objetivo se omiten.

Cómo funciona

  • Escalado hacia arriba — Las imágenes más pequeñas que el tamaño objetivo se escalan con Real-ESRGAN x4 (superresolución por IA mediante ONNX Runtime) para un agrandamiento de alta calidad, y luego se redimensionan al tamaño objetivo exacto
  • Escalado hacia abajo — Las imágenes más grandes que el tamaño objetivo se reducen con filtrado Lanczos para resultados nítidos
  • Banda de umbral — Las imágenes dentro del 80–120% del objetivo se dejan intactas para evitar reprocesamientos innecesarios

Tamaños objetivo

Tipo de medioObjetivoMétodo
Carátula1080px de altoEl ancho se escala proporcionalmente
Carátula 3D1080px de altoEl ancho se escala proporcionalmente (conserva la transparencia)
Capturas1080px de altoEl ancho se escala proporcionalmente
Mandos1280px en el lado más largoConserva la transparencia (RGBA)
Hardware1280px en el lado más largoConserva la transparencia (RGBA)
FanartOmitidoNo se estandariza (se deja en el tamaño original)

Cómo ejecutarlo

  1. Ve a Ajustes → Sistema → Mantenimiento o a Herramientas de ROM → Redimensionador de imágenes
  2. Haz clic en «Iniciar» para comenzar la estandarización masiva
  3. La tarea se ejecuta en segundo plano con progreso en notificación que muestra el archivo actual y las estadísticas
  4. Las imágenes también se autoestandarizan durante el scraping (las nuevas descargas se estandarizan de inmediato)

Compatibilidad de hardware

El modelo Real-ESRGAN detecta automáticamente tu hardware y usa el mejor proveedor disponible:

  • CUDA — Aceleración por GPU de NVIDIA
  • ROCm — Aceleración por GPU de AMD (con anulación automática de la versión gfx para la serie RX 6000)
  • CoreML — Aceleración de Apple Silicon
  • CPU — Reserva para sistemas sin compatibilidad con GPU

El archivo del modelo ONNX se descarga automáticamente de Hugging Face en el primer uso y se almacena en caché localmente.

Mantenimiento

Las operaciones de mantenimiento están disponibles en Ajustes → Sistema → Mantenimiento. Estas ayudan a mantener tu biblioteca limpia y optimizada.

Escaneo de la biblioteca

  • Escanear biblioteca — Escanea tus directorios de ROM en busca de juegos nuevos. Detecta carpetas de sistema y tipos de archivo admitidos usando las listas de extensiones de systeminfo.txt de ES-DE. También disponible desde el Panel.

Operaciones de limpieza

  • Limpiar ROMs ausentes — Elimina las entradas de la base de datos de juegos cuyos archivos de ROM ya no existen en el disco. Útil tras reorganizar o eliminar archivos de ROM.
  • Limpieza de medios huérfanos — Encuentra y elimina archivos de imagen en el disco (carátulas, capturas, fanart) que no tienen una referencia correspondiente en la base de datos. Previsualiza antes de eliminar para confirmar.
  • Borrar datos scrapeados — Elimina todos los metadatos scrapeados de los juegos manteniendo las entradas de los archivos de ROM. Útil para empezar el scraping de cero. La vista previa muestra los juegos afectados antes de la ejecución.
  • Borrar importaciones de CLZ — Elimina todos los registros de importación de CLZ Games (entradas solo de metadatos, sin archivos de ROM).

Optimización de la base de datos

  • Optimizar la base de datos — Ejecuta VACUUM y ANALYZE de SQLite para recuperar almacenamiento de los registros eliminados y actualizar las estadísticas del planificador de consultas. Recomendado tras grandes eliminaciones u operaciones de limpieza.

Copia de seguridad y restauración

Crear copias de seguridad

  1. Ve a Ajustes → Biblioteca → Copia de seguridad
  2. Haz clic en «Crear copia de seguridad»
  3. La copia de seguridad se guarda en la carpeta backups/ con un nombre de archivo con marca de tiempo

Qué se respalda

La copia de seguridad incluye toda la base de datos SQLite (roms.db), que contiene todos los metadatos de los juegos, las cuentas de usuario, los ajustes, los datos de trofeos, el progreso de logros, las etiquetas, las listas y los elementos de la lista de deseos.

Qué NO se respalda

Los archivos de medios (carátulas, capturas, fanart, vídeos, manuales) NO se incluyen en la copia de seguridad de la base de datos, ya que se pueden volver a descargar mediante scraping. Considera respaldar tu directorio static/images/ por separado si tienes subidas personalizadas.

Restaurar

  1. Encuentra la copia de seguridad en la lista de copias
  2. Haz clic en «Restaurar»
  3. Confirma la acción
Advertencia: Restaurar una copia de seguridad sobrescribe tu base de datos actual. ¡Crea una copia de seguridad nueva antes de restaurar una más antigua!

Actualizar RetroDB

Cómo actualizar

  1. Descarga la nueva versión de RetroDB
  2. Respalda estos archivos (contienen tus datos personales):
    • config.py (tus rutas y claves de API)
    • data/settings.json (tus preferencias de interfaz)
    • data/scraper_settings.json (tu configuración de scrapers)
    • data/rom_tools_config.json (tus preferencias de herramientas de ROM)
    • data/psn_tokens.json (tus tokens de autenticación de PSN)
    • data/xbox_tokens.json (tus tokens de autenticación de Xbox)
    • carpeta database/ (la base de datos de tu biblioteca de juegos)
  3. Extrae la nueva versión sobre la instalación existente
  4. Ejecuta python install.py para instalar las nuevas dependencias
  5. Reinicia el servidor

Archivos que se pueden sobrescribir con seguridad

Todos los archivos de código fuente (.py, .html, .css, .js) se pueden sobrescribir con seguridad. El instalador no sobrescribirá tus archivos de configuración personales.

Archivos que hay que conservar

Nunca elimines ni sobrescribas: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Migraciones de la base de datos

RetroDB gestiona automáticamente los cambios de esquema de la base de datos en el arranque. Las nuevas columnas y tablas se añaden según sea necesario sin pérdida de datos. No necesitas hacer nada especial — basta con iniciar la nueva versión y la base de datos se actualiza automáticamente.

Solución de problemas

Problemas comunes

«No se encontraron extensiones para el sistema»

La carpeta del sistema necesita un archivo systeminfo.txt de ES-DE válido que defina las extensiones de archivo de ROM admitidas. Asegúrate de que la estructura de tu directorio de ROM cumpla los estándares de ES-DE.

«Error de conexión con la API»

  • Comprueba tu conexión a internet
  • Verifica las claves de API en Ajustes → Scraping → Claves de API
  • Espera si has alcanzado el límite de tasa (algunas API tienen topes diarios/horarios)
  • Comprueba si el scraper está activado (los scrapers desactivados muestran «Desactivado» en el estado del Panel)
  • Consulta el Visor de registros para ver mensajes de error detallados

«Scraping masivo atascado»

Ve a Ajustes → Sistema → Solución de problemas → «Limpiar scraping masivo atascado». Esto reinicia el estado de la tarea sin afectar a tus datos.

«Cola de sincronización de RA atascada»

Limpia la cola de sincronización de RetroAchievements desde Ajustes → Sistema → Solución de problemas.

«Sincronización de PSN atascada»

Limpia la tarea de actualización de PSN desde Ajustes → Sistema → Solución de problemas.

«Generación del museo atascada»

Limpia la tarea de generación del museo desde Ajustes → Sistema → Solución de problemas.

«Errores de base de datos»

  1. Crea una copia de seguridad si es posible (Ajustes → Biblioteca → Copia de seguridad)
  2. Prueba con Ajustes → Sistema → Mantenimiento → Optimizar la base de datos
  3. Comprueba los permisos de archivo del directorio database/
  4. Último recurso: restaura desde una copia de seguridad o elimina la base de datos y vuelve a escanear

«Las imágenes no se guardan»

Comprueba los permisos de escritura en los directorios de medios: chmod -R 755 static/images/

«Página lenta o que no responde»

  • Las colecciones grandes pueden tardar en cargar — el desplazamiento infinito carga en lotes de 100
  • Prueba a recargar la página para liberar la memoria acumulada
  • Revisa la consola del navegador en busca de errores de JavaScript
  • Prueba a cambiar a un tema con un efecto de lienzo más ligero (p. ej. Amber o Elite)
  • Los efectos de lienzo detectan el hardware automáticamente; los dispositivos de gama baja usan la reserva por CPU a una tasa de fotogramas reducida

Banner de «Tareas interrumpidas» en el Panel

Si RetroDB se reinicia mientras se ejecutan tareas, aparecen en un banner de recuperación. Haz clic en «Reanudar» de forma individual o en «Reanudar todo» para reiniciarlas. Haz clic en «Descartar» o «Descartar todo» para quitarlas.

«Error de autenticación de PSN»

  • Los tokens NPSSO caducan — genera uno nuevo desde ca.account.sony.com/api/v1/ssocookie
  • Asegúrate de tener la sesión iniciada en store.playstation.com antes de visitar la URL de la cookie
  • Los tokens en caché en data/psn_tokens.json duran unos 2 meses

«Error de autenticación de Xbox»

  • Vuelve a autenticarte haciendo clic en «Iniciar sesión» en la pestaña Importación de juegos → Xbox
  • Los tokens de Xbox se almacenan en caché en data/xbox_tokens.json y se renuevan automáticamente

«Errores de escalado de imágenes»

  • El modelo ONNX de Real-ESRGAN se descarga en el primer uso — asegúrate de tener acceso a internet
  • La aceleración por GPU requiere controladores compatibles (CUDA para NVIDIA, ROCm para AMD)
  • Si la GPU falla, el sistema recurre automáticamente al procesamiento por CPU

Consejos de rendimiento

  • Mantén tu navegador actualizado para obtener el mejor rendimiento
  • Cierra otras pestañas del navegador al trabajar con colecciones muy grandes
  • Usa los filtros de sistema para reducir los juegos mostrados a la vez
  • Ejecuta Optimizar la base de datos periódicamente tras grandes operaciones (scraping, limpieza, importaciones)
  • Los efectos de tema en lienzo detectan el hardware automáticamente; los dispositivos de gama baja usan la reserva por CPU

Buenas prácticas de seguridad

  • Cambia la contraseña predeterminada — La contraseña de administrador predeterminada (admin) debe cambiarse de inmediato en el primer inicio de sesión. Usa una contraseña fuerte de al menos 8 caracteres.
  • Usa un proxy inverso con HTTPS — RetroDB no proporciona TLS/SSL por sí mismo. Colócalo detrás de un proxy inverso (p. ej. Nginx, Caddy, Traefik) con HTTPS activado para cifrar el tráfico entre los clientes y el servidor.
  • Restringe el acceso de red — Evita exponer RetroDB directamente a la internet pública. Usa una VPN o restringe el acceso a tu red local. Si necesitas acceso remoto, usa un proxy inverso con autenticación.
  • Mantén copias de seguridad periódicas — Usa la función de copia de seguridad integrada en Ajustes para crear copias periódicas de la base de datos. Guarda las copias en una ubicación distinta de la de la aplicación.
  • Mantén RetroDB actualizado — Comprueba si hay nuevas versiones con regularidad. Las correcciones de seguridad y las mejoras se incluyen en las actualizaciones.
  • Protege tus claves de API — Las claves de API se almacenan en data/scraper_settings.json. Asegúrate de que este archivo no sea accesible públicamente. Nunca compartas tu config.py ni tus archivos de tokens.

Funciones de seguridad integradas

  • Hash de contraseñas — Las contraseñas de administrador se cifran con hash mediante PBKDF2 (nunca se almacenan en texto plano)
  • Límite de tasa en el inicio de sesión — Protección contra ataques de fuerza bruta en el punto de inicio de sesión
  • Validación de rutas — Todas las operaciones de archivo usan los ayudantes safe_path y safe_filename para evitar ataques de traversía de directorios
  • Consultas parametrizadas — Todas las consultas a la base de datos usan sentencias parametrizadas para evitar inyecciones SQL
  • Protección XSS — Los diálogos modales usan construcción segura del DOM; la entrada del usuario se escapa
  • Protección contra bombas de descompresión de imágenes — El número máximo de píxeles de imagen está limitado para evitar el agotamiento de memoria por imágenes maliciosas
