Ufakelo

Iimfuno zeSystem

  • Python 3.8+ ene-pip
  • Ibhrawza yewebhu (Chrome, Firefox, Safari, Edge)
  • Inkqubo yokusebenza: Linux, Windows 10/11, okanye macOS

Ufakelo olukhawulezayo

  1. Khupha i-ZIP yeRetroDB uyibeke kwifolda oyikhethileyo
  2. Vula i-terminal/command prompt kuloo folda
  3. Qhuba: python install.py
  4. Qalisa iseva:
    • Linux: ./start.sh
    • Windows: cofa kabini start.bat
    • macOS: cofa kabini start.command
  5. Vula http://localhost:5000 kwibhrawza yakho

Umfaki weGUI

Kwi-Linux, ungaphinda uqhube ./setup.sh ukuze uvule i-wizard yomfaki enemifanekiso. Ijonga i-Python/pip/tkinter ngokuzenzekelayo, emva koko ikukhokela kuwo onke amanyathelo osetho ngelog yenkqubela ebonakalayo.

Into eyenziwa yi-install.py

  • Iqinisekisa ukuba i-Python 3.8+ nepip zikhona
  • Ifaka izixhobo ze-Python ezisuka ku-requirements.txt
  • Idala config.py isuka kumzekelo we-template
  • Idala iifolda ezifunekayo (database, iilog, iifolda zemidiya)
  • Yakha ii-bundle zeCSS neJS

Amanqaku ePlatform

Linux

  • Ivavanywe kwi-Ubuntu, Fedora, openSUSE, kunye ne-Arch Linux
  • Izixhobo zeROM zifuna: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) okanye into elingana nayo kwi-distro yakho
  • Ukuba usebenzisa i-Python yesistim, umfaki uphatha --break-system-packages ngokuzenzekelayo
  • Ukukhawulezisa kwe-GPU nge-ROCm kuyaxhaswa kwii-GPU ze-AMD (ukwandiswa komfanekiso nge-Real-ESRGAN)

Windows

  • Khuphela i-Python kwi-python.org (khetha "Add to PATH" ngexesha lofakelo)
  • Izixhobo zeROM: Faka i-7-Zip, WinRAR, kunye ne-MAME (yechdman)
  • Sebenzisa start.bat ukuvula, okanye uqhube python app.py kwiCommand Prompt

macOS

  • I-Python 3 ingafakwa nge-Homebrew: brew install python3
  • Izixhobo zeROM: brew install p7zip unrar rom-tools
  • Cofa kabini start.command kwiFinder ukuze uvule
  • Ukukhawulezisa kwe-CoreML kuyaxhaswa kwi-Apple Silicon (ukwandiswa komfanekiso nge-Real-ESRGAN)

Isikhokelo Sosetho lwe-API Key

Ii-API key azinyanzelekanga kodwa zivumela ukuscrapa imetadata etyebileyo neempawu ezongezelelweyo. Zicwangcise kwi-Settings → Scraping → API Keys.

Ii-scraper zeMetadata

TheGamesDB

  1. Yiya kwi-api.thegamesdb.net/key.php
  2. Cela ii-API key (simahla, zamkelwa ngesandla) — uya kufumana i-key ekaWonke-wonke kunye neyabucala
  3. Faka zombini ii-key kwi-Settings → API Keys → TheGamesDB
  4. I-key kaWonke-wonke (umda ngeIP nganye) isetyenziswa njengeyona key iphambili yokuscrapa
  5. I-key yabucala (echiba yenyanga eyabelwanayo) isetyenziswa njenge-fallback ukuba i-public key iyasilela

IGDB (nge-Twitch)

  1. Yenza iakhawunti yeTwitch kwi-twitch.tv
  2. Yiya kwi-dev.twitch.tv/console
  3. Bhalisa i-application entsha (nawuphi na igama, nawuphi na udidi, http://localhost njenge-OAuth redirect)
  4. Khuphela i-Client ID uze wenze i-Client Secret
  5. Faka zombini kwi-Settings → API Keys → IGDB

RAWG.io

  1. Yiya kwi-rawg.io/apidocs
  2. Cofa "Get API Key" uze wenze iakhawunti
  3. Khuphela i-API key yakho kwidashboard
  4. Yifake kwi-Settings → API Keys → RAWG

Inqanaba lasimahla: izicelo ezingama-20,000/ngenyanga

ScreenScraper

  1. Yenza iakhawunti kwi-screenscraper.fr
  2. Faka igama lokusebenzisa nephasiwedi yakho kwi-Settings → API Keys → ScreenScraper

Qaphela: I-ScreenScraper inemida yezicelo yemihla ngokwenqanaba leakhawunti yakho. Ukunikela kwidatabase kwandisa imida yakho.

Iisethingi

Iisethingi zihlelwe kwii-tab ezi-6, nganye inamacandelo amaninzi.

I-tab ye-Account

  • My Profile — Ukufaka/ukususa i-avatar, igama lokubonisa, ulwazi lwendima, utshintsho lwephasiwedi
  • RetroAchievements — Igama lokusebenzisa ne-API key yomanyaniso we-RA
  • PSN — I-cookie ye-NPSSO yokuvumelanisa iindebe ze-PlayStation Network
  • Timezone — Misela i-timezone yakho ukuze imihla ibonakale kuyo yonke i-app
  • Users — Ulawulo lwabasebenzisi: yongeza, hlela, cima abasebenzisi uze wabele iindima (kwi-admin kuphela)

I-tab yeLibrary

  • Paths — Indlela yelayibrari yeROM, indawo ye-database
  • Display — Ukhetho lwethima, isitayela se-boxart (2D/3D), inkqubo yekhetho leminyaka yobudala, izinto ngephepha ngalinye
  • ROM Naming — Ukubekwa kwe-article (u-"The" ophambili/ongasemva), uluhlu lwekhetho lengingqi, ingingqi emiselweyo, iindlela zokunika amagama
  • Backup — Yenza uze ubuyisele ii-backup ze-database

I-tab yeScraping

  • ES-DE — Iindlela zegamelist neemidiya zeES-DE zokungenisa idata yasekhaya
  • Scraper — Vula/cima ii-scraper ngazinye, ukumisela ukubaluleka ngokutsala-ubeke, iisethingi zomda wexesha nge-scraper nganye
  • API Keys — Zonke iziqinisekiso ze-scraper (TGDB, IGDB, RAWG, ScreenScraper), ukhetho lwe-provider ye-AI nokhetho lwemodeli (Gemini, OpenAI, Claude)

I-tab yeData

  • Stats — Ushwankathelo lweenkcukacha zelayibrari (imidlalo iyonke, iisistim, ukusetyenziswa kwendawo yokugcina)
  • Trophies — Uqwalaselo lwendlela yeendebe zeRPCS3 lokuscana iindebe zePS3 zasekhaya
  • Dropdowns — Yenza ngokwakho ikhetho lengingqi namanye amaxabiso e-dropdown asetyenziswa kuyo yonke i-app
  • Normalization — Imithetho ye-normalization ye-genre ne-modes — yongeza ii-mapping ezikhethiweyo ukwenza ithiwe kalinganiso i-output ye-scraper

I-tab yeCustomization

  • Notifications — Ukhetho lwexesha lesaziso (impumelelo, ulwazi, isilumkiso, impazamo — nganye ingacwangciswa ngokuzimeleyo)
  • Controllers — Lawula ilayibrari ye-controller, misela ii-controller ezimiselweyo ngesistim, yongeza ii-controller ezikhethiweyo. Ii-controller ezimiselweyo zibhala phezu kwamaxabiso escrapiweyo/e-AI ngexesha lokulanda imetadata.

AI Fill

Into eyenzayo

I-AI Fill isebenzisa i-large language model (Gemini, OpenAI, okanye Claude) ukuzalisa ngobulumko imetadata yomdlalo elahlekileyo okanye engaphelelanga. Ikrelekrele kunokuscrapa okuqhelekileyo kuba isebenzisa ulwazi lomxholo malunga nomdlalo ukunika idata echanekileyo ii-scraper ezingenokuba nayo.

Indlela yokuyisebenzisa

  1. Vula i-detail modal yomdlalo (okanye iphepha eliphelele leenkcukacha)

  3. I-AI ihlalutya isihloko somdlalo nesistim, emva koko izalise ii-field ezilahlekileyo
  4. Jonga iziphumo — utshintsho lugcinwa ngokuzenzekelayo

Into enokuyinika i-AI Fill

  • Genre, inkcazo, umphuhlisi, umpapashi, umhla wokukhutshwa
  • Abadlali, iimowudi zokudlala (Single-Player, Multi-Player, Co-op, njalo-njalo)
  • Ulwazi lwephulo nesakhelo somdlalo
  • Zonke ii-system ze-age rating ezi-8 (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Ingingqi, i-franchise, imidlalo efanayo
  • Inkxaso ye-controller, uhlobo lokugcina
  • I-perspective (First-Person, Top-Down, Side-Scroller, njalo-njalo), i-dimension (2D, 3D)
  • Ulwazi lohlobo, izikali zabahlalutyi nabasebenzisi

I-Smart Fill Logic

  • Ii-field ezingenanto zihlala zizaliswa
  • Idata ekhoyo yomsebenzisi ayize ibhalwe phezu kwayo
  • Imidlalo efanayo ihlala ihlaziywa (idata ye-AI ithembeke ngakumbi kule field)
  • Izikali ezidityaniswe ngokunqamlezayo — Ukuba enye i-rating system iyaziwa, izikali ezingenanto kwezinye iisistim zizaliswa ngokuzenzekelayo ngokusebenzisa ukudityaniswa ngamanqanaba okuvuthwa
  • Isihloko sokuhlela senziwa ngokuzenzekelayo xa sizaliswa
  • I-field yabadlali ithi kalinganiso i-range (umzekelo "1-4" iba ngu-4)

I-Genre Normalization
