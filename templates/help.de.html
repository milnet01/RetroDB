Installation

Systemanforderungen

  • Python 3.8+ mit pip
  • Webbrowser (Chrome, Firefox, Safari, Edge)
  • Betriebssystem: Linux, Windows 10/11 oder macOS

Schnellinstallation

  1. Entpacken Sie das RetroDB-ZIP in ein Verzeichnis Ihrer Wahl
  2. Öffnen Sie ein Terminal bzw. eine Eingabeaufforderung in diesem Verzeichnis
  3. Führen Sie aus: python install.py
  4. Starten Sie den Server:
    • Linux: ./start.sh
    • Windows: start.bat doppelklicken
    • macOS: start.command doppelklicken
  5. Öffnen Sie http://localhost:5000 in Ihrem Browser

Grafischer Installer

Unter Linux können Sie auch ./setup.sh ausführen, um einen grafischen Installationsassistenten zu starten. Er prüft automatisch auf Python/pip/tkinter und führt Sie anschließend mit einem visuellen Fortschrittsprotokoll durch jeden Einrichtungsschritt.

Was install.py tut

  • Überprüft, ob Python 3.8+ und pip verfügbar sind
  • Installiert die Python-Abhängigkeiten aus requirements.txt
  • Erstellt config.py aus der Beispielvorlage
  • Erstellt die erforderlichen Verzeichnisse (Datenbank, Protokolle, Medienordner)
  • Baut die CSS- und JS-Bundles

Erste Schritte

Erstmalige Einrichtung

Beim ersten Start zeigt RetroDB einen Einrichtungsassistenten, der Sie durch folgende Schritte führt:

  1. Administrator-Konto — Erstellen Sie Ihren Benutzernamen und Ihr Passwort
  2. Bibliothekspfad — Legen Sie Ihr ROM-Verzeichnis fest
  3. ES-DE-Integration — Verknüpfen Sie optional ES-DE-Gamelists und -Medien
  4. API-Schlüssel — Fügen Sie optional Scraper-API-Schlüssel hinzu

Klicken Sie nach Abschluss des Assistenten im Dashboard auf „Bibliothek scannen“, um Ihre ROMs zu erfassen.

Schnellstart-Ablauf

  1. Scannen Sie Ihre Bibliothek, um ROMs zu importieren
  2. Durchsuchen Sie nach System oder zeigen Sie alle Spiele in der Bibliothek an
  3. Scrapen Sie Metadaten einzeln oder per Massen-Scraping
  4. Organisieren Sie mit Tags, Listen und Wunschliste
  5. Verfolgen Sie Ihren Fortschritt mit Abschlussstatus und Achievements

Struktur der ROM-Bibliothek

RetroDB erwartet, dass Ihre ROMs innerhalb Ihres Bibliothekspfads in Systemordnern organisiert sind:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Jeder Systemordner sollte eine ES-DE-Datei systeminfo.txt enthalten, die die unterstützten Dateiendungen festlegt. RetroDB liest diese beim Scannen aus, um zu erkennen, welche Dateien für jedes System gültige ROMs sind.

Tipp: Wenn Sie bereits mit ES-DE gescrapt haben, kann RetroDB diese Daten importieren! Konfigurieren Sie die ES-DE-Pfade unter Einstellungen → ES-DE-Integration oder während des Einrichtungsassistenten.

Plattform-Hinweise

Linux

  • Getestet unter Ubuntu, Fedora, openSUSE und Arch Linux
  • ROM-Werkzeuge benötigen: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) oder das Äquivalent für Ihre Distribution
  • Bei Verwendung von System-Python kümmert sich der Installer automatisch um --break-system-packages
  • ROCm-GPU-Beschleunigung wird für AMD-GPUs unterstützt (Real-ESRGAN-Bildhochskalierung)

Windows

  • Laden Sie Python von python.org herunter (haken Sie bei der Installation „Add to PATH“ an)
  • ROM-Werkzeuge: Installieren Sie 7-Zip, WinRAR und MAME (für chdman)
  • Verwenden Sie start.bat zum Starten oder führen Sie python app.py in der Eingabeaufforderung aus

macOS

  • Python 3 kann über Homebrew installiert werden: brew install python3
  • ROM-Werkzeuge: brew install p7zip unrar rom-tools
  • Doppelklicken Sie auf start.command im Finder, um zu starten
  • CoreML-Beschleunigung wird für Apple Silicon unterstützt (Real-ESRGAN-Bildhochskalierung)

Anleitung zur Einrichtung von API-Schlüsseln

API-Schlüssel sind optional, ermöglichen aber umfangreiches Metadaten-Scraping und zusätzliche Funktionen. Konfigurieren Sie sie unter Einstellungen → Scraping → API-Schlüssel.

Metadaten-Scraper

TheGamesDB

  1. Gehen Sie zu api.thegamesdb.net/key.php
  2. Fordern Sie API-Schlüssel an (kostenlos, manuell freigegeben) — Sie erhalten einen öffentlichen und einen privaten Schlüssel
  3. Geben Sie beide Schlüssel unter Einstellungen → API-Schlüssel → TheGamesDB ein
  4. Der öffentliche Schlüssel (Ratenbegrenzung pro IP) wird als primärer Schlüssel für das Scraping verwendet
  5. Der private Schlüssel (gemeinsamer Monatspool) wird als Rückfall verwendet, falls der öffentliche Schlüssel fehlschlägt

IGDB (über Twitch)

  1. Erstellen Sie ein Twitch-Konto unter twitch.tv
  2. Gehen Sie zu dev.twitch.tv/console
  3. Registrieren Sie eine neue Anwendung (beliebiger Name, beliebige Kategorie, http://localhost als OAuth-Umleitung)
  4. Kopieren Sie die Client-ID und generieren Sie ein Client-Secret
  5. Geben Sie beides unter Einstellungen → API-Schlüssel → IGDB ein

RAWG.io

  1. Gehen Sie zu rawg.io/apidocs
  2. Klicken Sie auf „Get API Key“ und erstellen Sie ein Konto
  3. Kopieren Sie Ihren API-Schlüssel aus dem Dashboard
  4. Geben Sie ihn unter Einstellungen → API-Schlüssel → RAWG ein

Kostenloses Kontingent: 20.000 Anfragen/Monat

ScreenScraper

  1. Erstellen Sie ein Konto unter screenscraper.fr
  2. Geben Sie Ihren Benutzernamen und Ihr Passwort unter Einstellungen → API-Schlüssel → ScreenScraper ein

Hinweis: ScreenScraper hat tägliche Anfragegrenzen, die von Ihrer Kontostufe abhängen. Ein Beitrag zur Datenbank erhöht Ihre Grenzen.

Achievements & Trophäen

RetroAchievements

  1. Erstellen Sie ein Konto unter retroachievements.org
  2. Gehen Sie in Ihrem Profil zu Einstellungen → API-Schlüssel
  3. Kopieren Sie Ihren API-Schlüssel
  4. Geben Sie Ihren Benutzernamen und API-Schlüssel unter Einstellungen → Konto → RetroAchievements ein

Steam Web API

  1. Gehen Sie zu steamcommunity.com/dev/apikey
  2. Registrieren Sie sich für einen Steam-Web-API-Schlüssel (erfordert ein Steam-Konto)
  3. Geben Sie Ihren API-Schlüssel und Ihre Steam-ID (oder Vanity-URL) in den Einstellungen ein

Wird für den Steam-Bibliotheksimport und die Achievement-Verfolgung verwendet.

Xbox Live

Einstellungen

Die Einstellungen sind in 6 Registerkarten gegliedert, jede mit mehreren Unterabschnitten.

Registerkarte „Konto“

  • Mein Profil — Avatar hochladen/entfernen, Anzeigename, Rolleninfo, Passwortänderung
  • RetroAchievements — Benutzername und API-Schlüssel für die RA-Integration
  • PSN — NPSSO-Cookie für die PlayStation-Network-Trophäensynchronisierung
  • Zeitzone — Legen Sie Ihre Zeitzone für die Datumsanzeige in der gesamten App fest
  • Benutzer — Benutzerverwaltung: Benutzer hinzufügen, bearbeiten, löschen und Rollen zuweisen (nur Administrator)

Registerkarte „Bibliothek“

  • Pfade — ROM-Bibliothekspfad, Datenbankspeicherort
  • Anzeige — Designauswahl, Boxart-Stil (2D/3D), bevorzugtes Altersfreigabesystem, Einträge pro Seite
  • ROM-Benennung — Artikelplatzierung (vorangestelltes/nachgestelltes „The“), Liste der Regionsoptionen, Standardregion, Benennungskonventionen
  • Sicherung — Datenbanksicherungen erstellen und wiederherstellen

Registerkarte „Scraping“

  • ES-DE — ES-DE-Gamelist- und -Medienpfade für den lokalen Datenimport
  • Scraper — Einzelne Scraper aktivieren/deaktivieren, Prioritätsreihenfolge per Drag-and-Drop, Ratenbegrenzungseinstellungen pro Scraper
  • API-Schlüssel — Alle Scraper-Zugangsdaten (TGDB, IGDB, RAWG, ScreenScraper), Auswahl des KI-Anbieters und Modellwahl (Gemini, OpenAI, Claude)

Registerkarte „Daten“

  • Statistik — Übersicht der Bibliotheksstatistiken (Spiele gesamt, Systeme, Speicherverbrauch)
  • Trophäen — RPCS3-Trophäenpfadkonfiguration für das lokale Scannen von PS3-Trophäen
  • Dropdowns — Regionsoptionen und andere Dropdown-Werte anpassen, die in der gesamten App verwendet werden
  • Normalisierung — Normalisierungsregeln für Genre und Modi — eigene Zuordnungen hinzufügen, um die Scraper-Ausgabe zu standardisieren

Registerkarte „Anpassung“

  • Benachrichtigungen — Einstellungen für Benachrichtigungs-Timeouts (Erfolg, Info, Warnung, Fehler — jeweils unabhängig konfigurierbar)
  • Controller — Verwalten Sie die Controller-Bibliothek, legen Sie Standard-Controller pro System fest, fügen Sie eigene Controller hinzu. Standard-Controller überschreiben gescrapte/KI-Werte beim Metadatenabruf.
  • Logos — Anpassung der Systemlogos — Systemlogos importieren oder aus den Standardwerten aktualisieren

Registerkarte „System“

  • Wartung — Datenbankoptimierung (VACUUM/ANALYZE), Bereinigung verwaister Medien, fehlende ROMs bereinigen, gescrapte Daten löschen, CLZ-Importe löschen, Massen-Bildstandardisierung
  • Server — Serverkonfiguration (Host, Port, Debug-Modus)
  • Protokollierung — Einstellungen der Protokollstufe für verschiedene Kategorien
  • Fehlerbehebung — Stecken gebliebenes Massen-Scraping bereinigen, RA-Synchronisierungswarteschlange leeren, PSN-Aktualisierung bereinigen, Museumsgenerierung bereinigen, Server neu starten
Tipp: Deaktivierte Scraper lösen keine „API offline“-Warnungen im Dashboard aus. Wenn Sie einen Scraper nicht verwenden, deaktivieren Sie ihn unter Einstellungen → Scraping → Scraper, anstatt den API-Schlüssel zu löschen.

Hybrid-Scraping

RetroDB kombiniert automatisch Daten aus mehreren Quellen, um die Metadatenabdeckung zu maximieren:

  • Textmetadaten aus der verfügbaren Quelle mit der höchsten Priorität
  • Bilder und Medien aus Sekundärquellen, wenn die primäre Quelle sie nicht besitzt
  • Automatisches Schließen von Lücken über Scraper hinweg für maximale Abdeckung
  • Der Sortiertitel wird beim Scraping automatisch aus dem Spieltitel generiert

Medienverwaltung

  • Medienfelder (Boxart, 3D-Boxart, Screenshots, Fanart, Video, Handbuch) werden beim normalen Scraping niemals ersetzt — nur ausgefüllt, wenn sie leer sind
  • Screenshots werden immer angehängt, niemals ersetzt
  • Um Medien erneut herunterzuladen, löschen Sie zuerst das vorhandene Bild im Bearbeitungsdialog und scrapen Sie dann erneut
  • Der Modus Vollständiges Neu-Scrapen überschreibt dies und ersetzt alles
  • Veraltete Medienverweise (Datei gelöscht, aber Dateiname noch in der DB) werden vor dem Scraping automatisch gelöscht, damit frische Medien heruntergeladen werden können
  • Heruntergeladene Bilder werden automatisch auf Zielgrößen standardisiert (siehe Bildstandardisierung)

Scraper-Priorität

Konfigurieren Sie unter Einstellungen → Scraping → Scraper, welche Scraper zuerst laufen und welche aktiviert/deaktiviert sind. Ordnen Sie die Priorität per Drag-and-Drop neu. Deaktivierte Scraper werden beim Scraping nicht versucht und lösen keine API-Statuswarnungen im Dashboard aus.

Ratenbegrenzung

Jeder Scraper hat konfigurierbare Ratenbegrenzungen, um eine API-Drosselung zu verhindern. Die Standardverzögerungen sind konservativ eingestellt. Verringern Sie die Verzögerungen auf eigenes Risiko — das Überschreiten von API-Ratenlimits kann zu vorübergehenden Sperren durch den jeweiligen Dienst führen.

Massen-Scraping

Ein Massen-Scraping starten

  1. Gehen Sie zu einer beliebigen System- oder Bibliotheksseite
  2. Klicken Sie auf „Auswählen“, um in den Auswahlmodus zu wechseln
  3. Wählen Sie Spiele einzeln aus oder verwenden Sie die Schnellauswahl:
    • Alle auswählen — Alle sichtbaren Spiele
    • Nicht gescrapte auswählen — Nur Spiele ohne Metadaten
  4. Wählen Sie einen Modus: Fehlende ausfüllen oder Vollständiges Neu-Scrapen
  5. Klicken Sie auf „Ausgewählte scrapen“

Steuerung

  • Pause / Fortsetzen — Scraping pausieren oder fortsetzen
  • Abbrechen — Vollständig stoppen
  • Hintergrund — Minimieren und weiter stöbern, während das Scraping läuft

Toast-Benachrichtigung

Beim Ausführen im Hintergrund zeigt ein dauerhafter Toast den Fortschritt auf allen Seiten:

  • Aktueller Spielname, Fortschrittszähler und Ergebnisstatistiken (Erfolg, fehlgeschlagen, übersprungen)
  • Pause-/Abbrechen-Steuerung von jeder Seite aus verfügbar
  • Klicken Sie auf den Toast, um zum Scraping-Dialog zurückzukehren

Warteschlangensystem

Mehrere Massen-Scrapings werden automatisch in eine Warteschlange eingereiht:

  • Starten Sie ein neues Scraping, während eines läuft — es wird eingereiht
  • Die Warteschlange wird im Toast mit der Anzahl ausstehender Aufträge angezeigt
  • Aufträge werden automatisch der Reihe nach abgearbeitet
  • Verwenden Sie den Warteschlangenmanager, um eingereihte Aufträge anzuzeigen, neu zu ordnen oder abzubrechen

Scraping-Optionen

  • Nur Fehlende ausfüllen — Nur leere Metadatenfelder ausfüllen und vorhandene Daten erhalten
  • Vollständiges Neu-Scrapen — Alle Felder einschließlich Medien ersetzen (lädt frische Bilder und Videos herunter)
  • RetroAchievements prüfen — Beim Scraping zusätzlich auf RetroAchievements-Achievement-Sets prüfen

Auftragswiederherstellung

Wenn RetroDB neu gestartet wird, während ein Auftrag läuft, erscheinen unterbrochene Aufträge in einem Wiederherstellungsbanner im Dashboard. Klicken Sie bei einzelnen Aufträgen auf „Fortsetzen“ oder auf „Alle fortsetzen“, um sie neu zu starten. Der Fortschritts-Toast erscheint unmittelbar nach dem Fortsetzen.

KI-Ausfüllen

Was es tut

Das KI-Ausfüllen verwendet ein großes Sprachmodell (Gemini, OpenAI oder Claude), um fehlende oder unvollständige Spielmetadaten intelligent auszufüllen. Es ist cleverer als normales Scraping, da es kontextbezogenes Wissen über das Spiel nutzt, um genaue Daten zu liefern, die Scrapern möglicherweise fehlen.

Verwendung

  1. Öffnen Sie den Detaildialog eines Spiels (oder die vollständige Detailseite)
  2. Klicken Sie auf „KI-Ausfüllen“ (erfordert einen in den Einstellungen konfigurierten KI-API-Schlüssel)
  3. Die KI analysiert den Spieltitel und das System und füllt dann fehlende Felder aus
  4. Überprüfen Sie die Ergebnisse — Änderungen werden automatisch gespeichert

Was das KI-Ausfüllen liefern kann

  • Genre, Beschreibung, Entwickler, Publisher, Veröffentlichungsdatum
  • Spieleranzahl, Spielmodi (Einzelspieler, Mehrspieler, Koop usw.)
  • Kampagneninfo und Spielstruktur
  • Alle 8 Altersfreigabesysteme (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Region, Reihe, ähnliche Spiele
  • Controller-Unterstützung, Speichertyp
  • Perspektive (Ego-Perspektive, Vogelperspektive, Side-Scroller usw.), Dimension (2D, 3D)
  • Editionsinfo, Kritiker- und Nutzerbewertungen

Intelligente Ausfülllogik

  • Leere Felder werden immer ausgefüllt
  • Vorhandene Nutzerdaten werden niemals überschrieben
  • Ähnliche Spiele werden immer aktualisiert (KI-Daten sind für dieses Feld zuverlässiger)
  • Übergreifend zugeordnete Bewertungen — Wenn ein Bewertungssystem bekannt ist, werden leere Bewertungen in anderen Systemen automatisch über die übergreifende Zuordnung der Reifegrad-Stufen ausgefüllt
  • Sortiertitel wird beim Ausfüllen automatisch generiert
  • Das Feld Spieleranzahl normalisiert Bereiche (z. B. wird aus „1-4“ die Zahl 4)

Genre-Normalisierung

Das KI-Ausfüllen verwendet kanonische Genreformen mit Bindestrich-Namen:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Voraussetzungen

Mindestens ein KI-Anbieter-API-Schlüssel muss unter Einstellungen → Scraping → API-Schlüssel konfiguriert sein. Die günstigste Modellstufe (Gemini Flash Lite, GPT-4o Mini oder Claude Haiku) eignet sich gut für Metadaten.

Tags

Erstellen Sie eigene, farblich gekennzeichnete Tags, um Ihre Spiele zu organisieren. Tags funktionieren wie Etiketten — jedes Spiel kann mehrere Tags haben, und jedes Tag kann mehrere Spiele enthalten.

  • Bearbeiten oder löschen Sie Tags auf der Tag-Verwaltungsseite

Erstellen Sie kuratierte Spiellisten mit eigener Reihenfolge. Listen sind wie Playlists — Sie bestimmen die genaue Reihenfolge der Spiele.

  • Erstellen Sie Listen mit Name, Beschreibung und Symbol auf der Seite Listen

  • Ordnen Sie Spiele innerhalb einer Liste per Drag-and-Drop neu
  • Sortieren Sie nach eigener Reihenfolge oder alphabetisch

Wunschliste

Verfolgen Sie Spiele, die Sie erwerben möchten, ob physisch oder digital.

  • Fügen Sie Spiele manuell mit Titel, System, Notizen und Priorität (1–5) hinzu
  • Wunschlisteneinträge können mit vorhandenen Bibliotheksspielen verknüpft werden, falls gefunden
  • Sortiert nach Priorität (höchste zuerst), dann nach Hinzufügedatum
Tipp: Verwenden Sie Tags für übergreifende Etiketten (z. B. „Favoriten“, „Couch-Koop“, „Backlog“) und Listen für konkrete kuratierte Sammlungen (z. B. „Top 10 SNES-Spiele“, „Spiele zum Streamen“).

Importieren Sie Spielsammlungen aus externen Quellen. Zugriff über Spielimporte in der Seitenleiste. Alle Importtypen sind auf einer einzigen Seite mit Registerkarten zusammengefasst.

  1. Gehen Sie zur Registerkarte Spielimporte → PSN
  2. Geben Sie Ihren NPSSO-Cookie ein (siehe Trophäen → PSN-Authentifizierung für die Beschaffung)
  3. Klicken Sie auf „Bibliothek abrufen“, um Ihre PSN-Spiele abzurufen
  4. Wählen Sie zu importierende Spiele aus

  • Importierte Spiele können in der Bibliothek über den Quellenfilter gefiltert werden
Tipp: Nach dem Importieren von Spielen aus einer beliebigen Plattform können Sie Metadaten dafür per Massen-Scraping abrufen, genau wie bei ROM-Spielen. Importierte Spiele können außerdem Achievements von ihren jeweiligen Plattformen verfolgen.

Normalisierung

Was es tut

Normalisiert Genre- und Spielmoduswerte auf einheitliche kanonische Formen. Dies geschieht automatisch beim Scraping und KI-Ausfüllen und kann auch manuell auf Ihre vorhandene Bibliothek angewendet werden.

Warum es wichtig ist

Verschiedene Scraper verwenden unterschiedliche Namen für dieselbe Sache. Die Normalisierung sorgt für Einheitlichkeit in Ihrer gesamten Bibliothek:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Eigene Regeln

Sie können eigene Normalisierungsregeln unter Einstellungen → Daten → Normalisierung hinzufügen. Eigene Regeln überschreiben die integrierten Zuordnungen und ermöglichen es Ihnen, Ihre eigenen bevorzugten Genre- und Modusnamen festzulegen. Die Regeln werden in der Datenbank gespeichert.

Vorschau & Anwenden

Vor dem Anwenden der Normalisierung können Sie in einer Vorschau sehen, welche Spiele betroffen sein werden und welche Änderungen vorgenommen werden. So können Sie prüfen, bevor Sie Änderungen an Ihrer Bibliothek festschreiben.

Bildstandardisierung

Was es tut

Standardisiert alle Spielmedien auf einheitliche Zielgrößen für ein einheitliches Erscheinungsbild in Ihrer gesamten Bibliothek. Bilder innerhalb von 80–120 % der Zielgröße werden übersprungen.

So funktioniert es

  • Hochskalierung — Bilder, die kleiner als die Zielgröße sind, werden mit Real-ESRGAN x4 (KI-Superauflösung über ONNX Runtime) für hochwertige Vergrößerung hochskaliert und dann auf die exakte Zielgröße angepasst
  • Herunterskalierung — Bilder, die größer als die Zielgröße sind, werden mit Lanczos-Filterung für scharfe Ergebnisse herunterskaliert
  • Schwellenwertbereich — Bilder innerhalb von 80–120 % der Zielgröße werden unverändert gelassen, um unnötige Neuverarbeitung zu vermeiden

Häufige Probleme

„Keine Dateiendungen für System gefunden“

Der Systemordner benötigt eine gültige ES-DE-Datei systeminfo.txt, die die unterstützten ROM-Dateiendungen festlegt. Stellen Sie sicher, dass Ihre ROM-Verzeichnisstruktur den ES-DE-Standards entspricht.

„API-Verbindung fehlgeschlagen“

  • Prüfen Sie Ihre Internetverbindung
  • Überprüfen Sie die API-Schlüssel unter Einstellungen → Scraping → API-Schlüssel
  • Warten Sie bei Ratenbegrenzung (einige APIs haben tägliche/stündliche Obergrenzen)
  • Prüfen Sie, ob der Scraper aktiviert ist (deaktivierte Scraper zeigen „Deaktiviert“ im Dashboard-Status)
  • Prüfen Sie die Protokollanzeige auf detaillierte Fehlermeldungen

„Massen-Scraping steckt fest“

Gehen Sie zu Einstellungen → System → Fehlerbehebung → „Stecken gebliebenes Massen-Scraping bereinigen“. Dies setzt den Auftragszustand zurück, ohne Ihre Daten zu beeinträchtigen.

„RA-Synchronisierungswarteschlange steckt fest“

Leeren Sie die RetroAchievements-Synchronisierungswarteschlange unter Einstellungen → System → Fehlerbehebung.

„PSN-Synchronisierung steckt fest“

Bereinigen Sie den PSN-Aktualisierungsauftrag unter Einstellungen → System → Fehlerbehebung.

„Museumsgenerierung steckt fest“

Bereinigen Sie den Museumsgenerierungsauftrag unter Einstellungen → System → Fehlerbehebung.

„Datenbankfehler“

  1. Erstellen Sie nach Möglichkeit eine Sicherung (Einstellungen → Bibliothek → Sicherung)
  2. Versuchen Sie Einstellungen → System → Wartung → Datenbank optimieren
  3. Prüfen Sie die Dateiberechtigungen für das Verzeichnis database/
  4. Letzter Ausweg: aus einer Sicherung wiederherstellen oder die Datenbank löschen und neu scannen

„Bilder werden nicht gespeichert“

Prüfen Sie die Schreibberechtigungen für die Medienverzeichnisse: chmod -R 755 static/images/

„Seite langsam oder reagiert nicht“

  • Große Sammlungen brauchen möglicherweise Zeit zum Laden — das unendliche Scrollen lädt in Stapeln von 100
  • Versuchen Sie, die Seite neu zu laden, um angesammelten Speicher freizugeben
  • Prüfen Sie die Browserkonsole auf JavaScript-Fehler
  • Versuchen Sie, zu einem Design mit einem leichteren Canvas-Effekt zu wechseln (z. B. Amber oder Elite)
  • Canvas-Effekte erkennen die Hardware automatisch; leistungsschwächere Geräte nutzen den CPU-Rückfall bei reduzierter Bildrate

Banner „Unterbrochene Aufträge“ im Dashboard

Wenn RetroDB neu startet, während Aufträge laufen, erscheinen sie in einem Wiederherstellungsbanner. Klicken Sie einzeln auf „Fortsetzen“ oder auf „Alle fortsetzen“, um sie neu zu starten. Klicken Sie auf „Verwerfen“ oder „Alle verwerfen“, um sie zu entfernen.

„PSN-Authentifizierung fehlgeschlagen“

  • NPSSO-Tokens laufen ab — generieren Sie einen neuen unter ca.account.sony.com/api/v1/ssocookie
  • Stellen Sie sicher, dass Sie bei store.playstation.com angemeldet sind, bevor Sie die Cookie-URL aufrufen
  • Zwischengespeicherte Tokens in data/psn_tokens.json halten etwa 2 Monate

„Xbox-Authentifizierung fehlgeschlagen“

  • Authentifizieren Sie sich erneut, indem Sie auf der Registerkarte Spielimporte → Xbox auf „Anmelden“ klicken
  • Xbox-Tokens werden in data/xbox_tokens.json zwischengespeichert und automatisch aktualisiert

„Bildhochskalierungsfehler“

  • Das Real-ESRGAN-ONNX-Modell wird bei der ersten Verwendung heruntergeladen — stellen Sie Internetzugang sicher
  • Die GPU-Beschleunigung erfordert kompatible Treiber (CUDA für NVIDIA, ROCm für AMD)
  • Wenn die GPU fehlschlägt, fällt das System automatisch auf die CPU-Verarbeitung zurück

Leistungstipps

  • Halten Sie Ihren Browser für beste Leistung auf dem neuesten Stand
  • Schließen Sie andere Browser-Registerkarten, wenn Sie mit sehr großen Sammlungen arbeiten
  • Verwenden Sie Systemfilter, um die gleichzeitig angezeigten Spiele zu reduzieren
  • Führen Sie nach großen Vorgängen (Scraping, Bereinigung, Importe) regelmäßig „Datenbank optimieren“ aus
  • Canvas-Designeffekte erkennen die Hardware automatisch; leistungsschwächere Geräte nutzen den CPU-Rückfall

Sicherheit & Haftungsausschluss

Bewährte Sicherheitspraktiken

  • Ändern Sie das Standardpasswort — Das Standard-Administratorpasswort (admin) sollte bei der ersten Anmeldung sofort geändert werden. Verwenden Sie ein starkes Passwort mit mindestens 8 Zeichen.
  • Verwenden Sie einen HTTPS-Reverse-Proxy — RetroDB bietet selbst kein TLS/SSL. Platzieren Sie es hinter einem Reverse-Proxy (z. B. Nginx, Caddy, Traefik) mit aktiviertem HTTPS, um den Datenverkehr zwischen Clients und Server zu verschlüsseln.
  • Beschränken Sie den Netzwerkzugriff — Vermeiden Sie es, RetroDB direkt dem öffentlichen Internet auszusetzen. Verwenden Sie ein VPN oder beschränken Sie den Zugriff auf Ihr lokales Netzwerk. Wenn Fernzugriff benötigt wird, verwenden Sie einen Reverse-Proxy mit Authentifizierung.
  • Erstellen Sie regelmäßige Sicherungen — Verwenden Sie die integrierte Sicherungsfunktion unter Einstellungen, um regelmäßige Datenbanksicherungen zu erstellen. Bewahren Sie Sicherungen an einem von der Anwendung getrennten Ort auf.
  • Halten Sie RetroDB aktuell — Prüfen Sie regelmäßig auf neue Versionen. Sicherheitskorrekturen und Verbesserungen sind in Updates enthalten.
  • Schützen Sie Ihre API-Schlüssel — API-Schlüssel werden in data/scraper_settings.json gespeichert. Stellen Sie sicher, dass diese Datei nicht öffentlich zugänglich ist. Teilen Sie niemals Ihre config.py oder Token-Dateien.

Integrierte Sicherheitsfunktionen

  • Passwort-Hashing — Administratorpasswörter werden mit PBKDF2 gehasht (niemals im Klartext gespeichert)
  • Anmelde-Ratenbegrenzung — Brute-Force-Schutz am Anmelde-Endpunkt
  • Pfadvalidierung — Alle Dateioperationen verwenden die Hilfsfunktionen safe_path und safe_filename, um Directory-Traversal-Angriffe zu verhindern
  • Parametrisierte Abfragen — Alle Datenbankabfragen verwenden parametrisierte Anweisungen, um SQL-Injection zu verhindern
  • XSS-Schutz — Dialoge verwenden sichere DOM-Konstruktion; Benutzereingaben werden maskiert
  • Schutz vor Bilddekompressionsbomben — Die maximale Bildpixelanzahl ist begrenzt, um Speichererschöpfung durch bösartige Bilder zu verhindern
