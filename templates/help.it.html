Installazione

Requisiti di sistema

  • Python 3.8+ con pip
  • Browser web (Chrome, Firefox, Safari, Edge)
  • Sistema operativo: Linux, Windows 10/11 o macOS

Installazione rapida

  1. Estrai lo ZIP di RetroDB in una cartella a tua scelta
  2. Apri un terminale o prompt dei comandi in quella cartella
  3. Esegui: python install.py
  4. Avvia il server:
    • Linux: ./start.sh
    • Windows: fai doppio clic su start.bat
    • macOS: fai doppio clic su start.command
  5. Apri http://localhost:5000 nel browser

Installatore grafico

Su Linux puoi anche eseguire ./setup.sh per avviare una procedura guidata di installazione grafica. Verifica automaticamente la presenza di Python/pip/tkinter e ti accompagna in ogni passo della configurazione con un registro di avanzamento visivo.

Cosa fa install.py

  • Verifica che Python 3.8+ e pip siano disponibili
  • Installa le dipendenze Python da requirements.txt
  • Crea config.py dal modello di esempio
  • Crea le cartelle necessarie (database, log, cartelle media)
  • Compila i bundle CSS e JS

Per iniziare

Configurazione iniziale

Al primo avvio, RetroDB mostra una Procedura guidata di configurazione che ti guida attraverso:

  1. Account amministratore — Crea il tuo nome utente e password
  2. Percorso della libreria — Imposta la cartella delle ROM
  3. Integrazione ES-DE — Collega facoltativamente le gamelist e i media di ES-DE
  4. Chiavi API — Aggiungi facoltativamente le chiavi API degli scraper

Al termine della procedura guidata, fai clic su "Scansiona libreria" nella Dashboard per individuare le tue ROM.

Flusso di avvio rapido

  1. Scansiona la tua libreria per importare le ROM
  2. Sfoglia per sistema o visualizza tutti i giochi nella Libreria
  3. Esegui lo scraping dei metadati singolarmente o in blocco
  4. Organizza con tag, liste e lista dei desideri
  5. Monitora i tuoi progressi con stato di completamento e obiettivi

Struttura della libreria ROM

RetroDB si aspetta che le tue ROM siano organizzate in cartelle per sistema all'interno del percorso della libreria:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Ogni cartella di sistema dovrebbe contenere un file ES-DE systeminfo.txt che definisce le estensioni di file supportate. RetroDB lo legge durante la scansione per identificare quali file sono ROM valide per ogni sistema.

Suggerimento: Se hai già eseguito lo scraping con ES-DE, RetroDB può importare quei dati! Configura i percorsi di ES-DE in Impostazioni → Integrazione ES-DE, oppure durante la procedura guidata di configurazione.

Note sulle piattaforme

Linux

  • Testato su Ubuntu, Fedora, openSUSE e Arch Linux
  • Gli Strumenti ROM richiedono: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) o l'equivalente per la tua distribuzione
  • Se usi il Python di sistema, l'installatore gestisce automaticamente --break-system-packages
  • Accelerazione GPU ROCm supportata per le GPU AMD (upscaling delle immagini con Real-ESRGAN)

Windows

  • Scarica Python da python.org (seleziona "Add to PATH" durante l'installazione)
  • Strumenti ROM: installa 7-Zip, WinRAR e MAME (per chdman)
  • Usa start.bat per avviare, oppure esegui python app.py dal Prompt dei comandi

macOS

  • Python 3 può essere installato tramite Homebrew: brew install python3
  • Strumenti ROM: brew install p7zip unrar rom-tools
  • Fai doppio clic su start.command nel Finder per avviare
  • Accelerazione CoreML supportata per Apple Silicon (upscaling delle immagini con Real-ESRGAN)

Come funziona

  • Gli effetti su canvas includono il rilevamento automatico del livello hardware (alto/medio/basso) con accelerazione GPU quando disponibile e fallback su CPU per i dispositivi meno potenti

Ripristino dei processi

Se RetroDB si riavvia mentre dei processi in background sono in esecuzione (scraping in blocco, sincronizzazione RA, ridimensionamento immagini, ecc.), i processi interrotti appaiono in un banner di ripristino. Opzioni:

  • Riprendi — Riavvia un singolo processo interrotto
  • Riprendi tutti — Riavvia tutti i processi interrotti
  • Ignora — Rimuovi un singolo processo dall'elenco di ripristino
  • Ignora tutti — Rimuovi tutti i processi interrotti

Guida alla configurazione delle chiavi API

Le chiavi API sono facoltative ma abilitano lo scraping di metadati ricchi e funzionalità aggiuntive. Configurale in Impostazioni → Scraping → Chiavi API.

Scraper di metadati

TheGamesDB

  1. Vai su api.thegamesdb.net/key.php
  2. Richiedi le chiavi API (gratuite, approvate manualmente) — riceverai una chiave Pubblica e una Privata
  3. Inserisci entrambe le chiavi in Impostazioni → Chiavi API → TheGamesDB
  4. La chiave pubblica (limite di frequenza per IP) viene usata come chiave principale per lo scraping
  5. La chiave privata (pool mensile condiviso) viene usata come riserva se la chiave pubblica fallisce

IGDB (tramite Twitch)

  1. Crea un account Twitch su twitch.tv
  2. Vai su dev.twitch.tv/console
  3. Registra una nuova applicazione (nome qualsiasi, categoria qualsiasi, http://localhost come reindirizzamento OAuth)
  4. Copia il Client ID e genera un Client Secret
  5. Inserisci entrambi in Impostazioni → Chiavi API → IGDB

RAWG.io

  1. Vai su rawg.io/apidocs
  2. Fai clic su "Get API Key" e crea un account
  3. Copia la tua chiave API dalla dashboard
  4. Inseriscila in Impostazioni → Chiavi API → RAWG

Piano gratuito: 20.000 richieste/mese

ScreenScraper

  1. Crea un account su screenscraper.fr
  2. Inserisci il tuo nome utente e password in Impostazioni → Chiavi API → ScreenScraper

Nota: ScreenScraper ha limiti giornalieri di richieste basati sul livello del tuo account. Contribuire al database aumenta i tuoi limiti.

Obiettivi e trofei

RetroAchievements

  1. Crea un account su retroachievements.org
  2. Vai su Impostazioni → Chiavi API nel tuo profilo
  3. Copia la tua chiave API
  4. Inserisci il tuo nome utente e la chiave API in Impostazioni → Account → RetroAchievements

Steam Web API

  1. Vai su steamcommunity.com/dev/apikey
  2. Registrati per una chiave Steam Web API (richiede un account Steam)
  3. Inserisci la tua chiave API e l'ID Steam (o l'URL personalizzato) nelle Impostazioni

Usata per l'importazione della libreria Steam e il monitoraggio degli obiettivi.

Xbox Live

L'autenticazione Xbox usa OAuth2 — non è necessaria alcuna chiave API. Accedi con il tuo account Microsoft direttamente dalla scheda Importazione giochi → Xbox. I token vengono memorizzati nella cache automaticamente e aggiornati quando necessario.

PlayStation Network (PSN)

PSN usa l'autenticazione tramite cookie NPSSO. Consulta la sezione Trofei per le istruzioni di configurazione dettagliate.

Provider AI (per Compilazione AI e Museo)

Impostazioni

Le impostazioni sono organizzate in 6 schede, ciascuna con più sottosezioni.

Scheda Account

  • Il mio profilo — Caricamento/rimozione avatar, nome visualizzato, info sul ruolo, cambio password
  • RetroAchievements — Nome utente e chiave API per l'integrazione RA
  • PSN — Cookie NPSSO per la sincronizzazione dei trofei del PlayStation Network
  • Fuso orario — Imposta il tuo fuso orario per la visualizzazione delle date in tutta l'app
  • Utenti — Gestione utenti: aggiungi, modifica, elimina utenti e assegna ruoli (solo amministratore)

Scheda Libreria

  • Percorsi — Percorso della libreria ROM, posizione del database
  • Visualizzazione — Selezione del tema, stile boxart (2D/3D), sistema di classificazione per età preferito, elementi per pagina
  • Nomenclatura ROM — Posizione dell'articolo ("The" iniziale/finale), elenco delle opzioni di regione, regione predefinita, convenzioni di nomenclatura
  • Backup — Crea e ripristina i backup del database

Scheda Scraping

  • ES-DE — Percorsi delle gamelist e dei media ES-DE per l'importazione di dati locali
  • Scraper — Abilita/disabilita i singoli scraper, ordinamento delle priorità tramite trascinamento, impostazioni dei limiti di frequenza per scraper
  • Chiavi API — Tutte le credenziali degli scraper (TGDB, IGDB, RAWG, ScreenScraper), selezione del provider AI e scelta del modello (Gemini, OpenAI, Claude)

Scheda Dati

  • Statistiche — Panoramica delle statistiche della libreria (giochi totali, sistemi, utilizzo dello spazio)
  • Trofei — Configurazione del percorso dei trofei RPCS3 per la scansione dei trofei PS3 locali
  • Menu a tendina — Personalizza le opzioni di regione e altri valori dei menu a tendina usati in tutta l'app
  • Normalizzazione — Regole di normalizzazione per generi e modalità — aggiungi mappature personalizzate per standardizzare l'output degli scraper

Scheda Personalizzazione

  • Notifiche — Preferenze sul tempo di visualizzazione delle notifiche (successo, info, avviso, errore — ciascuna configurabile indipendentemente)
  • Controller — Gestisci la libreria dei controller, imposta i controller predefiniti per sistema, aggiungi controller personalizzati. I controller predefiniti sovrascrivono i valori scrapati/AI durante il recupero dei metadati.
  • Loghi — Personalizzazione dei loghi di sistema — importa i loghi dei sistemi o ripristina quelli predefiniti

Scheda Sistema

  • Manutenzione — Ottimizzazione del database (VACUUM/ANALYZE), pulizia dei media orfani, pulizia delle ROM mancanti, cancellazione dei dati scrapati, cancellazione delle importazioni CLZ, standardizzazione delle immagini in blocco
  • Server — Configurazione del server (host, porta, modalità di debug)
  • Logging — Impostazioni del livello di log per le diverse categorie
  • Risoluzione dei problemi — Sblocca lo scraping in blocco, svuota la coda di sincronizzazione RA, svuota l'aggiornamento PSN, svuota la generazione del museo, riavvia il server
Suggerimento: Gli scraper disabilitati non attivano gli avvisi "API offline" nella Dashboard. Se non usi uno scraper, disabilitalo in Impostazioni → Scraping → Scraper invece di eliminare la chiave API.

Scraping ibrido

RetroDB combina automaticamente i dati da più fonti per massimizzare la copertura dei metadati:

  • Metadati testuali dalla fonte disponibile a priorità più alta
  • Immagini e media da fonti secondarie quando la principale non li ha
  • Riempimento automatico delle lacune tra gli scraper per la massima copertura
  • Il titolo di ordinamento viene generato automaticamente dal titolo del gioco durante lo scraping

Gestione dei media

  • I campi media (boxart, boxart 3D, screenshot, fanart, video, manuale) non vengono mai sostituiti durante lo scraping normale — vengono solo riempiti quando vuoti
  • Gli screenshot vengono sempre aggiunti, mai sostituiti
  • Per riscaricare i media, cancella prima l'immagine esistente nella finestra modale di modifica, poi riesegui lo scraping
  • La modalità Riscraping completo sovrascrive questo comportamento e sostituisce tutto
  • I riferimenti media obsoleti (file eliminato ma nome file ancora nel DB) vengono cancellati automaticamente prima dello scraping in modo che i nuovi media possano essere scaricati
  • Le immagini scaricate vengono standardizzate automaticamente alle dimensioni target (vedi Standardizzazione delle immagini)

Priorità degli scraper

Configura quali scraper vengono eseguiti per primi e quali sono abilitati/disabilitati in Impostazioni → Scraping → Scraper. Trascina per riordinare la priorità. Gli scraper disabilitati non verranno provati durante lo scraping e non attiveranno avvisi sullo stato delle API nella Dashboard.

Limiti di frequenza

Ogni scraper ha limiti di frequenza configurabili per prevenire il throttling delle API. I ritardi predefiniti sono impostati in modo conservativo. Riduci i ritardi a tuo rischio — superare i limiti di frequenza delle API può comportare ban temporanei dal rispettivo servizio.

Scraping in blocco

Avviare uno scraping in blocco

  1. Vai su qualsiasi pagina Sistema o Libreria
  2. Fai clic su "Seleziona" per entrare in modalità di selezione
  3. Seleziona i giochi singolarmente o usa la selezione rapida:
    • Seleziona tutti — Tutti i giochi visibili
    • Seleziona non scrapati — Solo i giochi senza metadati
  4. Scegli la modalità: Riempi mancanti o Riscraping completo
  5. Fai clic su "Esegui lo scraping dei selezionati"

Controlli

  • Pausa / Riprendi — Metti in pausa o continua lo scraping
  • Annulla — Interrompi completamente
  • In background — Riduci a icona e continua a navigare mentre lo scraping prosegue

Notifica toast

Quando è in esecuzione in background, un toast persistente mostra l'avanzamento su tutte le pagine:

  • Nome del gioco corrente, conteggio dell'avanzamento e statistiche di esito (successo, falliti, saltati)
  • Controlli di pausa/annullamento disponibili da qualsiasi pagina
  • Fai clic sul toast per tornare alla finestra modale di scraping

Sistema di code

Più scraping in blocco vengono accodati automaticamente:

  • Avvia un nuovo scraping mentre ne è in esecuzione uno — verrà accodato
  • La coda viene mostrata nel toast con il conteggio dei processi in attesa
  • I processi vengono elaborati automaticamente in ordine
  • Usa il Gestore code per visualizzare, riordinare o annullare i processi in coda

Opzioni di scraping

  • Riempi solo i mancanti — Riempi solo i campi di metadati vuoti, preservando i dati esistenti
  • Riscraping completo — Sostituisci tutti i campi inclusi i media (scarica immagini e video nuovi)
  • Controlla RetroAchievements — Controlla anche la presenza di set di obiettivi RetroAchievements durante lo scraping

Ripristino dei processi

Se RetroDB viene riavviato mentre un processo è in esecuzione, i processi interrotti appaiono in un banner di ripristino nella Dashboard. Fai clic su "Riprendi" sui singoli processi o su "Riprendi tutti" per riavviarli. Il toast di avanzamento appare immediatamente dopo aver ripreso.

Compilazione AI

Cosa fa

La Compilazione AI usa un modello linguistico di grandi dimensioni (Gemini, OpenAI o Claude) per riempire in modo intelligente i metadati dei giochi mancanti o incompleti. È più intelligente dello scraping normale perché usa la conoscenza contestuale del gioco per fornire dati accurati che gli scraper potrebbero non avere.

Come usarla

  1. Apri la finestra modale dei dettagli di un gioco (o la pagina dei dettagli completa)
  2. Fai clic su "Compilazione AI" (richiede una chiave API AI configurata nelle Impostazioni)
  3. L'AI analizza il titolo del gioco e il sistema, poi riempie i campi mancanti
  4. Esamina i risultati — le modifiche vengono salvate automaticamente

Cosa può fornire la Compilazione AI

  • Genere, descrizione, sviluppatore, editore, data di uscita
  • Giocatori, modalità di gioco (Single-Player, Multi-Player, Co-op, ecc.)
  • Info sulla campagna e struttura del gioco
  • Tutti gli 8 sistemi di classificazione per età (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Regione, franchise, giochi simili
  • Supporto controller, tipo di salvataggio
  • Prospettiva (First-Person, Top-Down, Side-Scroller, ecc.), dimensione (2D, 3D)
  • Info sull'edizione, punteggi della critica e degli utenti

Logica di compilazione intelligente

  • I campi vuoti vengono sempre riempiti
  • I dati esistenti dell'utente non vengono mai sovrascritti
  • I giochi simili vengono sempre aggiornati (i dati AI sono più affidabili per questo campo)
  • Valutazioni mappate in modo incrociato — Se è nota una classificazione, le classificazioni vuote negli altri sistemi vengono riempite automaticamente usando la mappatura incrociata dei livelli di maturità
  • Il titolo di ordinamento viene generato automaticamente quando riempito
  • Il campo Giocatori normalizza gli intervalli (es. "1-4" diventa 4)

Normalizzazione dei generi

La Compilazione AI usa forme canoniche dei generi con nomi separati da trattini:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Requisiti

Deve essere configurata almeno una chiave API di un provider AI in Impostazioni → Scraping → Chiavi API. Il livello di modello più economico (Gemini Flash Lite, GPT-4o Mini o Claude Haiku) funziona bene per i metadati.

  2. Inseriscilo in Impostazioni → Account → PSN

Autenticazione PSN (cookie NPSSO)

PSN usa uno speciale cookie di autenticazione chiamato token NPSSO. Per ottenerlo:

  1. Apri un browser web e accedi a store.playstation.com
  2. Una volta effettuato l'accesso, vai a: https://ca.account.sony.com/api/v1/ssocookie
  3. La pagina mostrerà un JSON contenente il tuo token NPSSO
  4. Copia il valore npsso e incollalo in Impostazioni → Account → PSN

Una volta autenticati, i token vengono memorizzati nella cache localmente in data/psn_tokens.json e aggiornati automaticamente. I token memorizzati rimangono validi per circa 2 mesi.

Standardizzazione delle immagini

Cosa fa

Standardizza tutti i media dei giochi a dimensioni target coerenti per un aspetto uniforme in tutta la tua libreria. Le immagini entro l'80–120% della dimensione target vengono saltate.

Come funziona

  • Banda di soglia — Le immagini entro l'80–120% della dimensione target vengono lasciate intatte per evitare rielaborazioni non necessarie

Risoluzione dei problemi

Problemi comuni

"Nessuna estensione trovata per il sistema"

La cartella di sistema necessita di un file ES-DE systeminfo.txt valido che definisca le estensioni dei file ROM supportate. Assicurati che la struttura della tua cartella ROM rispetti gli standard di ES-DE.

"Connessione API fallita"

  • Verifica la tua connessione a internet
  • Verifica le chiavi API in Impostazioni → Scraping → Chiavi API
  • Attendi se sei soggetto a limiti di frequenza (alcune API hanno tetti giornalieri/orari)
  • Verifica se lo scraper è abilitato (gli scraper disabilitati mostrano "Disabilitato" nello stato della Dashboard)
  • Controlla il Visualizzatore log per messaggi di errore dettagliati

"Scraping in blocco bloccato"

Vai su Impostazioni → Sistema → Risoluzione dei problemi → "Sblocca scraping in blocco". Questo reimposta lo stato del processo senza alterare i tuoi dati.

"Coda di sincronizzazione RA bloccata"

Svuota la coda di sincronizzazione RetroAchievements da Impostazioni → Sistema → Risoluzione dei problemi.

"Sincronizzazione PSN bloccata"

Svuota il processo di aggiornamento PSN da Impostazioni → Sistema → Risoluzione dei problemi.

"Generazione del museo bloccata"

Svuota il processo di generazione del museo da Impostazioni → Sistema → Risoluzione dei problemi.

"Errori del database"

  1. Crea un backup se possibile (Impostazioni → Libreria → Backup)
  2. Prova Impostazioni → Sistema → Manutenzione → Ottimizza database
  3. Verifica i permessi dei file sulla cartella database/
  4. Ultima risorsa: ripristina da un backup o elimina il database e riesegui la scansione

"Le immagini non vengono salvate"

Verifica i permessi di scrittura sulle cartelle dei media: chmod -R 755 static/images/

"Pagina lenta o non reattiva"

  • Le collezioni di grandi dimensioni possono richiedere tempo per caricarsi — lo scorrimento infinito carica in blocchi di 100
  • Prova ad aggiornare la pagina per liberare la memoria accumulata
  • Controlla la console del browser per errori JavaScript
  • Prova a passare a un tema con un effetto canvas più leggero (es. Amber o Elite)
  • Gli effetti canvas rilevano automaticamente l'hardware; i dispositivi meno potenti usano il fallback su CPU a frame rate ridotto

Banner "Processi interrotti" nella Dashboard

Se RetroDB si riavvia mentre dei processi sono in esecuzione, questi appaiono in un banner di ripristino. Fai clic su "Riprendi" singolarmente o su "Riprendi tutti" per riavviarli. Fai clic su "Ignora" o "Ignora tutti" per rimuoverli.

"Autenticazione PSN fallita"

  • I token NPSSO scadono — generane uno nuovo da ca.account.sony.com/api/v1/ssocookie
  • Assicurati di aver effettuato l'accesso a store.playstation.com prima di visitare l'URL del cookie
  • I token memorizzati in data/psn_tokens.json durano circa 2 mesi

"Autenticazione Xbox fallita"

  • Riautenticati facendo clic su "Accedi" nella scheda Importazione giochi → Xbox
  • I token Xbox vengono memorizzati nella cache in data/xbox_tokens.json e aggiornati automaticamente

"Errori di upscaling delle immagini"

  • Il modello ONNX Real-ESRGAN viene scaricato al primo utilizzo — assicurati di avere accesso a internet
  • L'accelerazione GPU richiede driver compatibili (CUDA per NVIDIA, ROCm per AMD)
  • Se la GPU fallisce, il sistema ricade automaticamente sull'elaborazione tramite CPU

Consigli sulle prestazioni

  • Mantieni il tuo browser aggiornato per le migliori prestazioni
  • Chiudi le altre schede del browser quando lavori con collezioni molto grandi
  • Usa i filtri per sistema per ridurre i giochi visualizzati contemporaneamente
  • Esegui periodicamente Ottimizza database dopo operazioni di grandi dimensioni (scraping, pulizia, importazioni)
  • Gli effetti dei temi su canvas rilevano automaticamente l'hardware; i dispositivi meno potenti usano il fallback su CPU

Sicurezza e dichiarazione di non responsabilità

Migliori pratiche di sicurezza

  • Cambia la password predefinita — La password amministratore predefinita (admin) dovrebbe essere cambiata immediatamente al primo accesso. Usa una password robusta di almeno 8 caratteri.
  • Usa un reverse proxy HTTPS — RetroDB non fornisce TLS/SSL da solo. Posizionalo dietro un reverse proxy (es. Nginx, Caddy, Traefik) con HTTPS abilitato per cifrare il traffico tra i client e il server.
  • Limita l'accesso alla rete — Evita di esporre RetroDB direttamente a internet pubblico. Usa una VPN o limita l'accesso alla tua rete locale. Se è necessario l'accesso remoto, usa un reverse proxy con autenticazione.
  • Mantieni backup regolari — Usa la funzione di backup integrata nelle Impostazioni per creare backup periodici del database. Conserva i backup in una posizione separata dall'applicazione.
  • Mantieni RetroDB aggiornato — Controlla regolarmente la presenza di nuove versioni. Le correzioni di sicurezza e i miglioramenti sono inclusi negli aggiornamenti.
  • Proteggi le tue chiavi API — Le chiavi API sono memorizzate in data/scraper_settings.json. Assicurati che questo file non sia accessibile pubblicamente. Non condividere mai il tuo config.py o i file dei token.
