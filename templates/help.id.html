Instalasi

Persyaratan Sistem

  • Python 3.12+ dengan pip
  • Peramban web (Chrome, Firefox, Safari, Edge)
  • Sistem Operasi: Linux, Windows 10/11, atau macOS

Instalasi Cepat

  1. Ekstrak ZIP RetroDB ke direktori pilihan Anda
  2. Buka terminal/command prompt di direktori tersebut
  3. Jalankan: python install.py
  4. Jalankan server:
    • Linux: ./start.sh
    • Windows: klik dua kali start.bat
    • macOS: klik dua kali start.command
  5. Buka http://localhost:5000 di peramban Anda

Installer GUI

Di Linux, Anda juga bisa menjalankan ./setup.sh untuk membuka wizard installer bergrafis. Wizard ini otomatis memeriksa Python/pip/tkinter, lalu memandu Anda melalui setiap langkah pengaturan dengan log kemajuan visual.

Yang Dilakukan install.py

  • Memverifikasi Python 3.12+ dan pip tersedia
  • Memasang dependensi Python dari requirements.txt
  • Membuat config.py dari template contoh
  • Membuat direktori yang diperlukan (database, log, folder media)
  • Membangun bundel CSS dan JS

Memulai

Pengaturan Pertama Kali

Saat pertama kali dijalankan, RetroDB menampilkan Wizard Penyiapan yang memandu Anda melalui:

  1. Akun Admin — Buat nama pengguna dan kata sandi Anda
  2. Jalur Perpustakaan — Atur direktori ROM Anda
  3. Integrasi ES-DE — Opsional, hubungkan gamelist dan media ES-DE
  4. Kunci API — Opsional, tambahkan kunci API scraper

Setelah menyelesaikan wizard, klik "Scan Library" di Dasbor untuk menemukan ROM Anda.

Alur Kerja Mulai Cepat

  1. Pindai perpustakaan Anda untuk mengimpor ROM
  2. Jelajahi berdasarkan sistem atau lihat semua game di Library
  3. Ambil metadata satu per satu atau gunakan pengambilan data massal
  4. Atur dengan tag, daftar, dan wishlist
  5. Lacak kemajuan Anda dengan status penyelesaian dan achievement

Struktur Perpustakaan ROM

RetroDB mengharapkan ROM Anda diatur dalam folder per sistem di dalam jalur perpustakaan Anda:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA) (Disc 1).chd
    Final Fantasy VII (USA) (Disc 2).chd

Simpan berkas ROM langsung di folder sistem. Berkas di sub-folder dilewati, kecuali untuk PS3.

Setiap folder sistem harus berisi berkas systeminfo.txt gaya ES-DE yang mendefinisikan ekstensi berkas yang didukung. RetroDB membaca berkas ini saat memindai untuk mengenali berkas mana yang merupakan ROM yang valid untuk setiap sistem.

Tip: Jika Anda sudah pernah mengambil data dengan ES-DE, RetroDB bisa mengimpor data tersebut! Atur jalur ES-DE di Settings → ES-DE Integration, atau saat wizard pengaturan.

Catatan Platform

Linux

  • Sudah diuji di Ubuntu, Fedora, openSUSE, dan Arch Linux
  • Perkakas ROM memerlukan: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) atau yang setara untuk distro Anda
  • Jika Python bawaan sistem tidak mengizinkan pemasangan paket, installer membuat folder Python khusus untuk RetroDB (.venv) dan tidak mengubah Python sistem
  • Akselerasi GPU ROCm didukung untuk GPU AMD (peningkatan skala gambar Real-ESRGAN)

Windows

  • Unduh Python dari python.org (centang "Add to PATH" saat instalasi)
  • Perkakas ROM: Pasang 7-Zip, WinRAR, dan MAME (untuk chdman)
  • Gunakan start.bat untuk menjalankan, atau jalankan python app.py dari Command Prompt

macOS

  • Python 3 dapat dipasang lewat Homebrew: brew install python3
  • Perkakas ROM: brew install p7zip unrar rom-tools
  • Klik dua kali start.command di Finder untuk menjalankan
  • Akselerasi CoreML didukung untuk Apple Silicon (peningkatan skala gambar Real-ESRGAN)

Dasbor

Skor Kesehatan Koleksi

Cincin progres melingkar menunjukkan kesehatan keseluruhan koleksi Anda sebagai persentase, berkode warna sesuai kualitas:

  • Hijau (80%+) — Cakupan metadata sangat baik
  • Cyan (60–79%) — Cakupan baik dengan beberapa kekurangan
  • Oranye (40–59%) — Cakupan sedang, pertimbangkan pengambilan data massal
  • Merah (<40%) — Kekurangan metadata yang signifikan

Cincin-cincin rincian mini di bawahnya menunjukkan kelengkapan boxart, kelengkapan deskripsi, dan cakupan achievement.

Ringkasan Statistik

Kartu ringkas yang menampilkan:

  • Total Sistem — Jumlah platform dalam perpustakaan Anda
  • Total Game — Jumlah total game (tidak termasuk disc bonus)
  • Metadata Hilang — Game yang belum diambil datanya
  • Selesai — Game dengan metadata yang sudah diambil

Bagian Aktivitas Terbaru

Bagian yang bisa digulir menampilkan aktivitas terbaru Anda (masing-masing hanya muncul jika ada game yang relevan):

  • Lanjutkan Bermain — Game yang ditandai sebagai "In Progress"
  • Baru Ditambahkan — Game terbaru yang ditambahkan ke perpustakaan Anda
  • Baru Dilihat — Game yang baru saja Anda buka
  • Baru Di-scrape — Game dengan metadata yang baru saja diambil

Aksi Cepat

  • Scan Library — Pindai direktori ROM Anda untuk mencari game baru
  • Random Game — Pilih game acak dari perpustakaan Anda

Status API

Menampilkan status koneksi semua scraper dan API yang dikonfigurasi. Jika API yang dikonfigurasi offline, spanduk peringatan muncul dengan tautan ke Settings.

Pemulihan Job

Jika RetroDB dimulai ulang saat job latar belakang sedang berjalan (pengambilan data massal, sinkronisasi RA, pengubahan ukuran gambar, dll.), job yang terganggu akan muncul di spanduk pemulihan. Opsi:

  • Resume — Mulai ulang satu job yang terganggu
  • Resume All — Mulai ulang semua job yang terganggu
  • Dismiss — Hapus satu job dari daftar pemulihan
  • Dismiss All — Hapus semua job yang terganggu

Panduan Pengaturan Kunci API

Kunci API bersifat opsional tetapi memungkinkan pengambilan metadata yang kaya dan fitur tambahan. Konfigurasikan di Settings → Scraping → API Keys.

Scraper Metadata

TheGamesDB

  1. Kunjungi api.thegamesdb.net/key.php
  2. Minta kunci API (gratis, disetujui secara manual) — Anda akan menerima kunci Public dan Private
  3. Di Pengaturan → Scraping → Kunci API, isi kunci publik di TheGamesDB — Kunci Utama dan kunci privat di TheGamesDB — Kunci Cadangan
  4. Kunci utama dipakai lebih dulu; setiap koneksi internet punya jatah sendiri
  5. Kunci cadangan dipakai saat kunci utama habis; jatahnya sekitar 6.000 permintaan per bulan

IGDB (via Twitch)

  1. Buat akun Twitch di twitch.tv
  2. Kunjungi dev.twitch.tv/console
  3. Daftarkan aplikasi baru (nama dan kategori bebas, gunakan http://localhost sebagai OAuth redirect)
  4. Salin Client ID dan buat Client Secret
  5. Masukkan keduanya di Settings → API Keys → IGDB

RAWG.io

  1. Kunjungi rawg.io/apidocs
  2. Klik "Get API Key" dan buat akun
  3. Salin kunci API Anda dari dasbor
  4. Masukkan di Settings → API Keys → RAWG

Tingkat gratis: 20.000 permintaan/bulan

ScreenScraper

  1. Buat akun di screenscraper.fr
  2. Masukkan nama pengguna dan kata sandi Anda di Settings → API Keys → ScreenScraper

Catatan: ScreenScraper memiliki batas permintaan harian berdasarkan tingkat akun Anda. Berkontribusi ke database akan meningkatkan batas Anda.

Emulator dan Bermain

Admin menyiapkan emulator di Pengaturan → Emulator. Tambahkan folder tempat emulator Anda berada ke Folder emulator. RetroDB menemukan setiap emulator di sana (AppImage, skrip portabel, atau Flatpak yang terpasang) dan menautkannya ke sistem yang dijalankannya. Tabel pemetaan menampilkan setiap sistem satu kali, dengan daftar untuk memilih emulatornya, serta apakah emulator itu berfungsi dan apakah file BIOS-nya sudah tersedia. RetroDB hanya membaca file BIOS; RetroDB tidak pernah menyalin atau mengunduhnya.

Game yang emulatornya berfungsi mendapat tombol Mainkan di halaman game, di kartu Library, dan di halaman sistem.

Belum punya emulator? Tekan Dapatkan RetroArch di bawah Main di RetroDB di halaman yang sama. RetroDB mengunduh RetroArch resmi dari libretro, memeriksa unduhannya, dan memasangnya sebagai RetroArch (RetroDB), dengan pengaturan dan save miliknya sendiri, terpisah dari RetroArch lain yang sudah Anda pakai. Lalu RetroDB mengunduh core terbaik untuk setiap sistem saat pertama kali Anda bermain. Untuk game multi-disc, Disk berikutnya berfungsi tanpa pengaturan apa pun. Selama game seperti itu berjalan, dan di Windows dan macOS selama game apa pun berjalan, RetroArch mendengarkan perintah RetroDB di sebuah port jaringan.

Untuk DuckStation, PCSX2, dan RPCS3, RetroDB juga mengatur skala resolusi dan rasio aspek untuk setiap game, di file pengaturan per game milik emulator itu sendiri, serta apakah game dimulai dalam layar penuh. Ubah nilainya untuk satu sistem sekaligus dengan tombol Pengaturan di tabel pemetaan, atau untuk satu game di panel Pengaturan emulator pada halaman game-nya. Nilai ini ditulis saat Anda menekan Mainkan. Pengaturan yang Anda ubah di dalam emulator itu sendiri selalu diutamakan: sejak saat itu RetroDB tidak mengubahnya lagi. Jalankan setiap emulator sekali sebelum bermain, agar emulator membuat folder pengaturannya.

Cheat

Di bawah Cheat pada halaman yang sama, tekan Unduh untuk mengambil paket cheat publik yang gratis, atau impor folder cheat yang sudah Anda miliki. RetroDB menyalin file-nya dan tidak pernah mengubah folder Anda; impor lagi untuk mengambil file baru. Halaman game kemudian menampilkan panel Cheat untuk game yang dimainkan di RetroArch (RetroDB), DuckStation, atau PCSX2, dengan sakelar nyala/mati untuk setiap cheat. Untuk RetroArch (RetroDB), cheat yang Anda nyalakan berlaku saat Anda menekan Mainkan berikutnya, dan sakelar yang Anda ubah di menu RetroArch sendiri selama bermain tetap disimpan. Untuk DuckStation dan PCSX2, sakelarnya disimpan langsung di pengaturan emulator untuk game tersebut, sehingga perubahan yang dibuat di dalam emulator juga tampil di panel. RetroDB tidak pernah menimpa file cheat yang sudah dimiliki emulator. Cheat yang menyala menjeda mode hardcore RetroAchievements; DuckStation dan PCSX2 mengabaikan cheat dalam mode hardcore.

Untuk game arkade yang dimainkan di MAME, unduh "MAME XML Cheats Collection" dari mamecheat.co.uk lewat browser Anda, lalu impor folder yang berisinya. RetroDB menyimpannya tetap terkompresi, sesuai permintaan readme-nya, dan membaca nama cheat setiap game darinya satu kali, dengan mengambil perkakas 7-Zip dari internet untuk itu. Halaman game kemudian menampilkan daftar cheat game itu, dengan satu tombol untuk setiap cheat biasa yang hanya nyala/mati, dan MAME dimulai dengan cheat yang dinyalakan. Cheat yang menerima nilai, atau bekerja hanya sekali, tidak punya tombol: atur saat bermain dengan menekan Tab, lalu Plugin Options, lalu Cheat. Tombol yang Anda ubah di sana tampil di halaman game setelah Anda keluar dari MAME. Mengimpor koleksi yang lebih baru menggantikan yang lama.

Game arkade dengan RetroAchievements dimainkan di RetroArch (RetroDB) dengan core FinalBurn Neo, karena RetroAchievements tidak mendukung MAME; sisanya tetap di MAME. Tekan Unduh di samping Cheat arkade FinalBurn Neo pada halaman yang sama, lalu halaman setiap game itu menampilkan daftar cheat-nya. FinalBurn Neo mematikan semua cheat setiap kali game dimulai, jadi daftarnya tidak punya sakelar: saat bermain, tekan F1 untuk menu RetroArch, lalu pilih Core Options, lalu Cheat. Selama game berjalan, RetroDB menaruh file cheat-nya di folder sistem RetroArch, kecuali file dengan nama itu sudah ada di sana, dan menghapusnya saat game berhenti. Untuk memainkan salah satu game ini di MAME, pilih MAME di bawah Jalankan, Ganti Emulator di jendela edit game.

Pengambilan Data Hibrida

RetroDB secara otomatis menggabungkan data dari beberapa sumber untuk memaksimalkan cakupan metadata:

  • Metadata teks dari sumber tersedia dengan prioritas tertinggi
  • Gambar dan media dari sumber sekunder saat sumber utama tidak memilikinya
  • Pengisian celah otomatis lintas scraper untuk cakupan maksimal
  • Judul urut (sort title) dibuat otomatis dari judul game selama pengambilan data
  • Sebuah sumber hanya dicari jika sumber itu mencantumkan sistem game tersebut, dan hanya pada sistem itu: RAWG tidak punya Intellivision, jadi game Intellivision tidak dicari di RAWG, tempat game itu hanya akan cocok dengan game dari platform lain
  • Saat AI aktif, AI juga memberikan judul resmi game sebagaimana dirilis di wilayah ROM-nya, dan game diganti namanya menjadi judul itu, baik saat scraping satu game maupun di Bulk Scrape (lihat AI Fill)

Penanganan Media

  • Kolom media (boxart, boxart 3D, sisi belakang boks, screenshot, fanart, logo, video, manual) tidak pernah diganti selama pengambilan data normal — hanya diisi jika kosong
  • Screenshot selalu ditambahkan, tidak pernah diganti
  • Untuk mengunduh ulang media, kosongkan gambar yang ada di modal edit terlebih dahulu, lalu ambil data ulang
  • Mode Full Re-scrape menggantikan aturan ini dan mengganti semuanya
  • Referensi media yang basi (berkas dihapus tetapi nama berkas masih ada di database) otomatis dibersihkan sebelum pengambilan data agar media segar dapat diunduh
  • Gambar yang diunduh otomatis distandardisasi ke ukuran target (lihat Image Standardization)

Mempertahankan Judul

Saat Anda mengetik judul baru di jendela edit lalu menyimpannya, scraping tidak lagi mengubahnya, termasuk Full Re-scrape. Kotak Pertahankan judul ini saat scraping di jendela edit menunjukkan apakah sebuah judul dipertahankan; hapus centangnya agar scraper bisa mengganti nama game lagi. Atur Ulang di halaman game juga membuat scraper bisa mengganti namanya, dan Hapus data hasil scrape di Pemeliharaan membiarkan judul yang dipertahankan apa adanya.

Prioritas Scraper

Konfigurasikan scraper mana yang berjalan lebih dulu dan mana yang aktif/nonaktif di Settings → Scraping → Scraper. Seret dan lepas untuk mengurutkan ulang prioritas. Scraper yang dinonaktifkan tidak akan dicoba selama pengambilan data dan tidak akan memicu peringatan status API di Dasbor.

Pembatasan Laju

RetroDB mengatur sendiri jeda permintaannya ke setiap layanan; tidak ada yang perlu diatur. Saat sebuah layanan menyatakan batasnya sudah tercapai, RetroDB berhenti meminta ke layanan itu sampai waktu yang diberikannya, dan memberi tahu Anda (lihat Pemecahan Masalah).

Isi dengan AI

Fungsinya

AI Fill menggunakan model bahasa besar (Gemini, OpenAI, atau Claude) untuk mengisi metadata game yang hilang atau tidak lengkap secara cerdas. Fitur ini lebih pintar daripada pengambilan data biasa karena menggunakan pengetahuan kontekstual tentang game untuk memberikan data akurat yang mungkin tidak dimiliki scraper.

Cara Menggunakan

  1. Buka modal detail game (atau halaman detail penuh)
  2. Klik "AI Fill" (memerlukan kunci API AI yang dikonfigurasi di Settings)
  3. AI menganalisis judul dan sistem game, lalu mengisi kolom yang hilang
  4. Tinjau hasilnya — perubahan disimpan otomatis

Banyak Game Sekaligus

Untuk mengisi seluruh sistem, buka Alat ROM → Isi dengan AI Massal dan gunakan kartu Isi kolom kosong dengan AI. Aktifkan kolom yang ingin diisi; hanya game dengan salah satunya kosong yang dihitung, dan semakin sedikit kolom, semakin murah. Pilih sebuah sistem, atau Semua sistem, lalu tekan Isi dengan AI. Ia menjalankan Isi dengan AI pada setiap game dan menyimpan jawabannya langsung ke game. Bilah progres pada kartu dan kotak notifikasi Isi dengan AI menunjukkan sejauh mana prosesnya, dan Anda bisa meninggalkan halaman saat proses berjalan. Game yang sudah pernah melalui Isi dengan AI dilewati, jadi proses kedua hanya mengerjakan sisanya; aktifkan Sertakan game yang sudah pernah melalui Isi dengan AI untuk mengisi kolom pada game itu juga, seperti kopi terjual. Proses berhenti sendiri jika AI berhenti menjawab, misalnya saat kunci ditolak atau akun tidak punya saldo. Penyedia AI Anda menagih biaya untuk setiap game.

Apa yang Bisa Disediakan AI Fill

  • Genre, deskripsi, developer, publisher, tanggal rilis
  • Jumlah pemain, mode permainan (Single-Player, Multi-Player, Co-op, dll.)
  • Info campaign dan struktur game
  • Semua sistem rating usia (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd, CADPA)
  • Region, franchise, game serupa
  • Dukungan kontroler, jenis penyimpanan
  • Perspektif (First-Person, Top-Down, Side-Scroller, dll.), dimensi (2D, 3D)
  • Info edisi, skor kritikus dan pengguna

Logika Pengisian Cerdas

  • Kolom kosong selalu diisi
  • Data pengguna yang sudah ada tidak pernah ditimpa
  • Game serupa selalu disegarkan (data AI lebih andal untuk kolom ini)
  • Rating hasil pemetaan silang — Jika satu sistem rating sudah diketahui, rating kosong di sistem lain otomatis diisi menggunakan pemetaan silang tingkat kedewasaan
  • Sort title dibuat otomatis saat diisi
  • Judul resmi — AI juga menyebutkan judul resmi game sebagaimana dirilis di wilayah ROM-nya, dan game diganti namanya menjadi judul itu, di AI Fill dan setiap kali AI mengisi kekosongan selama scraping. Nama lama disimpan sebagai judul alternatif. Judul yang Anda ketik sendiri, atau Anda pertahankan dengan Pertahankan judul ini saat scraping, tidak pernah diganti
  • Kolom Players menormalkan rentang (mis. "1-4" menjadi 4)

Normalisasi Genre

AI Fill menggunakan bentuk genre baku dengan nama berbentuk hyphen:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Persyaratan

Setidaknya satu kunci API penyedia AI harus dikonfigurasi di Settings → Scraping → API Keys. Tingkatan model termurah (Gemini Flash Lite, GPT-4o Mini, atau Claude Haiku) sudah bekerja dengan baik untuk metadata.

Pencarian

Pencarian menyaring game berdasarkan judul (dan sort title). Tekan / untuk memfokuskan kotak pencarian. Hasil diperbarui secara real-time dengan debounce 300ms.

  • Steam Imports — Game yang diimpor dari Steam

Tombol Filter

Setiap filter membuka modal yang menampilkan semua nilai unik dalam perpustakaan Anda beserta jumlahnya. Filter mendukung dua mode:

  • Sertakan (IS) — Hanya tampilkan game yang cocok dengan nilai-nilai yang dipilih
  • Kecualikan (IS NOT) — Sembunyikan game yang cocok dengan nilai-nilai yang dipilih

Beralih antara mode sertakan dan kecualikan menggunakan sakelar di modal filter.

Di filter Genre, Seri, Penerbit, Pengembang, Mode Bermain, Perspektif, dan Dimensi, centang nilai sebanyak yang Anda mau lalu tekan Terapkan. Sebuah game tampil jika memiliki salah satu nilai yang dicentang; dalam mode kecualikan, game disembunyikan jika memiliki salah satunya. Setiap nilai mendapat tag sendiri di atas daftar game, dan × pada tag itu hanya menghapus nilai tersebut. Filter Rating dan Sumber hanya menerima satu nilai dan langsung berlaku begitu Anda mengkliknya.

  • Sisi belakang boks — Jika sebuah game memiliki sisi belakang boksnya, tombol Belakang ada di sampul. Tekan tombol itu untuk melihat sisi belakang, lalu tekan Depan untuk kembali.   • Badge impor platform — Menampilkan CLZ Import, Steam Import, Xbox Import, atau PSN Import dengan logo platform bila berlaku
  • Indikator disc bonus — Menampilkan badge dan tautan "Part of:" ke game induk beserta thumbnail-nya
  • Tombol Delete — Hapus game dari database (dengan konfirmasi)

  • Gameplay — Genre (tag multi-pilih), mode, struktur game, jumlah pemain, developer, publisher

Koleksi (Tag, Daftar, Wishlist)

Tag

Buat tag kustom berkode warna untuk mengatur game Anda. Tag bekerja seperti label — setiap game bisa memiliki beberapa tag, dan setiap tag bisa berisi beberapa game.

  • Edit atau hapus tag dari halaman manajemen Tags

Buat daftar game kurasi dengan urutan kustom. Daftar (Lists) mirip playlist — Anda mengendalikan urutan pasti dari game-game tersebut.

  • Buat daftar dengan nama, deskripsi, dan ikon dari halaman Lists

Wishlist

Lacak game yang ingin Anda miliki, baik fisik maupun digital.

Tip: Gunakan tag untuk label lintas kategori (mis. "Favorites", "Couch Co-op", "Backlog") dan daftar untuk koleksi kurasi tertentu (mis. "Top 10 SNES Games", "Games to Stream").

Autentikasi PSN (Cookie NPSSO)

PSN menggunakan cookie autentikasi khusus bernama token NPSSO. Untuk mendapatkannya:

  1. Buka peramban web dan masuk ke store.playstation.com
  2. Setelah masuk, kunjungi: https://ca.account.sony.com/api/v1/ssocookie
  3. Halaman tersebut akan menampilkan JSON yang berisi token NPSSO Anda
  4. Salin nilai npsso dan tempelkan di Settings → Account → PSN

Setelah terautentikasi, RetroDB menyimpan token akses secara aman di database-nya sendiri (per pengguna) dan memperbaruinya secara otomatis — Anda tidak perlu menempelkan NPSSO lagi setiap kali sinkronisasi. Saat sesi Sony berakhir, RetroDB masuk kembali dengan sendirinya menggunakan NPSSO yang tersimpan. Anda hanya perlu NPSSO baru jika Sony menolak NPSSO yang tersimpan; Settings → Account dan Dasbor akan memberi tahu Anda.

TabYang Diperiksa

Khusus Editor. Nama MAME

Khusus admin. MAME menemukan game berdasarkan nama filenya yang persis, jadi pertahankan nama pendeknya, seperti dyger.zip. Pilih daftar MAME (DAT yang cocok dengan ROM Anda, atau keluaran mame -listxml) lalu tekan "Beri Nama Game MAME". Setiap game mendapat nama asli, tahun, dan pembuatnya, dan filenya tidak diubah. Judul yang Anda ubah sendiri tetap dipertahankan. Tambahkan catver.ini untuk memfilter daftar menurut kategori. Set BIOS disembunyikan dari daftar tetapi tetap ada di disk, karena game lain membutuhkannya. Lakukan scraping setelah ini, agar scraper dapat menemukan setiap game.

Memerlukan: file daftar MAME

Memindai secara bertahap dengan statistik langsung yang menampilkan jumlah game dipindai, jumlah duplikat, dan ruang yang bisa dibebaskan. Hasil dikelompokkan berdasarkan game dan sistem. Anda bisa memilih berkas mana yang dipertahankan di setiap grup duplikat, atau gunakan "Simpan yang Terbesar" untuk otomatis mempertahankan versi dengan resolusi tertinggi. Jika Anda meninggalkan halaman ini selama atau setelah pemindaian, hasilnya tetap ada saat Anda kembali, selama 30 menit setelah pemindaian selesai, kecuali RetroDB dimulai ulang. Standardisasi Gambar

Fungsinya

Menstandardisasi semua media game ke ukuran target yang konsisten untuk tampilan yang seragam di seluruh perpustakaan Anda. Gambar dalam rentang 80–120% dari ukuran target akan dilewati.

Cara Kerja

  • Upscaling — Gambar yang lebih kecil dari ukuran target ditingkatkan skalanya menggunakan Real-ESRGAN x4 (super-resolusi AI lewat ONNX Runtime) untuk perbesaran berkualitas tinggi, lalu diubah ukurannya ke ukuran target yang tepat
  • Downscaling — Gambar yang lebih besar dari ukuran target diperkecil menggunakan filter Lanczos untuk hasil yang tajam
  • Zona ambang batas — Gambar dalam rentang 80–120% dari target dibiarkan apa adanya untuk menghindari pemrosesan ulang yang tidak perlu

Memperbarui RetroDB

Versi 4.0 adalah versi web terakhir RetroDB. Versi baru akan berupa aplikasi desktop untuk Windows, Linux, dan macOS, serta aplikasi Android. Aplikasi ini akan membuka Pustaka Anda yang sudah ada. Cara Memperbarui

  1. Unduh rilis RetroDB terbaru
  2. Cadangkan berkas-berkas ini (berisi data pribadi Anda):
    • config.py (jalur dan kunci API Anda)
    • data/settings.json (preferensi UI Anda)
    • data/scraper_settings.json (konfigurasi scraper Anda)
    • data/rom_tools_config.json (preferensi ROM tools Anda)
    • folder database/ (database perpustakaan game Anda, dan token login PSN/Xbox yang tersimpan)
  3. Ekstrak versi baru menimpa instalasi yang ada
  4. Jalankan python install.py untuk memasang dependensi baru
  5. Mulai ulang server

Berkas yang Aman untuk Ditimpa

Berkas yang Harus Disimpan

Jangan pernah menghapus atau menimpa: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

"AI tidak mengembalikan data. Periksa kunci API dan pengaturan penyedia Anda."

Di Pengaturan → Scraping → Kunci API, pilih Penyedia Metadata AI, masukkan kuncinya, tekan Simpan Kunci API, lalu Uji kunci AI yang tersimpan. Jika layanan AI menolak, pesannya menyebut alasannya, misalnya kredit habis.

"AI tidak menemukan kolom kosong untuk diisi"

Bukan error: game itu tidak punya kolom kosong yang bisa diisi oleh Isi dengan AI.

Isi dengan AI massal berhenti sendiri

Proses berhenti setelah tiga game berturut-turut tidak mendapat jawaban. Periksa kuncinya dengan Uji kunci AI yang tersimpan, lalu jalankan lagi. Game yang sudah terisi tetap memakai hasilnya.

Gambar

Gambar hilang setelah scrape

Gambar yang gagal diunduh dilewati tanpa pesan; Penampil Log menjelaskan alasannya. Pastikan RetroDB dapat menulis ke folder medianya (static/images/ kecuali Anda memindahkannya). Di Linux atau macOS, chmod -R u+rwX static/images/ memberi akun Anda akses tulis tanpa menandai gambar sebagai program.

Peningkatan resolusi tampaknya tidak berfungsi

  • Peningkatan resolusi pertama mengunduh model Real-ESRGAN, jadi memerlukan akses internet.
  • GPU memerlukan driver yang berfungsi (CUDA untuk NVIDIA, ROCm untuk AMD). Jika GPU gagal, peningkatan resolusi pindah ke CPU.
  • Jika peningkat resolusi sama sekali tidak bisa berjalan, RetroDB memperbesar gambar dengan cara biasa (Lanczos). logs/upscale_worker.log menjelaskan alasannya.

Memainkan Game

Game terbuka di komputer lain

Mainkan menjalankan emulator di komputer yang menjalankan RetroDB, bukan di perangkat tempat Anda menekannya.

"Program emulator tidak ditemukan di PATH"

Di halaman Emulator, di bawah Emulator terdaftar, edit emulatornya dan isi Lokasi program dengan lokasi programnya. Atau tambahkan folder yang menyimpannya di bawah Folder emulator. Untuk RetroArch, gunakan Deteksi otomatis pada kartu RetroArch, lalu Simpan.

"Tidak ada emulator yang dikonfigurasi untuk sistem …" atau "Emulator … dimatikan"

Pilih emulator untuk sistem itu di bawah Pemetaan per sistem di halaman Emulator, atau nyalakan emulatornya di bawah Emulator terdaftar. Jika game diatur ke emulator yang sudah tidak ada: hapus pilihan itu di jendela Edit Game-nya.

"… belum ada core RetroArch yang diatur" atau "Core RetroArch tidak ditemukan"

Di halaman Emulator, pastikan kartu RetroArch menunjuk ke folder yang berisi core Anda (Deteksi otomatis mengisinya), lalu tekan Simpan. Pasang core yang hilang dengan pengunduh core milik RetroArch sendiri. Atau pilih emulator lain untuk sistem itu di bawah Pemetaan per sistem.

"File ROM tidak ditemukan" atau "Jalur ROM berada di luar folder pindaian yang dikonfigurasi"

Berkasnya dipindahkan atau dihapus sejak pemindaian terakhir, atau berada di luar folder ROM Anda. Kembalikan ke folder sistem dan pindai pustaka lagi.

"Game ini sudah berjalan"

Tutup jendela emulator, atau terima tawaran untuk menutupnya dan memulai lagi.

"Tidak dapat mengunduh core …"

Mainkan di RetroDB mengunduh core yang belum ada saat pertama kali Anda bermain, kecuali Unduh core yang belum ada saat “Mainkan” ditekan dimatikan di halaman Emulator. Periksa koneksi internet dan tekan Mainkan lagi, atau tekan Pasang core untuk sistem saya di halaman Emulator.

Cheat

"Tidak ada cheat yang ditemukan untuk game ini."

Unduh paket cheat untuk emulatornya di kartu Cheat pada halaman Emulator, atau impor folder cheat milik Anda di sana. Cheat berfungsi di pemutar, DuckStation, PCSX2, dan MAME. Untuk MAME, impor koleksi cheat dari mamecheat.co.uk.

Cheat yang dinyalakan tidak berpengaruh

Cheat berlaku saat Anda menekan Mainkan berikutnya. Cheat yang menyala mematikan mode hardcore RetroAchievements selama Anda bermain.

"Jalankan … sekali agar membuat pengaturannya, lalu mainkan lagi."

DuckStation atau PCSX2 belum membuat folder pengaturannya. Jalankan emulatornya sekali secara terpisah, lalu tekan Mainkan lagi.

Achievement dan Trofi

Sinkronisasi RetroAchievements macet atau menunggu

Satu job RetroAchievements berjalan dalam satu waktu; sisanya menunggu dalam antrean di notifikasi progres. Tombol hentinya mengakhiri job yang berjalan, dan setiap job yang menunggu punya tombol Hapus dari antrean.

"RetroAchievements belum dikonfigurasi"

Simpan nama pengguna RetroAchievements dan kunci API web Anda di Pengaturan → Akun → Profil Saya → Pengaturan RetroAchievements.

"RetroAchievements tidak memasukkan Anda"

Masuk untuk bermain memerlukan kata sandi RetroAchievements Anda, bukan kunci API. Ini berlaku saat Anda menekan Mainkan berikutnya.

"Tidak ada game yang ditemukan. Pastikan profil Steam dan detail game Anda diatur ke Publik."

Di situs Steam, atur profil Anda dan detail game-nya ke Publik. Kunci Steam dan Steam ID 17 digit Anda diisi di Pengaturan → Akun → Profil Saya → Steam.

"OpenXBL tidak menerima kunci itu"

  • Salin kuncinya lagi dari xbl.io dan tempel di Pengaturan → Akun → Profil Saya → Xbox.
  • "Batas per jam OpenXBL sudah tercapai" berarti kunci itu sudah memakai 150 permintaannya jam ini. Sinkronkan lagi nanti; sinkronisasi dimulai dari game yang belum disinkronkan.

"Autentikasi PSN gagal"

  • Sony tidak lagi menerima token NPSSO yang Anda simpan. Buat yang baru dengan langkah-langkah di Pengaturan → Akun → Profil Saya → PlayStation Network, lalu tekan Simpan Profil Saya.
  • RetroDB menjaga sesi masuk tetap berjalan sendiri selama Sony menerima tokennya. Untuk mengganti token yang masih berfungsi, keluar dari PlayStation dulu.

Sinkronisasi trofi PSN macet

Penyegaran PSN punya tombol henti di notifikasi progresnya. Sinkronisasi trofi penuh tidak punya; memulai ulang RetroDB mengakhirinya.

Semua Trofi Kolektor tampil belum diperoleh

Tekan Segarkan Progres di halaman Trofi Kolektor. Membuka halaman itu tidak menghitungnya.

'Tidak ada kecocokan HLTB yang ditemukan untuk …'

Ketik judul yang dipakai HowLongToBeat di kotak pencarian dan cari lagi. Jika HowLongToBeat menyatakan terlalu banyak permintaan, RetroDB menunggu 15 menit sebelum bertanya lagi, dan pencarian tidak menemukan apa pun sampai saat itu.

Museum dan Alat ROM

"Tidak ada penyedia AI yang dikonfigurasi"

Museum menulis halamannya dengan penyedia AI yang diatur di Pengaturan → Scraping → Kunci API. Siapkan satu, lalu buat lagi.

Pembuatan museum macet

Tekan Batal di bawah bilah progres pada halaman Museum.

Pasang MAME tools, yang menyertakan chdman, atau atur lokasinya di Alat ROM → Pengaturan.

"Hasil pindaian ini sudah kedaluwarsa. Pindai lagi, lalu hapus."

Jalankan pindaian lagi, lalu hapus dari hasil yang baru.

Akun dan Masuk

"Terlalu banyak percobaan login. Silakan coba lagi nanti."

Setelah lima kata sandi salah dalam lima menit, tunggu lima menit lalu coba lagi.

Lupa kata sandi

Tidak ada reset lewat email. Admin mengatur kata sandi baru di Pengaturan → Akun → Manajemen Pengguna. Jika satu-satunya admin lupa kata sandinya, pulihkan backup yang dibuat saat kata sandi masih diketahui.

"Anda tidak memiliki izin untuk melakukan tindakan ini"

Peran Anda tidak mencakup fitur itu. Admin dapat mengubah peran Anda di Pengaturan → Akun → Manajemen Pengguna.

Database, Backup, dan Pembaruan

Kesalahan database

  1. Buat backup jika memungkinkan (Pengaturan → Pustaka → Backup)
  2. Coba Pengaturan → Sistem → Pemeliharaan → Optimalkan Database. Ini bisa gagal saat sebuah job sedang menulis; tunggu job selesai lalu coba lagi.
  3. Periksa hak akses berkas pada direktori database/
  4. Pilihan terakhir: pulihkan dari backup

"Tugas latar belakang sedang berjalan. Tunggu hingga selesai sebelum memulihkan."

Biarkan job selesai, atau hentikan dari notifikasi progresnya, lalu pulihkan. Setelah pemulihan, mulai ulang RetroDB.

"Salinan RetroDB ini adalah git checkout. Perbarui dengan git pull."

Pembaruan hanya dipasang di atas rilis yang diunduh. Salinan yang dibuat dengan git diperbarui dengan git pull.

Pembaruan gagal

Unduhan yang gagal tidak memasang apa pun; tekan Unduh pembaruan lagi. Pemasangan yang gagal mengembalikan versi lama sendiri dan menyebut alasannya. Rinciannya ada di logs/update.log.

Halaman dan Kecepatan

Halaman lambat atau tidak merespons

  • Koleksi besar mungkin butuh waktu untuk dimuat — infinite scroll memuat dalam kelompok 100
  • Coba muat ulang halaman untuk membersihkan memori yang menumpuk
  • Periksa konsol peramban untuk error JavaScript
  • Coba beralih ke tema dengan efek canvas yang lebih ringan (mis. Amber atau Elite)
  • Efek canvas otomatis mendeteksi perangkat keras; perangkat kelas bawah menggunakan fallback CPU dengan frame rate yang lebih rendah

Tips Performa

  • Jaga peramban Anda tetap mutakhir untuk performa terbaik
  • Tutup tab peramban lain saat bekerja dengan koleksi yang sangat besar
  • Gunakan filter sistem untuk mengurangi game yang ditampilkan sekaligus
  • Jalankan Optimalkan Database secara berkala setelah operasi besar (scraping, pembersihan, impor)

Keamanan & Penafian

Praktik Terbaik Keamanan

  • Ganti kata sandi bawaan — Kata sandi admin bawaan (admin) harus segera diganti saat login pertama kali. Gunakan kata sandi kuat setidaknya 12 karakter.
  • Gunakan reverse proxy HTTPS — RetroDB tidak menyediakan TLS/SSL sendiri. Tempatkan di belakang reverse proxy (mis. Nginx, Caddy, Traefik) dengan HTTPS diaktifkan untuk mengenkripsi lalu lintas antara klien dan server.
  • Batasi akses jaringan — Hindari mengekspos RetroDB langsung ke internet publik. Gunakan VPN atau batasi akses ke jaringan lokal Anda. Jika akses jarak jauh diperlukan, gunakan reverse proxy dengan autentikasi.
  • Buat cadangan rutin — Gunakan fitur cadangan bawaan di Settings untuk membuat cadangan database secara berkala. Simpan cadangan di lokasi terpisah dari aplikasi.
  • Jaga RetroDB tetap mutakhir — Periksa rilis baru secara berkala. Perbaikan keamanan dan peningkatan disertakan dalam pembaruan.
  • Lindungi kunci API Anda — Kunci API disimpan dalam data/scraper_settings.json. Pastikan berkas ini tidak dapat diakses secara publik. Jangan pernah membagikan config.py atau berkas token Anda.

Fitur Keamanan Bawaan

  • Hashing kata sandi — Kata sandi di-hash dengan PBKDF2 (tidak pernah disimpan dalam teks biasa)
  • Pembatasan laju login — Perlindungan brute-force pada endpoint login
  • Validasi jalur — Semua operasi berkas menggunakan helper safe_path dan safe_filename untuk mencegah serangan directory traversal
  • Kueri berparameter — Semua kueri database menggunakan pernyataan berparameter untuk mencegah SQL injection
  • Perlindungan XSS — Dialog modal menggunakan konstruksi DOM yang aman; input pengguna di-escape
  • Perlindungan bom dekompresi gambar — Jumlah piksel gambar maksimum dibatasi untuk mencegah kehabisan memori akibat gambar berbahaya

Penafian

RetroDB disediakan "APA ADANYA", tanpa jaminan dalam bentuk apa pun, tersurat maupun tersirat, termasuk namun tidak terbatas pada jaminan kelayakan jual, kesesuaian untuk tujuan tertentu, dan tidak adanya pelanggaran. Dalam keadaan apa pun para pengembang atau pemegang hak cipta tidak bertanggung jawab atas klaim, kerusakan, atau kewajiban lain apa pun, baik dalam tindakan kontrak, kesalahan (tort), atau lainnya, yang timbul dari, keluar dari, atau sehubungan dengan perangkat lunak ini atau penggunaan atau transaksi lain dalam perangkat lunak ini.

Anda sepenuhnya bertanggung jawab untuk mengamankan penerapan Anda, termasuk konfigurasi jaringan, kontrol akses, cadangan data, dan kepatuhan terhadap hukum yang berlaku terkait konten yang Anda kelola dengan perangkat lunak ini. Para pengembang tidak bertanggung jawab atas akses tidak sah, kehilangan data, atau penyalahgunaan akibat konfigurasi atau penerapan yang tidak tepat.
