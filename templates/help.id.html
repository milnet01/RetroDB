Instalasi

Persyaratan Sistem

  • Python 3.8+ dengan pip
  • Peramban web (Chrome, Firefox, Safari, Edge)
  • Sistem Operasi: Linux, Windows 10/11, atau macOS

Instalasi Cepat

  1. Ekstrak ZIP RetroDB ke direktori pilihan Anda
  2. Buka terminal/command prompt di direktori tersebut
  3. Jalankan: python install.py
  4. Jalankan server:
    • Linux: ./start.sh
    • Windows: klik dua kali start.bat
    • macOS: klik dua kali start.command
  5. Buka http://localhost:5000 di peramban Anda

Installer GUI

Di Linux, Anda juga bisa menjalankan ./setup.sh untuk membuka wizard installer bergrafis. Wizard ini otomatis memeriksa Python/pip/tkinter, lalu memandu Anda melalui setiap langkah pengaturan dengan log kemajuan visual.

Yang Dilakukan install.py

  • Memverifikasi Python 3.8+ dan pip tersedia
  • Memasang dependensi Python dari requirements.txt
  • Membuat config.py dari template contoh
  • Membuat direktori yang diperlukan (database, log, folder media)
  • Membangun bundel CSS dan JS

Memulai

Pengaturan Pertama Kali

Saat pertama kali dijalankan, RetroDB menampilkan Wizard Pengaturan yang memandu Anda melalui:

  1. Akun Admin — Buat nama pengguna dan kata sandi Anda
  2. Jalur Perpustakaan — Atur direktori ROM Anda
  3. Integrasi ES-DE — Opsional, hubungkan gamelist dan media ES-DE
  4. Kunci API — Opsional, tambahkan kunci API scraper

Setelah menyelesaikan wizard, klik "Scan Library" di Dasbor untuk menemukan ROM Anda.

Alur Kerja Mulai Cepat

  1. Pindai perpustakaan Anda untuk mengimpor ROM
  2. Jelajahi berdasarkan sistem atau lihat semua game di Library
  3. Ambil metadata satu per satu atau gunakan pengambilan data massal
  4. Atur dengan tag, daftar, dan wishlist
  5. Lacak kemajuan Anda dengan status penyelesaian dan achievement

Struktur Perpustakaan ROM

RetroDB mengharapkan ROM Anda diatur dalam folder per sistem di dalam jalur perpustakaan Anda:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd

Setiap folder sistem harus berisi berkas systeminfo.txt gaya ES-DE yang mendefinisikan ekstensi berkas yang didukung. RetroDB membaca berkas ini saat memindai untuk mengenali berkas mana yang merupakan ROM yang valid untuk setiap sistem.

Tip: Jika Anda sudah pernah mengambil data dengan ES-DE, RetroDB bisa mengimpor data tersebut! Atur jalur ES-DE di Settings → ES-DE Integration, atau saat wizard pengaturan.

Catatan Platform

Linux

  • Sudah diuji di Ubuntu, Fedora, openSUSE, dan Arch Linux
  • Perkakas ROM memerlukan: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) atau yang setara untuk distro Anda
  • Jika menggunakan Python bawaan sistem, installer otomatis menangani --break-system-packages
  • Akselerasi GPU ROCm didukung untuk GPU AMD (peningkatan skala gambar Real-ESRGAN)

Windows

  • Unduh Python dari python.org (centang "Add to PATH" saat instalasi)
  • Perkakas ROM: Pasang 7-Zip, WinRAR, dan MAME (untuk chdman)
  • Gunakan start.bat untuk menjalankan, atau jalankan python app.py dari Command Prompt

macOS

  • Python 3 dapat dipasang lewat Homebrew: brew install python3
  • Perkakas ROM: brew install p7zip unrar rom-tools
  • Klik dua kali start.command di Finder untuk menjalankan
  • Akselerasi CoreML didukung untuk Apple Silicon (peningkatan skala gambar Real-ESRGAN)

Dasbor

Skor Kesehatan Koleksi

Cincin progres melingkar menunjukkan kesehatan keseluruhan koleksi Anda sebagai persentase, berkode warna sesuai kualitas:

  • Hijau (80%+) — Cakupan metadata sangat baik
  • Cyan (60–79%) — Cakupan baik dengan beberapa kekurangan
  • Oranye (40–59%) — Cakupan sedang, pertimbangkan pengambilan data massal
  • Merah (<40%) — Kekurangan metadata yang signifikan

Cincin-cincin rincian mini di bawahnya menunjukkan kelengkapan boxart, kelengkapan deskripsi, dan cakupan achievement.

Ringkasan Statistik

Kartu ringkas yang menampilkan:

  • Total Sistem — Jumlah platform dalam perpustakaan Anda
  • Total Game — Jumlah total game (tidak termasuk disc bonus)
  • Metadata Hilang — Game yang belum diambil datanya
  • Lengkap — Game dengan metadata yang sudah diambil

Bagian Aktivitas Terbaru

Bagian yang bisa digulir menampilkan aktivitas terbaru Anda (masing-masing hanya muncul jika ada game yang relevan):

  • Sedang Dimainkan — Game yang ditandai sebagai "In Progress"
  • Baru Ditambahkan — Game terbaru yang ditambahkan ke perpustakaan Anda
  • Baru Dilihat — Game yang baru saja Anda buka
  • Baru Diambil Datanya — Game dengan metadata yang baru saja diambil

Aksi Cepat

  • Scan Library — Pindai direktori ROM Anda untuk mencari game baru
  • Random Game — Pilih game acak dari perpustakaan Anda

Status API

Menampilkan status koneksi semua scraper dan API yang dikonfigurasi. API yang offline atau salah konfigurasi menampilkan spanduk peringatan dengan tautan ke Settings.

Pemulihan Job

Jika RetroDB dimulai ulang saat job latar belakang sedang berjalan (pengambilan data massal, sinkronisasi RA, pengubahan ukuran gambar, dll.), job yang terganggu akan muncul di spanduk pemulihan. Opsi:

  • Resume — Mulai ulang satu job yang terganggu
  • Resume All — Mulai ulang semua job yang terganggu
  • Dismiss — Hapus satu job dari daftar pemulihan
  • Dismiss All — Hapus semua job yang terganggu

Panduan Pengaturan Kunci API

Kunci API bersifat opsional tetapi memungkinkan pengambilan metadata yang kaya dan fitur tambahan. Konfigurasikan di Settings → Scraping → API Keys.

Scraper Metadata

TheGamesDB

  1. Kunjungi api.thegamesdb.net/key.php
  2. Minta kunci API (gratis, disetujui secara manual) — Anda akan menerima kunci Public dan Private
  3. Masukkan kedua kunci di Settings → API Keys → TheGamesDB
  4. Kunci Public (batas laju per IP) digunakan sebagai kunci utama untuk pengambilan data
  5. Kunci Private (kuota bersama bulanan) digunakan sebagai cadangan jika kunci publik gagal

IGDB (via Twitch)

  1. Buat akun Twitch di twitch.tv
  2. Kunjungi dev.twitch.tv/console
  3. Daftarkan aplikasi baru (nama dan kategori bebas, gunakan http://localhost sebagai OAuth redirect)
  4. Salin Client ID dan buat Client Secret
  5. Masukkan keduanya di Settings → API Keys → IGDB

RAWG.io

  1. Kunjungi rawg.io/apidocs
  2. Klik "Get API Key" dan buat akun
  3. Salin kunci API Anda dari dasbor
  4. Masukkan di Settings → API Keys → RAWG

Tingkat gratis: 20.000 permintaan/bulan

ScreenScraper

  1. Buat akun di screenscraper.fr
  2. Masukkan nama pengguna dan kata sandi Anda di Settings → API Keys → ScreenScraper

Catatan: ScreenScraper memiliki batas permintaan harian berdasarkan tingkat akun Anda. Berkontribusi ke database akan meningkatkan batas Anda.

Achievement & Trofi

RetroAchievements

  1. Buat akun di retroachievements.org
  2. Kunjungi Settings → API Keys pada profil Anda
  3. Salin kunci API Anda
  4. Masukkan nama pengguna dan kunci API Anda di Settings → Account → RetroAchievements

Steam Web API

  1. Kunjungi steamcommunity.com/dev/apikey
  2. Daftarkan kunci Steam Web API (memerlukan akun Steam)
  3. Masukkan kunci API dan Steam ID (atau vanity URL) Anda di Settings

Digunakan untuk impor perpustakaan Steam dan pelacakan achievement.

Xbox Live

Autentikasi Xbox menggunakan OAuth2 — tidak diperlukan kunci API. Masuk dengan akun Microsoft Anda langsung dari tab Game Imports → Xbox. Token disimpan otomatis di cache dan diperbarui sesuai kebutuhan.

PlayStation Network (PSN)

PSN menggunakan autentikasi cookie NPSSO. Lihat bagian Trophies untuk petunjuk pengaturan yang rinci.

Pengambilan Data Hibrida

RetroDB secara otomatis menggabungkan data dari beberapa sumber untuk memaksimalkan cakupan metadata:

  • Metadata teks dari sumber tersedia dengan prioritas tertinggi
  • Gambar dan media dari sumber sekunder saat sumber utama tidak memilikinya
  • Pengisian celah otomatis lintas scraper untuk cakupan maksimal
  • Judul urut (sort title) dibuat otomatis dari judul game selama pengambilan data

Penanganan Media

  • Kolom media (boxart, boxart 3D, screenshot, fanart, video, manual) tidak pernah diganti selama pengambilan data normal — hanya diisi jika kosong
  • Screenshot selalu ditambahkan, tidak pernah diganti
  • Untuk mengunduh ulang media, kosongkan gambar yang ada di modal edit terlebih dahulu, lalu ambil data ulang
  • Mode Full Re-scrape menggantikan aturan ini dan mengganti semuanya
  • Referensi media yang basi (berkas dihapus tetapi nama berkas masih ada di database) otomatis dibersihkan sebelum pengambilan data agar media segar dapat diunduh
  • Gambar yang diunduh otomatis distandardisasi ke ukuran target (lihat Image Standardization)

Prioritas Scraper

Konfigurasikan scraper mana yang berjalan lebih dulu dan mana yang aktif/nonaktif di Settings → Scraping → Scraper. Seret dan lepas untuk mengurutkan ulang prioritas. Scraper yang dinonaktifkan tidak akan dicoba selama pengambilan data dan tidak akan memicu peringatan status API di Dasbor.

Pembatasan Laju

Setiap scraper memiliki batas laju yang dapat dikonfigurasi untuk mencegah pembatasan API. Jeda bawaan diatur secara konservatif. Mengurangi jeda adalah risiko Anda sendiri — melebihi batas laju API dapat mengakibatkan pemblokiran sementara dari layanan terkait.

Pengambilan Data Massal

Memulai Pengambilan Data Massal

  1. Buka halaman System atau Library mana pun
  2. Klik "Select" untuk masuk ke mode pemilihan
  3. Pilih game satu per satu atau gunakan pemilihan cepat:
    • Select All — Semua game yang terlihat
    • Select Unscraped — Hanya game tanpa metadata
  4. Pilih mode: Fill Missing atau Full Re-scrape
  5. Klik "Scrape Selected"

Kontrol

  • Pause / Resume — Jeda atau lanjutkan pengambilan data
  • Cancel — Hentikan sepenuhnya
  • Background — Kecilkan dan terus menjelajah selagi pengambilan data berjalan

Notifikasi Toast

Saat berjalan di latar belakang, toast yang persisten menampilkan kemajuan di semua halaman:

  • Nama game saat ini, jumlah kemajuan, dan statistik hasil (berhasil, gagal, dilewati)
  • Kontrol Pause/Cancel tersedia dari halaman mana pun
  • Klik toast untuk kembali ke modal pengambilan data

Sistem Antrean

Beberapa pengambilan data massal otomatis masuk antrean:

  • Mulai pengambilan data baru saat satu sedang berjalan — job masuk antrean
  • Antrean ditampilkan di toast dengan jumlah job yang tertunda
  • Job diproses otomatis secara berurutan
  • Gunakan Queue Manager untuk melihat, mengurutkan ulang, atau membatalkan job dalam antrean

Opsi Pengambilan Data

  • Fill Missing Only — Hanya mengisi kolom metadata yang kosong, mempertahankan data yang sudah ada
  • Full Re-scrape — Mengganti semua kolom termasuk media (mengunduh gambar dan video baru)
  • Check RetroAchievements — Juga memeriksa set achievement RetroAchievements selama pengambilan data

Pemulihan Job

AI Fill

Fungsinya

AI Fill menggunakan model bahasa besar (Gemini, OpenAI, atau Claude) untuk mengisi metadata game yang hilang atau tidak lengkap secara cerdas. Fitur ini lebih pintar daripada pengambilan data biasa karena menggunakan pengetahuan kontekstual tentang game untuk memberikan data akurat yang mungkin tidak dimiliki scraper.

Cara Menggunakan

  1. Buka modal detail game (atau halaman detail penuh)
  2. Klik "AI Fill" (memerlukan kunci API AI yang dikonfigurasi di Settings)
  3. AI menganalisis judul dan sistem game, lalu mengisi kolom yang hilang
  4. Tinjau hasilnya — perubahan disimpan otomatis

Apa yang Bisa Disediakan AI Fill

  • Genre, deskripsi, developer, publisher, tanggal rilis
  • Jumlah pemain, mode permainan (Single-Player, Multi-Player, Co-op, dll.)
  • Info campaign dan struktur game
  • Semua 8 sistem rating usia (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Region, franchise, game serupa
  • Dukungan kontroler, jenis penyimpanan
  • Perspektif (First-Person, Top-Down, Side-Scroller, dll.), dimensi (2D, 3D)
  • Info edisi, skor kritikus dan pengguna

Logika Pengisian Cerdas

  • Kolom kosong selalu diisi
  • Data pengguna yang sudah ada tidak pernah ditimpa
  • Game serupa selalu disegarkan (data AI lebih andal untuk kolom ini)
  • Rating hasil pemetaan silang — Jika satu sistem rating sudah diketahui, rating kosong di sistem lain otomatis diisi menggunakan pemetaan silang tingkat kedewasaan
  • Sort title dibuat otomatis saat diisi
  • Kolom Players menormalkan rentang (mis. "1-4" menjadi 4)

Normalisasi Genre

AI Fill menggunakan bentuk genre baku dengan nama berbentuk hyphen:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Persyaratan

Setidaknya satu kunci API penyedia AI harus dikonfigurasi di Settings → Scraping → API Keys. Tingkatan model termurah (Gemini Flash Lite, GPT-4o Mini, atau Claude Haiku) sudah bekerja dengan baik untuk metadata.

Koleksi (Tag, Daftar, Wishlist)

Tag

Buat tag kustom berkode warna untuk mengatur game Anda. Tag bekerja seperti label — setiap game bisa memiliki beberapa tag, dan setiap tag bisa berisi beberapa game.

  • Tetapkan tag ke game lewat modal detail game
  • Klik tag mana pun untuk menjelajahi semua game dengan tag tersebut
  • Edit atau hapus tag dari halaman manajemen Tags

Daftar Bernama

Buat daftar game kurasi dengan urutan kustom. Daftar (Lists) mirip playlist — Anda mengendalikan urutan pasti dari game-game tersebut.

  • Buat daftar dengan nama, deskripsi, dan ikon dari halaman Lists
  • Tambahkan game ke daftar lewat modal detail game atau halaman daftar
  • Seret dan lepas untuk mengurutkan ulang game dalam sebuah daftar
  • Urutkan berdasarkan urutan kustom atau alfabetis

Wishlist

Tip: Setelah mengimpor game dari platform mana pun, Anda dapat mengambil metadatanya menggunakan pengambilan data massal, sama seperti game ROM. Game yang diimpor juga bisa melacak achievement dari platform masing-masing.

Trofi PS3 / PSN

Trofi Lokal RPCS3

Lacak trofi yang diperoleh dalam game PS3 lewat emulator RPCS3.

  1. Atur jalur trofi RPCS3 Anda di Settings → Data → Trophies
  2. Klik "Scan Trophies" untuk mengimpor trofi yang sudah diperoleh
  3. Lihat daftar trofi dan detail trofi masing-masing di bagian RPCS3 Trophies

RPCS3 membaca data XML trofi dari direktori pengguna RPCS3 Anda dan mencocokkan game dengan perpustakaan Anda secara otomatis.

Trofi API PSN

Sinkronkan data trofi PlayStation Network Anda dari akun PSN Anda.

  1. Dapatkan cookie NPSSO Anda (lihat di bawah)
  2. Masukkan di Settings → Account → PSN
  3. Perpustakaan trofi PSN Anda diambil lewat API PlayStation
  4. Lihat progres trofi per game dengan jumlah diperoleh/total
  5. Detail trofi masing-masing mencakup deskripsi, kelangkaan, dan stempel waktu pembukaan

Autentikasi PSN (Cookie NPSSO)

PSN menggunakan cookie autentikasi khusus bernama token NPSSO. Untuk mendapatkannya:

  1. Buka peramban web dan masuk ke store.playstation.com
  2. Setelah masuk, kunjungi: https://ca.account.sony.com/api/v1/ssocookie
  3. Halaman tersebut akan menampilkan JSON yang berisi token NPSSO Anda
  4. Salin nilai npsso dan tempelkan di Settings → Account → PSN

Setelah terautentikasi, RetroDB menyimpan token akses secara aman di database-nya sendiri (per pengguna) dan memperbaruinya secara otomatis — Anda tidak perlu menempelkan NPSSO lagi setiap kali sinkronisasi. Sesi tetap berlaku selama kira-kira dua bulan, dan sekarang RetroDB juga memperbaruinya secara otomatis di latar belakang, sehingga dalam penggunaan normal Anda jarang perlu NPSSO baru.

Standardisasi Gambar

Fungsinya

Cara Kerja

  • Upscaling — Gambar yang lebih kecil dari ukuran target ditingkatkan skalanya menggunakan Real-ESRGAN x4 (super-resolusi AI lewat ONNX Runtime) untuk perbesaran berkualitas tinggi, lalu diubah ukurannya ke ukuran target yang tepat

  • Zona ambang batas — Gambar dalam rentang 80–120% dari target dibiarkan apa adanya untuk menghindari pemrosesan ulang yang tidak perlu

Keamanan & Penafian

Praktik Terbaik Keamanan

  • Ganti kata sandi bawaan — Kata sandi admin bawaan (admin) harus segera diganti saat login pertama kali. Gunakan kata sandi kuat setidaknya 8 karakter.
  • Gunakan reverse proxy HTTPS — RetroDB tidak menyediakan TLS/SSL sendiri. Tempatkan di belakang reverse proxy (mis. Nginx, Caddy, Traefik) dengan HTTPS diaktifkan untuk mengenkripsi lalu lintas antara klien dan server.
  • Batasi akses jaringan — Hindari mengekspos RetroDB langsung ke internet publik. Gunakan VPN atau batasi akses ke jaringan lokal Anda. Jika akses jarak jauh diperlukan, gunakan reverse proxy dengan autentikasi.
  • Buat cadangan rutin — Gunakan fitur cadangan bawaan di Settings untuk membuat cadangan database secara berkala. Simpan cadangan di lokasi terpisah dari aplikasi.
  • Jaga RetroDB tetap mutakhir — Periksa rilis baru secara berkala. Perbaikan keamanan dan peningkatan disertakan dalam pembaruan.
  • Lindungi kunci API Anda — Kunci API disimpan dalam data/scraper_settings.json. Pastikan berkas ini tidak dapat diakses secara publik. Jangan pernah membagikan config.py atau berkas token Anda.

Fitur Keamanan Bawaan

  • Hashing kata sandi — Kata sandi admin di-hash dengan PBKDF2 (tidak pernah disimpan dalam teks biasa)
  • Pembatasan laju login — Perlindungan brute-force pada endpoint login
  • Validasi jalur — Semua operasi berkas menggunakan helper safe_path dan safe_filename untuk mencegah serangan directory traversal
  • Kueri berparameter — Semua kueri database menggunakan pernyataan berparameter untuk mencegah SQL injection
  • Perlindungan XSS — Dialog modal menggunakan konstruksi DOM yang aman; input pengguna di-escape
  • Perlindungan bom dekompresi gambar — Jumlah piksel gambar maksimum dibatasi untuk mencegah kehabisan memori akibat gambar berbahaya

Penafian

RetroDB disediakan "APA ADANYA", tanpa jaminan dalam bentuk apa pun, tersurat maupun tersirat, termasuk namun tidak terbatas pada jaminan kelayakan jual, kesesuaian untuk tujuan tertentu, dan tidak adanya pelanggaran. Dalam keadaan apa pun para pengembang atau pemegang hak cipta tidak bertanggung jawab atas klaim, kerusakan, atau kewajiban lain apa pun, baik dalam tindakan kontrak, kesalahan (tort), atau lainnya, yang timbul dari, keluar dari, atau sehubungan dengan perangkat lunak ini atau penggunaan atau transaksi lain dalam perangkat lunak ini.

Anda sepenuhnya bertanggung jawab untuk mengamankan penerapan Anda, termasuk konfigurasi jaringan, kontrol akses, cadangan data, dan kepatuhan terhadap hukum yang berlaku terkait konten yang Anda kelola dengan perangkat lunak ini. Para pengembang tidak bertanggung jawab atas akses tidak sah, kehilangan data, atau penyalahgunaan akibat konfigurasi atau penerapan yang tidak tepat.
