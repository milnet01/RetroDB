🟢 Xbox Live Integration

Xbox integration requires a free Azure AD app registration. Follow these steps:

1
Create an Azure AD App Registration

Go to the Azure Portal and create a new app registration. Use any name (e.g. "RetroDB").

2
Set the Redirect URI

Under Authentication, add a Web platform redirect URI:

http://localhost:5000/api/xbox/callback
3
Add Xbox Live API Permission

Under API permissions → Add a permission → Xbox Live → check XboxLive.signin. Then click "Grant admin consent".

4
Copy the Application (Client) ID

From the app's Overview page, copy the "Application (client) ID" and paste it below.

5
Create a Client Secret

Under Certificates & secrets → New client secret. Copy the Value (not the Secret ID) and paste it below.
