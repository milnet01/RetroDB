Instalação

Requisitos do Sistema

  • Python 3.8+ com pip
  • Navegador web (Chrome, Firefox, Safari, Edge)
  • Sistema operacional: Linux, Windows 10/11 ou macOS

Instalação Rápida

  1. Extraia o ZIP do RetroDB para um diretório de sua escolha
  2. Abra um terminal/prompt de comando nesse diretório
  3. Execute: python install.py
  4. Inicie o servidor:
    • Linux: ./start.sh
    • Windows: dê dois cliques em start.bat
    • macOS: dê dois cliques em start.command
  5. Abra http://localhost:5000 no seu navegador

Instalador Gráfico

No Linux, você também pode executar ./setup.sh para abrir um assistente de instalação gráfico. Ele verifica automaticamente a presença de Python/pip/tkinter e, em seguida, conduz você por cada etapa da configuração com um registro de progresso visual.

O Que o install.py Faz

  • Verifica se Python 3.8+ e pip estão disponíveis
  • Instala as dependências Python a partir de requirements.txt
  • Cria config.py a partir do modelo de exemplo
  • Cria os diretórios necessários (banco de dados, registros, pastas de mídia)
  • Compila os pacotes de CSS e JS

Primeiros Passos

Configuração Inicial

No primeiro início, o RetroDB exibe um Assistente de Configuração que orienta você pelas seguintes etapas:

  1. Conta de Administrador — Crie seu nome de usuário e senha
  2. Caminho da Biblioteca — Defina o diretório dos seus ROMs
  3. Integração com o ES-DE — Opcionalmente vincule as gamelists e mídias do ES-DE
  4. Chaves de API — Opcionalmente adicione chaves de API dos coletores de dados

Após concluir o assistente, clique em "Escanear Biblioteca" no Painel para descobrir seus ROMs.

Fluxo de Início Rápido

  1. Escaneie sua biblioteca para importar os ROMs
  2. Navegue por sistema ou veja todos os jogos na Biblioteca
  3. Colete os metadados individualmente ou use a coleta em lote
  4. Organize com etiquetas, listas e lista de desejos
  5. Acompanhe seu progresso com o status de conclusão e as conquistas

Estrutura da Biblioteca de ROMs

O RetroDB espera que seus ROMs estejam organizados em pastas de sistema dentro do caminho da sua biblioteca:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Cada pasta de sistema deve conter um arquivo systeminfo.txt do ES-DE que define as extensões de arquivo suportadas. O RetroDB lê esse arquivo durante o escaneamento para identificar quais arquivos são ROMs válidos para cada sistema.

Dica: Se você já coletou dados com o ES-DE, o RetroDB pode importar esses dados! Configure os caminhos do ES-DE em Configurações → Integração com o ES-DE, ou durante o assistente de configuração.

Notas por Plataforma

Linux

  • Testado no Ubuntu, Fedora, openSUSE e Arch Linux
  • As Ferramentas de ROM requerem: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) ou o equivalente para a sua distribuição
  • Se você usar o Python do sistema, o instalador lida com --break-system-packages automaticamente
  • Aceleração por GPU ROCm suportada em GPUs AMD (ampliação de imagem com Real-ESRGAN)

Windows

  • Baixe o Python em python.org (marque "Add to PATH" durante a instalação)
  • Ferramentas de ROM: Instale o 7-Zip, o WinRAR e o MAME (para o chdman)
  • Use start.bat para iniciar, ou execute python app.py pelo Prompt de Comando

macOS

  • O Python 3 pode ser instalado via Homebrew: brew install python3
  • Ferramentas de ROM: brew install p7zip unrar rom-tools
  • Dê dois cliques em start.command no Finder para iniciar
  • Aceleração CoreML suportada no Apple Silicon (ampliação de imagem com Real-ESRGAN)

Um anel de progresso circular mostra a saúde geral da sua coleção como uma porcentagem, codificada por cor de acordo com a qualidade:

  • Verde (80%+) — Excelente cobertura de metadados
  • Ciano (60–79%) — Boa cobertura com algumas lacunas

  • Vermelho (<40%) — Lacunas significativas de metadados

Recuperação de Tarefas

Se o RetroDB for reiniciado enquanto tarefas em segundo plano estiverem em execução (coleta em lote, sincronização de RA, redimensionamento de imagens, etc.), as tarefas interrompidas aparecem em um aviso de recuperação. Opções:

  • Retomar — Reinicia uma tarefa interrompida individual
  • Retomar Todas — Reinicia todas as tarefas interrompidas
  • Dispensar — Remove uma tarefa individual da lista de recuperação
  • Dispensar Todas — Remove todas as tarefas interrompidas

Guia de Configuração de Chaves de API

As chaves de API são opcionais, mas habilitam a coleta de metadados ricos e recursos adicionais. Configure-as em Configurações → Coleta de Dados → Chaves de API.

Coletores de Metadados

TheGamesDB

  1. Acesse api.thegamesdb.net/key.php
  2. Solicite as chaves de API (gratuitas, aprovadas manualmente) — você receberá uma chave Pública e uma Privada
  3. Insira ambas as chaves em Configurações → Chaves de API → TheGamesDB
  4. A chave Pública (limite de taxa por IP) é usada como chave primária para a coleta
  5. A chave Privada (cota mensal compartilhada) é usada como alternativa caso a chave pública falhe

IGDB (via Twitch)

  1. Crie uma conta no Twitch em twitch.tv
  2. Acesse dev.twitch.tv/console
  3. Registre um novo aplicativo (qualquer nome, qualquer categoria, http://localhost como redirecionamento OAuth)
  4. Copie o Client ID e gere um Client Secret
  5. Insira ambos em Configurações → Chaves de API → IGDB

RAWG.io

  1. Acesse rawg.io/apidocs
  2. Clique em "Get API Key" e crie uma conta
  3. Copie sua chave de API no painel
  4. Insira-a em Configurações → Chaves de API → RAWG

Plano gratuito: 20.000 requisições/mês

ScreenScraper

  1. Crie uma conta em screenscraper.fr
  2. Insira seu nome de usuário e senha em Configurações → Chaves de API → ScreenScraper

Nota: o ScreenScraper tem limites diários de requisições com base no nível da sua conta. Contribuir com o banco de dados aumenta os seus limites.

Conquistas e Troféus

RetroAchievements

  1. Crie uma conta em retroachievements.org
  2. Acesse Configurações → Chaves de API no seu perfil
  3. Copie sua chave de API
  4. Insira seu nome de usuário e a chave de API em Configurações → Conta → RetroAchievements

Steam Web API

  1. Acesse steamcommunity.com/dev/apikey
  2. Registre-se para obter uma chave da Steam Web API (requer uma conta Steam)
  3. Insira sua chave de API e o Steam ID (ou URL personalizada) nas Configurações

Usado para a importação da biblioteca Steam e o acompanhamento de conquistas.

Xbox Live

A autenticação do Xbox usa OAuth2 — nenhuma chave de API é necessária. Faça login com sua conta Microsoft diretamente na aba Importação de Jogos → Xbox. Os tokens são armazenados em cache automaticamente e renovados conforme necessário.

PlayStation Network (PSN)

A PSN usa autenticação por cookie NPSSO. Consulte a seção Troféus para instruções detalhadas de configuração.

Configurações

As Configurações estão organizadas em 6 abas, cada uma com várias subseções.

Aba Conta

  • Meu Perfil — Envio/remoção de avatar, nome de exibição, informações de função, alteração de senha
  • RetroAchievements — Nome de usuário e chave de API para a integração com o RA
  • PSN — Cookie NPSSO para a sincronização de troféus da PlayStation Network
  • Fuso Horário — Defina seu fuso horário para a exibição de datas em todo o aplicativo
  • Usuários — Gerenciamento de usuários: adicionar, editar, excluir usuários e atribuir funções (somente administrador)

Aba Biblioteca

  • Caminhos — Caminho da biblioteca de ROMs, localização do banco de dados
  • Exibição — Seleção de tema, estilo de capa (2D/3D), sistema de classificação etária preferido, itens por página
  • Nomenclatura de ROMs — Posicionamento do artigo (inicial/final "The"), lista de opções de região, região padrão, convenções de nomenclatura
  • Backup — Criar e restaurar backups do banco de dados

Aba Coleta de Dados

  • ES-DE — Caminhos de gamelist e mídia do ES-DE para importação de dados locais
  • Coletor — Habilitar/desabilitar coletores individuais, ordenação de prioridade por arrastar e soltar, configurações de limite de taxa por coletor
  • Chaves de API — Todas as credenciais dos coletores (TGDB, IGDB, RAWG, ScreenScraper), seleção de provedor de IA e escolha de modelo (Gemini, OpenAI, Claude)

Aba Dados

  • Estatísticas — Visão geral das estatísticas da biblioteca (total de jogos, sistemas, uso de armazenamento)
  • Troféus — Configuração do caminho de troféus do RPCS3 para o escaneamento local de troféus de PS3
  • Listas Suspensas — Personalize as opções de região e outros valores de listas suspensas usados em todo o aplicativo
  • Normalização — Regras de normalização de gênero e modos — adicione mapeamentos personalizados para padronizar a saída dos coletores

Aba Personalização

  • Notificações — Preferências de tempo limite das notificações (sucesso, informação, aviso, erro — cada um configurável de forma independente)
  • Controles — Gerencie a biblioteca de controles, defina controles padrão por sistema, adicione controles personalizados. Os controles padrão substituem os valores coletados/de IA durante a obtenção de metadados.
  • Logotipos — Personalização de logotipos de sistemas — importe logotipos de sistemas ou atualize a partir dos padrões

Aba Sistema

  • Manutenção — Otimização do banco de dados (VACUUM/ANALYZE), limpeza de mídia órfã, limpeza de ROMs ausentes, limpar dados coletados, limpar importações CLZ, padronização de imagens em lote
  • Servidor — Configuração do servidor (host, porta, modo de depuração)
  • Registro — Configurações de nível de registro para diferentes categorias
  • Solução de Problemas — Limpar coleta em lote travada, limpar fila de sincronização de RA, limpar atualização da PSN, limpar geração do museu, reiniciar servidor
Dica: Coletores desabilitados não acionam avisos de "API offline" no Painel. Se você não usa um coletor, desabilite-o em Configurações → Coleta de Dados → Coletor em vez de excluir a chave de API.

Coleta Híbrida

O RetroDB combina automaticamente dados de múltiplas fontes para maximizar a cobertura de metadados:

  • Metadados de texto da fonte disponível de maior prioridade
  • Imagens e mídias de fontes secundárias quando a primária não as possui
  • Preenchimento automático de lacunas entre coletores para máxima cobertura
  • O título de ordenação é gerado automaticamente a partir do título do jogo durante a coleta

Tratamento de Mídia

  • Os campos de mídia (capa, capa 3D, capturas de tela, fanart, vídeo, manual) nunca são substituídos durante a coleta normal — só são preenchidos quando estão vazios
  • As capturas de tela são sempre acrescentadas, nunca substituídas
  • Para baixar mídia novamente, limpe primeiro a imagem existente na janela de edição e depois colete novamente
  • O modo Recoleta Completa ignora isso e substitui tudo
  • Referências de mídia obsoletas (arquivo excluído, mas com o nome ainda no banco de dados) são limpas automaticamente antes da coleta para que mídia nova possa ser baixada
  • As imagens baixadas são padronizadas automaticamente para os tamanhos-alvo (consulte Padronização de Imagens)

Prioridade dos Coletores

Configure quais coletores são executados primeiro e quais estão habilitados/desabilitados em Configurações → Coleta de Dados → Coletor. Arraste e solte para reordenar a prioridade. Coletores desabilitados não serão tentados durante a coleta e não acionarão avisos de status de API no Painel.

Limitação de Taxa

Cada coletor tem limites de taxa configuráveis para evitar a limitação por parte das APIs. Os atrasos padrão são definidos de forma conservadora. Reduza os atrasos por sua conta e risco — exceder os limites de taxa das APIs pode resultar em banimentos temporários do respectivo serviço.

Coleta em Lote

Iniciando uma Coleta em Lote

  1. Vá para qualquer página de Sistema ou da Biblioteca
  2. Clique em "Selecionar" para entrar no modo de seleção
  3. Selecione os jogos individualmente ou use a seleção rápida:
    • Selecionar Todos — Todos os jogos visíveis
    • Selecionar Não Coletados — Apenas jogos sem metadados
  4. Escolha o modo: Preencher Ausentes ou Recoleta Completa
  5. Clique em "Coletar Selecionados"

Controles

  • Pausar / Retomar — Pause ou continue a coleta
  • Cancelar — Pare completamente
  • Segundo Plano — Minimize e continue navegando enquanto a coleta é executada

Notificação Flutuante

Ao executar em segundo plano, uma notificação persistente mostra o progresso em todas as páginas:

  • Nome do jogo atual, contagem de progresso e estatísticas de resultado (sucesso, falha, pulados)
  • Controles de Pausar/Cancelar disponíveis em qualquer página
  • Clique na notificação para voltar à janela de coleta

Sistema de Fila

Várias coletas em lote são enfileiradas automaticamente:

  • Inicie uma nova coleta enquanto uma está em execução — ela entra na fila
  • A fila aparece na notificação com a contagem de tarefas pendentes
  • As tarefas são processadas automaticamente em ordem
  • Use o Gerenciador de Fila para ver, reordenar ou cancelar tarefas enfileiradas

Opções de Coleta

  • Preencher Apenas Ausentes — Preenche apenas os campos de metadados vazios, preservando os dados existentes
  • Recoleta Completa — Substitui todos os campos, incluindo mídia (baixa imagens e vídeos novos)
  • Verificar RetroAchievements — Também verifica conjuntos de conquistas do RetroAchievements durante a coleta

Recuperação de Tarefas

Se o RetroDB for reiniciado enquanto uma tarefa estiver em execução, as tarefas interrompidas aparecem em um aviso de recuperação no Painel. Clique em "Retomar" em tarefas individuais ou em "Retomar Todas" para reiniciá-las. A notificação de progresso aparece imediatamente após a retomada.

Preenchimento por IA

O Que Faz

O Preenchimento por IA usa um grande modelo de linguagem (Gemini, OpenAI ou Claude) para preencher de forma inteligente metadados de jogos ausentes ou incompletos. É mais inteligente do que a coleta comum porque usa conhecimento contextual sobre o jogo para fornecer dados precisos que os coletores podem não ter.

Como Usar

  1. Abra a janela de detalhes de um jogo (ou a página de detalhes completa)
  2. Clique em "Preenchimento por IA" (requer uma chave de API de IA configurada nas Configurações)
  3. A IA analisa o título e o sistema do jogo e, em seguida, preenche os campos ausentes
  4. Revise os resultados — as alterações são salvas automaticamente

O Que o Preenchimento por IA Pode Fornecer

  • Gênero, descrição, desenvolvedora, distribuidora, data de lançamento
  • Jogadores, modos de jogo (Um Jogador, Multijogador, Cooperativo, etc.)
  • Informações de campanha e estrutura do jogo
  • Todos os 8 sistemas de classificação etária (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Região, franquia, jogos similares
  • Suporte a controles, tipo de salvamento
  • Perspectiva (Primeira Pessoa, Vista de Cima, Rolagem Lateral, etc.), dimensão (2D, 3D)
  • Informações de edição, pontuações de crítica e de usuários

Lógica de Preenchimento Inteligente

  • Campos vazios são sempre preenchidos
  • Dados existentes do usuário nunca são sobrescritos
  • Jogos similares são sempre atualizados (os dados da IA são mais confiáveis para este campo)
  • Classificações cruzadas — Se um sistema de classificação for conhecido, as classificações vazias em outros sistemas são preenchidas automaticamente usando o cruzamento por nível de maturidade
  • Título de ordenação é gerado automaticamente quando preenchido
  • O campo Jogadores normaliza intervalos (por exemplo, "1-4" vira 4)

Normalização de Gênero

O Preenchimento por IA usa formas canônicas de gênero com nomes hifenizados:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Requisitos

Pelo menos uma chave de API de provedor de IA deve estar configurada em Configurações → Coleta de Dados → Chaves de API. O nível de modelo mais barato (Gemini Flash Lite, GPT-4o Mini ou Claude Haiku) funciona bem para metadados.

Filtragem e Busca

Busca

A busca filtra os jogos por título (e título de ordenação). Pressione / para focar na caixa de busca. Os resultados são atualizados em tempo real com um atraso (debounce) de 300ms.

Filtro de Fonte

Filtre os jogos pela fonte de importação:

  • Arquivos de ROM — Jogos da sua biblioteca de ROMs
  • Importações CLZ — Jogos físicos importados do CLZ
  • Importações Steam — Jogos importados da Steam
  • Importações Xbox — Jogos importados do Xbox
  • Importações PSN — Jogos importados da PlayStation Network

  • Incluir (É) — Mostra apenas os jogos que correspondem ao valor selecionado
  • Excluir (NÃO É) — Oculta os jogos que correspondem ao valor selecionado

Alterne entre os modos incluir e excluir usando o interruptor na janela de filtro.

Coleções (Etiquetas, Listas, Lista de Desejos)

Etiquetas

Crie etiquetas personalizadas e codificadas por cor para organizar seus jogos. As etiquetas funcionam como rótulos — cada jogo pode ter várias etiquetas, e cada etiqueta pode conter vários jogos.

  • Crie etiquetas com nomes e cores personalizados na página Etiquetas
  • Atribua etiquetas aos jogos pela janela de detalhes do jogo
  • Clique em qualquer etiqueta para navegar por todos os jogos com aquela etiqueta
  • Edite ou exclua etiquetas na página de gerenciamento de Etiquetas

Listas Nomeadas

Crie listas de jogos curadas com ordenação personalizada. As listas são como playlists — você controla a ordem exata dos jogos.

  • Crie listas com nome, descrição e ícone na página Listas
  • Adicione jogos às listas pela janela de detalhes do jogo ou pela página da lista
  • Arraste e solte para reordenar os jogos dentro de uma lista
  • Ordene por ordem personalizada ou alfabeticamente

Lista de Desejos

Acompanhe os jogos que você quer adquirir, sejam físicos ou digitais.

  • Adicione jogos manualmente com título, sistema, notas e prioridade (1–5)
  • Os itens da lista de desejos podem ser vinculados a jogos existentes na biblioteca, se encontrados
  • Ordenados por prioridade (a mais alta primeiro), depois por data de adição
Dica: Use etiquetas para rótulos transversais (por exemplo, "Favoritos", "Cooperativo de Sofá", "Pendentes") e listas para coleções curadas específicas (por exemplo, "Top 10 Jogos de SNES", "Jogos para Transmitir").

  2. Insira-o em Configurações → Conta → PSN

  4. Veja o progresso de troféus por jogo com as contagens obtido/total

Autenticação PSN (Cookie NPSSO)

A PSN usa um cookie de autenticação especial chamado token NPSSO. Para obtê-lo:

  1. Abra um navegador web e faça login em store.playstation.com
  2. Após o login, acesse: https://ca.account.sony.com/api/v1/ssocookie
  3. A página exibirá um JSON contendo seu token NPSSO
  4. Copie o valor npsso e cole-o em Configurações → Conta → PSN

Uma vez autenticados, os tokens são armazenados localmente em cache em data/psn_tokens.json e renovados automaticamente. Os tokens em cache permanecem válidos por aproximadamente 2 meses.

  • Os ícones dos troféus são baixados e armazenados localmente em cache
  • Porcentagem de conclusão por jogo
  • Data e hora de desbloqueio de cada troféu obtido

Sincronização em Lote

Sincronize todos os troféus dos jogos da PSN de uma vez via uma tarefa em segundo plano. O progresso é mostrado em uma notificação flutuante. A limitação de taxa (2,5s entre requisições) evita a limitação por parte da API da PSN.

Troféus de Colecionador

O Que É

Um sistema de gamificação que concede troféus com base nos marcos da sua coleção. À medida que você adiciona jogos, coleta metadados e conclui jogos, os troféus são desbloqueados automaticamente.

Níveis de Troféu

NívelExemplos
BronzeAdicionar o primeiro jogo, chegar a 10 jogos, primeira coleta, 5 sistemas, primeira conclusão
Prata100 jogos, 50 coletados, 10 sistemas, 10 conclusões, 500 jogos
Ouro1.000 jogos, 100% de cobertura de metadados, 20 sistemas, 50 conclusões
Platina5.000 jogos, 100 conclusões, mais de 30 sistemas

Como Funciona

  • O progresso é acompanhado automaticamente com base nas estatísticas da sua biblioteca
  • Visite a página Troféus de Colecionador para ver seu progresso em direção a cada troféu
  • Clique em "Atualizar" para atualizar o progresso após fazer alterações
  • Os troféus obtidos são exibidos com a data de desbloqueio
  • As barras de progresso mostram o quão perto você está do próximo marco

Museu

O Que É

Uma enciclopédia interativa de sistemas de videogame organizada por geração. Aprenda sobre a história, as especificações e os jogos notáveis de cada plataforma da sua coleção.

Página Inicial

A página inicial do Museu mostra uma linha do tempo de sistemas de videogame agrupados por geração (1ª–9ª Geração, Portáteis, Arcade, Computadores). Cada cartão de sistema mostra a imagem do hardware e a contagem de jogos da sua biblioteca.

Páginas de Detalhes do Sistema

Clique em qualquer sistema para ver sua página de museu, que inclui:

  • Imagem do Hardware — Foto do console/sistema
  • Especificações Técnicas — CPU, GPU, RAM, resolução, tipo de mídia
  • História — Narrativa gerada por IA sobre o desenvolvimento, o lançamento e o legado do sistema
  • Top 10 Jogos — Os títulos mais notáveis do sistema (a partir de pontuações da crítica e sugestões da IA)
  • Galeria de Controles — Imagens dos controles do sistema com descrições

Geração de Conteúdo por IA

O conteúdo do Museu é gerado usando IA (Gemini, OpenAI ou Claude). Você pode gerar conteúdo para:

  • Sistema único — Clique em "Gerar" na página de museu de qualquer sistema
  • Geração em lote — Gere conteúdo para todos os sistemas de uma vez na página inicial (executa como uma tarefa em segundo plano com progresso por notificação flutuante)

Imagens de Controles

As imagens de controles podem ser adicionadas via:

  • Busca de Imagens — Busque por fotos de controles usando a Busca de Imagens do Bing. Os resultados são classificados por relevância (nome do controle + fabricante + variações de sistema).
  • Envio Manual — Envie suas próprias imagens de controles
  • Remoção de Fundo — Remova fundos automaticamente usando IA local (biblioteca rembg) para imagens de controles transparentes sobre qualquer fundo
  • Propagação de Imagens — Quando uma imagem de controle é encontrada, ela é compartilhada automaticamente com o mesmo controle em outros sistemas (controles irmãos)
  • Busca em Lote — Busque imagens para todos os controles de um sistema de uma vez

Todas as imagens de controles são padronizadas para o tamanho-alvo e salvas no formato WebP.

Dica: Uma chave de API de IA é necessária para a geração de conteúdo. O Museu usa o mesmo provedor de IA configurado em Configurações → Coleta de Dados → Chaves de API.

Relatórios de ROM

O Que Faz

Valida os nomes de arquivos de ROM em relação às convenções de nomenclatura padrão e identifica possíveis problemas. Acesse via Relatórios de ROM na barra lateral.

Tipos de Relatório

AbaO Que Verifica
Nomes Fora do PadrãoROMs com nomes de arquivo que não correspondem às convenções de nomenclatura. Mostra o nome atual, os problemas detectados e o nome corrigido sugerido.
Divergências de NomeROMs em que o nome do arquivo não corresponde ao título dos metadados coletados. Mostra o nome atual do arquivo vs o título coletado, região, ano e desenvolvedora.

O Que É Verificado

  • Caracteres inválidos nos nomes de arquivo (: ? * / " < > | \)
  • Etiquetas de região ausentes ou incorretas (por exemplo, (USA), (Europe))
  • Etiquetas de ano ausentes
  • Divergências entre o nome do arquivo e o título do banco de dados

Os relatórios podem ser ordenados por sistema, nome de arquivo e tipo de problema. Use-os para manter sua biblioteca de ROMs organizada e com nomes consistentes.

Ferramentas de ROM

Acesse o painel de Ferramentas de ROM pela barra lateral. Cada ferramenta é executada como uma tarefa em segundo plano com atualizações de progresso em tempo real, suporte a pausar/retomar e registro.

Escâner de Arquivos Compactados

Extraia arquivos compactados de ROM (ZIP, 7Z, RAR) com opções para:

  • Escaneamento recursivo de subdiretórios
  • Remoção de arquivos indesejados após a extração
  • Geração automática de playlist M3U para jogos multidisco

Requer: 7z ou unzip

Conversor de CHD

Converta imagens de disco (ISO, BIN/CUE, GDI) para o formato comprimido CHD. Economiza armazenamento significativo mantendo a compatibilidade total com os emuladores.

Requer: chdman (do mame-tools)

Verificação de CHD

Verifique a integridade de arquivos CHD com validação por hash. Identifica conversões corrompidas ou incompletas.

Requer: chdman

Localizador de Duplicatas

Encontre ROMs duplicados por hash ou nome de arquivo, com opções para priorizar por etiquetas de região.

Sem dependências externas

Organizador Multidisco

Organize jogos multidisco em subdiretórios e gere playlists M3U para emuladores que as suportam. Útil para sistemas como PlayStation e Saturn.

Sem dependências externas

Deduplicação de Capturas de Tela

Encontre e remova capturas de tela duplicadas em toda a sua biblioteca de jogos para liberar espaço de armazenamento.

  • Hash Exato (MD5) — Identifica apenas arquivos idênticos
  • Similaridade Visual — Comparação por hash perceptual com limiar configurável (1–20, menor = correspondência mais rigorosa)

Escaneia progressivamente com estatísticas ao vivo mostrando os jogos escaneados, a contagem de duplicatas e o espaço recuperável. Os resultados são agrupados por jogo e sistema. Você pode selecionar qual arquivo manter em cada grupo de duplicatas, ou usar "Selecionar Maior" para manter automaticamente a versão de maior resolução.

Sem dependências externas

Redimensionador de Imagens

Padronize as mídias de jogos para tamanhos-alvo consistentes. Consulte Padronização de Imagens para detalhes completos.

Sem dependências externas (ampliação por IA baseada em Python)

Preencher Títulos Alternativos

Varre a biblioteca em busca de jogos cujo campo de títulos alternativos está vazio e o preenche a partir do IGDB / TGDB / ScreenScraper. Útil após importar um catálogo grande ou migrar de outra ferramenta que não armazenava títulos regionais / japoneses / subtítulos. Executa em segundo plano; o progresso é mostrado no cartão da ferramenta.

Requer pelo menos uma chave de API de coletor (IGDB / TGDB / ScreenScraper)

Consulta HLTB em Lote

Execute uma consulta ao HowLongToBeat para cada jogo sem uma estimativa de tempo de jogo. Cada correspondência é pontuada por título + plataforma + ano de lançamento; correspondências de alta confiança são salvas automaticamente. Qualquer coisa abaixo do limiar de confiança (ou com plataformas conflitantes) é reservada para revisão humana.

Sem dependências externas (usa o conjunto de dados HLTB offline incluído)

Revisão Pendente do HLTB

Fila de revisão para correspondências ambíguas geradas pela Consulta HLTB em Lote. Cada linha pendente mostra o jogo de origem ao lado do candidato do HLTB (título, plataforma, ano de lançamento, confiança). Aprove, rejeite ou escolha uma correspondência diferente por linha. O cartão da ferramenta de revisão só aparece no painel de Ferramentas de ROM quando há pelo menos uma correspondência pendente.

  • Abas de filtro para correspondências de baixa confiança, de título alternativo e de divergência de plataforma.
  • Aprovar grava a estimativa de tempo de jogo; Rejeitar descarta o candidato e mantém a fila de consulta limpa.

Configurações das Ferramentas

Configure caminhos, localizações de ferramentas, tipos de arquivos compactados e preferências compartilhadas entre todas as ferramentas de ROM.

Dica: Todas as ferramentas de ROM suportam pausar/retomar e são executadas em segundo plano. O progresso e os resultados são registrados e podem ser vistos no Visualizador de Registros. O status da ferramenta (disponível vs requer instalação) é mostrado em cada cartão de ferramenta.

Normalização

O Que Faz

Normaliza os valores de gênero e modo de jogo para formas canônicas consistentes. Isso acontece automaticamente durante a coleta e o Preenchimento por IA, e também pode ser aplicado manualmente à sua biblioteca existente.

Por Que Importa

Diferentes coletores usam nomes diferentes para a mesma coisa. A normalização garante a consistência em toda a sua biblioteca:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Regras Personalizadas

Você pode adicionar regras de normalização personalizadas em Configurações → Dados → Normalização. As regras personalizadas substituem os mapeamentos internos, permitindo que você defina seus próprios nomes preferidos de gênero e modo. As regras são armazenadas no banco de dados.

Visualizar e Aplicar

Antes de aplicar a normalização, você pode visualizar quais jogos serão afetados e quais alterações serão feitas. Isso permite que você revise antes de confirmar as mudanças na sua biblioteca.

Padronização de Imagens

O Que Faz

Padroniza todas as mídias de jogos para tamanhos-alvo consistentes, para uma aparência uniforme em toda a sua biblioteca. Imagens entre 80–120% do tamanho-alvo são puladas.

Como Funciona

  • Ampliação — Imagens menores que o tamanho-alvo são ampliadas usando o Real-ESRGAN x4 (super-resolução por IA via ONNX Runtime) para um aumento de alta qualidade, e depois redimensionadas para o tamanho-alvo exato
  • Redução — Imagens maiores que o tamanho-alvo são reduzidas usando a filtragem Lanczos para resultados nítidos
  • Faixa de limiar — Imagens entre 80–120% do alvo são deixadas intactas para evitar reprocessamento desnecessário

Capa 3D1080px de alturaA largura escala proporcionalmente (preserva a transparência)
Capturas de tela1080px de alturaA largura escala proporcionalmente

Como Executar

  1. Vá para Configurações → Sistema → Manutenção ou Ferramentas de ROM → Redimensionador de Imagens
  2. Clique em "Iniciar" para começar a padronização em lote
  3. A tarefa é executada em segundo plano com progresso por notificação flutuante mostrando o arquivo atual e as estatísticas
  4. As imagens também são padronizadas automaticamente durante a coleta (novos downloads são padronizados imediatamente)

Suporte de Hardware

O modelo Real-ESRGAN detecta automaticamente seu hardware e usa o melhor provedor disponível:

  • CUDA — Aceleração por GPU NVIDIA
  • ROCm — Aceleração por GPU AMD (com substituição automática da versão gfx para a série RX 6000)
  • CoreML — Aceleração no Apple Silicon
  • CPU — Alternativa para sistemas sem suporte a GPU

O arquivo do modelo ONNX é baixado automaticamente do Hugging Face no primeiro uso e armazenado localmente em cache.

Manutenção

As operações de manutenção estão disponíveis em Configurações → Sistema → Manutenção. Elas ajudam a manter sua biblioteca limpa e otimizada.

Escaneamento da Biblioteca

  • Escanear Biblioteca — Escaneia seus diretórios de ROMs em busca de novos jogos. Detecta as pastas de sistema e os tipos de arquivo suportados usando as listas de extensão do systeminfo.txt do ES-DE. Também disponível no Painel.

Operações de Limpeza

  • Limpar ROMs Ausentes — Remove as entradas do banco de dados de jogos cujos arquivos de ROM não existem mais no disco. Útil após reorganizar ou excluir arquivos de ROM.
  • Limpeza de Mídia Órfã — Encontra e exclui arquivos de imagem no disco (capa, capturas de tela, fanart) que não têm uma referência correspondente no banco de dados. Visualize antes de excluir para confirmar.

Otimização do Banco de Dados

  • Otimizar Banco de Dados — Executa o VACUUM e o ANALYZE do SQLite para recuperar armazenamento de registros excluídos e atualizar as estatísticas do planejador de consultas. Recomendado após grandes exclusões ou operações de limpeza.

Backup e Restauração

Criando Backups

  1. Vá para Configurações → Biblioteca → Backup
  2. Clique em "Criar Backup"
  3. O backup é salvo na pasta backups/ com um nome de arquivo com data e hora

O Que É Incluído no Backup

O backup inclui todo o banco de dados SQLite (roms.db), que contém todos os metadados de jogos, contas de usuário, configurações, dados de troféus, progresso de conquistas, etiquetas, listas e itens da lista de desejos.

O Que NÃO É Incluído no Backup

Os arquivos de mídia (capa, capturas de tela, fanart, vídeos, manuais) NÃO são incluídos no backup do banco de dados, pois podem ser baixados novamente pela coleta. Considere fazer backup do seu diretório static/images/ separadamente se você tiver envios personalizados.

Restaurando

  1. Encontre o backup na lista de backups
  2. Clique em "Restaurar"
  3. Confirme a ação
Aviso: Restaurar um backup sobrescreve seu banco de dados atual. Crie um backup novo antes de restaurar um mais antigo!

Atualizando o RetroDB

Como Atualizar

  1. Baixe a nova versão do RetroDB
  2. Faça backup destes arquivos (eles contêm seus dados pessoais):
    • config.py (seus caminhos e chaves de API)
    • data/settings.json (suas preferências de interface)
    • data/scraper_settings.json (sua configuração de coletores)
    • data/rom_tools_config.json (suas preferências das ferramentas de ROM)
    • data/psn_tokens.json (seus tokens de autenticação da PSN)
    • data/xbox_tokens.json (seus tokens de autenticação do Xbox)
    • pasta database/ (o banco de dados da sua biblioteca de jogos)
  3. Extraia a nova versão sobre a instalação existente
  4. Execute python install.py para instalar quaisquer novas dependências
  5. Reinicie o servidor

Arquivos Seguros para Sobrescrever

Todos os arquivos de código-fonte (.py, .html, .css, .js) podem ser sobrescritos com segurança. O instalador não sobrescreverá seus arquivos de configuração pessoais.

Arquivos a Manter

Nunca exclua ou sobrescreva: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Migrações de Banco de Dados

O RetroDB lida automaticamente com as alterações de esquema do banco de dados na inicialização. Novas colunas e tabelas são adicionadas conforme necessário, sem perda de dados. Você não precisa fazer nada especial — basta iniciar a nova versão e o banco de dados é atualizado automaticamente.

Solução de Problemas

Problemas Comuns

"Nenhuma extensão encontrada para o sistema"

A pasta do sistema precisa de um arquivo systeminfo.txt válido do ES-DE que defina as extensões de arquivo de ROM suportadas. Certifique-se de que a estrutura do seu diretório de ROMs corresponda aos padrões do ES-DE.

"Falha na conexão com a API"

  • Verifique sua conexão com a internet
  • Verifique as chaves de API em Configurações → Coleta de Dados → Chaves de API
  • Aguarde se houver limitação de taxa (algumas APIs têm limites diários/horários)
  • Verifique se o coletor está habilitado (coletores desabilitados mostram "Desabilitado" no status do Painel)
  • Verifique o Visualizador de Registros para mensagens de erro detalhadas

"Coleta em Lote Travada"

Vá para Configurações → Sistema → Solução de Problemas → "Limpar Coleta em Lote Travada". Isso redefine o estado da tarefa sem afetar seus dados.

"Fila de Sincronização de RA Travada"

Limpe a fila de sincronização do RetroAchievements em Configurações → Sistema → Solução de Problemas.

"Sincronização da PSN Travada"

Limpe a tarefa de atualização da PSN em Configurações → Sistema → Solução de Problemas.

"Geração do Museu Travada"

Limpe a tarefa de geração do museu em Configurações → Sistema → Solução de Problemas.

"Erros de Banco de Dados"

  1. Crie um backup se possível (Configurações → Biblioteca → Backup)
  2. Tente Configurações → Sistema → Manutenção → Otimizar Banco de Dados
  3. Verifique as permissões de arquivo no diretório database/
  4. Último recurso: restaure a partir de um backup ou exclua o banco de dados e escaneie novamente

"Imagens Não Salvam"

Verifique as permissões de escrita nos diretórios de mídia: chmod -R 755 static/images/

"Página Lenta ou Sem Resposta"

  • Coleções grandes podem levar tempo para carregar — a rolagem infinita carrega em lotes de 100
  • Tente atualizar a página para liberar memória acumulada
  • Verifique o console do navegador por erros de JavaScript
  • Tente mudar para um tema com um efeito de canvas mais leve (por exemplo, Amber ou Elite)
  • Os efeitos em canvas detectam o hardware automaticamente; dispositivos mais modestos usam a alternativa por CPU com taxa de quadros reduzida

Aviso de "Tarefas Interrompidas" no Painel

Se o RetroDB reiniciar enquanto tarefas estiverem em execução, elas aparecem em um aviso de recuperação. Clique em "Retomar" individualmente ou em "Retomar Todas" para reiniciá-las. Clique em "Dispensar" ou "Dispensar Todas" para removê-las.

"Falha na Autenticação PSN"

  • Os tokens NPSSO expiram — gere um novo a partir de ca.account.sony.com/api/v1/ssocookie
  • Certifique-se de estar logado em store.playstation.com antes de visitar a URL do cookie
  • Os tokens em cache em data/psn_tokens.json duram aproximadamente 2 meses

"Falha na Autenticação Xbox"

  • Autentique novamente clicando em "Entrar" na aba Importação de Jogos → Xbox
  • Os tokens do Xbox são armazenados em cache em data/xbox_tokens.json e renovados automaticamente

"Erros de Ampliação de Imagem"

  • O modelo ONNX do Real-ESRGAN é baixado no primeiro uso — garanta acesso à internet
  • A aceleração por GPU requer drivers compatíveis (CUDA para NVIDIA, ROCm para AMD)
  • Se a GPU falhar, o sistema recorre automaticamente ao processamento por CPU

Dicas de Desempenho

  • Mantenha seu navegador atualizado para o melhor desempenho
  • Feche outras abas do navegador ao trabalhar com coleções muito grandes
  • Use os filtros de sistema para reduzir a quantidade de jogos exibidos de uma vez
  • Execute o Otimizar Banco de Dados periodicamente após grandes operações (coleta, limpeza, importações)
  • Os efeitos de tema em canvas detectam o hardware automaticamente; dispositivos mais modestos usam a alternativa por CPU

Segurança e Isenção de Responsabilidade

Boas Práticas de Segurança

  • Altere a senha padrão — A senha padrão de administrador (admin) deve ser alterada imediatamente no primeiro login. Use uma senha forte de pelo menos 8 caracteres.
  • Use um proxy reverso HTTPS — O RetroDB não fornece TLS/SSL por conta própria. Coloque-o atrás de um proxy reverso (por exemplo, Nginx, Caddy, Traefik) com HTTPS habilitado para criptografar o tráfego entre os clientes e o servidor.
  • Restrinja o acesso à rede — Evite expor o RetroDB diretamente à internet pública. Use uma VPN ou restrinja o acesso à sua rede local. Se o acesso remoto for necessário, use um proxy reverso com autenticação.
  • Mantenha backups regulares — Use o recurso de backup integrado em Configurações para criar backups periódicos do banco de dados. Armazene os backups em um local separado do aplicativo.
  • Mantenha o RetroDB atualizado — Verifique se há novas versões regularmente. Correções de segurança e melhorias são incluídas nas atualizações.
  • Proteja suas chaves de API — As chaves de API são armazenadas em data/scraper_settings.json. Garanta que este arquivo não seja publicamente acessível. Nunca compartilhe seu config.py ou arquivos de token.

Recursos de Segurança Integrados

  • Hashing de senha — As senhas de administrador são protegidas por hash com PBKDF2 (nunca armazenadas em texto simples)
  • Limitação de taxa de login — Proteção contra força bruta no endpoint de login
  • Validação de caminho — Todas as operações de arquivo usam os auxiliares safe_path e safe_filename para evitar ataques de travessia de diretório
  • Consultas parametrizadas — Todas as consultas ao banco de dados usam declarações parametrizadas para evitar injeção de SQL
  • Proteção contra XSS — As janelas modais usam construção segura de DOM; a entrada do usuário é escapada
  • Proteção contra bomba de descompressão de imagem — A contagem máxima de pixels da imagem é limitada para evitar o esgotamento de memória por imagens maliciosas
