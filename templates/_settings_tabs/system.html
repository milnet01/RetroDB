🗂️ Orphaned Media Cleanup

Find and delete media files (boxart, screenshots, videos, etc.) for ROMs that no longer exist in the database. This cleans up leftover files from deleted games.

🖼️ Missing Media References

The reverse of orphaned-media cleanup: find games whose boxart, screenshots, video or manual point to files that are no longer on disk, and clear those stale references so scrapers can re-download them. If a whole media folder looks missing or empty (for example an unmounted drive), its references are kept and flagged rather than wiped.

💾 Database Optimization

Optimize the database for better performance. Runs VACUUM to reclaim unused space and ANALYZE to update query planner statistics.
