Установка

Системные требования

  • Python 3.8+ с pip
  • Веб-браузер (Chrome, Firefox, Safari, Edge)
  • Операционная система: Linux, Windows 10/11 или macOS

Быстрая установка

  1. Распакуйте ZIP-архив RetroDB в выбранный каталог
  2. Откройте терминал/командную строку в этом каталоге
  3. Выполните: python install.py
  4. Запустите сервер:
    • Linux: ./start.sh
    • Windows: дважды щёлкните start.bat
    • macOS: дважды щёлкните start.command
  5. Откройте http://localhost:5000 в браузере

Графический установщик

В Linux можно также запустить ./setup.sh, чтобы открыть мастер установки с графическим интерфейсом. Он автоматически проверяет наличие Python/pip/tkinter, а затем проводит вас через все шаги настройки с наглядным журналом хода выполнения.

Что делает install.py

  • Проверяет наличие Python 3.8+ и pip
  • Устанавливает зависимости Python из requirements.txt
  • Создаёт config.py из файла-примера
  • Создаёт необходимые каталоги (база данных, журналы, папки для медиафайлов)
  • Собирает пакеты CSS и JS

Начало работы

Первоначальная настройка

При первом запуске RetroDB показывает Мастер настройки, который проведёт вас через следующие шаги:

  1. Учётная запись администратора — создайте имя пользователя и пароль
  2. Путь к библиотеке — укажите каталог с ROM-файлами
  3. Интеграция с ES-DE — по желанию свяжите списки игр и медиафайлы ES-DE
  4. Ключи API — по желанию добавьте ключи API для скраперов

После завершения мастера нажмите «Сканировать библиотеку» на панели управления, чтобы обнаружить ваши ROM-файлы.

Быстрый старт

  1. Просканируйте библиотеку, чтобы импортировать ROM-файлы
  2. Просматривайте игры по системам или все игры сразу в разделе «Библиотека»
  3. Скрапьте метаданные по отдельности или используйте массовый скрапинг
  4. Организуйте с помощью тегов, списков и списка желаний
  5. Отслеживайте прогресс с помощью статуса прохождения и достижений

Структура библиотеки ROM

RetroDB ожидает, что ваши ROM-файлы организованы по папкам систем внутри пути к библиотеке:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Каждая папка системы должна содержать файл ES-DE systeminfo.txt, определяющий поддерживаемые расширения файлов. RetroDB читает этот файл во время сканирования, чтобы определить, какие файлы являются допустимыми ROM-файлами для каждой системы.

Совет: если вы уже скрапили данные с помощью ES-DE, RetroDB может импортировать эти данные! Настройте пути ES-DE в разделе «Настройки → Интеграция с ES-DE» или во время мастера настройки.

Заметки по платформам

Linux

  • Протестировано на Ubuntu, Fedora, openSUSE и Arch Linux
  • Для инструментов ROM требуется: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) или аналог для вашего дистрибутива
  • При использовании системного Python установщик автоматически обрабатывает --break-system-packages
  • Поддерживается ускорение ROCm GPU для видеокарт AMD (масштабирование изображений Real-ESRGAN)

Windows

  • Скачайте Python с сайта python.org (отметьте «Add to PATH» при установке)
  • Инструменты ROM: установите 7-Zip, WinRAR и MAME (для chdman)
  • Используйте start.bat для запуска или выполните python app.py из командной строки

macOS

  • Python 3 можно установить через Homebrew: brew install python3
  • Инструменты ROM: brew install p7zip unrar rom-tools
  • Дважды щёлкните start.command в Finder для запуска
  • Поддерживается ускорение CoreML для Apple Silicon (масштабирование изображений Real-ESRGAN)

Навигация

Разделы боковой панели

Основные

  • Панель управления — оценка состояния коллекции, обзор статистики, статус API, недавно сыгранные/добавленные/скрапленные игры, восстановление заданий
  • Системы — просмотр платформ с количеством игр, изображениями систем, характеристиками, фильтрацией по типу и возможностям
  • Библиотека — все игры с бесконечной прокруткой, расширенной фильтрацией (включение/исключение), поиском и сортировкой
  • Аналитика — графики и статистика коллекции на 12 вкладках с возможностью экспорта

Трофеи и достижения

  • Трофеи RPCS3 — трофеи PS3, полученные локально через эмулятор RPCS3
  • Трофеи PSN — синхронизация трофеев PlayStation Network через API PSN
  • Достижения — отслеживание прогресса RetroAchievements по системам
  • Достижения Steam — отслеживание достижений Steam с подробностями по каждой игре
  • Достижения Xbox — отслеживание достижений и игрового рейтинга (gamerscore) Xbox

Моя коллекция

  • Теги — собственные цветные теги для игр
  • Списки — именованные подборки игр с сортировкой перетаскиванием
  • Список желаний — отслеживание игр, которые вы хотите приобрести, с уровнями приоритета
  • Трофеи коллекционера — игровые достижения (геймификация) для вашей коллекции

Инструменты

  • Отчёты ROM — проверка именования ROM-файлов и соответствия стандартам
  • Импорт игр — импорт из CLZ, Steam, Xbox и PSN
  • Инструменты ROM — сканер архивов, конвертер/проверка CHD, поиск дубликатов, организатор многодисковых игр, удаление дублей скриншотов, изменение размера изображений

Конфигурация

  • Настройки — вся конфигурация приложения (6 вкладок со множеством подразделов)
  • Просмотр журналов — просмотр журналов приложения по всем категориям

Информация

  • Музей — интерактивная энциклопедия игровых систем с контентом, созданным ИИ
  • Справка — эта страница документации
  • Журнал изменений — история версий

Подсветка боковой панели

Как это работает

  • Темы переопределяют переменные цвета CSS — все элементы интерфейса адаптируются автоматически
  • Эффекты на холсте включают автоматическое определение уровня оборудования (высокий/средний/низкий) с ускорением на GPU при наличии и резервным режимом на CPU для менее мощных устройств
  • Эффекты приостанавливаются, когда вкладка не видна, чтобы сэкономить ресурсы
  • Состояние дыма Cyberpunk сохраняется при переходах между страницами для плавных переходов
  • Лёгкий эффект строк развёртки в стиле ЭЛТ адаптируется под цветовую палитру каждой темы
  • Ваш выбор темы сохраняется в браузере и остаётся между сеансами

Значки с учётом темы

Значки уведомлений, индикаторы состояния заданий и значки действий автоматически адаптируются под текущую тему. Например, значок успеха может показывать зелёную галочку в Cyberpunk, но другой символ в Matrix, чтобы соответствовать эстетике «зелёное на чёрном».

Панель управления

Оценка состояния коллекции

Круговое кольцо прогресса показывает общее состояние коллекции в процентах, окрашенное по качеству:

  • Зелёный (80%+) — отличное покрытие метаданными
  • Голубой (60–79%) — хорошее покрытие с некоторыми пробелами
  • Оранжевый (40–59%) — умеренное покрытие, стоит рассмотреть массовый скрапинг
  • Красный (<40%) — значительные пробелы в метаданных

Обзор статистики

Карточки с наглядной информацией:

  • Всего систем — количество платформ в вашей библиотеке
  • Всего игр — общее количество игр (без учёта бонусных дисков)
  • Отсутствуют метаданные — игры, которые ещё не скраплены
  • Готово — игры со скрапленными метаданными

Разделы недавней активности

Прокручиваемые разделы, показывающие вашу недавнюю активность (каждый появляется только при наличии соответствующих игр):

  • Сейчас играете — игры, отмеченные как «В процессе»
  • Недавно добавленные — последние игры, добавленные в библиотеку
  • Недавно просмотренные — игры, которые вы недавно открывали
  • Недавно скрапленные — игры с недавно полученными метаданными

Быстрые действия

  • Сканировать библиотеку — сканирование каталогов ROM на наличие новых игр
  • Случайная игра — выбор случайной игры из вашей библиотеки

Статус API

Показывает статус подключения всех настроенных скраперов и API. Отключённые или неправильно настроенные API отображают предупреждающий баннер со ссылкой на настройки.

Восстановление заданий

Если RetroDB перезапускается во время выполнения фоновых заданий (массовый скрапинг, синхронизация RA, изменение размера изображений и т. д.), прерванные задания появляются в баннере восстановления. Варианты:

  • Возобновить — перезапустить отдельное прерванное задание
  • Возобновить все — перезапустить все прерванные задания
  • Скрыть — убрать отдельное задание из списка восстановления
  • Скрыть все — убрать все прерванные задания

Обзор систем

Сетка систем

Страница «Системы» показывает все платформы вашей библиотеки в виде карточек в адаптивной сетке типа «кирпичная кладка». Каждая карточка показывает:

  • Логотип системы (настраивается в разделе «Настройки → Персонализация → Логотипы»)
  • Количество ROM-файлов и количество нескрапленных
  • Значок типа системы — консоль, портативная система, компьютер, аркада или движок
  • Значки возможностей — поддержка RetroAchievements, локальные трофеи (RPCS3)

Окно характеристик системы

Нажмите на кнопку информации на любой карточке системы, чтобы увидеть подробные характеристики оборудования:

  • Изображение оборудования (фото консоли/системы)
  • Производитель и дата выпуска
  • ЦП, ГП, ОЗУ, видеопамять
  • Разрешение, глубина цвета, звуковой чип
  • Тип носителя (картридж, диск и т. д.)

Фильтрация и поиск

  • Текстовый поиск — фильтр по названию системы или папки
  • Фильтр по типу — консоль, портативная система, компьютер, аркада, движок
  • Фильтр по возможностям — поддержка RetroAchievements, локальные трофеи
  • Строка результатов фильтрации показывает «X из Y систем»
  • Фильтры сохраняются между перезагрузками страницы через хранилище сеанса

Список игр по системе

Щёлкните по любой карточке системы, чтобы просмотреть её игры. Список игр по системе имеет те же возможности, что и полная страница «Библиотека» — бесконечную прокрутку, поиск, все параметры фильтрации, массовый выбор и сортировку. Заголовок системы показывает название системы, количество игр и значок типа системы.

Руководство по настройке ключей API

Ключи API необязательны, но позволяют получать более полные метаданные и дополнительные возможности. Настройте их в разделе Настройки → Скрапинг → Ключи API.

Скраперы метаданных

TheGamesDB

  1. Перейдите на api.thegamesdb.net/key.php
  2. Запросите ключи API (бесплатно, одобряются вручную) — вы получите публичный (Public) и приватный (Private) ключи
  3. Введите оба ключа в разделе «Настройки → Ключи API → TheGamesDB»
  4. Публичный ключ (ограничение по IP-адресу) используется как основной ключ для скрапинга
  5. Приватный ключ (общий ежемесячный пул) используется как запасной вариант, если публичный ключ не сработал

IGDB (через Twitch)

  1. Создайте учётную запись Twitch на сайте twitch.tv
  2. Перейдите на dev.twitch.tv/console
  3. Зарегистрируйте новое приложение (любое название, любая категория, http://localhost в качестве OAuth redirect)
  4. Скопируйте Client ID и сгенерируйте Client Secret
  5. Введите оба значения в разделе «Настройки → Ключи API → IGDB»

RAWG.io

  1. Перейдите на rawg.io/apidocs
  2. Нажмите «Get API Key» и создайте учётную запись
  3. Скопируйте свой ключ API из панели управления
  4. Введите его в разделе «Настройки → Ключи API → RAWG»

Бесплатный тариф: 20 000 запросов в месяц

ScreenScraper

  1. Создайте учётную запись на screenscraper.fr
  2. Введите имя пользователя и пароль в разделе «Настройки → Ключи API → ScreenScraper»

Примечание: ScreenScraper имеет дневные ограничения на количество запросов в зависимости от уровня учётной записи. Вклад в базу данных увеличивает ваши лимиты.

Достижения и трофеи

RetroAchievements

  1. Создайте учётную запись на retroachievements.org
  2. Перейдите в Настройки → Ключи API в своём профиле
  3. Скопируйте свой ключ API
  4. Введите имя пользователя и ключ API в разделе «Настройки → Учётная запись → RetroAchievements»

Steam Web API

  1. Перейдите на steamcommunity.com/dev/apikey
  2. Зарегистрируйте ключ Steam Web API (требуется учётная запись Steam)
  3. Введите ключ API и Steam ID (или vanity-URL) в настройках

Используется для импорта библиотеки Steam и отслеживания достижений.

Xbox Live

Аутентификация Xbox использует OAuth2 — ключ API не требуется. Войдите с учётной записью Microsoft прямо на вкладке «Импорт игр → Xbox». Токены кэшируются автоматически и обновляются по мере необходимости.

PlayStation Network (PSN)

PSN использует аутентификацию через cookie NPSSO. См. раздел Трофеи для подробных инструкций по настройке.

Настройки

Настройки организованы в 6 вкладок, каждая с несколькими подразделами.

Вкладка «Учётная запись»

  • Мой профиль — загрузка/удаление аватара, отображаемое имя, информация о роли, смена пароля
  • RetroAchievements — имя пользователя и ключ API для интеграции с RA
  • PSN — cookie NPSSO для синхронизации трофеев PlayStation Network
  • Часовой пояс — установка часового пояса для отображения дат во всём приложении
  • Пользователи — управление пользователями: добавление, редактирование, удаление пользователей и назначение ролей (только для администратора)

Вкладка «Библиотека»

  • Пути — путь к библиотеке ROM, расположение базы данных
  • Отображение — выбор темы, стиль обложки (2D/3D), предпочитаемая система возрастных рейтингов, количество элементов на странице
  • Именование ROM — расположение артикля (ведущее/конечное «The»), список вариантов региона, регион по умолчанию, соглашения об именовании
  • Резервное копирование — создание и восстановление резервных копий базы данных

Вкладка «Скрапинг»

  • ES-DE — пути к спискам игр и медиафайлам ES-DE для импорта локальных данных
  • Скрапер — включение/отключение отдельных скраперов, изменение приоритета перетаскиванием, настройка ограничения частоты запросов для каждого скрапера
  • Ключи API — все учётные данные скраперов (TGDB, IGDB, RAWG, ScreenScraper), выбор провайдера ИИ и модели (Gemini, OpenAI, Claude)

Вкладка «Данные»

  • Статистика — обзор статистики библиотеки (общее количество игр, систем, использование хранилища)
  • Трофеи — настройка пути к трофеям RPCS3 для локального сканирования трофеев PS3
  • Выпадающие списки — настройка вариантов региона и других значений выпадающих списков, используемых в приложении
  • Нормализация — правила нормализации жанров и режимов игры — добавление собственных сопоставлений для стандартизации данных скраперов

Вкладка «Персонализация»

  • Уведомления — настройки времени показа уведомлений (успех, информация, предупреждение, ошибка — каждое настраивается отдельно)
  • Контроллеры — управление библиотекой контроллеров, установка контроллеров по умолчанию для каждой системы, добавление собственных контроллеров. Контроллеры по умолчанию имеют приоритет над значениями из скрапинга/ИИ при получении метаданных.
  • Логотипы — настройка логотипов систем — импорт логотипов систем или обновление до значений по умолчанию

Вкладка «Система»

  • Обслуживание — оптимизация базы данных (VACUUM/ANALYZE), очистка «осиротевших» медиафайлов, очистка отсутствующих ROM, очистка скрапленных данных, очистка импортов CLZ, массовая стандартизация изображений
  • Сервер — конфигурация сервера (хост, порт, режим отладки)
  • Журналирование — настройки уровня журналирования для разных категорий
  • Устранение неполадок — сброс зависшего массового скрапинга, очистка очереди синхронизации RA, очистка обновления PSN, очистка генерации музея, перезапуск сервера
Совет: отключённые скраперы не вызывают предупреждения «API offline» на панели управления. Если вы не используете скрапер, отключите его в разделе «Настройки → Скрапинг → Скрапер», а не удаляйте ключ API.

Скрапинг метаданных

Скрапинг одной игры

  1. Откройте окно с деталями любой игры (щёлкните по карточке игры)
  2. Нажмите «Скрапить»
  3. При необходимости измените название для поиска
  4. Выберите нужный результат из найденных совпадений
  5. Нажмите «Применить»

Гибридный скрапинг

RetroDB автоматически объединяет данные из нескольких источников, чтобы максимизировать охват метаданных:

  • Текстовые метаданные из доступного источника с наивысшим приоритетом
  • Изображения и медиафайлы из вторичных источников, если у основного их нет
  • Автоматическое заполнение пробелов между скраперами для максимального охвата
  • Сортировочное название генерируется автоматически из названия игры во время скрапинга

Работа с медиафайлами

  • Поля медиафайлов (обложка, 3D-обложка, скриншоты, фан-арт, видео, инструкция) никогда не заменяются при обычном скрапинге — заполняются только если пусты
  • Скриншоты всегда добавляются, но никогда не заменяются
  • Чтобы заново загрузить медиафайл, сначала очистите существующее изображение в окне редактирования, затем повторите скрапинг
  • Режим «Полный повторный скрапинг» отменяет это правило и заменяет всё
  • Устаревшие ссылки на медиафайлы (файл удалён, но имя файла всё ещё в базе данных) автоматически очищаются перед скрапингом, чтобы можно было загрузить новые медиафайлы
  • Загруженные изображения автоматически приводятся к целевым размерам (см. Стандартизацию изображений)

Приоритет скраперов

Настройте, какие скраперы запускаются первыми и какие включены/отключены, в разделе Настройки → Скрапинг → Скрапер. Перетаскивайте для изменения приоритета. Отключённые скраперы не будут использоваться при скрапинге и не будут вызывать предупреждения о статусе API на панели управления.

Ограничение частоты запросов

Каждый скрапер имеет настраиваемые ограничения частоты запросов для предотвращения блокировки API. Задержки по умолчанию установлены с запасом. Уменьшайте задержки на свой страх и риск — превышение лимитов частоты запросов API может привести к временной блокировке со стороны соответствующего сервиса.

Массовый скрапинг

Запуск массового скрапинга

  1. Перейдите на любую страницу системы или библиотеки
  2. Нажмите «Выбрать», чтобы войти в режим выбора
  3. Выберите игры по отдельности или используйте быстрый выбор:
    • Выбрать все — все видимые игры
    • Выбрать нескрапленные — только игры без метаданных
  4. Выберите режим: «Заполнить недостающее» или «Полный повторный скрапинг»
  5. Нажмите «Скрапить выбранные»

Управление

  • Пауза / Продолжить — приостановить или продолжить скрапинг
  • Отмена — полностью остановить
  • В фон — свернуть и продолжить просмотр, пока скрапинг выполняется

Всплывающее уведомление

При работе в фоне постоянное всплывающее уведомление показывает прогресс на всех страницах:

  • Название текущей игры, счётчик прогресса и статистика результатов (успешно, ошибка, пропущено)
  • Управление паузой/отменой доступно с любой страницы
  • Щёлкните по уведомлению, чтобы вернуться в окно скрапинга

Система очередей

Несколько массовых скрапингов ставятся в очередь автоматически:

  • Запустите новый скрапинг, пока выполняется другой — он встанет в очередь
  • Очередь отображается во всплывающем уведомлении с количеством ожидающих заданий
  • Задания обрабатываются автоматически по порядку
  • Используйте менеджер очереди для просмотра, изменения порядка или отмены заданий в очереди

Параметры скрапинга

  • Только заполнить недостающее — заполнять только пустые поля метаданных, сохраняя существующие данные
  • Полный повторный скрапинг — заменить все поля, включая медиафайлы (загружает новые изображения и видео)
  • Проверять RetroAchievements — также искать наборы достижений RetroAchievements во время скрапинга

Восстановление заданий

Если RetroDB перезапускается во время выполнения задания, прерванные задания появляются в баннере восстановления на панели управления. Нажмите «Возобновить» для отдельных заданий или «Возобновить все», чтобы перезапустить их. Всплывающее уведомление о прогрессе появится сразу после возобновления.

Заполнение ИИ

Что это делает

Заполнение ИИ использует большую языковую модель (Gemini, OpenAI или Claude), чтобы интеллектуально заполнить недостающие или неполные метаданные игры. Это умнее обычного скрапинга, поскольку используются контекстные знания об игре для получения точных данных, которых может не быть у скраперов.

Как использовать

  1. Откройте окно с деталями игры (или полную страницу деталей)
  2. Нажмите «Заполнить ИИ» (требуется настроенный ключ API ИИ в настройках)
  3. ИИ анализирует название игры и систему, затем заполняет недостающие поля
  4. Проверьте результаты — изменения сохраняются автоматически

Что может предоставить заполнение ИИ

  • Жанр, описание, разработчик, издатель, дата выпуска
  • Количество игроков, режимы игры (одиночная игра, многопользовательская игра, кооператив и т. д.)
  • Информация о кампании и структура игры
  • Все 8 систем возрастных рейтингов (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Регион, франшиза, похожие игры
  • Поддержка контроллеров, тип сохранения
  • Перспектива (от первого лица, вид сверху, сайд-скроллер и т. д.), измерение (2D, 3D)
  • Информация об издании, оценки критиков и пользователей

Логика умного заполнения

  • Пустые поля заполняются всегда
  • Существующие пользовательские данные никогда не перезаписываются
  • Похожие игры обновляются всегда (данные ИИ более надёжны для этого поля)
  • Взаимно сопоставленные рейтинги — если известна одна система рейтингов, пустые рейтинги в других системах автоматически заполняются с помощью сопоставления по уровням зрелости
  • Сортировочное название генерируется автоматически при заполнении
  • Поле «Количество игроков» нормализует диапазоны (например, «1-4» становится 4)

Нормализация жанров

Заполнение ИИ использует канонические формы жанров с дефисным написанием:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Требования

Необходимо настроить хотя бы один ключ API провайдера ИИ в разделе Настройки → Скрапинг → Ключи API. Самый дешёвый уровень модели (Gemini Flash Lite, GPT-4o Mini или Claude Haiku) хорошо подходит для метаданных.

Фильтрация и поиск

Поиск

Поиск фильтрует игры по названию (и сортировочному названию). Нажмите /, чтобы перейти к полю поиска. Результаты обновляются в реальном времени с задержкой 300 мс.

Фильтр по источнику

Фильтрация игр по источнику импорта:

  • Файлы ROM — игры из вашей библиотеки ROM
  • Импорт CLZ — физические игры, импортированные из CLZ
  • Импорт Steam — игры, импортированные из Steam
  • Импорт Xbox — игры, импортированные из Xbox
  • Импорт PSN — игры, импортированные из PlayStation Network

Кнопки фильтров

Каждый фильтр открывает окно со всеми уникальными значениями в вашей библиотеке и их количеством. Фильтры поддерживают два режима:

  • Включение (IS) — показывать только игры с выбранным значением
  • Исключение (IS NOT) — скрывать игры с выбранным значением

Переключайтесь между режимами включения и исключения с помощью переключателя в окне фильтра.

  • Дата выпуска — в хронологическом порядке (сначала самые ранние)
  • Платформа — группировка по названию системы

Навигация по алфавиту

Переход к играм, начинающимся на определённую букву. Буквы без соответствующих игр выделены серым. Цифры и символы сгруппированы под знаком #.

Бесконечная прокрутка

Игры загружаются партиями по 100 по мере прокрутки. Новые страницы загружаются автоматически при приближении к концу списка. Изменение фильтров или поиска мгновенно сбрасывает и перезагружает результаты.

Сохранение состояния

Ваши текущие фильтры, поисковый запрос и позиция прокрутки сохраняются в хранилище сеанса. Они восстанавливаются при возврате на страницу или её обновлении.

Детали игры

Окно с деталями игры

Щелчок по любой карточке игры открывает окно с деталями и кэшированным быстрым просмотром. Окно показывает:

  • Обложку (2D и 3D), фон из фан-арта
  • Описание и информацию о выпуске
  • Значки разработчика, издателя, жанра
  • Количество игроков, режимы игры, структуру игры
  • Изображение возрастного рейтинга (из вашей предпочитаемой системы, с резервным сопоставлением)
  • Галерею скриншотов с навигацией клавиатурой (← →)
  • Трейлер (если доступен)
  • Оценки времени прохождения HLTB (основная сюжетная линия, основная линия + дополнения, стопроцентное прохождение)
  • Статус и прогресс RetroAchievements
  • Похожие игры (кликабельные ссылки)
  • Подробности о поддержке контроллеров
  • Теги, присвоенные игре
  • Размер файла и путь к ROM

Полная страница деталей игры

Щёлкните по ссылке названия игры или перейдите по хлебным крошкам, чтобы просмотреть полную страницу деталей игры. Дополнительные возможности на полной странице включают:

  • Заголовок с фоном из фан-арта и навигацией по хлебным крошкам
  • Значки импорта с платформ — показывает импорт из CLZ, Steam, Xbox или PSN с логотипами платформ, если применимо
  • Индикатор бонусного диска — показывает значок и ссылку «Часть:» на родительскую игру с миниатюрой
  • Кнопка удаления — удалить игру из базы данных (с подтверждением)
  • Кнопка очистки — очистить все скрапленные метаданные, сохранив запись ROM

Окно редактирования

Нажмите «Редактировать» (или клавишу e), чтобы открыть окно редактирования, разделённое на секции:

  • Идентификация — название, сортировочное название (генерируется автоматически, но редактируется), франшиза, издание
  • Информация о выпуске — дата выпуска, регион (из настраиваемого выпадающего списка)
  • Игровой процесс — жанр (мультивыбор тегов), режимы, структура игры, количество игроков, разработчик, издатель
  • Технические данные — контроллеры (мультивыбор), тип сохранения, перспектива (множественное значение), измерение (множественное значение)
  • Возрастные рейтинги — все 8 систем рейтингов с официальными изображениями рейтингов и автоматическим взаимным сопоставлением. Изменение одного рейтинга автоматически заполняет пустые рейтинги в других системах.
  • Оценки — оценка критиков, оценка пользователей
  • Описание — текст описания игры
  • Собственные изображения — загрузка собственной обложки (2D), 3D-обложки и фан-арта. Очистите существующие изображения, чтобы разрешить повторный скрапинг.
  • Видео / трейлер — загрузка или ссылка на видео-трейлер

Быстрые действия

  • Редактировать — открыть окно редактирования (e)
  • Скрапить — получить метаданные из источников скрапинга (s)
  • Заполнить ИИ — заполнить недостающие поля с помощью ИИ (требуется ключ API ИИ)
  • Проверить RA — поиск набора достижений RetroAchievements
  • Поиск HLTB — найти оценки времени прохождения на HowLongToBeat

Статус прохождения

Отслеживайте свой прогресс с помощью следующих статусов (отображаются как значки на карточках игр):

  • Не начато — ещё не играли
  • В процессе — сейчас играете
  • Сыграно — играли, но не закончили
  • Пройдено — завершили основную игру
  • 100% — завершено всё

  • Создавайте списки с названием, описанием и значком на странице «Списки»
  • Добавляйте игры в списки через окно деталей игры или страницу списка

  • Сортируйте по собственному порядку или по алфавиту

Список желаний

  • Элементы списка желаний можно связать с существующими играми библиотеки, если они найдены
  • Сортировка по приоритету (сначала наивысший), затем по дате добавления
Совет: используйте теги для сквозных меток (например, «Избранное», «Диван на двоих», «Отложено»), а списки — для конкретных тематических подборок (например, «Топ-10 игр SNES», «Игры для стрима»).

Импорт игр

Импортируйте коллекции игр из внешних источников. Доступ через раздел «Импорт игр» на боковой панели. Все типы импорта объединены на одной странице с вкладками.

Импорт из CLZ Games

Импортируйте свою коллекцию физических игр из CLZ Games.

  1. Экспортируйте коллекцию CLZ Games в PDF
  2. Перейдите на вкладку «Импорт игр → CLZ»
  3. Загрузите PDF-файл
  4. Просмотрите распознанные игры
  5. Выберите, какие игры импортировать

Импорт из CLZ отслеживается отдельно от игр ROM (с помощью префикса clz_import/), что позволяет каталогизировать как физические, так и цифровые коллекции. Импорт CLZ можно полностью очистить в разделе «Настройки → Система → Обслуживание».

Импорт из Steam

Импортируйте свою библиотеку игр Steam и отслеживайте достижения.

  1. Настройте ключ Steam Web API и Steam ID в настройках
  2. Перейдите на вкладку «Импорт игр → Steam»
  3. Нажмите «Получить библиотеку», чтобы получить игры Steam
  4. Выберите игры для импорта (дубликаты определяются автоматически)
  5. Импортированные игры помечаются идентификатором приложения Steam для отслеживания достижений

Импорт из Xbox

Импортируйте свою библиотеку игр Xbox через учётную запись Microsoft.

  1. Перейдите на вкладку «Импорт игр → Xbox»
  2. Нажмите «Войти», чтобы пройти аутентификацию через учётную запись Microsoft (поток OAuth2)
  3. История ваших игр Xbox загружается автоматически
  4. Выберите игры для импорта с определением дубликатов
  5. Импортированные игры помечаются идентификатором Xbox Title ID для отслеживания достижений

Токены Xbox кэшируются в файле data/xbox_tokens.json и обновляются автоматически.

Импорт из PSN

Импортируйте свою библиотеку игр PlayStation Network.

  1. Перейдите на вкладку «Импорт игр → PSN»
  2. Введите свой cookie NPSSO (см. раздел Трофеи → Аутентификация PSN о том, как его получить)
  3. Нажмите «Получить библиотеку», чтобы получить игры PSN
  4. Выберите игры для импорта

После импорта

  • Импортированные игры появляются в вашей библиотеке со значками конкретной платформы
  • Используйте массовый скрапинг для получения метаданных импортированных игр
  • Отслеживание достижений/трофеев автоматически привязывается к исходной платформе
  • Импортированные игры можно отфильтровать в библиотеке с помощью фильтра по источнику
Совет: после импорта игр с любой платформы вы можете скрапить для них метаданные с помощью массового скрапинга, точно так же, как для игр ROM. Импортированные игры также могут отслеживать достижения на своих соответствующих платформах.

RetroAchievements

Настройка

  1. Создайте учётную запись на retroachievements.org
  2. Сгенерируйте ключ API в настройках профиля
  3. Введите имя пользователя и ключ API в разделе «Настройки → Учётная запись → RetroAchievements»

Страница достижений

  • Вкладки систем — просмотр достижений по платформам (запоминает последнюю просмотренную вкладку)
  • Навигация по алфавиту — переход к играм по первой букве в пределах вкладки каждой системы
  • Обновить прогресс — синхронизировать прогресс достижений с RetroAchievements
  • Общая статистика — полученные достижения и очки по всем системам
  • Прогресс по каждой игре — процент завершения для каждой игры с индикаторами прогресса

Очередь синхронизации

Несколько синхронизаций систем можно поставить в очередь:

  • Нажмите «Обновить прогресс» для любой системы, чтобы начать или поставить синхронизацию в очередь
  • Если синхронизация уже выполняется, новые запросы ставятся в очередь автоматически
  • Очередь обрабатывается автоматически после завершения текущей синхронизации
  • Всплывающее уведомление показывает текущий прогресс и количество в очереди

Поиск игр с достижениями

  • Фильтр библиотеки — используйте фильтр «Есть RA», чтобы показать только игры с достижениями
  • Проверить RA — в окнах деталей игры нажмите, чтобы найти набор достижений
  • Массовый скрапинг — включите параметр «Проверять RA», чтобы находить достижения во время скрапинга
  • Задание обновления RA — сканирование всех игр системы для определения, какие поддерживают RA

Подробности на уровне игры

Щёлкните по любой игре на странице достижений, чтобы увидеть подробную информацию о достижениях для этой игры, включая названия отдельных достижений, описания, количество очков и статус получения.

Примечание: «Обновить прогресс» синхронизирует прогресс для игр, к которым уже привязаны RetroAchievements. Чтобы найти НОВЫЕ наборы достижений, используйте «Проверить RA» в окнах деталей игры или включите эту функцию во время массового скрапинга.

Трофеи PS3 / PSN

Локальные трофеи RPCS3

Отслеживайте трофеи, полученные в играх PS3 через эмулятор RPCS3.

  1. Укажите путь к трофеям RPCS3 в разделе «Настройки → Данные → Трофеи»
  2. Нажмите «Сканировать трофеи», чтобы импортировать полученные трофеи
  3. Просматривайте списки трофеев и подробности отдельных трофеев в разделе «Трофеи RPCS3»

RPCS3 читает данные трофеев XML из вашего пользовательского каталога RPCS3 и автоматически сопоставляет игры с вашей библиотекой.

Трофеи через API PSN

Синхронизируйте данные трофеев PlayStation Network из вашей учётной записи PSN.

  1. Получите свой cookie NPSSO (см. ниже)
  2. Введите его в разделе «Настройки → Учётная запись → PSN»
  3. Библиотека трофеев PSN загружается через API PlayStation
  4. Просматривайте прогресс трофеев по каждой игре с количеством полученных/всего
  5. Подробности отдельных трофеев включают описание, редкость и время разблокировки

Аутентификация PSN (cookie NPSSO)

PSN использует специальный аутентификационный cookie под названием токен NPSSO. Чтобы его получить:

  1. Откройте веб-браузер и войдите на store.playstation.com
  2. После входа перейдите по адресу: https://ca.account.sony.com/api/v1/ssocookie
  3. На странице отобразится JSON с вашим токеном NPSSO
  4. Скопируйте значение npsso и вставьте его в разделе «Настройки → Учётная запись → PSN»

После аутентификации RetroDB безопасно кэширует токены доступа в собственной базе данных (для каждого пользователя) и обновляет их автоматически — вам не нужно вставлять NPSSO заново при каждой синхронизации. Сеанс остаётся действительным примерно два месяца, и теперь RetroDB также автоматически продлевает его в фоновом режиме, поэтому при обычном использовании свежий NPSSO требуется редко.

Подробности трофея

  • Типы трофеев: бронза, серебро, золото, платина
  • Значки трофеев загружаются и кэшируются локально
  • Процент завершения по каждой игре
  • Время разблокировки для каждого полученного трофея

Массовая синхронизация

Синхронизируйте все трофеи игр PSN одновременно через фоновое задание. Прогресс отображается во всплывающем уведомлении. Ограничение частоты запросов (2,5 с между запросами) предотвращает блокировку API PSN.

Что это такое

Система геймификации, присуждающая трофеи на основе достижений вашей коллекции. По мере добавления игр, скрапинга метаданных и прохождения игр трофеи открываются автоматически.

Как это работает

  • Прогресс отслеживается автоматически на основе статистики вашей библиотеки
  • Посетите страницу «Трофеи коллекционера», чтобы увидеть свой прогресс к каждому трофею
  • Нажмите «Обновить», чтобы обновить прогресс после внесения изменений
  • Полученные трофеи отображаются с датой разблокировки
  • Индикаторы прогресса показывают, насколько вы близки к следующему рубежу

Музей

Что это такое

Интерактивная энциклопедия игровых систем, организованная по поколениям. Узнайте об истории, характеристиках и заметных играх для каждой платформы в вашей коллекции.

Главная страница

Главная страница Музея показывает временную шкалу игровых систем, сгруппированных по поколениям (1–9 поколение, портативные системы, аркады, компьютеры). Каждая карточка системы показывает изображение оборудования и количество игр из вашей библиотеки.

Страницы деталей системы

Щёлкните по любой системе, чтобы просмотреть её страницу в музее, которая включает:

  • Изображение оборудования — фото консоли/системы
  • Технические характеристики — ЦП, ГП, ОЗУ, разрешение, тип носителя
  • История — повествование, созданное ИИ, о разработке, выпуске и наследии системы
  • Топ-10 игр — самые заметные игры для системы (на основе оценок критиков и предложений ИИ)
  • Галерея контроллеров — изображения контроллеров системы с описаниями

Создание контента ИИ

Контент Музея создаётся с помощью ИИ (Gemini, OpenAI или Claude). Вы можете создать контент для:

  • Одной системы — нажмите «Создать» на странице музея любой системы
  • Массового создания — создать контент для всех систем сразу с главной страницы (выполняется как фоновое задание с прогрессом во всплывающем уведомлении)

Изображения контроллеров

Изображения контроллеров можно добавить следующими способами:

  • Поиск изображений — поиск фотографий контроллеров с помощью Bing Image Search. Результаты ранжируются по релевантности (название контроллера + производитель + варианты систем).
  • Ручная загрузка — загрузите собственные изображения контроллеров
  • Удаление фона — автоматическое удаление фона с помощью локального ИИ (библиотека rembg) для получения прозрачных изображений контроллеров на любом фоне
  • Распространение изображений — при нахождении изображения контроллера оно автоматически используется для того же контроллера на других системах (родственные контроллеры)
  • Массовая загрузка — получить изображения для всех контроллеров системы сразу

Все изображения контроллеров приводятся к целевому размеру и сохраняются в формате WebP.

Совет: для создания контента требуется ключ API ИИ. Музей использует того же провайдера ИИ, который настроен в разделе «Настройки → Скрапинг → Ключи API».

Отчёты ROM

Что это делает

Проверяет имена файлов ROM на соответствие стандартным соглашениям об именовании и выявляет возможные проблемы. Доступ через раздел «Отчёты ROM» на боковой панели.

Типы отчётов

ВкладкаЧто проверяется
Нестандартные именаROM-файлы, чьи имена не соответствуют соглашениям об именовании. Показывает текущее имя файла, обнаруженные проблемы и предлагаемое исправленное имя.
Несоответствия имёнROM-файлы, где имя файла не совпадает со скрапленным названием метаданных. Показывает текущее имя файла в сравнении со скрапленным названием, регионом, годом и разработчиком.

  • Отсутствующие или неверные метки региона (например, (USA), (Europe))
  • Отсутствующие метки года
  • Несоответствия между именем файла и названием в базе данных

Отчёты можно сортировать по системе, имени файла и типу проблемы. Используйте их, чтобы поддерживать вашу библиотеку ROM организованной и последовательно названной.

Инструменты ROM

Доступ к центру инструментов ROM с боковой панели. Каждый инструмент выполняется как фоновое задание с обновлением прогресса в реальном времени, поддержкой паузы/возобновления и журналированием.

Сканер архивов

Извлечение архивов ROM (ZIP, 7Z, RAR) с параметрами:

  • Рекурсивное сканирование подкаталогов
  • Удаление нежелательных файлов после извлечения
  • Автоматическая генерация плейлистов M3U для многодисковых игр

Требуется: 7z или unzip

Конвертер CHD

Конвертация образов дисков (ISO, BIN/CUE, GDI) в сжатый формат CHD. Значительно экономит место при сохранении полной совместимости с эмуляторами.

Требуется: chdman (из mame-tools)

Проверка CHD

Проверка целостности файлов CHD с помощью проверки хеш-суммы. Выявляет повреждённые или неполные конвертации.

Требуется: chdman

Поиск дубликатов

Поиск дублирующихся ROM-файлов по хешу или имени файла с возможностью приоритезации по меткам региона.

Без внешних зависимостей

Организатор многодисковых игр

Организация многодисковых игр по подкаталогам и генерация плейлистов M3U для эмуляторов, которые их поддерживают. Полезно для таких систем, как PlayStation и Saturn.

Без внешних зависимостей

Удаление дублей скриншотов

Поиск и удаление дублирующихся скриншотов в вашей библиотеке игр для освобождения места на диске.

  • Точное совпадение хеша (MD5) — определяет только полностью идентичные файлы
  • Визуальное сходство — сравнение методом перцептивного хеширования с настраиваемым порогом (1–20, чем ниже, тем строже совпадение)

Сканирование выполняется поэтапно с живой статистикой, показывающей отсканированные игры, количество дубликатов и объём освобождаемого места. Результаты группируются по игре и системе. Вы можете выбрать, какой файл сохранить в каждой группе дубликатов, или использовать «Выбрать наибольший», чтобы автоматически сохранить версию с наивысшим разрешением.

Без внешних зависимостей

Изменение размера изображений

Приведение медиафайлов игр к единым целевым размерам. См. Стандартизацию изображений для полной информации.

Без внешних зависимостей (масштабирование ИИ на основе Python)

Заполнение альтернативных названий

Просматривает библиотеку в поисках игр, у которых поле альтернативных названий пусто, и заполняет его данными из IGDB / TGDB / ScreenScraper. Полезно после импорта большого каталога или переноса из другого инструмента, который не хранил региональные/японские/дополнительные названия. Выполняется в фоне; прогресс отображается на карточке инструмента.

Требуется хотя бы один ключ API скрапера (IGDB / TGDB / ScreenScraper)

Массовый поиск HLTB

Выполняет поиск HowLongToBeat для каждой игры без оценки времени прохождения. Каждое совпадение оценивается по названию + платформе + году выпуска; совпадения с высокой достоверностью сохраняются автоматически. Всё, что ниже порога достоверности (или с конфликтующими платформами), откладывается для проверки человеком.

Без внешних зависимостей (используется встроенный автономный набор данных HLTB)

Ожидающие проверки HLTB

Очередь проверки неоднозначных совпадений, найденных при массовом поиске HLTB. В каждой строке ожидания показана исходная игра рядом с кандидатом HLTB (название, платформа, год выпуска, достоверность). Одобрите, отклоните или выберите другое совпадение для каждой строки. Карточка инструмента проверки появляется в центре инструментов ROM только при наличии хотя бы одного ожидающего совпадения.

  • Вкладки фильтров для совпадений с низкой достоверностью, альтернативным названием и несоответствием платформы.
  • Одобрить записывает оценку времени прохождения; Отклонить удаляет кандидата, сохраняя очередь поиска чистой.

Настройки инструментов

Настройка путей, расположения инструментов, типов архивов и параметров, общих для всех инструментов ROM.

Совет: все инструменты ROM поддерживают паузу/возобновление и работают в фоне. Прогресс и результаты журналируются и доступны в средстве просмотра журналов. Статус инструмента (доступен или требует установки) отображается на карточке каждого инструмента.

Нормализация

Что это делает

Приводит значения жанров и режимов игры к единым каноническим формам. Это происходит автоматически во время скрапинга и заполнения ИИ, а также может применяться вручную к существующей библиотеке.

Почему это важно

Разные скраперы используют разные названия для одного и того же. Нормализация обеспечивает единообразие по всей вашей библиотеке:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Собственные правила

Вы можете добавить собственные правила нормализации в разделе «Настройки → Данные → Нормализация». Собственные правила имеют приоритет над встроенными сопоставлениями, позволяя вам задать предпочитаемые названия жанров и режимов. Правила хранятся в базе данных.

Предпросмотр и применение

Перед применением нормализации вы можете посмотреть, какие игры будут затронуты и какие изменения будут внесены. Это позволяет проверить изменения перед их применением к вашей библиотеке.

Стандартизация изображений

Что это делает

Приводит все медиафайлы игр к единым целевым размерам для единообразного вида по всей библиотеке. Изображения в пределах 80–120% от целевого размера пропускаются.

Как это работает

  • Увеличение — изображения меньше целевого размера увеличиваются с помощью Real-ESRGAN x4 (суперразрешение на основе ИИ через ONNX Runtime) для качественного увеличения, а затем приводятся к точному целевому размеру
  • Уменьшение — изображения больше целевого размера уменьшаются с помощью фильтрации Ланцоша для чётких результатов
  • Пороговый диапазон — изображения в пределах 80–120% от целевого размера остаются без изменений во избежание лишней повторной обработки

  1. Перейдите в раздел «Настройки → Система → Обслуживание» или «Инструменты ROM → Изменение размера изображений»
  2. Нажмите «Начать», чтобы начать массовую стандартизацию
  3. Задание выполняется в фоне с всплывающим уведомлением о прогрессе, показывающим текущий файл и статистику
  4. Изображения также автоматически стандартизируются во время скрапинга (новые загрузки стандартизируются сразу)

Поддержка оборудования

Модель Real-ESRGAN автоматически определяет ваше оборудование и использует лучший доступный провайдер:

  • CUDA — ускорение на GPU NVIDIA
  • ROCm — ускорение на GPU AMD (с автоматическим переопределением версии gfx для серии RX 6000)
  • CoreML — ускорение на Apple Silicon
  • CPU — резервный вариант для систем без поддержки GPU

Файл модели ONNX автоматически загружается с Hugging Face при первом использовании и кэшируется локально.

  • Очистка «осиротевших» медиафайлов — найти и удалить файлы изображений на диске (обложки, скриншоты, фан-арт), не имеющие соответствующей ссылки в базе данных. Перед удалением показывается предпросмотр для подтверждения.

Страница входа показывает всех активных пользователей. Учётные записи администраторов требуют пароль; другие роли просто щёлкают по своему имени для входа. Сеансы сохраняются до выхода из системы.

Настройки для каждого пользователя

  • Аватар (загрузка собственного изображения)
  • Отображаемое имя
  • Предпочитаемую тему
  • Количество элементов на странице
  • Часовой пояс
  • Путь к трофеям RPCS3
  • Учётные данные RetroAchievements (имя пользователя + ключ API)
  • Учётные данные PSN (cookie NPSSO)

Резервное копирование и восстановление

Создание резервных копий

  1. Перейдите в раздел «Настройки → Библиотека → Резервное копирование»
  2. Нажмите «Создать резервную копию»
  3. Резервная копия сохраняется в папку backups/ с именем файла, содержащим временную метку

Что включается в резервную копию

Резервная копия включает всю базу данных SQLite (roms.db), которая содержит все метаданные игр, учётные записи пользователей, настройки, данные трофеев, прогресс достижений, теги, списки и элементы списка желаний.

Что НЕ включается в резервную копию

Медиафайлы (обложки, скриншоты, фан-арт, видео, инструкции) НЕ включаются в резервную копию базы данных, так как их можно заново загрузить через скрапинг. Рассмотрите отдельное резервное копирование каталога static/images/, если у вас есть собственные загрузки.

Восстановление

  1. Найдите резервную копию в списке резервных копий
  2. Нажмите «Восстановить»
  3. Подтвердите действие
Предупреждение: восстановление резервной копии перезаписывает текущую базу данных. Создайте новую резервную копию перед восстановлением более старой!

Обновление RetroDB

Как обновить

  1. Скачайте новую версию RetroDB
  2. Сделайте резервную копию этих файлов (они содержат ваши личные данные):
    • config.py (ваши пути и ключи API)
    • data/settings.json (ваши настройки интерфейса)
    • data/scraper_settings.json (конфигурация скраперов)
    • data/rom_tools_config.json (настройки инструментов ROM)
    • папка database/ (база данных вашей библиотеки игр и сохранённые токены входа PSN/Xbox)
  3. Распакуйте новую версию поверх существующей установки
  4. Выполните python install.py, чтобы установить новые зависимости
  5. Перезапустите сервер

Файлы, безопасные для перезаписи

Все файлы исходного кода (.py, .html, .css, .js) можно безопасно перезаписывать. Установщик не будет перезаписывать ваши личные файлы конфигурации.

Файлы, которые нужно сохранить

Никогда не удаляйте и не перезаписывайте: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Миграции базы данных

RetroDB автоматически обрабатывает изменения схемы базы данных при запуске. Новые столбцы и таблицы добавляются по мере необходимости без потери данных. Вам не нужно делать ничего особенного — просто запустите новую версию, и база данных обновится автоматически.

Устранение неполадок

Распространённые проблемы

«No extensions found for system» (не найдены расширения для системы)

Для папки системы требуется допустимый файл ES-DE systeminfo.txt, определяющий поддерживаемые расширения файлов ROM. Убедитесь, что структура каталога ROM соответствует стандартам ES-DE.

«API Connection Failed» (ошибка подключения к API)

  • Проверьте подключение к интернету
  • Проверьте ключи API в разделе «Настройки → Скрапинг → Ключи API»
  • Подождите, если действует ограничение частоты запросов (у некоторых API есть дневные/часовые лимиты)
  • Проверьте, включён ли скрапер (отключённые скраперы показывают «Отключено» в статусе панели управления)
  • Проверьте средство просмотра журналов для подробных сообщений об ошибках

«Bulk Scrape Stuck» (массовый скрапинг завис)

Перейдите в «Настройки → Система → Устранение неполадок → «Сбросить зависший массовый скрапинг»». Это сбрасывает состояние задания, не затрагивая ваши данные.

«RA Sync Queue Stuck» (очередь синхронизации RA зависла)

Очистите очередь синхронизации RetroAchievements в разделе «Настройки → Система → Устранение неполадок».

«PSN Sync Stuck» (синхронизация PSN зависла)

Очистите задание обновления PSN в разделе «Настройки → Система → Устранение неполадок».

«Museum Generation Stuck» (генерация музея зависла)

Очистите задание генерации музея в разделе «Настройки → Система → Устранение неполадок».

«Database Errors» (ошибки базы данных)

  1. Создайте резервную копию, если возможно («Настройки → Библиотека → Резервное копирование»)
  2. Попробуйте «Настройки → Система → Обслуживание → Оптимизировать базу данных»
  3. Проверьте права доступа к файлам каталога database/
  4. Крайняя мера: восстановите из резервной копии или удалите базу данных и просканируйте заново

«Images Not Saving» (изображения не сохраняются)

Проверьте права на запись в каталогах медиафайлов: chmod -R 755 static/images/

«Page Slow or Unresponsive» (страница медленная или не отвечает)

  • Большим коллекциям может потребоваться время для загрузки — бесконечная прокрутка загружает партиями по 100
  • Попробуйте обновить страницу, чтобы очистить накопленную память
  • Проверьте консоль браузера на наличие ошибок JavaScript
  • Попробуйте переключиться на тему с более лёгким эффектом на холсте (например, Amber или Elite)
  • Эффекты на холсте автоматически определяют оборудование; менее мощные устройства используют резервный режим CPU со сниженной частотой кадров

Баннер «Interrupted Jobs» (прерванные задания) на панели управления

Если RetroDB перезапускается во время выполнения заданий, они появляются в баннере восстановления. Нажмите «Возобновить» для отдельных заданий или «Возобновить все», чтобы перезапустить их. Нажмите «Скрыть» или «Скрыть все», чтобы убрать их.

«PSN Authentication Failed» (ошибка аутентификации PSN)

  • Токены NPSSO истекают — сгенерируйте новый на ca.account.sony.com/api/v1/ssocookie
  • Убедитесь, что вы вошли на store.playstation.com перед переходом по адресу cookie
  • RetroDB кэширует ваш сеанс PSN примерно на два месяца и теперь автоматически продлевает его в фоновом режиме; если он всё же истёк, просто вставьте новый NPSSO в разделе «Настройки → Учётная запись → PSN»

«Xbox Authentication Failed» (ошибка аутентификации Xbox)

  • Повторно пройдите аутентификацию, нажав «Войти» на вкладке «Импорт игр → Xbox»
  • Токены Xbox кэшируются в файле data/xbox_tokens.json и обновляются автоматически

«Image Upscaling Errors» (ошибки увеличения изображений)

  • Модель Real-ESRGAN ONNX загружается при первом использовании — убедитесь в наличии доступа к интернету
  • Ускорение на GPU требует совместимых драйверов (CUDA для NVIDIA, ROCm для AMD)
  • Если GPU не работает, система автоматически переключается на обработку CPU

Советы по производительности

  • Поддерживайте браузер в актуальном состоянии для наилучшей производительности
  • Закрывайте другие вкладки браузера при работе с очень большими коллекциями
  • Используйте фильтры по системам, чтобы уменьшить количество одновременно отображаемых игр
  • Периодически запускайте оптимизацию базы данных после крупных операций (скрапинг, очистка, импорт)
  • Эффекты темы на холсте автоматически определяют оборудование; менее мощные устройства используют резервный режим CPU

Безопасность и отказ от ответственности

Рекомендации по безопасности

  • Смените пароль по умолчанию — пароль администратора по умолчанию (admin) следует немедленно изменить при первом входе. Используйте надёжный пароль длиной не менее 8 символов.
  • Используйте обратный прокси с HTTPS — RetroDB не предоставляет TLS/SSL самостоятельно. Разместите его за обратным прокси-сервером (например, Nginx, Caddy, Traefik) с включённым HTTPS для шифрования трафика между клиентами и сервером.
  • Ограничьте сетевой доступ — избегайте прямого предоставления доступа к RetroDB из публичного интернета. Используйте VPN или ограничьте доступ вашей локальной сетью. Если требуется удалённый доступ, используйте обратный прокси с аутентификацией.
  • Регулярно делайте резервные копии — используйте встроенную функцию резервного копирования в настройках для создания периодических резервных копий базы данных. Храните резервные копии отдельно от приложения.
  • Поддерживайте RetroDB в актуальном состоянии — регулярно проверяйте наличие новых выпусков. Исправления безопасности и улучшения включаются в обновления.
  • Защищайте свои ключи API — ключи API хранятся в файле data/scraper_settings.json. Убедитесь, что этот файл недоступен публично. Никогда не передавайте свой config.py или файлы токенов.

Встроенные функции безопасности

  • Хеширование паролей — пароли администраторов хешируются с помощью PBKDF2 (никогда не хранятся в открытом виде)
  • Ограничение частоты входа в систему — защита от подбора пароля на конечной точке входа
  • Проверка путей — все файловые операции используют вспомогательные функции safe_path и safe_filename для предотвращения атак обхода каталогов
  • Параметризованные запросы — все запросы к базе данных используют параметризованные выражения для предотвращения SQL-инъекций
  • Защита от XSS — модальные окна используют безопасное построение DOM; пользовательский ввод экранируется
  • Защита от «бомб» декомпрессии изображений — максимальное количество пикселей изображения ограничено для предотвращения исчерпания памяти вредоносными изображениями
