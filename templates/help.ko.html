설치

시스템 요구 사항

  • Python 3.8 이상(pip 포함)
  • 웹 브라우저(Chrome, Firefox, Safari, Edge)
  • 운영 체제: Linux, Windows 10/11 또는 macOS

빠른 설치

  1. RetroDB ZIP 파일을 원하는 디렉터리에 압축 해제합니다
  2. 해당 디렉터리에서 터미널/명령 프롬프트를 엽니다
  3. 다음을 실행합니다: python install.py
  4. 서버를 시작합니다:
    • Linux: ./start.sh
    • Windows: start.bat 더블 클릭
    • macOS: start.command 더블 클릭
  5. 브라우저에서 http://localhost:5000 을 엽니다

GUI 설치 프로그램

Linux에서는 ./setup.sh 를 실행하여 그래픽 설치 마법사를 시작할 수도 있습니다. Python/pip/tkinter 유무를 자동으로 확인한 후, 시각적인 진행 로그와 함께 모든 설정 단계를 안내합니다.

install.py가 수행하는 작업

  • requirements.txt 에서 Python 의존성을 설치합니다
  • 예제 템플릿에서 config.py 를 생성합니다
  • 필요한 디렉터리(데이터베이스, 로그, 미디어 폴더)를 생성합니다
  • CSS와 JS 번들을 빌드합니다

시작하기

최초 설정

처음 실행할 때 RetroDB는 다음 과정을 안내하는 설정 마법사를 표시합니다:

  1. 관리자 계정 — 사용자 이름과 비밀번호를 만듭니다
  2. 라이브러리 경로 — ROM 디렉터리를 설정합니다
  3. ES-DE 연동 — 선택적으로 ES-DE 게임리스트와 미디어를 연결합니다
  4. API 키 — 선택적으로 스크레이퍼 API 키를 추가합니다

마법사를 완료한 후 대시보드에서 "라이브러리 스캔"을 클릭하여 ROM을 검색합니다.

빠른 시작 워크플로

  1. 라이브러리를 스캔하여 ROM을 가져옵니다
  2. 시스템별로 탐색하거나 라이브러리에서 모든 게임을 봅니다
  3. 개별적으로 또는 일괄 스크래핑으로 메타데이터를 스크래핑합니다
  4. 태그, 목록, 위시리스트로 정리합니다
  5. 완료 상태와 업적으로 진행 상황을 추적합니다

ROM 라이브러리 구조

RetroDB는 ROM이 라이브러리 경로 내의 시스템 폴더에 정리되어 있을 것으로 예상합니다:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

각 시스템 폴더에는 지원되는 파일 확장자를 정의하는 ES-DE systeminfo.txt 파일이 있어야 합니다. RetroDB는 스캔 중에 이 파일을 읽어 각 시스템에서 어떤 파일이 유효한 ROM인지 식별합니다.

팁: 이미 ES-DE로 스크래핑한 경우, RetroDB가 해당 데이터를 가져올 수 있습니다! 설정 → ES-DE 연동에서, 또는 설정 마법사 중에 ES-DE 경로를 구성하세요.

플랫폼별 참고

Linux

  • Ubuntu, Fedora, openSUSE, Arch Linux에서 테스트되었습니다
  • ROM 도구에는 다음이 필요합니다: sudo apt install p7zip-full unrar mame-tools(Debian/Ubuntu) 또는 사용 중인 배포판에 맞는 동등한 패키지
  • 시스템 Python을 사용하는 경우, 설치 프로그램이 --break-system-packages 를 자동으로 처리합니다
  • AMD GPU용 ROCm GPU 가속을 지원합니다(Real-ESRGAN 이미지 업스케일링)

Windows

  • python.org 에서 Python을 다운로드합니다(설치 중 "Add to PATH" 체크)
  • ROM 도구: 7-Zip, WinRAR, MAME(chdman용)를 설치합니다
  • start.bat 으로 실행하거나 명령 프롬프트에서 python app.py 를 실행합니다

macOS

  • Python 3은 Homebrew 를 통해 설치할 수 있습니다: brew install python3
  • ROM 도구: brew install p7zip unrar rom-tools
  • Finder에서 start.command 를 더블 클릭하여 실행합니다
  • Apple Silicon용 CoreML 가속을 지원합니다(Real-ESRGAN 이미지 업스케일링)

작동 방식

  • 테마는 CSS 색상 변수를 재정의합니다 — 모든 UI 요소가 자동으로 적응합니다
  • 캔버스 효과는 자동 하드웨어 등급 감지(높음/중간/낮음)를 포함하며, 가능한 경우 GPU 가속을, 저사양 기기에는 CPU 폴백을 사용합니다
  • 탭이 보이지 않을 때는 리소스 절약을 위해 효과가 일시 중지됩니다
  • Cyberpunk 연기 상태는 페이지 탐색 간에 유지되어 매끄러운 전환을 제공합니다
  • 은은한 CRT 스타일 스캔라인 오버레이가 각 테마의 색상 팔레트에 맞게 적응합니다
  • 테마 환경 설정은 브라우저에 저장되어 세션 간에 유지됩니다

테마 인식 아이콘

알림 아이콘, 작업 상태 표시기, 동작 아이콘이 현재 테마에 맞게 자동으로 적응합니다. 예를 들어, 성공 아이콘은 Cyberpunk에서는 녹색 체크 표시로 나타나지만, Matrix에서는 검은색 위 녹색 미학에 맞는 다른 기호로 나타날 수 있습니다.

대시보드

컬렉션 상태 점수

원형 진행 링이 전체 컬렉션 상태를 백분율로 표시하며, 품질에 따라 색상으로 구분됩니다:

  • 녹색(80% 이상) — 우수한 메타데이터 적용률
  • 청록색(60–79%) — 일부 빈틈이 있는 양호한 적용률
  • 주황색(40–59%) — 보통 수준의 적용률, 일괄 스크래핑 고려
  • 빨간색(40% 미만) — 상당한 메타데이터 빈틈

아래의 세부 미니 링은 박스아트 완성도, 설명 완성도, 업적 적용률을 보여줍니다.

통계 개요

한눈에 보는 카드:

  • 총 시스템 — 라이브러리의 플랫폼 수
  • 총 게임 — 총 게임 수(보너스 디스크 제외)
  • 메타데이터 없음 — 아직 스크래핑하지 않은 게임
  • 완료 — 메타데이터가 스크래핑된 게임

최근 활동 섹션

최근 활동을 보여주는 스크롤 가능한 섹션(각 섹션은 관련 게임이 있을 때만 나타남):

  • 현재 플레이 중 — "진행 중"으로 표시된 게임
  • 최근 추가됨 — 라이브러리에 가장 최근에 추가된 게임
  • 최근 본 항목 — 최근에 연 게임
  • 최근 스크래핑됨 — 최근에 메타데이터를 가져온 게임

빠른 동작

  • 라이브러리 스캔 — ROM 디렉터리에서 새 게임을 스캔
  • 랜덤 게임 — 라이브러리에서 무작위 게임 선택

API 상태

구성된 모든 스크레이퍼와 API의 연결 상태를 보여줍니다. 오프라인이거나 잘못 구성된 API는 설정으로 연결되는 링크와 함께 경고 배너를 표시합니다.

작업 복구

백그라운드 작업(일괄 스크래핑, RA 동기화, 이미지 크기 조정 등)이 실행되는 동안 RetroDB가 재시작되면, 중단된 작업이 복구 배너에 나타납니다. 옵션:

  • 재개 — 중단된 개별 작업을 다시 시작
  • 모두 재개 — 중단된 모든 작업을 다시 시작
  • 해제 — 복구 목록에서 개별 작업 지우기
  • 모두 해제 — 중단된 모든 작업 지우기

시스템 브라우저

시스템 그리드

시스템 페이지는 라이브러리의 모든 플랫폼을 반응형 메이슨리 그리드 레이아웃의 카드로 보여줍니다. 각 카드에 표시되는 항목:

  • 시스템 로고(설정 → 사용자 지정 → 로고에서 변경 가능)
  • ROM 수 및 미스크래핑 수
  • 시스템 유형 배지 — 콘솔, 휴대용, 컴퓨터, 아케이드 또는 엔진
  • 기능 배지 — RetroAchievements 지원, 로컬 트로피(RPCS3)

시스템 사양 모달

시스템 카드의 정보 버튼을 클릭하면 상세 하드웨어 사양을 볼 수 있습니다:

  • 하드웨어 이미지(콘솔/시스템 사진)
  • 제조사 및 출시일
  • CPU, GPU, RAM, VRAM
  • 해상도, 색 심도, 사운드 칩
  • 미디어 유형(카트리지, 디스크 등)

필터링 및 검색

  • 텍스트 검색 — 시스템 이름 또는 폴더 이름으로 필터링
  • 유형 필터 — 콘솔, 휴대용, 컴퓨터, 아케이드, 엔진
  • 기능 필터 — RetroAchievements 지원, 로컬 트로피
  • 필터 결과 바에 "Y개 중 X개 시스템"이 표시됩니다
  • 필터는 세션 저장소를 통해 페이지를 새로고침해도 유지됩니다

시스템별 게임 목록

시스템 카드를 클릭하면 해당 게임을 볼 수 있습니다. 시스템별 게임 목록은 전체 라이브러리 페이지와 동일한 기능을 갖습니다 — 무한 스크롤, 검색, 모든 필터 옵션, 일괄 선택, 정렬. 시스템 헤더에는 시스템 이름, 게임 수, 시스템 유형 배지가 표시됩니다.

API 키 설정 가이드

API 키는 선택 사항이지만, 풍부한 메타데이터 스크래핑과 추가 기능을 활성화합니다. 설정 → 스크래핑 → API 키에서 구성합니다.

메타데이터 스크레이퍼

TheGamesDB

  1. api.thegamesdb.net/key.php 로 이동합니다
  2. API 키를 요청합니다(무료, 수동 승인) — 공개(Public) 키와 비공개(Private) 키를 받게 됩니다
  3. 두 키를 모두 설정 → API 키 → TheGamesDB에 입력합니다
  4. 공개 키(IP별 요청 제한)는 스크래핑의 기본 키로 사용됩니다
  5. 비공개 키(공유 월간 풀)는 공개 키가 실패할 경우 폴백으로 사용됩니다

IGDB(Twitch 경유)

  1. twitch.tv 에서 Twitch 계정을 만듭니다
  2. dev.twitch.tv/console 로 이동합니다
  3. 새 애플리케이션을 등록합니다(이름과 카테고리는 자유, OAuth 리디렉션은 http://localhost)
  4. Client ID를 복사하고 Client Secret을 생성합니다
  5. 둘 다 설정 → API 키 → IGDB에 입력합니다

RAWG.io

  1. rawg.io/apidocs 로 이동합니다
  2. "Get API Key"를 클릭하고 계정을 만듭니다
  3. 대시보드에서 API 키를 복사합니다
  4. 설정 → API 키 → RAWG에 입력합니다

무료 등급: 월 20,000회 요청

ScreenScraper

  1. screenscraper.fr 에서 계정을 만듭니다
  2. 사용자 이름과 비밀번호를 설정 → API 키 → ScreenScraper에 입력합니다

참고: ScreenScraper는 계정 등급에 따라 일일 요청 제한이 있습니다. 데이터베이스에 기여하면 제한이 늘어납니다.

업적 및 트로피

RetroAchievements

  1. retroachievements.org 에서 계정을 만듭니다
  2. 프로필에서 설정 → API 키로 이동합니다
  3. API 키를 복사합니다
  4. 사용자 이름과 API 키를 설정 → 계정 → RetroAchievements에 입력합니다

Steam Web API

  1. steamcommunity.com/dev/apikey 로 이동합니다
  2. Steam Web API 키를 등록합니다(Steam 계정 필요)
  3. API 키와 Steam ID(또는 vanity URL)를 설정에 입력합니다

Steam 라이브러리 가져오기 및 업적 추적에 사용됩니다.

Xbox Live

Xbox 인증은 OAuth2를 사용합니다 — API 키가 필요하지 않습니다. 게임 가져오기 → Xbox 탭에서 직접 Microsoft 계정으로 로그인하세요. 토큰은 자동으로 캐시되고 필요에 따라 갱신됩니다.

PlayStation Network(PSN)

PSN은 NPSSO 쿠키 인증을 사용합니다. 자세한 설정 방법은 트로피 섹션을 참조하세요.

설정

설정은 6개 탭으로 구성되며, 각 탭에는 여러 하위 섹션이 있습니다.

계정 탭

  • 내 프로필 — 아바타 업로드/제거, 표시 이름, 역할 정보, 비밀번호 변경
  • RetroAchievements — RA 연동을 위한 사용자 이름과 API 키
  • PSN — PlayStation Network 트로피 동기화를 위한 NPSSO 쿠키
  • 시간대 — 앱 전체의 날짜 표시를 위한 시간대 설정
  • 사용자 — 사용자 관리: 사용자 추가, 편집, 삭제 및 역할 할당(관리자 전용)

라이브러리 탭

  • 경로 — ROM 라이브러리 경로, 데이터베이스 위치
  • 디스플레이 — 테마 선택, 박스아트 스타일(2D/3D), 선호 연령 등급 시스템, 페이지당 항목 수
  • ROM 명명 — 관사 위치(앞/뒤 "The"), 지역 옵션 목록, 기본 지역, 명명 규칙
  • 백업 — 데이터베이스 백업 생성 및 복원

스크래핑 탭

  • ES-DE — 로컬 데이터 가져오기를 위한 ES-DE 게임리스트 및 미디어 경로
  • 스크레이퍼 — 개별 스크레이퍼 활성화/비활성화, 드래그 앤 드롭 우선순위 정렬, 스크레이퍼별 요청 제한 설정
  • API 키 — 모든 스크레이퍼 자격 증명(TGDB, IGDB, RAWG, ScreenScraper), AI 제공자 선택 및 모델 선택(Gemini, OpenAI, Claude)

데이터 탭

  • 통계 — 라이브러리 통계 개요(총 게임, 시스템, 저장 공간 사용량)
  • 트로피 — 로컬 PS3 트로피 스캔을 위한 RPCS3 트로피 경로 구성
  • 드롭다운 — 앱 전체에서 사용되는 지역 옵션 및 기타 드롭다운 값 사용자 지정
  • 정규화 — 장르 및 모드 정규화 규칙 — 스크레이퍼 출력을 표준화하기 위한 사용자 지정 매핑 추가

사용자 지정 탭

  • 알림 — 알림 시간 초과 환경 설정(성공, 정보, 경고, 오류 — 각각 독립적으로 구성 가능)
  • 컨트롤러 — 컨트롤러 라이브러리 관리, 시스템별 기본 컨트롤러 설정, 사용자 지정 컨트롤러 추가. 기본 컨트롤러는 메타데이터 가져오기 중에 스크래핑/AI 값을 재정의합니다.
  • 로고 — 시스템 로고 사용자 지정 — 시스템 로고 가져오기 또는 기본값에서 새로고침

시스템 탭

  • 유지 관리 — 데이터베이스 최적화(VACUUM/ANALYZE), 고아 미디어 정리, 누락된 ROM 정리, 스크래핑 데이터 지우기, CLZ 가져오기 지우기, 일괄 이미지 표준화
  • 서버 — 서버 구성(호스트, 포트, 디버그 모드)
  • 로깅 — 카테고리별 로그 레벨 설정
  • 문제 해결 — 멈춘 일괄 스크래핑 지우기, RA 동기화 큐 지우기, PSN 새로고침 지우기, 박물관 생성 지우기, 서버 재시작
팁: 비활성화된 스크레이퍼는 대시보드에서 "API 오프라인" 경고를 트리거하지 않습니다. 스크레이퍼를 사용하지 않는다면, API 키를 삭제하는 대신 설정 → 스크래핑 → 스크레이퍼에서 비활성화하세요.

메타데이터 스크래핑

단일 게임 스크래핑

  1. 게임의 상세 모달을 엽니다(게임 카드 클릭)
  2. "스크래핑"을 클릭합니다
  3. 필요하면 검색 제목을 수정합니다
  4. 일치 항목 중에서 올바른 결과를 선택합니다
  5. "적용"을 클릭합니다

하이브리드 스크래핑

RetroDB는 여러 소스의 데이터를 자동으로 결합하여 메타데이터 적용률을 극대화합니다:

  • 가장 우선순위가 높은 사용 가능한 소스의 텍스트 메타데이터
  • 기본 소스에 없는 경우 보조 소스의 이미지 및 미디어
  • 최대 적용률을 위한 스크레이퍼 간 자동 빈틈 채우기
  • 정렬 제목은 스크래핑 중 게임 제목으로부터 자동 생성됩니다

미디어 처리

  • 미디어 필드(박스아트, 3D 박스아트, 스크린샷, 팬아트, 동영상, 설명서)는 일반 스크래핑 중에 절대 교체되지 않으며 — 비어 있을 때만 채워집니다
  • 스크린샷은 항상 추가되며, 절대 교체되지 않습니다
  • 미디어를 다시 다운로드하려면, 먼저 편집 모달에서 기존 이미지를 지운 다음 다시 스크래핑하세요
  • 전체 다시 스크래핑 모드는 이를 재정의하고 모든 것을 교체합니다
  • 오래된 미디어 참조(파일은 삭제되었지만 파일명이 여전히 DB에 있는 경우)는 스크래핑 전에 자동으로 지워져 새 미디어를 다운로드할 수 있습니다
  • 다운로드된 이미지는 자동으로 목표 크기로 표준화됩니다(이미지 표준화 참조)

스크레이퍼 우선순위

설정 → 스크래핑 → 스크레이퍼에서 어떤 스크레이퍼를 먼저 실행할지, 어떤 것을 활성화/비활성화할지 구성합니다. 드래그 앤 드롭으로 우선순위를 재정렬하세요. 비활성화된 스크레이퍼는 스크래핑 중에 시도되지 않으며 대시보드에서 API 상태 경고를 트리거하지 않습니다.

요청 제한(Rate Limiting)

각 스크레이퍼에는 API 제한(throttling)을 방지하기 위한 구성 가능한 요청 제한이 있습니다. 기본 지연 시간은 보수적으로 설정되어 있습니다. 지연 시간 단축은 사용자 책임입니다 — API 요청 제한을 초과하면 해당 서비스에서 일시적으로 차단될 수 있습니다.

일괄 스크래핑

일괄 스크래핑 시작하기

  1. 임의의 시스템 또는 라이브러리 페이지로 이동합니다
  2. "선택"을 클릭하여 선택 모드로 들어갑니다
  3. 게임을 개별적으로 선택하거나 빠른 선택을 사용합니다:
    • 모두 선택 — 표시된 모든 게임
    • 미스크래핑 선택 — 메타데이터가 없는 게임만
  4. 모드를 선택합니다: 누락 채우기 또는 전체 다시 스크래핑
  5. "선택 항목 스크래핑"을 클릭합니다

컨트롤

  • 일시 중지 / 재개 — 스크래핑을 일시 중지하거나 계속
  • 취소 — 완전히 중지
  • 백그라운드 — 최소화하고 스크래핑이 실행되는 동안 계속 탐색

토스트 알림

백그라운드에서 실행할 때, 지속적인 토스트가 모든 페이지에서 진행 상황을 표시합니다:

  • 현재 게임 이름, 진행 횟수, 결과 통계(성공, 실패, 건너뜀)
  • 어느 페이지에서든 일시 중지/취소 컨트롤 사용 가능
  • 토스트를 클릭하면 스크래핑 모달로 돌아갑니다

큐 시스템

여러 일괄 스크래핑이 자동으로 큐에 들어갑니다:

  • 하나가 실행 중일 때 새 스크래핑을 시작하면 — 큐에 들어갑니다
  • 큐는 대기 중인 작업 수와 함께 토스트에 표시됩니다
  • 작업이 순서대로 자동 처리됩니다
  • 큐 관리자를 사용하여 큐에 들어간 작업을 보거나 재정렬하거나 취소합니다

스크래핑 옵션

  • 누락만 채우기 — 기존 데이터를 보존하면서 비어 있는 메타데이터 필드만 채움
  • 전체 다시 스크래핑 — 미디어를 포함한 모든 필드를 교체(새 이미지와 동영상 다운로드)
  • RetroAchievements 확인 — 스크래핑 중에 RetroAchievements 업적 세트도 확인

작업 복구

작업이 실행되는 동안 RetroDB가 재시작되면, 중단된 작업이 대시보드의 복구 배너에 나타납니다. 개별 작업에서 "재개"를 클릭하거나 "모두 재개"를 클릭하여 다시 시작하세요. 진행 토스트는 재개 직후 즉시 나타납니다.

AI 채우기

기능 설명

AI 채우기는 대규모 언어 모델(Gemini, OpenAI 또는 Claude)을 사용하여 누락되거나 불완전한 게임 메타데이터를 지능적으로 채웁니다. 게임에 대한 맥락적 지식을 활용해 스크레이퍼가 갖지 못한 정확한 데이터를 제공하므로 일반 스크래핑보다 더 똑똑합니다.

사용 방법

  1. 게임의 상세 모달(또는 전체 상세 페이지)을 엽니다
  2. "AI 채우기"를 클릭합니다(설정에 AI API 키가 구성되어 있어야 함)
  3. AI가 게임 제목과 시스템을 분석한 다음 누락된 필드를 채웁니다
  4. 결과를 검토합니다 — 변경 사항은 자동으로 저장됩니다

AI 채우기가 제공할 수 있는 항목

  • 장르, 설명, 개발사, 배급사, 출시일
  • 플레이어 수, 플레이 모드(싱글 플레이어, 멀티 플레이어, 협동 등)
  • 캠페인 정보 및 게임 구조
  • 8가지 모든 연령 등급 시스템(ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • 지역, 프랜차이즈, 유사 게임
  • 컨트롤러 지원, 저장 방식
  • 시점(1인칭, 탑다운, 사이드 스크롤러 등), 차원(2D, 3D)
  • 에디션 정보, 평론가 및 사용자 점수

스마트 채우기 로직

  • 빈 필드는 항상 채워집니다
  • 기존 사용자 데이터는 절대 덮어쓰지 않습니다
  • 유사 게임은 항상 새로 고쳐집니다(이 필드는 AI 데이터가 더 신뢰할 수 있음)
  • 교차 매핑된 등급 — 하나의 등급 시스템을 알고 있으면, 다른 시스템의 빈 등급은 성숙도 등급 교차 매핑을 사용하여 자동으로 채워집니다
  • 정렬 제목은 채워질 때 자동 생성됩니다
  • 플레이어 수 필드는 범위를 정규화합니다(예: "1-4"는 4가 됨)

장르 정규화

AI 채우기는 하이픈으로 연결된 이름의 정식 장르 형식을 사용합니다:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

요구 사항

설정 → 스크래핑 → API 키에 하나 이상의 AI 제공자 API 키가 구성되어 있어야 합니다. 가장 저렴한 모델 등급(Gemini Flash Lite, GPT-4o Mini 또는 Claude Haiku)도 메타데이터에 충분히 잘 작동합니다.

필터링 및 검색

검색

검색은 제목(및 정렬 제목)으로 게임을 필터링합니다. / 를 누르면 검색 상자에 포커스가 갑니다. 결과는 300ms 디바운스로 실시간 업데이트됩니다.

소스 필터

가져오기 소스별로 게임을 필터링합니다:

  • ROM 파일 — ROM 라이브러리의 게임
  • CLZ 가져오기 — CLZ에서 가져온 실물 게임
  • Steam 가져오기 — Steam에서 가져온 게임
  • Xbox 가져오기 — Xbox에서 가져온 게임
  • PSN 가져오기 — PlayStation Network에서 가져온 게임

필터 버튼

각 필터는 라이브러리의 모든 고유 값을 개수와 함께 보여주는 모달을 엽니다. 필터는 두 가지 모드를 지원합니다:

  • 포함(IS) — 선택한 값과 일치하는 게임만 표시
  • 제외(IS NOT) — 선택한 값과 일치하는 게임 숨기기

필터 모달의 스위치를 사용하여 포함 모드와 제외 모드 사이를 전환합니다.

정렬 옵션

  • 제목 — 정렬 제목 기준 알파벳순(대소문자 구분 안 함)
  • 출시일 — 연대순(가장 이른 것부터)
  • 플랫폼 — 시스템 이름별 그룹화

알파벳 탐색

특정 문자로 시작하는 게임으로 이동합니다. 일치하는 게임이 없는 문자는 회색으로 표시됩니다. 숫자와 기호는 # 아래에 그룹화됩니다.

무한 스크롤

스크롤할 때 게임이 100개 단위로 로드됩니다. 하단에 가까워지면 새 페이지가 자동으로 로드됩니다. 필터나 검색을 변경하면 즉시 초기화되고 결과가 다시 로드됩니다.

상태 유지

현재 필터, 검색어, 스크롤 위치는 세션 저장소에 저장됩니다. 페이지로 다시 이동하거나 새로고침할 때 복원됩니다.

게임 상세

게임 상세 모달

게임 카드를 클릭하면 캐시된 빠른 보기와 함께 상세 모달이 열립니다. 모달에 표시되는 항목:

  • 박스아트(2D 및 3D), 팬아트 배경
  • 설명 및 출시 정보
  • 개발사, 배급사, 장르 배지
  • 플레이어 수, 플레이 모드, 게임 구조
  • 연령 등급 이미지(선호하는 시스템 기준, 교차 매핑 폴백 포함)
  • 키보드 탐색이 가능한 스크린샷 갤러리(← →)
  • 예고편 동영상(사용 가능한 경우)
  • HLTB 플레이 시간 추정치(메인 스토리, 메인 + 부가, 완전 정복)
  • RetroAchievements 상태 및 진행 상황
  • 유사 게임(클릭 가능한 링크)
  • 컨트롤러 지원 세부 정보
  • 게임에 할당된 태그
  • 파일 크기 및 ROM 경로

전체 게임 상세 페이지

게임 제목 링크를 클릭하거나 이동 경로에서 이동하면 전체 게임 상세 페이지를 볼 수 있습니다. 전체 페이지의 추가 기능:

  • 팬아트 배경 헤더 — 이동 경로 탐색 포함
  • 플랫폼 가져오기 배지 — 해당하는 경우 CLZ 가져오기, Steam 가져오기, Xbox 가져오기 또는 PSN 가져오기를 플랫폼 로고와 함께 표시
  • 보너스 디스크 표시기 — 배지와 함께 썸네일이 있는 부모 게임으로의 "다음의 일부:" 링크 표시
  • 삭제 버튼 — 데이터베이스에서 게임 제거(확인 절차 포함)
  • 지우기 버튼 — ROM 항목은 유지하면서 스크래핑된 모든 메타데이터 지우기

편집 모달

편집을 클릭(또는 e 누르기)하면 섹션으로 구성된 편집 모달이 열립니다:

  • 식별 정보 — 제목, 정렬 제목(자동 생성되지만 편집 가능), 프랜차이즈, 에디션
  • 출시 정보 — 출시일, 지역(구성 가능한 드롭다운에서)
  • 게임플레이 — 장르(다중 선택 태그), 모드, 게임 구조, 플레이어 수, 개발사, 배급사
  • 기술 — 컨트롤러(다중 선택), 저장 방식, 시점(다중 값), 차원(다중 값)
  • 연령 등급 — 공식 등급 이미지와 자동 교차 매핑이 있는 8가지 모든 등급 시스템. 하나의 등급을 변경하면 다른 시스템의 빈 등급이 자동으로 채워집니다.
  • 점수 — 평론가 점수, 사용자 점수
  • 설명 — 게임 설명 텍스트
  • 사용자 지정 이미지 — 사용자 지정 박스아트(2D), 3D 박스아트, 팬아트 업로드. 기존 이미지를 지우면 다시 스크래핑을 허용합니다.
  • 동영상 / 예고편 — 동영상 예고편 업로드 또는 링크

빠른 동작

  • 편집 — 편집 모달 열기(e)
  • 스크래핑 — 스크레이퍼 소스에서 메타데이터 가져오기(s)
  • AI 채우기 — AI로 누락된 필드 채우기(AI API 키 필요)
  • RA 확인 — RetroAchievements 업적 세트 검색
  • HLTB 조회 — HowLongToBeat에서 플레이 시간 추정치 찾기

완료 상태

다음 상태로 진행 상황을 추적합니다(게임 카드에 배지로 표시):

  • 시작 안 함 — 아직 플레이하지 않음
  • 진행 중 — 현재 플레이 중
  • 플레이함 — 플레이했지만 끝내지 않음
  • 완료 — 메인 게임을 끝냄
  • 100% — 모든 것을 완료함

보너스 디스크

RetroDB는 보너스/추가 디스크(예: 사운드트랙 CD, 추가 콘텐츠 디스크)를 자동으로 감지하여 부모 게임에 연결합니다. 보너스 디스크는 라이브러리에서 기본적으로 숨겨집니다 — 필터에서 "보너스 표시"를 전환하여 표시하세요. 연결된 보너스 디스크는 부모 게임의 상세 모달에 나타납니다.

팁: 상세 모달은 더 빠른 로딩을 위해 최근에 본 게임을 캐시합니다. 편집 사항은 새로고침 없이 페이지의 게임 카드를 자동으로 업데이트합니다.

일괄 편집

사용 방법

  1. 임의의 시스템 또는 라이브러리 페이지로 이동합니다
  2. "선택"을 클릭하여 선택 모드로 들어갑니다
  3. 편집할 게임을 선택합니다(개별, 모두 선택 또는 미스크래핑 선택)
  4. "일괄 편집"을 클릭합니다
  5. 수정할 필드를 선택하고 새 값을 설정합니다
  6. 교체 또는 추가 모드를 선택합니다
  7. "적용"을 클릭하여 선택한 모든 게임을 업데이트합니다

교체 대 추가

  • 교체 — 기존 값을 새 값으로 덮어씁니다
  • 추가 — 기존 값에 새 값을 더합니다(다중 값 필드의 경우)

게임 비교

기능 설명

두 게임의 메타데이터를 표 형식으로 나란히 비교합니다. 메타데이터 품질 확인, 중복 항목 발견, 또는 여러 시스템에 걸친 같은 게임의 버전 비교에 유용합니다.

사용 방법

  1. 비교로 이동합니다(라이브러리 페이지에서 접근 가능)
  2. 첫 번째 게임을 검색하고 선택합니다
  3. 두 번째 게임을 검색하고 선택합니다
  4. 비교 표를 검토합니다 — 차이점이 강조 표시됩니다

비교 필드

시스템, 개발사, 배급사, 출시일, 장르, 프랜차이즈, 지역, 플레이어 수, 모드, 시점, 차원, 8가지 모든 연령 등급, 사용자 평점, 평론가 점수, 플레이 시간 추정치, 컨트롤러 지원, 저장 방식, 파일 크기, 유사 게임, 설명 등.

컬렉션(태그, 목록, 위시리스트)

태그

사용자 지정 색상 코드 태그를 만들어 게임을 정리하세요. 태그는 라벨처럼 작동합니다 — 각 게임은 여러 태그를 가질 수 있고, 각 태그는 여러 게임을 포함할 수 있습니다.

  • 태그 페이지에서 사용자 지정 이름과 색상으로 태그를 만듭니다
  • 게임 상세 모달을 통해 게임에 태그를 할당합니다
  • 임의의 태그를 클릭하면 그 태그가 있는 모든 게임을 탐색합니다
  • 태그 관리 페이지에서 태그를 편집하거나 삭제합니다

이름이 지정된 목록

사용자 지정 정렬이 가능한 큐레이션 게임 목록을 만드세요. 목록은 재생목록과 같습니다 — 게임의 정확한 순서를 직접 제어합니다.

  • 목록 페이지에서 이름, 설명, 아이콘으로 목록을 만듭니다
  • 게임 상세 모달 또는 목록 페이지를 통해 목록에 게임을 추가합니다
  • 드래그 앤 드롭으로 목록 내 게임을 재정렬합니다
  • 사용자 지정 순서 또는 알파벳순으로 정렬합니다

위시리스트

실물이든 디지털이든 획득하고 싶은 게임을 추적하세요.

  • 제목, 시스템, 메모, 우선순위(1–5)와 함께 게임을 수동으로 추가합니다
  • 위시리스트 항목은 찾을 경우 기존 라이브러리 게임에 연결할 수 있습니다
  • 우선순위(높은 것부터) 다음 추가된 날짜순으로 정렬됩니다
팁: 교차적인 라벨(예: "즐겨찾기", "소파 협동", "백로그")에는 태그를, 특정 큐레이션 컬렉션(예: "최고의 SNES 게임 10선", "스트리밍할 게임")에는 목록을 사용하세요.

게임 가져오기

외부 소스에서 게임 컬렉션을 가져옵니다. 사이드바의 게임 가져오기를 통해 접근합니다. 모든 가져오기 유형은 하나의 탭형 페이지로 통합되어 있습니다.

CLZ Games 가져오기

CLZ Games에서 실물 게임 컬렉션을 가져옵니다.

  1. CLZ Games 컬렉션을 PDF로 내보냅니다
  2. 게임 가져오기 → CLZ 탭으로 이동합니다
  3. PDF 파일을 업로드합니다
  4. 파싱된 게임을 검토합니다
  5. 가져올 게임을 선택합니다

CLZ 가져오기는 ROM 게임과 별도로 추적되며(clz_import/ 접두사 사용), 실물과 디지털 컬렉션을 모두 카탈로그화할 수 있습니다. CLZ 가져오기는 설정 → 시스템 → 유지 관리에서 전부 지울 수 있습니다.

Steam 가져오기

Steam 게임 라이브러리를 가져오고 업적을 추적합니다.

  1. 설정에서 Steam Web API 키와 Steam ID를 구성합니다
  2. 게임 가져오기 → Steam 탭으로 이동합니다
  3. "라이브러리 가져오기"를 클릭하여 Steam 게임을 검색합니다
  4. 가져올 게임을 선택합니다(중복은 자동으로 감지됨)
  5. 가져온 게임은 업적 추적을 위해 Steam App ID로 태그가 지정됩니다

Xbox 가져오기

Microsoft 계정을 통해 Xbox 게임 라이브러리를 가져옵니다.

  1. 게임 가져오기 → Xbox 탭으로 이동합니다
  2. "로그인"을 클릭하여 Microsoft 계정으로 인증합니다(OAuth2 흐름)
  3. Xbox 타이틀 기록이 자동으로 검색됩니다
  4. 중복 감지와 함께 가져올 게임을 선택합니다
  5. 가져온 게임은 업적 추적을 위해 Xbox Title ID로 태그가 지정됩니다

Xbox 토큰은 data/xbox_tokens.json 에 캐시되고 자동으로 갱신됩니다.

PSN 가져오기

PlayStation Network 게임 라이브러리를 가져옵니다.

  1. 게임 가져오기 → PSN 탭으로 이동합니다
  2. NPSSO 쿠키를 입력합니다(얻는 방법은 트로피 → PSN 인증 참조)
  3. "라이브러리 가져오기"를 클릭하여 PSN 게임을 검색합니다
  4. 가져올 게임을 선택합니다

가져오기 후

  • 가져온 게임은 플랫폼별 배지와 함께 라이브러리에 나타납니다
  • 일괄 스크래핑을 사용하여 가져온 게임의 메타데이터를 가져옵니다
  • 업적/트로피 추적은 소스 플랫폼에 자동으로 연결됩니다
  • 가져온 게임은 라이브러리에서 소스 필터를 사용하여 필터링할 수 있습니다
팁: 어느 플랫폼에서든 게임을 가져온 후, ROM 게임과 마찬가지로 일괄 스크래핑을 사용하여 메타데이터를 스크래핑할 수 있습니다. 가져온 게임은 각자의 플랫폼에서 업적을 추적할 수도 있습니다.

  • RA 새로고침 작업 — 시스템의 모든 게임을 스캔하여 RA를 지원하는 게임 식별

PS3 / PSN 트로피

RPCS3 로컬 트로피

RPCS3 에뮬레이터를 통해 PS3 게임에서 획득한 트로피를 추적합니다.

  1. 설정 → 데이터 → 트로피에서 RPCS3 트로피 경로를 설정합니다
  2. "트로피 스캔"을 클릭하여 획득한 트로피를 가져옵니다
  3. RPCS3 트로피 섹션에서 트로피 목록과 개별 트로피 세부 정보를 봅니다

RPCS3는 RPCS3 사용자 디렉터리에서 트로피 XML 데이터를 읽어 게임을 라이브러리에 자동으로 매칭합니다.

PSN API 트로피

PSN 계정에서 PlayStation Network 트로피 데이터를 동기화합니다.

  1. NPSSO 쿠키를 얻습니다(아래 참조)
  2. 설정 → 계정 → PSN에 입력합니다
  3. PSN 트로피 라이브러리가 PlayStation API를 통해 검색됩니다
  4. 획득/총 개수와 함께 게임별 트로피 진행 상황을 봅니다
  5. 개별 트로피 세부 정보에는 설명, 희귀도, 해제 타임스탬프가 포함됩니다

PSN 인증(NPSSO 쿠키)

PSN은 NPSSO 토큰이라는 특수한 인증 쿠키를 사용합니다. 얻는 방법:

  1. 웹 브라우저를 열고 store.playstation.com 에 로그인합니다
  2. 로그인한 후, https://ca.account.sony.com/api/v1/ssocookie 로 이동합니다
  3. 페이지에 NPSSO 토큰이 포함된 JSON이 표시됩니다
  4. npsso 값을 복사하여 설정 → 계정 → PSN에 붙여넣습니다

인증이 완료되면 토큰은 data/psn_tokens.json 에 로컬로 캐시되고 자동으로 갱신됩니다. 캐시된 토큰은 약 2개월 동안 유효합니다.

트로피 세부 정보

  • 트로피 종류: 브론즈, 실버, 골드, 플래티넘
  • 트로피 아이콘은 다운로드되어 로컬에 캐시됩니다
  • 게임별 완료 백분율
  • 획득한 각 트로피의 해제 타임스탬프

일괄 동기화

백그라운드 작업을 통해 모든 PSN 게임 트로피를 한 번에 동기화합니다. 진행 상황은 토스트 알림에 표시됩니다. 요청 제한(요청 간 2.5초)이 PSN API 제한(throttling)을 방지합니다.

수집가 트로피

개요

컬렉션 마일스톤을 기준으로 트로피를 수여하는 게임화 시스템입니다. 게임을 추가하고, 메타데이터를 스크래핑하고, 게임을 완료함에 따라 트로피가 자동으로 잠금 해제됩니다.

트로피 등급

등급예시
브론즈첫 게임 추가, 10개 게임 도달, 첫 스크래핑, 5개 시스템, 첫 완료
실버100개 게임, 50개 스크래핑, 10개 시스템, 10개 완료, 500개 게임
골드1,000개 게임, 100% 메타데이터 적용률, 20개 시스템, 50개 완료
플래티넘5,000개 게임, 100개 완료, 30개 이상 시스템

작동 방식

  • 진행 상황은 라이브러리 통계를 기준으로 자동으로 추적됩니다
  • 수집가 트로피 페이지를 방문하여 각 트로피를 향한 진행 상황을 확인하세요
  • 변경한 후 "새로고침"을 클릭하여 진행 상황을 업데이트하세요
  • 획득한 트로피는 해제 날짜와 함께 표시됩니다
  • 진행 표시줄은 다음 마일스톤에 얼마나 가까운지 보여줍니다

박물관

개요

세대별로 정리된 게임 시스템의 인터랙티브 백과사전입니다. 컬렉션에 있는 각 플랫폼의 역사, 사양, 주목할 만한 게임에 대해 알아보세요.

랜딩 페이지

박물관 랜딩 페이지는 세대별로 그룹화된 게임 시스템의 타임라인을 보여줍니다(1–9세대, 휴대용, 아케이드, 컴퓨터). 각 시스템 카드는 하드웨어 이미지와 라이브러리의 게임 수를 보여줍니다.

시스템 상세 페이지

임의의 시스템을 클릭하면 박물관 페이지를 볼 수 있으며, 다음을 포함합니다:

  • 하드웨어 이미지 — 콘솔/시스템 사진
  • 기술 사양 — CPU, GPU, RAM, 해상도, 미디어 유형
  • 역사 — 시스템의 개발, 출시, 유산에 대한 AI 생성 서사
  • 톱 10 게임 — 시스템의 가장 주목할 만한 타이틀(평론가 점수와 AI 제안 기반)
  • 컨트롤러 갤러리 — 설명과 함께하는 시스템 컨트롤러 이미지

AI 콘텐츠 생성

박물관 콘텐츠는 AI(Gemini, OpenAI 또는 Claude)를 사용하여 생성됩니다. 다음에 대한 콘텐츠를 생성할 수 있습니다:

  • 단일 시스템 — 임의의 시스템 박물관 페이지에서 "생성" 클릭
  • 일괄 생성 — 랜딩 페이지에서 모든 시스템의 콘텐츠를 한 번에 생성(토스트 진행 상황과 함께 백그라운드 작업으로 실행)

컨트롤러 이미지

컨트롤러 이미지는 다음을 통해 추가할 수 있습니다:

  • 이미지 검색 — Bing 이미지 검색을 사용하여 컨트롤러 사진 검색. 결과는 관련성(컨트롤러 이름 + 제조사 + 시스템 변형)에 따라 순위가 매겨집니다.
  • 수동 업로드 — 직접 컨트롤러 이미지 업로드
  • 배경 제거 — 로컬 AI(rembg 라이브러리)를 사용하여 배경을 자동으로 제거, 어떤 배경에서도 투명한 컨트롤러 이미지 제공
  • 이미지 전파 — 컨트롤러 이미지를 찾으면, 다른 시스템의 동일한 컨트롤러(형제 컨트롤러)와 자동으로 공유됩니다
  • 일괄 가져오기 — 한 시스템의 모든 컨트롤러 이미지를 한 번에 가져오기

모든 컨트롤러 이미지는 목표 크기로 표준화되어 WebP 형식으로 저장됩니다.

팁: 콘텐츠 생성에는 AI API 키가 필요합니다. 박물관은 설정 → 스크래핑 → API 키에 구성된 동일한 AI 제공자를 사용합니다.

ROM 리포트

기능 설명

ROM 파일명을 표준 명명 규칙과 대조하여 검증하고 잠재적 문제를 식별합니다. 사이드바의 ROM 리포트를 통해 접근합니다.

리포트 유형

탭확인 내용
비표준 이름명명 규칙과 일치하지 않는 파일명을 가진 ROM. 현재 파일명, 감지된 문제, 제안된 수정 이름을 표시합니다.
이름 불일치파일명이 스크래핑된 메타데이터 제목과 일치하지 않는 ROM. 현재 파일명 대 스크래핑된 제목, 지역, 연도, 개발사를 표시합니다.

확인 항목

  • 파일명의 잘못된 문자(: ? * / " < > | \)
  • 누락되거나 잘못된 지역 태그(예: (USA), (Europe))
  • 누락된 연도 태그
  • 파일명 대 데이터베이스 제목 불일치

리포트는 시스템, 파일명, 문제 유형별로 정렬할 수 있습니다. ROM 라이브러리를 정리되고 일관되게 명명된 상태로 유지하는 데 사용하세요.

ROM 도구

사이드바에서 ROM 도구 허브에 접근합니다. 각 도구는 실시간 진행 상황 업데이트, 일시 중지/재개 지원, 로깅과 함께 백그라운드 작업으로 실행됩니다.

아카이브 스캐너

ROM 아카이브(ZIP, 7Z, RAR)를 다음 옵션으로 압축 해제합니다:

  • 하위 디렉터리의 재귀적 스캔
  • 압축 해제 후 불필요한 파일 제거
  • 멀티 디스크 게임용 자동 M3U 재생목록 생성

필요: 7z 또는 unzip

CHD 변환기

디스크 이미지(ISO, BIN/CUE, GDI)를 압축된 CHD 형식으로 변환합니다. 에뮬레이터와의 완전한 호환성을 유지하면서 상당한 저장 공간을 절약합니다.

필요: chdman(mame-tools에서)

CHD 검증

해시 검증으로 CHD 파일의 무결성을 확인합니다. 손상되거나 불완전한 변환을 식별합니다.

필요: chdman

중복 찾기

해시 또는 파일명으로 중복 ROM을 찾으며, 지역 태그로 우선순위를 지정하는 옵션이 있습니다.

외부 의존성 없음

멀티 디스크 정리

멀티 디스크 게임을 하위 디렉터리로 정리하고, 이를 지원하는 에뮬레이터용 M3U 재생목록을 생성합니다. PlayStation과 Saturn 같은 시스템에 유용합니다.

외부 의존성 없음

스크린샷 중복 제거

게임 라이브러리 전체에서 중복 스크린샷을 찾아 제거하여 저장 공간을 확보합니다.

  • 정확한 해시(MD5) — 동일한 파일만 식별
  • 시각적 유사성 — 구성 가능한 임곗값(1–20, 낮을수록 엄격한 일치)으로 지각 해시 비교

스캔한 게임, 중복 개수, 회수 가능한 공간을 보여주는 실시간 통계와 함께 점진적으로 스캔합니다. 결과는 게임과 시스템별로 그룹화됩니다. 각 중복 그룹에서 보관할 파일을 선택하거나, "가장 큰 것 선택"을 사용하여 가장 높은 해상도 버전을 자동으로 보관할 수 있습니다.

외부 의존성 없음

이미지 크기 조정기

게임 미디어를 일관된 목표 크기로 표준화합니다. 자세한 내용은 이미지 표준화를 참조하세요.

외부 의존성 없음(Python 기반 AI 업스케일링)

대체 제목 채우기

대체 제목 필드가 비어 있는 게임을 라이브러리에서 찾아 IGDB / TGDB / ScreenScraper에서 채웁니다. 대규모 카탈로그를 가져왔거나, 지역별/일본어/부제 제목을 저장하지 않은 다른 도구에서 마이그레이션한 후에 유용합니다. 백그라운드에서 실행되며, 진행 상황은 도구 카드에 표시됩니다.

하나 이상의 스크레이퍼 API 키 필요(IGDB / TGDB / ScreenScraper)

일괄 HLTB 조회

플레이 시간 추정치가 없는 모든 게임에 대해 HowLongToBeat 조회를 실행합니다. 각 일치 항목은 제목 + 플랫폼 + 출시 연도로 점수가 매겨지며, 신뢰도가 높은 일치 항목은 자동으로 저장됩니다. 신뢰도 임곗값 미만(또는 플랫폼이 충돌하는) 항목은 사람의 검토를 위해 보류됩니다.

외부 의존성 없음(번들된 오프라인 HLTB 데이터셋 사용)

HLTB 검토 대기

일괄 HLTB 조회에서 나온 모호한 일치 항목을 위한 검토 큐입니다. 각 보류 행은 HLTB 후보(제목, 플랫폼, 출시 연도, 신뢰도)와 함께 소스 게임을 보여줍니다. 행마다 승인, 거부 또는 다른 일치 항목을 선택할 수 있습니다. 검토 도구 카드는 보류 중인 일치 항목이 하나 이상 있을 때만 ROM 도구 허브에 나타납니다.

  • 낮은 신뢰도, 대체 제목, 플랫폼 불일치 일치 항목을 위한 필터 탭.
  • 승인은 플레이 시간 추정치를 기록하고, 거부는 후보를 삭제하여 조회 큐를 깔끔하게 유지합니다.

도구 설정

모든 ROM 도구에서 공유되는 경로, 도구 위치, 아카이브 유형, 환경 설정을 구성합니다.

팁: 모든 ROM 도구는 일시 중지/재개를 지원하며 백그라운드에서 실행됩니다. 진행 상황과 결과는 로그에 기록되어 로그 뷰어에서 볼 수 있습니다. 도구 상태(사용 가능 대 설치 필요)는 각 도구 카드에 표시됩니다.

정규화

기능 설명

장르와 플레이 모드 값을 일관된 정식 형식으로 정규화합니다. 이는 스크래핑과 AI 채우기 중에 자동으로 일어나며, 기존 라이브러리에 수동으로 적용할 수도 있습니다.

중요한 이유

스크레이퍼마다 같은 것에 다른 이름을 사용합니다. 정규화는 전체 라이브러리에 걸쳐 일관성을 보장합니다:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

사용자 지정 규칙

설정 → 데이터 → 정규화에서 사용자 지정 정규화 규칙을 추가할 수 있습니다. 사용자 지정 규칙은 기본 제공 매핑을 재정의하여 선호하는 장르 및 모드 이름을 직접 정의할 수 있게 합니다. 규칙은 데이터베이스에 저장됩니다.

미리 보기 및 적용

정규화를 적용하기 전에, 어떤 게임이 영향을 받고 어떤 변경이 이루어질지 미리 볼 수 있습니다. 이를 통해 라이브러리에 변경 사항을 적용하기 전에 검토할 수 있습니다.

이미지 표준화

기능 설명

라이브러리 전체에서 균일한 모습을 위해 모든 게임 미디어를 일관된 목표 크기로 표준화합니다. 목표 크기의 80–120% 이내의 이미지는 건너뜁니다.

작동 방식

  • 업스케일링 — 목표 크기보다 작은 이미지는 고품질 확대를 위해 Real-ESRGAN x4(ONNX Runtime을 통한 AI 초해상도)를 사용하여 업스케일된 다음 정확한 목표 크기로 조정됩니다
  • 다운스케일링 — 목표 크기보다 큰 이미지는 선명한 결과를 위해 Lanczos 필터링을 사용하여 다운스케일됩니다
  • 임곗값 대역 — 목표 크기의 80–120% 이내의 이미지는 불필요한 재처리를 피하기 위해 그대로 둡니다

실행 방법

  1. 설정 → 시스템 → 유지 관리 또는 ROM 도구 → 이미지 크기 조정기로 이동합니다
  2. "시작"을 클릭하여 일괄 표준화를 시작합니다
  3. 작업은 현재 파일과 통계를 보여주는 토스트 진행 상황과 함께 백그라운드에서 실행됩니다
  4. 이미지는 스크래핑 중에도 자동 표준화됩니다(새 다운로드는 즉시 표준화됨)

하드웨어 지원

Real-ESRGAN 모델은 하드웨어를 자동으로 감지하여 사용 가능한 최상의 제공자를 사용합니다:

  • CUDA — NVIDIA GPU 가속
  • ROCm — AMD GPU 가속(RX 6000 시리즈용 자동 gfx 버전 재정의 포함)
  • CoreML — Apple Silicon 가속
  • CPU — GPU 지원이 없는 시스템용 폴백

ONNX 모델 파일은 첫 사용 시 Hugging Face에서 자동으로 다운로드되어 로컬에 캐시됩니다.

  • 라이브러리 스캔 — ROM 디렉터리에서 새 게임을 스캔합니다. ES-DE systeminfo.txt 확장자 목록을 사용하여 시스템 폴더와 지원되는 파일 유형을 감지합니다. 대시보드에서도 사용 가능합니다.

정리 작업

  • 누락된 ROM 정리 — ROM 파일이 더 이상 디스크에 존재하지 않는 게임의 데이터베이스 항목을 제거합니다. ROM 파일을 재정리하거나 삭제한 후에 유용합니다.
  • 고아 미디어 정리 — 해당하는 데이터베이스 참조가 없는 디스크의 이미지 파일(박스아트, 스크린샷, 팬아트)을 찾아 삭제합니다. 삭제 전에 확인을 위해 미리 봅니다.
  • 스크래핑 데이터 지우기 — ROM 파일 항목은 유지하면서 게임에서 스크래핑된 모든 메타데이터를 제거합니다. 스크래핑을 새로 시작하는 데 유용합니다. 미리 보기는 실행 전에 영향받는 게임을 보여줍니다.
  • CLZ 가져오기 지우기 — 모든 CLZ Games 가져오기 기록(ROM 파일이 없는 메타데이터 전용 항목)을 제거합니다.

데이터베이스 최적화

  • 데이터베이스 최적화 — SQLite VACUUM과 ANALYZE를 실행하여 삭제된 레코드로부터 저장 공간을 회수하고 쿼리 플래너 통계를 업데이트합니다. 대량 삭제나 정리 작업 후에 권장됩니다.

데이터베이스 마이그레이션

RetroDB는 시작 시 데이터베이스 스키마 변경을 자동으로 처리합니다. 새 열과 테이블이 데이터 손실 없이 필요에 따라 추가됩니다. 특별히 할 일은 없습니다 — 그냥 새 버전을 시작하면 데이터베이스가 자동으로 업데이트됩니다.

문제 해결

일반적인 문제

"No extensions found for system"

시스템 폴더에는 지원되는 ROM 파일 확장자를 정의하는 유효한 ES-DE systeminfo.txt 파일이 필요합니다. ROM 디렉터리 구조가 ES-DE 표준과 일치하는지 확인하세요.

"API Connection Failed"

  • 인터넷 연결을 확인하세요
  • 설정 → 스크래핑 → API 키에서 API 키를 확인하세요
  • 요청이 제한된 경우 기다리세요(일부 API는 일일/시간별 상한이 있음)
  • 스크레이퍼가 활성화되어 있는지 확인하세요(비활성화된 스크레이퍼는 대시보드 상태에 "비활성화"로 표시됨)
  • 자세한 오류 메시지는 로그 뷰어를 확인하세요

"Bulk Scrape Stuck"

설정 → 시스템 → 문제 해결 → "멈춘 일괄 스크래핑 지우기"로 이동하세요. 이는 데이터에 영향을 주지 않고 작업 상태를 재설정합니다.

"RA Sync Queue Stuck"

설정 → 시스템 → 문제 해결에서 RetroAchievements 동기화 큐를 지우세요.

"PSN Sync Stuck"

설정 → 시스템 → 문제 해결에서 PSN 새로고침 작업을 지우세요.

"Museum Generation Stuck"

설정 → 시스템 → 문제 해결에서 박물관 생성 작업을 지우세요.

"Database Errors"

  1. 가능하면 백업을 만드세요(설정 → 라이브러리 → 백업)
  2. 설정 → 시스템 → 유지 관리 → 데이터베이스 최적화를 시도하세요
  3. database/ 디렉터리의 파일 권한을 확인하세요
  4. 최후의 수단: 백업에서 복원하거나 데이터베이스를 삭제하고 다시 스캔하세요

"Images Not Saving"

미디어 디렉터리의 쓰기 권한을 확인하세요: chmod -R 755 static/images/

"Page Slow or Unresponsive"

  • 큰 컬렉션은 로드하는 데 시간이 걸릴 수 있습니다 — 무한 스크롤은 100개 단위로 로드합니다
  • 누적된 메모리를 비우기 위해 페이지를 새로고침해 보세요
  • JavaScript 오류는 브라우저 콘솔을 확인하세요
  • 더 가벼운 캔버스 효과의 테마로 전환해 보세요(예: Amber 또는 Elite)
  • 캔버스 효과는 하드웨어를 자동 감지하며, 저사양 기기는 낮은 프레임 속도로 CPU 폴백을 사용합니다

대시보드의 "Interrupted Jobs" 배너

작업이 실행되는 동안 RetroDB가 재시작되면, 작업이 복구 배너에 나타납니다. 개별적으로 "재개"를 클릭하거나 "모두 재개"를 클릭하여 다시 시작하세요. "해제" 또는 "모두 해제"를 클릭하여 지우세요.

"PSN Authentication Failed"

  • NPSSO 토큰은 만료됩니다 — ca.account.sony.com/api/v1/ssocookie 에서 새로 생성하세요
  • 쿠키 URL을 방문하기 전에 store.playstation.com에 로그인되어 있는지 확인하세요
  • data/psn_tokens.json 의 캐시된 토큰은 약 2개월 동안 유지됩니다

"Xbox Authentication Failed"

  • 게임 가져오기 → Xbox 탭에서 "로그인"을 클릭하여 다시 인증하세요
  • Xbox 토큰은 data/xbox_tokens.json 에 캐시되고 자동으로 갱신됩니다

"Image Upscaling Errors"

  • Real-ESRGAN ONNX 모델은 첫 사용 시 다운로드됩니다 — 인터넷 접근이 가능한지 확인하세요
  • GPU 가속에는 호환되는 드라이버가 필요합니다(NVIDIA용 CUDA, AMD용 ROCm)
  • GPU가 실패하면 시스템이 자동으로 CPU 처리로 폴백합니다

성능 팁

  • 최상의 성능을 위해 브라우저를 최신 상태로 유지하세요
  • 매우 큰 컬렉션으로 작업할 때는 다른 브라우저 탭을 닫으세요
  • 한 번에 표시되는 게임을 줄이기 위해 시스템 필터를 사용하세요
  • 대량 작업(스크래핑, 정리, 가져오기) 후에는 주기적으로 데이터베이스 최적화를 실행하세요
  • 캔버스 테마 효과는 하드웨어를 자동 감지하며, 저사양 기기는 CPU 폴백을 사용합니다

보안 및 면책 조항

보안 모범 사례

  • 기본 비밀번호 변경 — 기본 관리자 비밀번호(admin)는 첫 로그인 시 즉시 변경해야 합니다. 최소 8자 이상의 강력한 비밀번호를 사용하세요.
  • HTTPS 리버스 프록시 사용 — RetroDB는 자체적으로 TLS/SSL을 제공하지 않습니다. 클라이언트와 서버 간의 트래픽을 암호화하려면 HTTPS가 활성화된 리버스 프록시(예: Nginx, Caddy, Traefik) 뒤에 두세요.
  • 네트워크 접근 제한 — RetroDB를 공용 인터넷에 직접 노출하지 마세요. VPN을 사용하거나 로컬 네트워크로 접근을 제한하세요. 원격 접근이 필요하면 인증이 있는 리버스 프록시를 사용하세요.
  • 정기적인 백업 유지 — 설정의 기본 제공 백업 기능을 사용하여 주기적인 데이터베이스 백업을 만드세요. 백업은 애플리케이션과 별도의 위치에 보관하세요.
  • RetroDB 최신 상태 유지 — 새 릴리스를 정기적으로 확인하세요. 보안 수정과 개선 사항이 업데이트에 포함됩니다.
  • API 키 보호 — API 키는 data/scraper_settings.json 에 저장됩니다. 이 파일이 공개적으로 접근되지 않도록 하세요. config.py 나 토큰 파일을 절대 공유하지 마세요.

기본 제공 보안 기능

  • 비밀번호 해싱 — 관리자 비밀번호는 PBKDF2로 해싱됩니다(평문으로 저장되지 않음)
  • 로그인 요청 제한 — 로그인 엔드포인트에 무차별 대입 공격 방지

  • 매개변수화된 쿼리 — 모든 데이터베이스 쿼리는 SQL 인젝션을 방지하기 위해 매개변수화된 구문을 사용합니다
  • XSS 보호 — 모달 대화 상자는 안전한 DOM 구성을 사용하며, 사용자 입력은 이스케이프됩니다
