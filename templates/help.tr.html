Kurulum

Sistem Gereksinimleri

  • Python 3.8+ ve pip
  • Web tarayıcısı (Chrome, Firefox, Safari, Edge)
  • İşletim Sistemi: Linux, Windows 10/11 veya macOS

Hızlı Kurulum

  1. RetroDB ZIP dosyasını istediğiniz bir dizine çıkarın
  2. O dizinde bir terminal/komut istemi açın
  3. Şunu çalıştırın: python install.py
  4. Sunucuyu başlatın:
    • Linux: ./start.sh
    • Windows: start.bat dosyasına çift tıklayın
    • macOS: start.command dosyasına çift tıklayın
  5. Tarayıcınızda http://localhost:5000 adresini açın

Grafik Arayüzlü Kurulum

Linux'ta, grafiksel bir kurulum sihirbazı başlatmak için ./setup.sh komutunu da çalıştırabilirsiniz. Python/pip/tkinter varlığını otomatik olarak kontrol eder, ardından görsel bir ilerleme günlüğüyle her kurulum adımında size rehberlik eder.

install.py Ne Yapar

  • Python 3.8+ ve pip'in mevcut olduğunu doğrular
  • requirements.txt dosyasından Python bağımlılıklarını kurar
  • Örnek şablondan config.py dosyasını oluşturur
  • Gerekli dizinleri oluşturur (veritabanı, günlükler, medya klasörleri)
  • CSS ve JS paketlerini derler

Başlarken

İlk Kurulum

İlk çalıştırmada RetroDB, size şu adımlarda rehberlik eden bir Kurulum Sihirbazı gösterir:

  1. Yönetici Hesabı — Kullanıcı adınızı ve şifrenizi oluşturun
  2. Kütüphane Yolu — ROM dizininizi ayarlayın
  3. ES-DE Entegrasyonu — İsteğe bağlı olarak ES-DE oyun listelerini ve medyasını bağlayın
  4. API Anahtarları — İsteğe bağlı olarak veri çekme API anahtarları ekleyin

Sihirbazı tamamladıktan sonra, ROM'larınızı keşfetmek için Kontrol Panelinde "Kütüphaneyi Tara" düğmesine tıklayın.

Hızlı Başlangıç İş Akışı

  1. ROM'larınızı içe aktarmak için kütüphanenizi tarayın
  2. Sisteme göre göz atın veya Kütüphane'de tüm oyunları görüntüleyin
  3. Metadata'yı tek tek çekin veya toplu veri çekmeyi kullanın
  4. Etiketler, listeler ve istek listesiyle düzenleyin
  5. Tamamlama durumu ve başarımlarla ilerlemenizi takip edin

Platform Notları

Linux

  • Ubuntu, Fedora, openSUSE ve Arch Linux üzerinde test edilmiştir
  • ROM Araçları şunları gerektirir: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) veya dağıtımınıza uygun eşdeğeri
  • Sistem Python'u kullanıyorsanız, kurulum programı --break-system-packages seçeneğini otomatik olarak yönetir
  • AMD GPU'lar için ROCm GPU hızlandırması desteklenir (Real-ESRGAN görsel büyütme)

Windows

  • Python'u python.org adresinden indirin (kurulum sırasında "Add to PATH" seçeneğini işaretleyin)
  • ROM Araçları: 7-Zip, WinRAR ve MAME (chdman için) kurun
  • Başlatmak için start.bat dosyasını kullanın veya Komut İstemi'nden python app.py çalıştırın

macOS

  • Python 3, Homebrew aracılığıyla kurulabilir: brew install python3
  • ROM Araçları: brew install p7zip unrar rom-tools
  • Başlatmak için Finder'da start.command dosyasına çift tıklayın
  • Apple Silicon için CoreML hızlandırması desteklenir (Real-ESRGAN görsel büyütme)

API Anahtarı Kurulum Kılavuzu

API anahtarları isteğe bağlıdır ancak zengin metadata çekimi ve ek özellikler sağlar. Bunları Ayarlar → Veri Çekme → API Anahtarları bölümünde yapılandırın.

Metadata Veri Çekiciler

TheGamesDB

  1. api.thegamesdb.net/key.php adresine gidin
  2. API anahtarları isteyin (ücretsiz, manuel olarak onaylanır) — bir Public ve Private anahtar alacaksınız
  3. Her iki anahtarı da Ayarlar → API Anahtarları → TheGamesDB bölümüne girin
  4. Public anahtar (IP başına hız sınırı), veri çekme için birincil anahtar olarak kullanılır
  5. Private anahtar (paylaşılan aylık havuz), public anahtar başarısız olursa yedek olarak kullanılır

IGDB (Twitch üzerinden)

  1. twitch.tv adresinde bir Twitch hesabı oluşturun
  2. dev.twitch.tv/console adresine gidin
  3. Yeni bir uygulama kaydedin (herhangi bir ad, herhangi bir kategori, OAuth yönlendirmesi olarak http://localhost)
  4. Client ID'yi kopyalayın ve bir Client Secret oluşturun
  5. Her ikisini de Ayarlar → API Anahtarları → IGDB bölümüne girin

RAWG.io

  1. rawg.io/apidocs adresine gidin
  2. "Get API Key" düğmesine tıklayın ve bir hesap oluşturun
  3. API anahtarınızı kontrol panelinden kopyalayın
  4. Ayarlar → API Anahtarları → RAWG bölümüne girin

Ücretsiz seviye: ayda 20.000 istek

ScreenScraper

  1. screenscraper.fr adresinde bir hesap oluşturun
  2. Kullanıcı adınızı ve şifrenizi Ayarlar → API Anahtarları → ScreenScraper bölümüne girin

Not: ScreenScraper, hesap seviyenize bağlı günlük istek sınırlarına sahiptir. Veritabanına katkıda bulunmak sınırlarınızı artırır.

Başarımlar ve Kupalar

RetroAchievements

  1. retroachievements.org adresinde bir hesap oluşturun
  2. Profilinizde Ayarlar → API Anahtarları bölümüne gidin
  3. API anahtarınızı kopyalayın
  4. Kullanıcı adınızı ve API anahtarınızı Ayarlar → Hesap → RetroAchievements bölümüne girin

Steam Web API

  1. steamcommunity.com/dev/apikey adresine gidin
  2. Bir Steam Web API anahtarı için kaydolun (bir Steam hesabı gerektirir)
  3. API anahtarınızı ve Steam ID'nizi (veya vanity URL'nizi) Ayarlar bölümüne girin

Steam kütüphanesi içe aktarma ve başarım takibi için kullanılır.

Xbox Live

Xbox kimlik doğrulaması OAuth2 kullanır — API anahtarına gerek yoktur. Oyun İçe Aktarma → Xbox sekmesinden doğrudan Microsoft hesabınızla oturum açın. Belirteçler (token) otomatik olarak önbelleğe alınır ve gerektiğinde yenilenir.

PlayStation Network (PSN)

PSN, NPSSO çerez kimlik doğrulaması kullanır. Ayrıntılı kurulum talimatları için Kupalar bölümüne bakın.

Ayarlar

Ayarlar, her biri birden çok alt bölüme sahip 6 sekmede düzenlenmiştir.

Hesap Sekmesi

  • Profilim — Avatar yükleme/kaldırma, görünen ad, rol bilgisi, şifre değiştirme
  • RetroAchievements — RA entegrasyonu için kullanıcı adı ve API anahtarı
  • PSN — PlayStation Network kupa senkronizasyonu için NPSSO çerezi
  • Saat Dilimi — Uygulama genelinde tarih görüntüleme için saat diliminizi ayarlayın
  • Kullanıcılar — Kullanıcı yönetimi: kullanıcı ekleme, düzenleme, silme ve rol atama (yalnızca yönetici)

Kütüphane Sekmesi

  • Yollar — ROM kütüphane yolu, veritabanı konumu
  • Görünüm — Tema seçimi, kutu resmi stili (2D/3D), tercih edilen yaş derecelendirme sistemi, sayfa başına öğe sayısı
  • ROM Adlandırma — Makale yerleşimi (başta/sonda "The"), bölge seçenekleri listesi, varsayılan bölge, adlandırma kuralları
  • Yedekleme — Veritabanı yedekleri oluşturma ve geri yükleme

Veri Çekme Sekmesi

  • ES-DE — Yerel veri içe aktarma için ES-DE oyun listesi ve medya yolları
  • Veri Çekici — Tek tek veri çekicileri etkinleştirme/devre dışı bırakma, sürükle-bırak öncelik sıralaması, veri çekici başına hız sınırı ayarları
  • API Anahtarları — Tüm veri çekici kimlik bilgileri (TGDB, IGDB, RAWG, ScreenScraper), AI sağlayıcı seçimi ve model seçimi (Gemini, OpenAI, Claude)

Veri Sekmesi

  • İstatistikler — Kütüphane istatistikleri özeti (toplam oyun, sistem, depolama kullanımı)
  • Kupalar — Yerel PS3 kupa taraması için RPCS3 kupa yolu yapılandırması
  • Açılır Menüler — Bölge seçeneklerini ve uygulama genelinde kullanılan diğer açılır menü değerlerini özelleştirin
  • Normalleştirme — Tür ve mod normalleştirme kuralları — veri çekici çıktısını standartlaştırmak için özel eşlemeler ekleyin

Özelleştirme Sekmesi

  • Bildirimler — Bildirim zaman aşımı tercihleri (başarı, bilgi, uyarı, hata — her biri bağımsız olarak yapılandırılabilir)
  • Kontrolcüler — Kontrolcü kütüphanesini yönetin, sistem başına varsayılan kontrolcüleri ayarlayın, özel kontrolcüler ekleyin. Varsayılan kontrolcüler, metadata çekimi sırasında veri çekilen/AI değerlerini geçersiz kılar.
  • Logolar — Sistem logosu özelleştirme — sistem logolarını içe aktarın veya varsayılanlardan yenileyin

Sistem Sekmesi

  • Bakım — Veritabanı optimizasyonu (VACUUM/ANALYZE), sahipsiz medya temizliği, eksik ROM'ları temizleme, veri çekilen verileri temizleme, CLZ içe aktarmalarını temizleme, toplu görsel standartlaştırma
  • Sunucu — Sunucu yapılandırması (host, port, hata ayıklama modu)
  • Günlükleme — Farklı kategoriler için günlük seviyesi ayarları
  • Sorun Giderme — Takılan toplu veri çekmeyi temizleme, RA senkronizasyon kuyruğunu temizleme, PSN yenilemeyi temizleme, müze oluşturmayı temizleme, sunucuyu yeniden başlatma
İpucu: Devre dışı bırakılan veri çekiciler, Kontrol Panelinde "API çevrimdışı" uyarılarını tetiklemez. Bir veri çekiciyi kullanmıyorsanız, API anahtarını silmek yerine Ayarlar → Veri Çekme → Veri Çekici bölümünden devre dışı bırakın.

Hibrit Veri Çekme

RetroDB, metadata kapsamını en üst düzeye çıkarmak için birden fazla kaynaktan gelen verileri otomatik olarak birleştirir:

  • En yüksek öncelikli mevcut kaynaktan metin metadata'sı
  • Birincil kaynakta bulunmadığında ikincil kaynaklardan görseller ve medya
  • Maksimum kapsam için veri çekiciler arasında otomatik boşluk doldurma
  • Sıralama başlığı, veri çekme sırasında oyun başlığından otomatik olarak oluşturulur

Medya İşleme

  • Medya alanları (kutu resmi, 3D kutu resmi, ekran görüntüleri, fanart, video, kılavuz) normal veri çekme sırasında asla değiştirilmez — yalnızca boş olduklarında doldurulur
  • Ekran görüntüleri her zaman eklenir, asla değiştirilmez
  • Medyayı yeniden indirmek için önce düzenleme penceresindeki mevcut görseli temizleyin, ardından yeniden veri çekin
  • Tam Yeniden Veri Çekme modu bunu geçersiz kılar ve her şeyi değiştirir
  • Eski medya referansları (dosya silinmiş ancak dosya adı hâlâ veritabanında) yeni medyanın indirilebilmesi için veri çekmeden önce otomatik olarak temizlenir
  • İndirilen görseller otomatik olarak hedef boyutlara standartlaştırılır (bkz. Görsel Standartlaştırma)

Veri Çekici Önceliği

Hangi veri çekicilerin önce çalışacağını ve hangilerinin etkin/devre dışı olduğunu Ayarlar → Veri Çekme → Veri Çekici bölümünde yapılandırın. Önceliği yeniden sıralamak için sürükleyip bırakın. Devre dışı bırakılan veri çekiciler, veri çekme sırasında denenmez ve Kontrol Panelinde API durum uyarılarını tetiklemez.

Hız Sınırlama

Her veri çekicinin, API kısıtlamasını önlemek için yapılandırılabilir hız sınırları vardır. Varsayılan gecikmeler muhafazakâr şekilde ayarlanmıştır. Gecikmeleri kendi sorumluluğunuzda azaltın — API hız sınırlarını aşmak, ilgili hizmetten geçici olarak yasaklanmanıza neden olabilir.

  3. Oyunları tek tek seçin veya hızlı seçimi kullanın:

Kontroller

Toast Bildirimi

Arka planda çalışırken, kalıcı bir toast tüm sayfalarda ilerlemeyi gösterir:

  • Herhangi bir sayfadan Duraklat/İptal kontrolleri kullanılabilir
  • Veri çekme penceresine dönmek için toast'a tıklayın

Kuyruk Sistemi

Birden fazla toplu veri çekme otomatik olarak kuyruğa girer:

  • Biri çalışırken yeni bir veri çekme başlatın — kuyruğa girer
  • Kuyruk, toast içinde bekleyen iş sayısıyla gösterilir
  • İşler otomatik olarak sırayla işlenir
  • Kuyruğa alınan işleri görüntülemek, yeniden sıralamak veya iptal etmek için Kuyruk Yöneticisi'ni kullanın

Veri Çekme Seçenekleri

  • Yalnızca Eksikleri Doldur — Mevcut verileri koruyarak yalnızca boş metadata alanlarını doldurur

İş Kurtarma

Bir iş çalışırken RetroDB yeniden başlatılırsa, kesintiye uğrayan işler Kontrol Panelinde bir kurtarma banner'ında görünür. Onları yeniden başlatmak için tek tek işlerde "Devam Ettir" veya "Tümünü Devam Ettir" düğmesine tıklayın. İlerleme toast'ı, devam ettirdikten hemen sonra görünür.

AI Doldurma

Ne Yapar

AI Doldurma, eksik veya tamamlanmamış oyun metadata'sını akıllıca doldurmak için büyük bir dil modeli (Gemini, OpenAI veya Claude) kullanır. Veri çekicilerin sahip olmayabileceği doğru verileri sağlamak için oyun hakkındaki bağlamsal bilgiyi kullandığından normal veri çekmeden daha akıllıdır.

Nasıl Kullanılır

  1. Bir oyunun detay penceresini (veya tam detay sayfasını) açın
  2. "AI Doldurma" düğmesine tıklayın (Ayarlar'da yapılandırılmış bir AI API anahtarı gerektirir)
  3. AI, oyun başlığını ve sistemini analiz eder, ardından eksik alanları doldurur
  4. Sonuçları gözden geçirin — değişiklikler otomatik olarak kaydedilir

AI Doldurma Neler Sağlayabilir

  • Tür, açıklama, geliştirici, yayıncı, piyasaya çıkış tarihi
  • Oyuncu sayısı, oynanış modları (Tek Oyunculu, Çok Oyunculu, Co-op vb.)
  • Kampanya bilgisi ve oyun yapısı
  • Tüm 8 yaş derecelendirme sistemi (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Bölge, marka, benzer oyunlar
  • Kontrolcü desteği, kayıt türü
  • Perspektif (Birinci Şahıs, Üstten Görünüm, Yandan Kaydırmalı vb.), boyut (2D, 3D)
  • Sürüm bilgisi, eleştirmen ve kullanıcı puanları

Akıllı Doldurma Mantığı

  • Boş alanlar her zaman doldurulur
  • Mevcut kullanıcı verileri asla üzerine yazılmaz
  • Benzer oyunlar her zaman yenilenir (AI verisi bu alan için daha güvenilirdir)
  • Çapraz eşlenmiş derecelendirmeler — Bir derecelendirme sistemi biliniyorsa, diğer sistemlerdeki boş derecelendirmeler olgunluk seviyesi çapraz eşlemesi kullanılarak otomatik olarak doldurulur
  • Sıralama başlığı doldurulduğunda otomatik olarak oluşturulur
  • Oyuncu sayısı alanı aralıkları normalleştirir (örn. "1-4" değeri 4 olur)

Tür Normalleştirme

AI Doldurma, tireli isimlerle standart tür biçimlerini kullanır:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Gereksinimler

Ayarlar → Veri Çekme → API Anahtarları bölümünde en az bir AI sağlayıcı API anahtarı yapılandırılmalıdır. En ucuz model seviyesi (Gemini Flash Lite, GPT-4o Mini veya Claude Haiku) metadata için iyi çalışır.

Filtreleme ve Arama

Arama

Arama, oyunları başlığa (ve sıralama başlığına) göre filtreler. Arama kutusuna odaklanmak için / tuşuna basın. Sonuçlar 300 ms'lik bir gecikmeyle gerçek zamanlı olarak güncellenir.

Kaynak Filtresi

Oyunları içe aktarma kaynağına göre filtreleyin:

  • ROM Dosyaları — ROM kütüphanenizden gelen oyunlar
  • CLZ İçe Aktarmaları — CLZ'den içe aktarılan fiziksel oyunlar
  • Steam İçe Aktarmaları — Steam'den içe aktarılan oyunlar
  • Xbox İçe Aktarmaları — Xbox'tan içe aktarılan oyunlar
  • PSN İçe Aktarmaları — PlayStation Network'ten içe aktarılan oyunlar

Filtre Düğmeleri

Her filtre, sayılarla birlikte kütüphanenizdeki tüm benzersiz değerleri gösteren bir pencere açar. Filtreler iki modu destekler:

Oyun Detay Penceresi

Herhangi bir oyun kartına tıklamak, önbelleğe alınmış hızlı bir görünümle bir detay penceresi açar. Pencere şunları gösterir:

  • Kutu resmi (2D ve 3D), fanart arka planı
  • Açıklama ve piyasaya çıkış bilgisi
  • Geliştirici, yayıncı, tür rozetleri
  • Oyuncu sayısı, oynanış modları, oyun yapısı
  • Yaş derecelendirme görseli (tercih ettiğiniz sistemden, çapraz eşleme yedeğiyle)

  • Fragman videosu (varsa)
  • HLTB oynanış süresi tahminleri (Ana Hikaye, Ana + Ekstralar, Tamamlayıcı)
  • RetroAchievements durumu ve ilerlemesi
  • Benzer oyunlar (tıklanabilir bağlantılar)
  • Kontrolcü desteği ayrıntıları
  • Oyuna atanmış etiketler
  • Dosya boyutu ve ROM yolu

Tam Oyun Detay Sayfası

Tam oyun detay sayfasını görüntülemek için oyun başlığı bağlantısına tıklayın veya gezinme yolundan gidin. Tam sayfadaki ek özellikler şunları içerir:

  • Gezinme yollu fanart arka plan başlığı
  • Platform içe aktarma rozetleri — Uygulanabilir olduğunda platform logolarıyla CLZ İçe Aktarma, Steam İçe Aktarma, Xbox İçe Aktarma veya PSN İçe Aktarma gösterir
  • Bonus disk göstergesi — Bir rozet ve küçük resimle üst oyuna "Parçası:" bağlantısı gösterir
  • Sil düğmesi — Oyunu veritabanından kaldırır (onay ile)
  • Temizle düğmesi — ROM girişini korurken tüm veri çekilen metadata'yı temizler

Düzenleme Penceresi

Bölümlere ayrılmış düzenleme penceresini açmak için Düzenle düğmesine tıklayın (veya e tuşuna basın):

  • Kimlik — Başlık, sıralama başlığı (otomatik oluşturulur ama düzenlenebilir), marka, sürüm
  • Piyasaya Çıkış Bilgisi — Piyasaya çıkış tarihi, bölge (yapılandırılabilir açılır menüden)
  • Oynanış — Tür (çoklu seçim etiketleri), modlar, oyun yapısı, oyuncu sayısı, geliştirici, yayıncı
  • Teknik — Kontrolcüler (çoklu seçim), kayıt türü, perspektif (çoklu değer), boyut (çoklu değer)
  • Yaş Derecelendirmeleri — Resmi derecelendirme görselleri ve otomatik çapraz eşleme ile tüm 8 derecelendirme sistemi. Bir derecelendirmeyi değiştirmek, diğer sistemlerdeki boş derecelendirmeleri otomatik olarak doldurur.
  • Puanlar — Eleştirmen puanı, kullanıcı puanı
  • Açıklama — Oyun açıklama metni
  • Özel Görseller — Özel kutu resmi (2D), 3D kutu resmi ve fanart yükleyin. Yeniden veri çekmeye izin vermek için mevcut görselleri temizleyin.
  • Video / Fragman — Bir video fragmanı yükleyin veya bağlayın

Koleksiyonlar (Etiketler, Listeler, İstek Listesi)

Etiketler

Oyunlarınızı düzenlemek için özel renk kodlu etiketler oluşturun. Etiketler ad kartları gibi çalışır — her oyunun birden fazla etiketi olabilir ve her etiket birden fazla oyun içerebilir.

  • Etiketler sayfasından özel adlar ve renklerle etiketler oluşturun
  • Oyun detay penceresi aracılığıyla oyunlara etiket atayın
  • Bu etikete sahip tüm oyunlara göz atmak için herhangi bir etikete tıklayın
  • Etiketler yönetim sayfasından etiketleri düzenleyin veya silin

İsimlendirilmiş Listeler

Özel sıralamayla özel oyun listeleri oluşturun. Listeler çalma listeleri gibidir — oyunların tam sırasını siz kontrol edersiniz.

  • Listeler sayfasından ad, açıklama ve simgeyle listeler oluşturun
  • Oyun detay penceresi veya liste sayfası aracılığıyla listelere oyun ekleyin
  • Bir liste içindeki oyunları yeniden sıralamak için sürükleyip bırakın
  • Özel sıraya göre veya alfabetik olarak sıralayın

İstek Listesi

Fiziksel veya dijital olsun, edinmek istediğiniz oyunları takip edin.

  • Başlık, sistem, notlar ve öncelikle (1–5) oyunları manuel olarak ekleyin
  • İstek listesi öğeleri, bulunursa mevcut kütüphane oyunlarıyla bağlanabilir
  • Önceliğe göre (en yüksek önce), ardından eklenme tarihine göre sıralanır
İpucu: Genel etiketler için etiketleri (örn. "Favoriler", "Kanepe Co-op", "Bekleme Listesi"), belirli düzenlenmiş koleksiyonlar için ise listeleri kullanın (örn. "En İyi 10 SNES Oyunu", "Yayınlanacak Oyunlar").

Oyun İçe Aktarma

Harici kaynaklardan oyun koleksiyonları içe aktarın. Kenar çubuğundaki Oyun İçe Aktarma aracılığıyla erişin. Tüm içe aktarma türleri tek bir sekmeli sayfada birleştirilmiştir.

CLZ Games İçe Aktarma

Fiziksel oyun koleksiyonunuzu CLZ Games'ten içe aktarın.

  1. CLZ Games koleksiyonunuzu PDF olarak dışa aktarın
  2. Oyun İçe Aktarma → CLZ sekmesine gidin
  3. PDF dosyasını yükleyin
  4. Ayrıştırılan oyunları gözden geçirin
  5. İçe aktarılacak oyunları seçin

CLZ içe aktarmaları, ROM oyunlarından ayrı olarak takip edilir (clz_import/ öneki kullanılarak), böylece hem fiziksel hem de dijital koleksiyonları kataloglayabilirsiniz. CLZ içe aktarmaları Ayarlar → Sistem → Bakım bölümünden tamamen temizlenebilir.

Steam İçe Aktarma

Steam oyun kütüphanenizi içe aktarın ve başarımları takip edin.

  1. Ayarlar'da Steam Web API anahtarınızı ve Steam ID'nizi yapılandırın
  2. Oyun İçe Aktarma → Steam sekmesine gidin
  3. Steam oyunlarınızı almak için "Kütüphaneyi Getir" düğmesine tıklayın
  4. İçe aktarılacak oyunları seçin (yinelenenler otomatik olarak tespit edilir)
  5. İçe aktarılan oyunlar, başarım takibi için Steam App ID'leriyle etiketlenir

Xbox İçe Aktarma

Xbox oyun kütüphanenizi Microsoft hesabı üzerinden içe aktarın.

  1. Oyun İçe Aktarma → Xbox sekmesine gidin
  2. Microsoft hesabınızla kimlik doğrulamak için "Oturum Aç" düğmesine tıklayın (OAuth2 akışı)
  3. Xbox oyun geçmişiniz otomatik olarak alınır
  4. Yinelenen tespitiyle içe aktarılacak oyunları seçin
  5. İçe aktarılan oyunlar, başarım takibi için Xbox Title ID'leriyle etiketlenir

Xbox belirteçleri data/xbox_tokens.json içinde önbelleğe alınır ve otomatik olarak yenilenir.

PSN İçe Aktarma

PlayStation Network oyun kütüphanenizi içe aktarın.

  1. Oyun İçe Aktarma → PSN sekmesine gidin
  2. NPSSO çerezinizi girin (nasıl alınacağı için bkz. Kupalar → PSN Kimlik Doğrulama)
  3. PSN oyunlarınızı almak için "Kütüphaneyi Getir" düğmesine tıklayın
  4. İçe aktarılacak oyunları seçin

İçe Aktarma Sonrası

  • İçe aktarılan oyunlar, platforma özgü rozetlerle Kütüphanenizde görünür
  • İçe aktarılan oyunlar için metadata almak amacıyla toplu veri çekmeyi kullanın
  • Başarım/kupa takibi otomatik olarak kaynak platforma bağlanır
  • İçe aktarılan oyunlar, Kütüphanede Kaynak filtresi kullanılarak filtrelenebilir
İpucu: Herhangi bir platformdan oyun içe aktardıktan sonra, tıpkı ROM oyunlarında olduğu gibi toplu veri çekmeyi kullanarak onlar için metadata çekebilirsiniz. İçe aktarılan oyunlar ayrıca kendi platformlarından başarımları da takip edebilir.

Kurulum

Birden fazla sistem senkronizasyonu kuyruğa alınabilir:

  • Bir senkronizasyonu başlatmak veya kuyruğa almak için herhangi bir sistemde "İlerlemeyi Yenile" düğmesine tıklayın

  • Geçerli senkronizasyon tamamlandığında kuyruk otomatik olarak işlenir

  • RA İçin Kontrol Et — Oyun detay pencerelerinde, bir başarım seti aramak için tıklayın
  • Toplu Veri Çekme — Veri çekme sırasında başarımları bulmak için "RA Kontrol Et" seçeneğini etkinleştirin
  • RA Yenileme İşi — Hangi oyunların RA desteğine sahip olduğunu belirlemek için bir sistemdeki tüm oyunları tarayın

Not: "İlerlemeyi Yenile", zaten RetroAchievements bağlantısı olan oyunlar için ilerlemenizi senkronize eder. YENİ başarım setleri bulmak için oyun detay pencerelerinde "RA İçin Kontrol Et" seçeneğini kullanın veya toplu veri çekme sırasında etkinleştirin.

PS3 / PSN Kupaları

RPCS3 Yerel Kupaları

RPCS3 emülatörü aracılığıyla PS3 oyunlarında kazanılan kupaları takip edin.

  1. RPCS3 kupa yolunuzu Ayarlar → Veri → Kupalar bölümünde ayarlayın
  2. Kazanılan kupaları içe aktarmak için "Kupaları Tara" düğmesine tıklayın
  3. Kupa listelerini ve bireysel kupa ayrıntılarını RPCS3 Kupaları bölümünde görüntüleyin

RPCS3, kupa XML verilerini RPCS3 kullanıcı dizininizden okur ve oyunları otomatik olarak kütüphanenizle eşleştirir.

PSN API Kupaları

PSN hesabınızdan PlayStation Network kupa verilerinizi senkronize edin.

  1. NPSSO çerezinizi alın (aşağıya bakın)
  2. Ayarlar → Hesap → PSN bölümüne girin
  3. PSN kupa kütüphaneniz PlayStation API'si aracılığıyla alınır
  4. Kazanılan/toplam sayılarla oyun başına kupa ilerlemesini görüntüleyin
  5. Bireysel kupa ayrıntıları açıklama, nadirlik ve kilit açma zaman damgalarını içerir

PSN Kimlik Doğrulama (NPSSO Çerezi)

PSN, NPSSO belirteci adı verilen özel bir kimlik doğrulama çerezi kullanır. Bunu almak için:

  1. Bir web tarayıcısı açın ve store.playstation.com adresine giriş yapın
  2. Giriş yaptıktan sonra şuraya gidin: https://ca.account.sony.com/api/v1/ssocookie
  3. Sayfa, NPSSO belirtecinizi içeren JSON görüntüler
  4. npsso değerini kopyalayın ve Ayarlar → Hesap → PSN bölümüne yapıştırın

Kimlik doğrulandıktan sonra, RetroDB erişim belirteçlerini kendi veritabanında (kullanıcı başına) güvenli bir şekilde önbelleğe alır ve otomatik olarak yeniler — her senkronizasyonda NPSSO'yu tekrar yapıştırmanız gerekmez. Oturum yaklaşık iki ay geçerli kalır ve RetroDB artık bunu arka planda otomatik olarak da yeniler, bu nedenle normal kullanımda nadiren yeni bir NPSSO'ya ihtiyaç duymanız gerekir.

Kupa Ayrıntıları

  • Kupa türleri: Bronz, Gümüş, Altın, Platin
  • Kupa simgeleri indirilir ve yerel olarak önbelleğe alınır
  • Oyun başına tamamlanma yüzdesi
  • Her kazanılan kupa için kilit açma zaman damgaları

Toplu Senkronizasyon

Tüm PSN oyun kupalarını bir arka plan işi aracılığıyla tek seferde senkronize edin. İlerleme bir toast bildiriminde gösterilir. Hız sınırlaması (istekler arasında 2,5 sn) PSN API kısıtlamasını önler.

Müze

Nedir

Nesle göre düzenlenmiş oyun sistemlerinin etkileşimli bir ansiklopedisi. Koleksiyonunuzdaki her platform için tarih, teknik özellikler ve dikkat çekici oyunlar hakkında bilgi edinin.

Ana Sayfa

Müze ana sayfası, nesle göre gruplandırılmış oyun sistemlerinin bir zaman çizelgesini gösterir (1.–9. Nesil, El Cihazları, Arcade, Bilgisayarlar). Her sistem kartı, donanım görselini ve kütüphanenizdeki oyun sayısını gösterir.

Sistem Detay Sayfaları

Müze sayfasını görüntülemek için herhangi bir sisteme tıklayın; sayfa şunları içerir:

  • Donanım Görseli — Konsolun/sistemin fotoğrafı
  • Teknik Özellikler — CPU, GPU, RAM, çözünürlük, medya türü
  • Tarihçe — Sistemin geliştirilmesi, piyasaya çıkışı ve mirası hakkında AI tarafından oluşturulan anlatı
  • En İyi 10 Oyun — Sistemin en dikkat çekici oyunları (eleştirmen puanlarından ve AI önerilerinden)
  • Kontrolcü Galerisi — Açıklamalarla sistemin kontrolcülerinin görselleri

AI İçerik Oluşturma

Müze içeriği AI (Gemini, OpenAI veya Claude) kullanılarak oluşturulur. Şunlar için içerik oluşturabilirsiniz:

  • Tekli sistem — Herhangi bir sistemin müze sayfasında "Oluştur" düğmesine tıklayın
  • Toplu oluşturma — Ana sayfadan tüm sistemler için tek seferde içerik oluşturun (toast ilerlemesiyle arka plan işi olarak çalışır)

Kontrolcü Görselleri

Kontrolcü görselleri şu yollarla eklenebilir:

  • Görsel Arama — Bing Görsel Arama kullanarak kontrolcü fotoğrafları arayın. Sonuçlar alaka düzeyine göre sıralanır (kontrolcü adı + üretici + sistem varyasyonları).
  • Manuel Yükleme — Kendi kontrolcü görsellerinizi yükleyin
  • Arka Plan Kaldırma — Herhangi bir arka planda saydam kontrolcü görselleri için yerel AI (rembg kütüphanesi) kullanarak arka planları otomatik olarak kaldırın
  • Görsel Yayılımı — Bir kontrolcü görseli bulunduğunda, diğer sistemlerdeki aynı kontrolcüyle (kardeş kontrolcüler) otomatik olarak paylaşılır
  • Toplu Getirme — Bir sistemdeki tüm kontrolcüler için görselleri tek seferde getirin

Tüm kontrolcü görselleri hedef boyuta standartlaştırılır ve WebP biçiminde kaydedilir.

İpucu: İçerik oluşturma için bir AI API anahtarı gereklidir. Müze, Ayarlar → Veri Çekme → API Anahtarları bölümünde yapılandırılan aynı AI sağlayıcısını kullanır.

Ekran Görüntüsü Yinelenen Giderme

Depolama alanı boşaltmak için oyun kütüphaneniz genelinde yinelenen ekran görüntülerini bulun ve kaldırın.

  • Kesin Hash (MD5) — Yalnızca özdeş dosyaları tanımlar
  • Görsel Benzerlik — Yapılandırılabilir eşikle algısal hash karşılaştırması (1–20, düşük = daha katı eşleşme)

Taranan oyunları, yinelenen sayısını ve geri kazanılabilir alanı gösteren canlı istatistiklerle aşamalı olarak tarar. Sonuçlar oyuna ve sisteme göre gruplandırılır. Her yinelenen grupta hangi dosyanın tutulacağını seçebilir veya en yüksek çözünürlüklü sürümü otomatik olarak tutmak için "En Büyüğü Seç" seçeneğini kullanabilirsiniz.

Her eşleşme başlık + platform + piyasaya çıkış yılına göre puanlanır; yüksek güvenilirlikli eşleşmeler otomatik olarak kaydedilir. Toplu HLTB Arama tarafından ortaya çıkarılan belirsiz eşleşmeler için inceleme kuyruğu. Her bekleyen satır, kaynak oyunu HLTB adayının (başlık, platform, piyasaya çıkış yılı, güven) yanında gösterir. Her satır için farklı bir eşleşmeyi onaylayın, reddedin veya seçin. İnceleme araç kartı, ROM Araçları merkezinde yalnızca en az bir bekleyen eşleşme olduğunda görünür.

  • Düşük güvenilirlik, alternatif başlık ve platform uyuşmazlığı eşleşmeleri için filtre sekmeleri.
  • Onayla oynanış süresi tahminini yazar; Reddet adayı düşürür ve arama kuyruğunu temiz tutar.

Güvenlik ve Sorumluluk Reddi

En İyi Güvenlik Uygulamaları

  • Varsayılan şifreyi değiştirin — Varsayılan yönetici şifresi (admin) ilk girişte hemen değiştirilmelidir. En az 8 karakterlik güçlü bir şifre kullanın.
  • HTTPS ters proxy kullanın — RetroDB kendi başına TLS/SSL sağlamaz. İstemciler ve sunucu arasındaki trafiği şifrelemek için HTTPS etkinleştirilmiş bir ters proxy'nin (örn. Nginx, Caddy, Traefik) arkasına yerleştirin.
  • Ağ erişimini kısıtlayın — RetroDB'yi doğrudan genel internete açmaktan kaçının. Bir VPN kullanın veya erişimi yerel ağınızla sınırlayın. Uzaktan erişim gerekiyorsa, kimlik doğrulamalı bir ters proxy kullanın.
  • Düzenli yedekler alın — Periyodik veritabanı yedekleri oluşturmak için Ayarlar altındaki yerleşik yedekleme özelliğini kullanın. Yedekleri uygulamadan ayrı bir konumda saklayın.
  • RetroDB'yi güncel tutun — Yeni sürümleri düzenli olarak kontrol edin. Güvenlik düzeltmeleri ve iyileştirmeler güncellemelere dahildir.
  • API anahtarlarınızı koruyun — API anahtarları data/scraper_settings.json içinde saklanır. Bu dosyanın herkese açık olarak erişilebilir olmadığından emin olun. config.py veya belirteç dosyalarınızı asla paylaşmayın.

Yerleşik Güvenlik Özellikleri

  • Şifre karma (hash) — Yönetici şifreleri PBKDF2 ile karmalanır (asla düz metin olarak saklanmaz)
  • Giriş hız sınırlaması — Giriş uç noktasında kaba kuvvet saldırısı koruması
  • Yol doğrulama — Dizin geçişi saldırılarını önlemek için tüm dosya işlemleri safe_path ve safe_filename yardımcılarını kullanır
  • Parametreli sorgular — SQL enjeksiyonunu önlemek için tüm veritabanı sorguları parametreli ifadeler kullanır
  • XSS koruması — Pencere iletişim kutuları güvenli DOM oluşturma kullanır; kullanıcı girdisi kaçışlanır (escape)
