Installasjon

Systemkrav

  • Python 3.8+ med pip
  • Nettleser (Chrome, Firefox, Safari, Edge)
  • Operativsystem: Linux, Windows 10/11 eller macOS

Hurtiginstallasjon

  1. Pakk ut RetroDB-ZIP-filen i en mappe du velger
  2. Åpne en terminal/ledetekst i den mappen
  3. Kjør: python install.py
  4. Start serveren:
    • Linux: ./start.sh
    • Windows: dobbeltklikk start.bat
    • macOS: dobbeltklikk start.command
  5. Åpne http://localhost:5000 i nettleseren din

Grafisk installasjonsveiviser

På Linux kan du også kjøre ./setup.sh for å starte en grafisk installasjonsveiviser. Den sjekker automatisk om Python/pip/tkinter er tilgjengelig, og veileder deg deretter gjennom hvert oppsettstrinn med en visuell fremdriftslogg.

Hva install.py gjør

  • Bekrefter at Python 3.8+ og pip er tilgjengelig
  • Installerer Python-avhengigheter fra requirements.txt
  • Oppretter config.py fra eksempelmalen
  • Oppretter nødvendige mapper (database, logger, mediemapper)
  • Bygger CSS- og JS-pakkene

Komme i gang

Førstegangsoppsett

Ved første oppstart viser RetroDB en oppsettsveiviser som veileder deg gjennom:

  1. Administratorkonto — Opprett brukernavn og passord
  2. Biblioteksti — Angi ROM-mappen din
  3. ES-DE-integrasjon — Koble til ES-DE-spillister og medier (valgfritt)
  4. API-nøkler — Legg til API-nøkler for skrapere (valgfritt)

Når veiviseren er fullført, klikk "Scan Library" på Dashboardet for å oppdage ROM-ene dine.

Hurtigstart-arbeidsflyt

  1. Skann biblioteket ditt for å importere ROM-er
  2. Bla gjennom etter system eller vis alle spill i Bibliotek
  3. Scrap metadata individuelt eller bruk masse-scraping
  4. Organiser med tagger, lister og ønskeliste
  5. Følg med på fremgangen din med fullføringsstatus og prestasjoner

ROM-biblioteksstruktur

RetroDB forventer at ROM-ene dine er organisert i systemmapper innenfor bibliotekstien din:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Hver systemmappe bør inneholde en ES-DE systeminfo.txt-fil som definerer støttede filendelser. RetroDB leser denne under skanning for å avgjøre hvilke filer som er gyldige ROM-er for hvert system.

Tips: Hvis du allerede har scrapet med ES-DE, kan RetroDB importere disse dataene! Konfigurer ES-DE-stier i Innstillinger → ES-DE-integrasjon, eller under oppsettsveiviseren.

Plattformnotater

Linux

  • Testet på Ubuntu, Fedora, openSUSE og Arch Linux
  • ROM-verktøy krever: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) eller tilsvarende for din distro
  • Hvis du bruker systemets Python, håndterer installasjonsprogrammet --break-system-packages automatisk
  • ROCm GPU-akselerasjon støttes for AMD-GPU-er (Real-ESRGAN bildeoppskalering)

Windows

  • Last ned Python fra python.org (kryss av for "Add to PATH" under installasjonen)
  • ROM-verktøy: Installer 7-Zip, WinRAR og MAME (for chdman)
  • Bruk start.bat for å starte, eller kjør python app.py fra ledeteksten

macOS

  • Python 3 kan installeres via Homebrew: brew install python3
  • ROM-verktøy: brew install p7zip unrar rom-tools
  • Dobbeltklikk start.command i Finder for å starte
  • CoreML-akselerasjon støttes for Apple Silicon (Real-ESRGAN bildeoppskalering)

Oppsettsguide for API-nøkler

API-nøkler er valgfrie, men gir rikere metadata-scraping og tilleggsfunksjoner. Konfigurer dem i Innstillinger → Scraping → API-nøkler.

Metadata-skrapere

TheGamesDB

  1. Gå til api.thegamesdb.net/key.php
  2. Be om API-nøkler (gratis, godkjennes manuelt) — du vil motta en offentlig og en privat nøkkel
  3. Angi begge nøklene i Innstillinger → API-nøkler → TheGamesDB
  4. Den offentlige nøkkelen (grense per IP) brukes som hovednøkkel for scraping
  5. Den private nøkkelen (delt månedlig kvote) brukes som reserveløsning hvis den offentlige nøkkelen feiler

IGDB (via Twitch)

  1. Opprett en Twitch-konto på twitch.tv
  2. Gå til dev.twitch.tv/console
  3. Registrer en ny applikasjon (hvilket som helst navn, hvilken som helst kategori, http://localhost som OAuth-omdirigering)
  4. Kopier Client ID og generer en Client Secret
  5. Angi begge i Innstillinger → API-nøkler → IGDB

RAWG.io

  1. Gå til rawg.io/apidocs
  2. Klikk "Get API Key" og opprett en konto
  3. Kopier API-nøkkelen din fra dashbordet
  4. Angi den i Innstillinger → API-nøkler → RAWG

Gratisnivå: 20 000 forespørsler/måned

ScreenScraper

  1. Opprett en konto på screenscraper.fr
  2. Angi brukernavnet og passordet ditt i Innstillinger → API-nøkler → ScreenScraper

Merk: ScreenScraper har daglige forespørselsgrenser basert på kontonivået ditt. Å bidra til databasen øker grensene dine.

Prestasjoner og trofeer

RetroAchievements

  1. Opprett en konto på retroachievements.org
  2. Gå til Innstillinger → API-nøkler på profilen din
  3. Kopier API-nøkkelen din
  4. Angi brukernavnet og API-nøkkelen din i Innstillinger → Konto → RetroAchievements

Steam Web API

  1. Gå til steamcommunity.com/dev/apikey
  2. Registrer deg for en Steam Web API-nøkkel (krever en Steam-konto)
  3. Angi API-nøkkelen og Steam-ID-en din (eller vanity-URL-en) i Innstillinger

Brukes til Steam-biblioteksimport og sporing av prestasjoner.

Xbox Live

Xbox-autentisering bruker OAuth2 — ingen API-nøkkel er nødvendig. Logg inn med Microsoft-kontoen din direkte fra Spillimport → Xbox-fanen. Tokens caches automatisk og fornyes ved behov.

PlayStation Network (PSN)

PSN bruker NPSSO-informasjonskapsel-autentisering. Se Trofeer-seksjonen for detaljerte oppsettsinstruksjoner.

Innstillinger

Innstillinger er organisert i 6 faner, hver med flere underseksjoner.

Konto-fanen

  • Min profil — Last opp/fjern avatar, visningsnavn, rolleinfo, endre passord
  • RetroAchievements — Brukernavn og API-nøkkel for RA-integrasjon
  • PSN — NPSSO-informasjonskapsel for synkronisering av PlayStation Network-trofeer
  • Tidssone — Angi tidssonen din for datovisning i hele appen
  • Brukere — Brukeradministrasjon: legg til, rediger, slett brukere og tildel roller (kun admin)

Bibliotek-fanen

  • Stier — ROM-biblioteksti, databaseplassering
  • Visning — Temavalg, boksbilde-stil (2D/3D), foretrukket aldersgrense-system, elementer per side
  • ROM-navngiving — Plassering av artikkel (ledende/etterfølgende "The"), liste over regionalternativer, standardregion, navngivingskonvensjoner
  • Sikkerhetskopi — Opprett og gjenopprett databasesikkerhetskopier

Scraping-fanen

  • ES-DE — ES-DE-spilliste- og medie-stier for lokal dataimport
  • Skraper — Aktiver/deaktiver individuelle skrapere, dra-og-slipp-prioritering, hastighetsgrenseinnstillinger per skraper
  • API-nøkler — Alle skraper-legitimasjoner (TGDB, IGDB, RAWG, ScreenScraper), valg av KI-leverandør og modell (Gemini, OpenAI, Claude)

Data-fanen

  • Statistikk — Oversikt over biblioteksstatistikk (totalt antall spill, systemer, lagringsbruk)
  • Trofeer — Konfigurasjon av RPCS3-trofesti for lokal skanning av PS3-trofeer
  • Nedtrekksmenyer — Tilpass regionalternativer og andre nedtrekksverdier brukt i appen
  • Normalisering — Regler for normalisering av sjanger og spillmodus — legg til egendefinerte tilordninger for å standardisere skraperutdata

Tilpasning-fanen

  • Varsler — Innstillinger for varslingstidsavbrudd (suksess, info, advarsel, feil — hver kan konfigureres uavhengig)
  • Kontrollere — Administrer kontrollerbiblioteket, angi standardkontrollere per system, legg til egendefinerte kontrollere. Standardkontrollere overstyrer scrapede/KI-verdier under metadatahenting.
  • Logoer — Tilpasning av systemlogoer — importer systemlogoer eller last inn standardverdier på nytt

System-fanen

  • Vedlikehold — Databaseoptimalisering (VACUUM/ANALYZE), opprydding av foreldreløse medier, fjerning av manglende ROM-er, tømming av scrapede data, tømming av CLZ-import, masse-standardisering av bilder
  • Server — Serverkonfigurasjon (vert, port, feilsøkingsmodus)
  • Logging — Logg-nivåinnstillinger for ulike kategorier
  • Feilsøking — Fjern fastlåst masse-scraping, tøm RA-synkroniseringskø, tøm PSN-oppdatering, tøm museumsgenerering, start server på nytt
Tips: Deaktiverte skrapere vil ikke utløse "API offline"-varsler på Dashboardet. Hvis du ikke bruker en skraper, deaktiver den i Innstillinger → Scraping → Skraper i stedet for å slette API-nøkkelen.

Hybrid scraping

RetroDB kombinerer automatisk data fra flere kilder for å maksimere metadatadekningen:

  • Tekstmetadata fra kilden med høyest prioritet som er tilgjengelig
  • Bilder og medier fra sekundære kilder når primærkilden ikke har dem
  • Automatisk utfylling av hull på tvers av skrapere for maksimal dekning
  • Sorteringstittel genereres automatisk fra spilltittelen under scraping

Mediehåndtering

  • Mediefelt (boksbilde, 3D-boksbilde, skjermbilder, fanart, video, manual) blir aldri erstattet under normal scraping — kun fylt ut når de er tomme
  • Skjermbilder blir alltid lagt til, aldri erstattet
  • For å laste ned medier på nytt, fjern det eksisterende bildet i redigeringsmodalen først, og scrap deretter på nytt
  • Full Re-scrape-modus overstyrer dette og erstatter alt
  • Foreldede medietilkoblinger (fil slettet, men filnavnet fortsatt i databasen) tømmes automatisk før scraping slik at nye medier kan lastes ned
  • Nedlastede bilder standardiseres automatisk til målstørrelser (se Bildestandardisering)

Skraper-prioritet

Konfigurer hvilke skrapere som kjører først, og hvilke som er aktivert/deaktivert, i Innstillinger → Scraping → Skraper. Dra og slipp for å endre prioritetsrekkefølgen. Deaktiverte skrapere forsøkes ikke under scraping og utløser ikke API-statusvarsler på Dashboardet.

Hastighetsbegrensning

Hver skraper har konfigurerbare hastighetsgrenser for å unngå API-strupe. Standardforsinkelser er satt konservativt. Reduser forsinkelser på eget ansvar — å overskride API-hastighetsgrenser kan føre til midlertidig utestengelse fra den aktuelle tjenesten.

Masse-scraping

Starte en masse-scraping

  1. Gå til en hvilken som helst System- eller Bibliotek-side
  2. Klikk "Select" for å gå inn i valgmodus
  3. Velg spill individuelt eller bruk hurtigvalg:
    • Velg alle — Alle synlige spill
    • Velg ikke-scrapede — Kun spill uten metadata
  4. Velg modus: Fill Missing eller Full Re-scrape
  5. Klikk "Scrape Selected"

Kontroller

  • Pause/gjenoppta — Sett scraping på pause eller fortsett
  • Avbryt — Stopp helt
  • Bakgrunn — Minimer og fortsett å bla mens scraping kjører

Varselboble

Når den kjører i bakgrunnen, viser en vedvarende varselboble fremgang på alle sider:

  • Gjeldende spillnavn, fremdriftstelling og resultatstatistikk (vellykket, feilet, hoppet over)
  • Pause/avbryt-kontroller tilgjengelig fra hvilken som helst side
  • Klikk varselboblen for å gå tilbake til scraping-modalen

Køsystem

Flere masse-scrapinger settes automatisk i kø:

  • Start en ny scraping mens én allerede kjører — den settes i kø
  • Køen vises i varselboblen med antall ventende jobber

KI-utfylling

Hva den gjør

KI-utfylling bruker en stor språkmodell (Gemini, OpenAI eller Claude) til å fylle ut manglende eller ufullstendig spillmetadata på en intelligent måte. Den er smartere enn vanlig scraping fordi den bruker kontekstuell kunnskap om spillet til å levere nøyaktige data som skrapere kanskje ikke har.

Slik bruker du den

  1. Åpne detaljmodalen for et spill (eller hele detaljsiden)
  2. Klikk "AI Fill" (krever en KI-API-nøkkel konfigurert i Innstillinger)
  3. KI-en analyserer spilltittelen og systemet, og fyller deretter ut manglende felt
  4. Se over resultatene — endringer lagres automatisk

Hva KI-utfylling kan levere

  • Sjanger, beskrivelse, utvikler, utgiver, utgivelsesdato
  • Antall spillere, spillmodus (enkeltspiller, flerspiller, samarbeid, osv.)
  • Informasjon om kampanje og spillstruktur
  • Alle 8 aldersgrense-systemer (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Region, franchise, lignende spill
  • Kontrollerstøtte, lagringstype
  • Perspektiv (førsteperson, ovenfra-og-ned, sidescroller, osv.), dimensjon (2D, 3D)
  • Utgaveinformasjon, kritiker- og brukerscore

Smart utfyllingslogikk

  • Tomme felt fylles alltid ut
  • Eksisterende brukerdata overskrives aldri
  • Lignende spill oppdateres alltid (KI-data er mer pålitelig for dette feltet)
  • Kryssmappede aldersgrenser — Hvis ett aldersgrense-system er kjent, fylles tomme aldersgrenser i andre systemer automatisk ut ved hjelp av kryssmapping av modenhetsnivå
  • Sorteringstittel genereres automatisk når den fylles ut
  • Antall spillere-feltet normaliserer intervaller (f.eks. blir "1-4" til 4)

Sjangernormalisering

KI-utfylling bruker kanoniske sjangerformer med bindestrek-navn:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Krav

Minst én API-nøkkel for en KI-leverandør må være konfigurert i Innstillinger → Scraping → API-nøkler. Det billigste modellnivået (Gemini Flash Lite, GPT-4o Mini eller Claude Haiku) fungerer godt for metadata.

PSN-autentisering (NPSSO-informasjonskapsel)

PSN bruker en spesiell autentiseringsinformasjonskapsel kalt et NPSSO-token. Slik skaffer du det:

  1. Åpne en nettleser og logg inn på store.playstation.com
  2. Når du er logget inn, naviger til: https://ca.account.sony.com/api/v1/ssocookie
  3. Siden vil vise JSON som inneholder NPSSO-tokenet ditt
  4. Kopier npsso-verdien og lim den inn i Innstillinger → Konto → PSN

Etter autentisering bufrer RetroDB tilgangstokenene sikkert i sin egen database (per bruker) og fornyer dem automatisk — du trenger ikke lime inn NPSSO igjen ved hver synkronisering. Økten forblir gyldig i omtrent to måneder, og RetroDB fornyer den nå også automatisk i bakgrunnen, så i normal bruk bør du sjelden trenge en ny NPSSO.

Kjør et HowLongToBeat-oppslag for hvert spill som mangler et spilletidsestimat. Hvert treff scores etter tittel + plattform + utgivelsesår; treff med høy tillit lagres automatisk. Alt under tillitsterskelen (eller med motstridende plattformer) parkeres for manuell gjennomgang.

Ingen eksterne avhengigheter (bruker det medfølgende frakoblede HLTB-datasettet)

HLTB ventende gjennomgang

Gjennomgangskø for tvetydige treff funnet av Masse-HLTB-oppslag. Hver ventende rad viser kildespillet sammen med HLTB-kandidaten (tittel, plattform, utgivelsesår, tillit). Godkjenn, avvis, eller velg et annet treff per rad. Gjennomgangsverktøykortet vises kun i ROM-verktøy-navet når det finnes minst ett ventende treff.

  • Filterfaner for lav tillit, alternativ tittel og plattform-mismatch-treff.
  • Approve skriver spilletidsestimatet; Reject fjerner kandidaten og holder oppslagskøen ren.

Normalisering

Hva den gjør

Normaliserer sjanger- og spillmodus-verdier til konsekvente kanoniske former. Dette skjer automatisk under scraping og KI-utfylling, og kan også brukes manuelt på det eksisterende biblioteket ditt.

Hvorfor det er viktig

Ulike skrapere bruker ulike navn for samme ting. Normalisering sikrer konsistens gjennom hele biblioteket ditt:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Bildestandardisering

Hva den gjør

Standardiserer alle spillmedier til konsekvente målstørrelser for et enhetlig utseende gjennom hele biblioteket ditt. Bilder innenfor 80–120% av målstørrelsen hoppes over.

Slik fungerer det

  • Oppskalering — Bilder mindre enn målstørrelsen skaleres opp med Real-ESRGAN x4 (KI-superoppløsning via ONNX Runtime) for høykvalitets forstørrelse, og endres deretter til nøyaktig målstørrelse
  • Nedskalering — Bilder større enn målstørrelsen skaleres ned med Lanczos-filtrering for skarpe resultater
  • Terskelbånd — Bilder innenfor 80–120% av målet la stå urørt for å unngå unødvendig ny behandling

Vanlige problemer

"No extensions found for system"

Systemmappen trenger en gyldig ES-DE systeminfo.txt-fil som definerer støttede ROM-filendelser. Sørg for at ROM-mappestrukturen din samsvarer med ES-DE-standarder.

"API Connection Failed"

  • Sjekk internettforbindelsen din
  • Verifiser API-nøkler i Innstillinger → Scraping → API-nøkler
  • Vent hvis hastighetsbegrenset (noen API-er har daglige/timevise grenser)
  • Sjekk om skraperen er aktivert (deaktiverte skrapere viser "Disabled" i Dashboard-status)
  • Sjekk Loggvisning for detaljerte feilmeldinger

"Bulk Scrape Stuck"

Gå til Innstillinger → System → Feilsøking → "Clear Stuck Bulk Scrape". Dette tilbakestiller jobbtilstanden uten å påvirke dataene dine.

"RA Sync Queue Stuck"

Tøm RetroAchievements-synkroniseringskøen fra Innstillinger → System → Feilsøking.

"PSN Sync Stuck"

Tøm PSN-oppdateringsjobben fra Innstillinger → System → Feilsøking.

"Museum Generation Stuck"

Tøm museumsgenereringsjobben fra Innstillinger → System → Feilsøking.

"Database Errors"

  1. Opprett en sikkerhetskopi hvis mulig (Innstillinger → Bibliotek → Sikkerhetskopi)
  2. Prøv Innstillinger → System → Vedlikehold → Optimaliser database
  3. Sjekk filtillatelser på database/-mappen
  4. Siste utvei: gjenopprett fra en sikkerhetskopi eller slett databasen og skann på nytt

"Images Not Saving"

Sjekk skrivetillatelser på mediemappene: chmod -R 755 static/images/

"Page Slow or Unresponsive"

  • Store samlinger kan ta tid å laste — uendelig rulling laster i puljer på 100
  • Prøv å oppdatere siden for å tømme akkumulert minne
  • Sjekk nettleserkonsollen for JavaScript-feil
  • Prøv å bytte til et tema med en lettere lerret-effekt (f.eks. Amber eller Elite)
  • Lerret-effekter oppdager maskinvare automatisk; svakere enheter bruker CPU-reserveløsning med redusert bildefrekvens

"Interrupted Jobs"-banner på Dashboard

Hvis RetroDB starter på nytt mens jobber kjører, vises de i et gjenopprettingsbanner. Klikk "Resume" individuelt eller "Resume All" for å starte dem på nytt. Klikk "Dismiss" eller "Dismiss All" for å fjerne dem.

"PSN Authentication Failed"

  • NPSSO-tokens utløper — generer et nytt fra ca.account.sony.com/api/v1/ssocookie
  • Sørg for at du er logget inn på store.playstation.com før du besøker informasjonskapsel-URL-en
  • RetroDB bufrer PSN-økten din i omtrent to måneder og fornyer den nå også automatisk i bakgrunnen; hvis den likevel utløper, bare lim inn en fersk NPSSO i Innstillinger → Konto → PSN

"Xbox Authentication Failed"

  • Autentiser på nytt ved å klikke "Sign In" på Spillimport → Xbox-fanen
  • Xbox-tokens caches i data/xbox_tokens.json og fornyes automatisk

"Image Upscaling Errors"

  • Real-ESRGAN ONNX-modellen lastes ned ved første bruk — sørg for internettilgang
  • GPU-akselerasjon krever kompatible drivere (CUDA for NVIDIA, ROCm for AMD)
  • Hvis GPU-en feiler, faller systemet automatisk tilbake til CPU-behandling

Ytelsestips

  • Hold nettleseren din oppdatert for best ytelse
  • Lukk andre nettleserfaner når du arbeider med svært store samlinger
  • Bruk systemfiltre for å redusere antall viste spill av gangen
  • Kjør Optimaliser database jevnlig etter store operasjoner (scraping, opprydding, import)
  • Lerret-temaeffekter oppdager maskinvare automatisk; svakere enheter bruker CPU-reserveløsning

Sikkerhet og ansvarsfraskrivelse

Beste praksis for sikkerhet

  • Endre standardpassordet — Standard admin-passord (admin) bør endres umiddelbart ved første innlogging. Bruk et sterkt passord på minst 8 tegn.
  • Bruk en HTTPS-omvendt proxy — RetroDB tilbyr ikke TLS/SSL på egen hånd. Plasser det bak en omvendt proxy (f.eks. Nginx, Caddy, Traefik) med HTTPS aktivert for å kryptere trafikken mellom klienter og serveren.
  • Begrens nettverkstilgang — Unngå å eksponere RetroDB direkte mot det åpne internett. Bruk en VPN eller begrens tilgangen til det lokale nettverket ditt. Hvis fjerntilgang er nødvendig, bruk en omvendt proxy med autentisering.
  • Ta regelmessige sikkerhetskopier — Bruk den innebygde sikkerhetskopifunksjonen under Innstillinger for å opprette periodiske databasesikkerhetskopier. Lagre sikkerhetskopier på et annet sted enn applikasjonen.
  • Hold RetroDB oppdatert — Se etter nye utgivelser jevnlig. Sikkerhetsfikser og forbedringer er inkludert i oppdateringer.
  • Beskytt API-nøklene dine — API-nøkler lagres i data/scraper_settings.json. Sørg for at denne filen ikke er offentlig tilgjengelig. Del aldri config.py-filen din eller token-filer.

Innebygde sikkerhetsfunksjoner

  • Passord-hashing — Admin-passord hashes med PBKDF2 (aldri lagret i klartekst)
  • Hastighetsbegrensning ved innlogging — Beskyttelse mot brute force-angrep på innloggingsendepunktet
  • Stivalidering — Alle filoperasjoner bruker hjelpefunksjonene safe_path og safe_filename for å forhindre katalogtraversering-angrep
  • Parameteriserte spørringer — Alle databasespørringer bruker parameteriserte setninger for å forhindre SQL-injeksjon
  • XSS-beskyttelse — Modale dialoger bruker trygg DOM-konstruksjon; brukerinndata escapes
