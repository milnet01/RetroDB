Встановлення

Системні вимоги

  • Python 3.12+ з pip
  • Веб-браузер (Chrome, Firefox, Safari, Edge)
  • Операційна система: Linux, Windows 10/11 або macOS

Швидке встановлення

  1. Розпакуйте ZIP-архів RetroDB у папку на свій вибір
  2. Відкрийте термінал/командний рядок у цій папці
  3. Запустіть: python install.py
  4. Запустіть сервер:
    • Linux: ./start.sh
    • Windows: подвійний клік на start.bat
    • macOS: подвійний клік на start.command
  5. Відкрийте http://localhost:5000 у браузері

Графічний інсталятор

У Linux можна також запустити ./setup.sh, щоб відкрити майстер графічного встановлення. Він автоматично перевіряє наявність Python/pip/tkinter, а потім проведе вас через усі кроки налаштування з візуальним журналом прогресу.

Що робить install.py

  • Перевіряє наявність Python 3.12+ і pip
  • Встановлює залежності Python з requirements.txt
  • Створює config.py з файлу-прикладу
  • Створює необхідні папки (базу даних, журнали, папки медіа)
  • Збирає пакети CSS і JS

Початок роботи

Первинне налаштування

Під час першого запуску RetroDB показує Майстер налаштування, який проведе вас через:

  1. Обліковий запис адміністратора — Створіть ім'я користувача та пароль
  2. Шлях до бібліотеки — Вкажіть папку з ROM
  3. Інтеграція з ES-DE — За бажанням прив'яжіть списки ігор та медіа ES-DE
  4. Ключі API — За бажанням додайте ключі API скраперів

Після завершення роботи майстра натисніть "Сканувати бібліотеку" на панелі приладів, щоб знайти ваші ROM.

Швидкий початок роботи

  1. Скануйте бібліотеку, щоб імпортувати ROM
  2. Переглядайте ігри за системою або всі ігри в бібліотеці
  3. Скрапте метадані окремо або скористайтеся масовим скрапінгом
  4. Організовуйте ігри за допомогою тегів, списків і списку бажань
  5. Відстежуйте прогрес за допомогою статусу проходження та досягнень

Структура бібліотеки ROM

RetroDB очікує, що ваші ROM організовані у папках систем усередині шляху до бібліотеки:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA) (Disc 1).chd
    Final Fantasy VII (USA) (Disc 2).chd

Тримайте файли ROM безпосередньо в папці системи. Файли у вкладених папках пропускаються, окрім PS3.

Кожна папка системи повинна містити файл ES-DE systeminfo.txt, який визначає підтримувані розширення файлів. RetroDB читає цей файл під час сканування, щоб визначити, які файли є коректними ROM для кожної системи.

Порада: Якщо ви вже скрапили дані за допомогою ES-DE, RetroDB може імпортувати ці дані! Налаштуйте шляхи ES-DE в Налаштування → Інтеграція з ES-DE, або під час роботи майстра налаштування.

Примітки щодо платформ

Linux

  • Протестовано на Ubuntu, Fedora, openSUSE та Arch Linux
  • Інструменти ROM потребують: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) або еквівалент для вашого дистрибутива
  • Якщо використовується системний Python, інсталятор автоматично обробляє --break-system-packages
  • Підтримується прискорення ROCm GPU для відеокарт AMD (масштабування зображень Real-ESRGAN)

Windows

  • Завантажте Python з python.org (позначте "Add to PATH" під час встановлення)
  • Інструменти ROM: встановіть 7-Zip, WinRAR та MAME (для chdman)
  • Використовуйте start.bat для запуску або виконайте python app.py з командного рядка

macOS

  • Python 3 можна встановити через Homebrew: brew install python3
  • Інструменти ROM: brew install p7zip unrar rom-tools
  • Подвійний клік на start.command у Finder для запуску
  • Підтримується прискорення CoreML для Apple Silicon (масштабування зображень Real-ESRGAN)

Навігація

Пошук будь-де

Поле пошуку під вашим ім'ям на бічній панелі є на кожній сторінці. Введіть дві або більше літер, щоб побачити відповідні консолі й до восьми відповідних ігор. Натискайте ↓ і ↑, щоб переходити між ними, Enter, щоб відкрити одну, і Esc, щоб закрити список. Переглянути всі результати або Enter, коли нічого не вибрано, відкриває Бібліотеку з цим пошуком.

Теми

RetroDB пропонує 7 візуальних тем, кожна з унікальною кольоровою палітрою та анімованим фоновим ефектом на полотні (canvas). Змінюйте теми в Налаштування → Бібліотека → Відображення. Фон зупиняється, коли ви не користуєтеся RetroDB: коли його вікно не на передньому плані або після хвилини без руху миші чи натискання клавіш. Щоб залишити його нерухомим на цьому комп’ютері, вимкніть Рухомий фон під темами.

Як це працює

  • Теми перевизначають CSS-змінні кольорів — усі елементи інтерфейсу адаптуються автоматично
  • Ефекти полотна включають автоматичне визначення рівня обладнання (високий/середній/низький) з апаратним прискоренням GPU за наявності та резервним варіантом на CPU для менш потужних пристроїв
  • Ефекти призупиняються, коли вкладка не видима, для економії ресурсів
  • Стан диму Cyberpunk зберігається під час переходів між сторінками для безшовних переходів
  • Тонке накладення сканліній у стилі CRT адаптується до кольорової палітри кожної теми
  • Ваша тема зберігається у вашому обліковому записі, тож вона доступна в будь-якому браузері, у якому ви входите

Значки, чутливі до теми

Значки сповіщень, індикатори стану завдань і значки дій автоматично адаптуються до поточної теми. Наприклад, значок успіху може показувати зелену галочку в Cyberpunk, але інший символ у Matrix, щоб відповідати естетиці "зелене на чорному".

Панель приладів

Оцінка стану колекції

Кругова шкала прогресу показує загальний стан вашої колекції у відсотках, з кольоровим кодуванням за якістю:

  • Зелений (80%+) — Відмінне покриття метаданих
  • Блакитний (60–79%) — Гарне покриття з деякими прогалинами
  • Помаранчевий (40–59%) — Помірне покриття, варто розглянути масовий скрапінг
  • Червоний (<40%) — Значні прогалини в метаданих

Нижче міні-шкали розбивки показують повноту обкладинок, повноту описів і покриття досягнень.

Огляд статистики

Картки з швидким переглядом, що показують:

  • Усього систем — Кількість платформ у вашій бібліотеці
  • Усього ігор — Загальна кількість ігор (без урахування бонусних дисків)
  • Відсутні метадані — Ігри, які ще не скраплено
  • Завершено — Ігри зі скрапленими метаданими

Розділи останньої активності

Прокручувані розділи, що показують вашу останню активність (кожен з'являється лише за наявності відповідних ігор):

  • Продовжити гру — Ігри, позначені як "В процесі"
  • Нещодавно додані — Останні ігри, додані до бібліотеки
  • Нещодавно переглянуті — Ігри, які ви нещодавно відкривали
  • Нещодавно скраплені — Ігри з нещодавно отриманими метаданими

Швидкі дії

  • Сканувати бібліотеку — Сканувати папки ROM на наявність нових ігор
  • Випадкова гра — Обрати випадкову гру з вашої бібліотеки

Статус API

Показує статус з'єднання всіх налаштованих скраперів та API. Коли налаштований API офлайн, з'являється банер попередження з посиланням на Налаштування.

Відновлення завдань

Якщо RetroDB перезапускається під час виконання фонових завдань (масовий скрапінг, синхронізація RA, зміна розміру зображень тощо), перервані завдання з'являються в банері відновлення. Варіанти:

  • Відновити — Перезапустити окреме перерване завдання
  • Відновити все — Перезапустити всі перервані завдання
  • Відхилити — Прибрати окреме завдання зі списку відновлення
  • Відхилити все — Прибрати всі перервані завдання

Огляд систем

Сітка систем

Сторінка "Системи" показує всі платформи у вашій бібліотеці у вигляді карток в адаптивній сітці масонрі. Кожна картка показує:

  • Логотип системи (налаштовується в Налаштування → Персоналізація → Логотипи)
  • Кількість ROM та кількість нескраплених
  • Значок типу системи — Консоль, Портативна, Комп'ютер, Аркада або Рушій
  • Значки можливостей — Підтримка RetroAchievements, Локальні трофеї (RPCS3)

Модальне вікно характеристик системи

Натисніть кнопку інформації на будь-якій картці системи, щоб переглянути детальні апаратні характеристики:

  • Зображення обладнання (фото консолі/системи)
  • Виробник і дата випуску
  • CPU, GPU, RAM, VRAM
  • Роздільна здатність, глибина кольору, звуковий чип
  • Тип носія (картридж, диск тощо)

Фільтрація та пошук

  • Текстовий пошук — Фільтрація за назвою системи або назвою папки
  • Фільтр за типом — Консоль, Портативна, Комп'ютер, Аркада, Рушій
  • Фільтр за можливостями — Підтримка RetroAchievements, Локальні трофеї
  • Панель результатів фільтрації показує "X із Y систем"
  • Фільтри зберігаються між перезавантаженнями сторінки через сховище сеансу

Список ігор за системою

Натисніть на будь-яку картку системи, щоб переглянути її ігри. Список ігор за системою має ті самі можливості, що й повна сторінка бібліотеки — нескінченне прокручування, пошук, усі опції фільтрації, масовий вибір і сортування. Заголовок системи показує назву системи, кількість ігор і значок типу системи.

Посібник з налаштування ключів API

Ключі API необов'язкові, але дозволяють отримати розширені метадані та додаткові можливості. Налаштуйте їх в Налаштування → Скрапінг → Ключі API.

Скрапери метаданих

TheGamesDB

  1. Перейдіть на api.thegamesdb.net/key.php
  2. Запросіть ключі API (безкоштовно, схвалюється вручну) — ви отримаєте Public та Private ключ
  3. У розділі Налаштування → Скрапінг → Ключі API впишіть публічний ключ у поле TheGamesDB — основний ключ, а приватний — у поле TheGamesDB — резервний ключ
  4. Основний ключ використовується першим; кожне інтернет-з'єднання має свій ліміт запитів
  5. Резервний ключ використовується, коли основний вичерпано; він дозволяє приблизно 6000 запитів на місяць

IGDB (через Twitch)

  1. Створіть обліковий запис Twitch на twitch.tv
  2. Перейдіть на dev.twitch.tv/console
  3. Зареєструйте нову програму (будь-яка назва, будь-яка категорія, http://localhost як OAuth-редирект)
  4. Скопіюйте Client ID і згенеруйте Client Secret
  5. Введіть обидва в Налаштування → Ключі API → IGDB

RAWG.io

  1. Перейдіть на rawg.io/apidocs
  2. Натисніть "Get API Key" і створіть обліковий запис
  3. Скопіюйте свій ключ API з панелі керування
  4. Введіть його в Налаштування → Ключі API → RAWG

Безкоштовний рівень: 20 000 запитів/місяць

ScreenScraper

  1. Створіть обліковий запис на screenscraper.fr
  2. Введіть своє ім'я користувача та пароль у Налаштування → Ключі API → ScreenScraper

Примітка: ScreenScraper має денні ліміти запитів залежно від рівня вашого облікового запису. Внесок у базу даних збільшує ваші ліміти.

Досягнення та трофеї

RetroAchievements

  1. Створіть обліковий запис на retroachievements.org
  2. Перейдіть на Налаштування → Ключі API у вашому профілі
  3. Скопіюйте свій ключ API
  4. Введіть ім'я користувача та ключ API в Налаштування → Обліковий запис → RetroAchievements

Steam Web API

  1. Перейдіть на steamcommunity.com/dev/apikey
  2. Зареєструйте ключ Steam Web API (потрібен обліковий запис Steam)
  3. Введіть ключ API та Steam ID (або vanity URL) у Налаштуваннях

Використовується для імпорту бібліотеки Steam та відстеження досягнень.

Xbox Live

Xbox підключається до RetroDB через OpenXBL — безкоштовний сервіс. Кожен використовує власний ключ: увійдіть на xbl.io зі своїм обліковим записом Xbox, скопіюйте ключ API і вставте його в Налаштування → Обліковий запис → Мій профіль → Xbox. Зберегти мій профіль перевіряє ключ і показує ваш gamertag. Безкоштовний ключ дозволяє 150 запитів на годину.

PlayStation Network (PSN)

PSN використовує автентифікацію через кукі NPSSO. Дивіться розділ Трофеї для детальних інструкцій з налаштування.

Для заповнення метаданих ШІ та генерації контенту Музею потрібен один постачальник ШІ. Оберіть з-поміж:

Налаштування

Налаштування організовані у вкладки, кожна з підрозділами. Адміністратори також бачать вкладку «Емулятори», яка відкривається на окремій сторінці.

Кожен бачить лише ті налаштування, які може змінювати його роль. Глядач або гравець бачить вкладку «Обліковий запис». Редактор також бачить «Бонусні диски» та «Контролери». Усе інше — для адміністраторів.

Вкладка "Обліковий запис"

  • Мій профіль — Ваш аватар, ваша тека трофеїв RPCS3 і ваші власні облікові записи RetroAchievements, PlayStation Network, Xbox та Steam. Ім'я користувача й веб-ключ API RetroAchievements показують ваші досягнення; вхід за паролем відкриває досягнення під час гри. Одна кнопка Зберегти мій профіль зберігає всю картку й перевіряє новий токен PlayStation або ключ Xbox. Змінити пароль просить ввести новий пароль двічі; потрібно щонайменше 12 символів.
  • Тема й мова — Ваша тема, ваша мова та рухомий фон
  • Сповіщення — Як довго кожен вид повідомлень залишається на екрані, лише для вас
  • Часовий пояс — Встановіть часовий пояс для відображення дат у застосунку
  • Користувачі — Керування користувачами: додавання, редагування, видалення користувачів і призначення ролей (лише для адміністратора)

Вкладка "Бібліотека"

  • Шляхи — Тека бібліотеки ROM, теки списків ігор і медіа ES-DE та спільна тека трофеїв RPCS3, під однією кнопкою «Зберегти»
  • Відображення — Стиль обкладинки (2D/3D) і бажана система вікових рейтингів, для всіх
  • Іменування ROM — Розташування артикля (провідний/кінцевий "The"), список опцій регіонів, регіон за замовчуванням, конвенції іменування
  • Бонусні диски — Пошук бонусних дисків і прив'язування їх до ігор
  • Резервне копіювання — Створення та відновлення резервних копій бази даних

Вкладка "Скрапінг"

  • Скрапер — Вмикайте або вимикайте скрапери й перетягуйте їх у порядку, у якому їх пробують. Фільтр збігів для масового скрапінгу визначає, наскільки точним має бути результат: Суворо бере лише точні назви, Звичайно (за замовчуванням) — близьку назву для потрібної системи, а Вільно — ще й часткові назви. Налаштування, зроблене в попередній версії, показується як Власне, доки ви не виберете інше.
  • Ключі API — Усі облікові дані скраперів (TheGamesDB, IGDB, RAWG, ScreenScraper), вибір постачальника ШІ та моделі (Gemini, OpenAI, Claude), а також спільні ключі RetroAchievements і Steam. Власний ключ RetroAchievements із розділу «Мій профіль» використовується першим, а спільний — лише для тих, у кого його немає. Спільний ключ Steam обслуговує лише адміністратора без власного ключа.

Вкладка "Дані"

  • Випадні списки — Налаштуйте значення, які пропонуються у списках, як-от жанр, ракурс і тип збереження
  • Нормалізація — Правила нормалізації жанрів і режимів — додавайте власні відповідності для стандартизації результатів скраперів

Вкладка "Персоналізація"

  • Контролери — Відкрити контролери веде на сторінку контролерів. Там ви задаєте контролери за замовчуванням для кожної системи, додаєте власні та редагуєте бібліотеку контролерів. Контролери за замовчуванням перевизначають скраплені/ШІ-значення під час отримання метаданих.
  • Логотипи — Оновити логотипи систем копіює нові логотипи з вашої теки ES-DE, а потім показує, у яких систем логотипів досі немає

Вкладка "Система"

  • Обслуговування — Очищення відсутніх ROM, очищення імпортів CLZ або скраплених даних, видалення медіафайлів, які не використовує жодна гра, очищення посилань на медіафайли, яких більше немає, оптимізація бази даних і обчислення розмірів файлів
  • Оновлення — Перевірка, завантаження та встановлення нової версії
  • Сервер — Перезапуск або вимкнення RetroDB, порт, який він використовує (адреса змінюється після перезапуску), і місце, де лежить його база даних
  • Журналювання — Налаштування рівня журналювання для різних категорій і файли журналів

Емулятори та гра

Адміністратори налаштовують емулятори в розділі Налаштування → Емулятори. Додайте теку, де лежать ваші емулятори, до Теки емуляторів. RetroDB знаходить там кожен емулятор (AppImage, портативний скрипт або встановлений Flatpak) і пов'язує його із системами, які він запускає. У таблиці зіставлення для кожної системи видно, чи працює її емулятор і чи на місці файли BIOS. RetroDB лише читає файли BIOS; він ніколи їх не копіює й не завантажує.

Ігри, емулятор яких працює, отримують кнопку Грати на сторінці гри, на картках бібліотеки та на сторінках систем.

Ще немає емулятора? Натисніть Отримати RetroArch у розділі Грати в RetroDB на тій самій сторінці. RetroDB завантажує офіційний RetroArch від libretro, перевіряє завантаження і встановлює його як RetroArch (RetroDB), з власними налаштуваннями та збереженнями, окремо від будь-якого RetroArch, яким ви вже користуєтеся. Потім він завантажує найкраще ядро для кожної системи, коли ви граєте вперше. Для гри на кількох дисках Наступний диск працює без жодного налаштування. Поки така гра запущена, а у Windows і macOS — поки запущена будь-яка гра, RetroArch слухає команди RetroDB на мережевому порту.

Для DuckStation, PCSX2 і RPCS3 RetroDB також задає для кожної гри масштаб роздільної здатності та співвідношення сторін у власному файлі налаштувань емулятора для цієї гри, а також те, чи гра запускається на весь екран. Змінюйте значення для цілої системи кнопкою Налаштування в таблиці зіставлення, а для однієї гри — на панелі Налаштування емулятора на її сторінці. Вони записуються, коли ви натискаєте «Грати». Налаштування, яке ви змінили в самому емуляторі, завжди має пріоритет: відтоді RetroDB його не чіпає. Запустіть кожен емулятор один раз перед грою, щоб він створив свою теку налаштувань.

Чити

У розділі Чити на тій самій сторінці натисніть Завантажити, щоб отримати безкоштовні загальнодоступні пакети читів, або імпортуйте теку з читами, яка у вас уже є. RetroDB копіює файли й ніколи не змінює вашу теку; імпортуйте ще раз, щоб додати нові файли. Тоді сторінка гри показує панель Чити для ігор, у які ви граєте в RetroArch (RetroDB), DuckStation чи PCSX2, із перемикачем «увімк./вимк.» для кожного чита. У RetroArch (RetroDB) чити, які ви ввімкнули, застосуються, коли ви наступного разу натиснете «Грати», а перемикач, який ви змінили у власному меню RetroArch під час гри, зберігається. Для DuckStation і PCSX2 перемикачі зберігаються просто в налаштуваннях емулятора для цієї гри, тож зміну, зроблену в самому емуляторі, теж видно на панелі. RetroDB ніколи не перезаписує файл читів, який емулятор уже має. Увімкнений чит призупиняє режим хардкор RetroAchievements; DuckStation і PCSX2 ігнорують чити в режимі хардкор.

Для аркадних ігор у MAME завантажте у браузері «MAME XML Cheats Collection» з mamecheat.co.uk, а потім імпортуйте теку, у якій вона лежить. RetroDB зберігає її запакованою, як просить її readme, і один раз читає з неї назви читів кожної гри, для чого завантажує з інтернету інструмент 7-Zip. Тоді сторінка гри показує чити цієї гри, з перемикачем біля кожного простого чита «увімк/вимк», а MAME запускається з увімкненими читами. Чит, що приймає значення або спрацьовує один раз, перемикача не має: задайте його під час гри, натиснувши Tab, потім Plugin Options, потім Cheat. Перемикачі, які ви змінили там, з'являться на сторінці гри після виходу з MAME. Імпорт новішої збірки замінює стару.

Гібридний скрапінг

RetroDB автоматично поєднує дані з кількох джерел для максимального покриття метаданих:

  • Текстові метадані з джерела з найвищим пріоритетом
  • Зображення та медіа з другорядних джерел, якщо основне джерело їх не має
  • Автоматичне заповнення прогалин серед скраперів для максимального покриття
  • Назва для сортування генерується автоматично з назви гри під час скрапінгу
  • Джерело шукають лише тоді, коли воно має систему гри, і лише в цій системі: у RAWG немає Intellivision, тому ігри Intellivision не шукають у RAWG, де вони збігалися б лише з іграми з інших платформ
  • Коли ШІ увімкнено, він також дає офіційну назву гри, під якою її випустили в регіоні її ROM, і гру перейменовують на неї — і під час скрапінгу однієї гри, і під час масового скрапінгу (дивіться Заповнення ШІ)

Робота з медіа

  • Поля медіа (обкладинка, 3D-обкладинка, задня сторона коробки, скріншоти, fanart, логотип, відео, посібник) ніколи не замінюються під час звичайного скрапінгу — заповнюються лише коли порожні
  • Скріншоти завжди додаються, ніколи не замінюються
  • Щоб повторно завантажити медіа, спочатку очистіть наявне зображення в модальному вікні редагування, а потім скрапте повторно
  • Режим Повторний повний скрапінг перевизначає це і замінює все
  • Застарілі посилання на медіа (файл видалено, але назва файлу все ще в базі даних) автоматично очищуються перед скрапінгом, щоб можна було завантажити нові медіа
  • Завантажені зображення автоматично стандартизуються до цільових розмірів (дивіться Стандартизація зображень)

Збереження назви

Коли ви вводите нову назву у вікні редагування й зберігаєте, скрапінг більше її не змінює, включно з повторним повним скрапінгом. Прапорець Зберігати цю назву під час скрапінгу у вікні редагування показує, чи назву збережено; зніміть його, щоб скрапери знову могли перейменувати гру. Скинути на сторінці гри також дозволяє скраперам перейменувати її, а Очистити скраплені дані в Обслуговуванні залишає збережені назви без змін.

Пріоритет скраперів

Налаштуйте, які скрапери запускаються першими та які увімкнено/вимкнено, в Налаштування → Скрапінг → Скрапер. Перетягніть, щоб змінити порядок пріоритету. Вимкнені скрапери не будуть використовуватися під час скрапінгу та не викликатимуть попереджень про статус API на панелі приладів.

Обмеження швидкості

RetroDB сам розподіляє свої запити до кожної служби в часі; налаштовувати нічого не потрібно. Коли служба повідомляє, що її ліміт вичерпано, RetroDB перестає звертатися до неї до часу, який вказала служба, і повідомляє про це (див. Усунення несправностей).

Масовий скрапінг

Початок масового скрапінгу

  1. Перейдіть на будь-яку сторінку системи або бібліотеки
  2. Натисніть "Вибрати", щоб увійти в режим вибору. Інструменти вибору з'являються на панелі внизу вікна.
  3. Виберіть ігри окремо або скористайтеся швидким вибором:
    • Вибрати все — Усі видимі ігри
    • Вибрати нескраплені — Лише ігри без метаданих
  4. Оберіть режим: Заповнити відсутнє або Повторний повний скрапінг
  5. Натисніть "Скрапити вибрані"
  6. Натисніть "Готово", щоб вийти з режиму вибору

Керування

  • Пауза / Продовжити — Призупинити або продовжити скрапінг
  • Скасувати — Зупинити повністю
  • У фоні — Згорнути та продовжити перегляд, поки триває скрапінг

Спливаюче сповіщення

Під час роботи у фоні постійне спливаюче сповіщення показує прогрес на всіх сторінках:

  • Назва поточної гри, кількість прогресу та статистика результатів (успіх, помилка, пропущено)
  • Керування паузою/скасуванням доступне з будь-якої сторінки
  • Натисніть на сповіщення, щоб повернутися до вікна скрапінгу

Система черги

Декілька масових скрапінгів автоматично стають у чергу:

  • Почніть новий скрапінг, поки виконується інший — він стає в чергу
  • Черга показується у сповіщенні з кількістю завдань, що очікують
  • Завдання обробляються автоматично по черзі
  • Використовуйте менеджер черги для перегляду, зміни порядку або скасування завдань у черзі

Опції скрапінгу

  • Заповнити лише відсутнє — Заповнювати лише порожні поля метаданих, зберігаючи наявні дані
  • Повторний повний скрапінг — Замінити всі поля, включно з медіа (завантажує нові зображення та відео)
  • Зберегти наявні медіафайли — Разом із повним повторним скрапінгом залишати арт, відео та посібники, які вже є на диску, замість того щоб завантажувати їх знову. Нові знімки екрана все одно додаються.
  • Перевіряти RetroAchievements — Також перевіряти наявність наборів досягнень RetroAchievements під час скрапінгу

Відновлення завдань

Якщо RetroDB перезапускається під час виконання завдання, перервані завдання з'являються в банері відновлення на панелі приладів. Натисніть "Resume" для окремих завдань або "Resume All", щоб перезапустити їх усі. Спливаюче сповіщення про прогрес з'являється одразу після відновлення.

Заповнення ШІ

Що це робить

Заповнення ШІ використовує велику мовну модель (Gemini, OpenAI або Claude), щоб інтелектуально заповнити відсутні або неповні метадані гри. Це розумніше за звичайний скрапінг, оскільки використовує контекстні знання про гру для надання точних даних, яких можуть не мати скрапери.

Як використовувати

  1. Відкрийте модальне вікно деталей гри (або повну сторінку деталей)
  2. Натисніть "AI Fill" (потребує налаштованого ключа API ШІ в Налаштуваннях)
  3. ШІ аналізує назву гри та систему, а потім заповнює відсутні поля
  4. Перегляньте результати — зміни зберігаються автоматично

Багато ігор одразу

Щоб заповнити цілу систему, відкрийте Інструменти ROM → Масове заповнення ШІ і скористайтеся карткою Заповнити порожні поля з ШІ. Увімкніть поля, які потрібно заповнити; враховуються лише ігри, у яких хоча б одне з них порожнє, а чим менше полів, тим дешевше. Виберіть систему або «Усі системи» і натисніть Заповнити з ШІ. Заповнення ШІ запускається для кожної гри, і відповіді одразу зберігаються в грі. Індикатор виконання на картці та сповіщення Заповнення ШІ показують, як далеко просунулася робота, а поки вона триває, сторінку можна залишити. Ігри, які вже пройшли заповнення ШІ, пропускаються, тож повторний запуск обробить лише решту; увімкніть параметр Включити ігри, уже оброблені Заповненням ШІ, щоб заповнити поле й у них, наприклад «Продано копій». Запуск сам зупиняється, якщо ШІ перестає відповідати, наприклад коли ключ відхилено або на рахунку немає коштів. Ваш постачальник ШІ бере плату за кожну гру.

Що може надати заповнення ШІ

  • Жанр, опис, розробника, видавця, дату випуску
  • Кількість гравців, режими гри (одиночна гра, багатокористувацька, кооператив тощо)
  • Інформацію про кампанію та структуру гри
  • Усі системи вікових рейтингів (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd, CADPA)
  • Регіон, франшизу, схожі ігри
  • Підтримку контролерів, тип збереження
  • Перспективу (від першої особи, вигляд зверху, платформер з горизонтальним прокручуванням тощо), вимірність (2D, 3D)
  • Інформацію про видання, оцінки критиків і користувачів

Логіка розумного заповнення

  • Порожні поля заповнюються завжди
  • Наявні дані користувача ніколи не перезаписуються
  • Схожі ігри завжди оновлюються (дані ШІ надійніші для цього поля)
  • Перехресно зіставлені рейтинги — Якщо відома одна система рейтингів, порожні рейтинги в інших системах автоматично заповнюються за допомогою перехресного зіставлення рівнів зрілості
  • Назва для сортування генерується автоматично при заповненні
  • Офіційна назва — ШІ також називає офіційну назву гри, під якою її випустили в регіоні її ROM, і гру перейменовують на неї — під час Заповнення ШІ та щоразу, коли ШІ заповнює прогалини під час скрапінгу. Стара назва зберігається як альтернативна. Назву, яку ви ввели самі або зберегли за допомогою Зберігати цю назву під час скрапінгу, ніколи не перейменовують
  • Поле Кількість гравців нормалізує діапазони (наприклад, "1-4" стає 4)

Нормалізація жанрів

Заповнення ШІ використовує канонічні форми жанрів із назвами через дефіс:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Вимоги

Потрібно налаштувати принаймні один ключ API постачальника ШІ в Налаштування → Скрапінг → Ключі API. Найдешевший рівень моделі (Gemini Flash Lite, GPT-4o Mini або Claude Haiku) добре працює для метаданих.

Фільтрація та пошук

Пошук

Пошук фільтрує ігри за назвою (та назвою для сортування). Натисніть /, щоб перевести фокус на поле пошуку. Результати оновлюються в реальному часі з затримкою 300 мс.

Фільтр за джерелом

Фільтруйте ігри за джерелом імпорту:

  • Файли ROM — Ігри з вашої бібліотеки ROM
  • Імпорти CLZ — Фізичні ігри, імпортовані з CLZ
  • Імпорти Steam — Ігри, імпортовані зі Steam
  • Імпорти Xbox — Ігри, імпортовані з Xbox
  • Імпорти PSN — Ігри, імпортовані з PlayStation Network

Кнопки фільтрів

Кожен фільтр відкриває модальне вікно з усіма унікальними значеннями у вашій бібліотеці з підрахунком. Фільтри підтримують два режими:

  • Включити (IS) — Показувати лише ігри, що відповідають обраному значенню
  • Виключити (IS NOT) — Приховувати ігри, що відповідають обраному значенню

Перемикайтеся між режимами включення та виключення за допомогою перемикача в модальному вікні фільтра.

У фільтрах «Жанр», «Серія», «Видавець», «Розробник», «Режим гри», «Перспектива» і «Вимірність» позначте будь-яку кількість значень і натисніть Застосувати. Гра показується, якщо вона має будь-яке з позначених значень; у режимі виключення гру приховано, якщо вона має будь-яке з них. Кожне значення отримує власний тег над іграми, і його × прибирає лише це значення. Фільтри «Рейтинг» і «Джерело» приймають одне значення й застосовуються, щойно ви на нього клацнете.

Опції сортування

Виберіть порядок у списку Сортувати за поруч із кількістю ігор:

  • Назва — За алфавітом за назвою для сортування (без урахування регістру)
  • Найновіші випуски / Найстаріші випуски — За датою випуску
  • Оцінка критиків / Оцінка гравців — Спочатку найвищі
  • Нещодавно додано — Першими йдуть ігри, які ви додали до бібліотеки останніми

Ігри без дати чи оцінки йдуть останніми. «Очистити» зберігає вибране сортування.

Навігація за алфавітом

Перейдіть до ігор, що починаються на певну літеру. Літери без відповідних ігор виділено сірим. Цифри та символи згруповано під #. Панель працює під час сортування за назвою, а для будь-якого іншого сортування виділена сірим.

Нескінченне прокручування

Ігри завантажуються партіями по 100 під час прокручування. Нові сторінки завантажуються автоматично, коли ви наближаєтеся до кінця. Зміна фільтрів або пошуку миттєво скидає та перезавантажує результати.

Збереження стану

Ваші поточні фільтри, пошуковий запит, сортування і положення прокручування зберігаються в сховищі сеансу. Вони відновлюються, коли ви повертаєтеся на сторінку або оновлюєте її.

Деталі гри

Модальне вікно деталей гри

Клацання на будь-яку картку гри відкриває модальне вікно деталей з кешованим швидким переглядом. Модальне вікно показує:

  • Обкладинку (2D і 3D), фон fanart
  • Опис та інформацію про випуск
  • Значки розробника, видавця, жанру
  • Кількість гравців, режими гри, структуру гри
  • Зображення вікового рейтингу (з вашої бажаної системи, з резервним перехресним зіставленням)
  • Галерею скріншотів з навігацією клавіатурою (← →)
  • Відео трейлера (якщо доступне)
  • Оцінки часу проходження HLTB (основна історія, основна + додатковий контент, повне проходження)
  • Статус і прогрес RetroAchievements
  • Схожі ігри (клікабельні посилання)
  • Деталі підтримки контролерів
  • Теги, призначені грі
  • Розмір файлу та шлях до ROM

Повна сторінка деталей гри

Натисніть на посилання назви гри або перейдіть із хлібних крихт, щоб переглянути повну сторінку деталей гри. Додаткові можливості на повній сторінці включають:

  • Заголовок з фоном fanart з навігацією хлібними крихтами
  • Логотип гри — Логотип гри показується над її назвою, яка залишається текстом. Гра без обкладинки показує логотип на місці коробки. Скрапінг заповнює логотипи з ES-DE, ScreenScraper, TheGamesDB, IGDB і Steam; масовий скрапінг у режимі Заповнити відсутнє заповнює їх для ігор, скраплених раніше
  • Задня сторона коробки — Коли гра має задню сторону коробки, на обкладинці є кнопка Зад. Натисніть її, щоб побачити задню сторону, і натисніть Перед, щоб повернутися. Клацніть задню сторону, щоб збільшити її. Скрапінг заповнює задні сторони з ES-DE, ScreenScraper і TheGamesDB щоразу, коли гру скраплять
  • Значки платформи імпорту — Показує CLZ Import, Steam Import, Xbox Import або PSN Import з логотипами платформ, де застосовно
  • Індикатор бонусного диска — Показує значок і посилання "Part of:" на батьківську гру з мініатюрою
  • Кнопка видалення — Видалити гру з бази даних (з підтвердженням)
  • Кнопка очищення — Очистити всі скраплені метадані, зберігаючи запис ROM

Модальне вікно редагування

Натисніть Edit (або клавішу e), щоб відкрити модальне вікно редагування, організоване в розділи:

  • Ідентичність — Назва, назва для сортування (генерується автоматично, але редагована), франшиза, видання
  • Інформація про випуск — Дата випуску, регіон (з налаштовуваного випадаючого списку)
  • Ігровий процес — Жанр (теги з множинним вибором), режими, структура гри, кількість гравців, розробник, видавець
  • Технічні дані — Контролери (множинний вибір), тип збереження, перспектива (множинне значення), вимірність (множинне значення)
  • Вікові рейтинги — Усі системи рейтингів з офіційними зображеннями рейтингів та автоматичним перехресним зіставленням. Зміна одного рейтингу автоматично заповнює порожні рейтинги в інших системах.
  • Оцінки — Оцінка критиків, оцінка користувачів
  • Опис — Текст опису гри
  • Власні зображення — Завантаження власної обкладинки (2D), 3D-обкладинки, задньої сторони коробки, fanart і логотипа. Очистіть наявні зображення, щоб дозволити повторний скрапінг.
  • Імпортувати 3D-коробку — Також у розділі «Власні зображення». Зберігається одразу, без кнопки «Зберегти зміни». Виберіть файл .box.json, збережений Slipcase, разом із його зображеннями (можна вибрати й усю теку). Slipcase 1.4.0 або новіший зберігає цей файл поруч із кожним експортованим зображенням. RetroDB зберігає грані коробки для цієї гри; тоді клік по обкладинці показує коробку в 3D, яку можна перетягувати або обертати клавішами зі стрілками. Ваше зображення обкладинки 3D не змінюється. Якщо гра вже має грані, RetroDB спершу запитає, чи замінити їх, а Видалити їх видаляє.
  • Відео / Трейлер — Завантаження або посилання на відеотрейлер

Швидкі дії

  • Edit — Відкрити модальне вікно редагування (e)
  • Scrape — Отримати метадані з джерел скрапінгу (s)
  • AI Fill — Заповнити відсутні поля за допомогою ШІ (потребує ключа API ШІ)
  • Check for RA — Пошук набору досягнень RetroAchievements
  • HLTB Lookup — Знайти оцінки часу проходження з HowLongToBeat

Статус проходження

Відстежуйте прогрес за допомогою цих статусів (показані як значки на картках ігор):

  • Не розпочато — Ще не грали
  • В процесі — Наразі граєте

Регіональні версії

Якщо у вас є одна гра з кількох регіонів, пов'яжіть версії, і Бібліотека покаже їх однією карткою зі значком 🌐. Картка відкриває й запускає версію з вашого бажаного регіону (Налаштування → Бібліотека → Типовий регіон). Сторінка гри перелічує всі версії, порівнює їх (дата випуску, видавець, розмір файлу, ревізія, мови, оцінки, RetroAchievements) і містить посилання на кожну. Редактори можуть там від'єднати версію або знайти в тій самій системі іншу, щоб пов'язати її. Редактори також можуть натиснути Описати відмінності за допомогою ШІ, щоб отримати список відомих відмінностей між версіями, як-от цензура чи вилучений вміст. Його позначено як написаний ШІ, і він може містити помилки; для нього потрібен постачальник ШІ в Налаштування → Скрапінг. Заголовок сторінки показує кількість ігор, а поруч кількість ROM, якщо ці числа відрізняються.

Порада: Модальне вікно деталей кешує нещодавно переглянуті ігри для швидшого завантаження. Редагування автоматично оновлює картку гри на сторінці без потреби в оновленні.

Порівняння ігор

Що це робить

Порівняння метаданих двох ігор поруч у вигляді таблиці. Корисно для перевірки якості метаданих, виявлення дублікатів або порівняння версій однієї гри для різних систем.

Як використовувати

  1. Перейдіть у розділ Порівняння (доступний зі сторінки бібліотеки)
  2. Знайдіть та оберіть першу гру
  3. Знайдіть та оберіть другу гру
  4. Перегляньте таблицю порівняння — відмінності виділено

Поля для порівняння

Система, розробник, видавець, дата випуску, жанр, франшиза, регіон, кількість гравців, режими, перспектива, вимірність, усі вікові рейтинги, користувацький рейтинг, оцінка критиків, оцінки часу проходження, підтримка контролерів, тип збереження, розмір файлу, схожі ігри, опис та інше.

Колекції (Теги, Списки, Список бажань)

Теги

Створюйте власні кольорові теги для організації ігор. Теги працюють як ярлики — кожна гра може мати кілька тегів, а кожен тег може містити кілька ігор.

  • Створюйте теги з власними назвами та кольорами на сторінці Теги
  • Призначайте теги іграм через модальне вікно деталей гри
  • Натисніть на будь-який тег, щоб переглянути всі ігри з цим тегом
  • Редагуйте або видаляйте теги на сторінці керування тегами

Іменовані списки

Створюйте кураторські списки ігор із власним порядком. Списки схожі на плейлисти — ви керуєте точним порядком ігор.

  • Створюйте списки з назвою, описом та іконкою на сторінці Списки
  • Додавайте ігри до списків через модальне вікно деталей гри або сторінку списку
  • Перетягуйте, щоб змінити порядок ігор у списку
  • Сортуйте за власним порядком або за алфавітом

Список бажань

Відстежуйте ігри, які ви хочете придбати, фізично чи цифрово.

  • Додавайте ігри вручну з назвою, системою, нотатками та пріоритетом (1–5)
  • Елементи списку бажань можуть бути прив'язані до наявних ігор у бібліотеці, якщо їх знайдено
  • Сортуються за пріоритетом (найвищий спочатку), потім за датою додавання
Порада: Використовуйте теги для наскрізних ярликів (наприклад, "Улюблені", "Кооп на дивані", "Черга") і списки для конкретних кураторських колекцій (наприклад, "Топ-10 ігор SNES", "Ігри для стрімів").

Імпорт ігор

Імпортуйте колекції ігор із зовнішніх джерел. Доступ через Імпорт ігор на бічній панелі. Усі типи імпорту об'єднано на одній сторінці з вкладками.

Імпорт з CLZ Games

Імпортуйте вашу фізичну колекцію ігор із CLZ Games.

  1. Експортуйте вашу колекцію CLZ Games у PDF
  2. Перейдіть в Імпорт ігор → вкладка CLZ
  3. Завантажте PDF-файл
  4. Перегляньте розпізнані ігри
  5. Оберіть, які ігри імпортувати

Імпорти CLZ відстежуються окремо від ігор ROM (з використанням префікса clz_import/), що дозволяє каталогізувати як фізичні, так і цифрові колекції. Імпорти CLZ можна повністю очистити в Налаштування → Система → Обслуговування.

Імпорт зі Steam

Імпортуйте вашу бібліотеку ігор Steam та відстежуйте досягнення.

  1. Налаштуйте ключ Steam Web API та Steam ID у Налаштуваннях
  2. Перейдіть в Імпорт ігор → вкладка Steam
  3. Натисніть "Отримати бібліотеку", щоб отримати ваші ігри Steam
  4. Оберіть ігри для імпорту. Гру, яка вже є у вашому списку Windows під тією самою назвою, прив'язують до Steam, а не додають двічі
  5. Імпортовані ігри позначаються їхнім Steam App ID для відстеження досягнень
  6. У фоновому режимі кожна гра заповнює свої порожні дані зі своєї сторінки в магазині Steam, і надходять ваші досягнення та час гри. Сторінка гри показує ваш час гри. Скрапте гру, щоб отримати її жанр і дату випуску: дані Steam надто загальні або є датою, коли гра з'явилася в Steam

Імпорт з Xbox

Імпортуйте ігри Xbox, у які ви грали, за допомогою власного ключа OpenXBL.

  1. Збережіть свій ключ OpenXBL у Налаштування → Мій профіль → Xbox (див. «Ключі API» вище)
  2. Перейдіть в Імпорт ігор → вкладка Xbox і натисніть Отримати бібліотеку
  3. Оберіть ігри для імпорту з виявленням дублікатів. Застосунки та ігри лише для телефона не включаються.
  4. Імпортовані ігри позначаються їхнім Xbox Title ID для відстеження досягнень

Імпорт з PSN

Імпортуйте вашу бібліотеку ігор PlayStation Network.

  1. Перейдіть в Імпорт ігор → вкладка PSN
  2. Введіть ваш кукі NPSSO (дивіться Трофеї → Автентифікація PSN для того, як його отримати)
  3. Натисніть "Отримати бібліотеку", щоб отримати ваші ігри PSN
  4. Оберіть ігри для імпорту

Після імпортування

  • Імпортовані ігри з'являються у вашій бібліотеці зі значками, специфічними для платформи
  • Використовуйте масовий скрапінг для отримання метаданих для імпортованих ігор
  • Відстеження досягнень/трофеїв автоматично прив'язується до вихідної платформи
  • Імпортовані ігри можна фільтрувати в бібліотеці за допомогою фільтра джерела
Порада: Після імпортування ігор з будь-якої платформи ви можете скрапити для них метадані за допомогою масового скрапінгу, так само як і для ігор ROM. Імпортовані ігри також можуть відстежувати досягнення з відповідних платформ.

RetroAchievements

Налаштування

  1. Створіть обліковий запис на retroachievements.org
  2. Згенеруйте ключ API в налаштуваннях профілю
  3. Введіть ім'я користувача та ключ API в Налаштування → Обліковий запис → RetroAchievements

Щоб здобувати досягнення під час гри в RetroArch від RetroDB, DuckStation або PCSX2, один раз введіть свій пароль RetroAchievements у розділі Здобувайте досягнення в RetroArch, DuckStation і PCSX2 на цій самій сторінці. Він надсилається лише до RetroAchievements і не зберігається; RetroDB зберігає отриманий у відповідь токен входу, по одному на кожного користувача RetroDB. За бажанням позначте там Режим хардкор. Якщо вхід для досягнень перестане працювати, наприклад після скидання ключа на сайті RetroAchievements, вийдіть і ввійдіть знову. Коли ви натискаєте «Грати» в DuckStation або PCSX2, RetroDB записує ваш вхід у власний файл налаштувань цього емулятора, де він залишається, доки ви не вийдете або доки не зіграє інший користувач RetroDB. Вхід, виконаний у власному меню емулятора, залишається без змін. RetroDB не може виконати вхід у DuckStation на Mac.

Сторінка досягнень

  • Вкладки систем — Перегляд досягнень за платформою (запам'ятовує останню переглянуту вкладку)
  • Навігація за алфавітом — Перейдіть до ігор за першою літерою в межах кожної вкладки системи
  • Оновити прогрес — Синхронізувати прогрес досягнень з RetroAchievements
  • Загальна статистика — Отримані досягнення та бали за всіма системами
  • Прогрес по кожній грі — Перегляд відсотка завершення для кожної гри зі смугами прогресу

Черга синхронізації

Кілька синхронізацій систем можуть стояти в черзі:

  • Натисніть "Refresh Progress" на будь-якій системі, щоб почати або поставити синхронізацію в чергу
  • Якщо синхронізація вже виконується, нові запити ставляться в чергу автоматично
  • Черга обробляється автоматично після завершення поточної синхронізації
  • Спливаюче сповіщення показує поточний прогрес і кількість у черзі

Пошук ігор з досягненнями

  • Фільтр бібліотеки — Використовуйте фільтр "Has RA", щоб показувати лише ігри з досягненнями
  • Check for RA — У модальних вікнах деталей гри натисніть, щоб знайти набір досягнень
  • Масовий скрапінг — Увімкніть опцію "Check RA", щоб знаходити досягнення під час скрапінгу
  • Завдання оновлення RA — Скануйте всі ігри системи, щоб визначити, які підтримують RA

Деталі на рівні гри

Натисніть на будь-яку гру на сторінці досягнень, щоб побачити детальну інформацію про досягнення для цієї гри, включно з назвами окремих досягнень, описами, кількістю балів і статусом отримання.

Примітка: "Refresh Progress" синхронізує ваш прогрес для ігор, які вже прив'язані до RetroAchievements. Щоб знайти НОВІ набори досягнень, використовуйте "Check for RA" у модальних вікнах деталей гри або увімкніть цю опцію під час масового скрапінгу.

Сторінка досягнень

  • Загальна статистика — Усього ігор Steam, отримані досягнення, відсоток завершення
  • Прогрес по кожній грі — Смуги завершення для кожної гри

  • Глобальний відсоток гравців, які розблокували кожне досягнення

Синхронізація

  • Синхронізуйте досягнення однієї гри з її сторінки деталей
  • Масова синхронізація всіх ігор Steam зі сторінки досягнень
  • Синхронізація виконується як фонове завдання з прогресом у спливаючому сповіщенні

Досягнення Xbox

Налаштування

  2. Збережіть свій ключ OpenXBL у Налаштування → Мій профіль → Xbox

Деталі досягнень для кожної гри

  • Статус розблоковано/заблоковано з мітками часу розблокування
  • Значки gamerscore на кожному досягненні

Трофеї PS3 / PSN

Локальні трофеї RPCS3

Відстежуйте трофеї, отримані в іграх PS3 через емулятор RPCS3.

  1. Встановіть шлях до трофеїв RPCS3 в Налаштування → Дані → Трофеї
  2. Натисніть "Scan Trophies", щоб імпортувати отримані трофеї
  3. Переглядайте списки трофеїв і відомості про кожен трофей на вкладці RPCS3 розділу Досягнення

RPCS3 читає дані трофеїв XML з вашої користувацької папки RPCS3 та автоматично зіставляє ігри з вашою бібліотекою.

Трофеї через API PSN

Синхронізуйте дані трофеїв PlayStation Network з вашого облікового запису PSN.

  1. Отримайте свій кукі NPSSO (див. нижче)
  2. Введіть його в Налаштування → Обліковий запис → PSN
  3. Ваша бібліотека трофеїв PSN буде отримана через API PlayStation
  4. Переглядайте прогрес трофеїв для кожної гри з підрахунком отримано/усього
  5. Деталі окремих трофеїв включають опис, рідкість і мітки часу розблокування

Автентифікація PSN (кукі NPSSO)

PSN використовує спеціальний автентифікаційний кукі, який називається токеном NPSSO. Щоб його отримати:

  1. Відкрийте веб-браузер і увійдіть на store.playstation.com
  2. Після входу перейдіть за адресою: https://ca.account.sony.com/api/v1/ssocookie
  3. На сторінці відобразиться JSON, що містить ваш токен NPSSO
  4. Скопіюйте значення npsso і вставте його в Налаштування → Обліковий запис → PSN

Після автентифікації RetroDB безпечно кешує токени доступу у власній базі даних (для кожного користувача) і автоматично оновлює їх — вам не потрібно вставляти NPSSO знову перед кожною синхронізацією. Коли сеанс Sony завершується, RetroDB сам знову входить за допомогою збереженого NPSSO. Новий NPSSO потрібен лише тоді, коли Sony відхиляє збережений; тоді про це повідомлять Налаштування → Обліковий запис і панель керування.

Деталі трофеїв

Музей

Що це таке

Інтерактивна енциклопедія ігрових систем, організована за поколіннями. Дізнайтеся про історію, характеристики та примітні ігри для кожної платформи у вашій колекції.

Головна сторінка

Головна сторінка Музею показує хронологію ігрових систем, згрупованих за поколіннями (1–9 покоління, портативні, аркадні, комп'ютери). Кожна картка системи показує зображення обладнання та кількість ігор з вашої бібліотеки.

Сторінки деталей системи

Натисніть на будь-яку систему, щоб переглянути її сторінку музею, яка включає:

  • Зображення обладнання — Фото консолі/системи
  • Технічні характеристики — CPU, GPU, RAM, роздільна здатність, тип носія
  • Історія — Згенерована ШІ розповідь про розробку системи, її запуск і спадщину
  • Топ-10 ігор — Найпримітніші тайтли системи (за оцінками критиків і пропозиціями ШІ)
  • Галерея контролерів — Зображення контролерів системи з описами

Генерація контенту ШІ

Контент Музею генерується за допомогою ШІ (Gemini, OpenAI або Claude). Ви можете генерувати контент для:

  • Однієї системи — Натисніть "Generate" на сторінці музею будь-якої системи
  • Масової генерації — Генеруйте контент для всіх систем одразу з головної сторінки (виконується як фонове завдання з прогресом у спливаючому сповіщенні)

Зображення контролерів

Зображення контролерів можна додати через:

  • Пошук зображень — Шукайте фото контролерів за допомогою Bing Image Search. Результати ранжуються за релевантністю (назва контролера + виробник + варіації системи).
  • Ручне завантаження — Завантажте власні зображення контролерів
  • Видалення фону — Автоматичне видалення фону за допомогою локального ШІ (бібліотека rembg) для прозорих зображень контролерів на будь-якому фоні
  • Поширення зображень — Коли знайдено зображення контролера, воно автоматично поширюється на той самий контролер в інших системах (спорідненні контролери)
  • Масове отримання — Отримати зображення для всіх контролерів системи одразу

Усі зображення контролерів стандартизуються до цільового розміру та зберігаються у форматі WebP.

Порада: Для генерації контенту потрібен ключ API ШІ. Музей використовує того ж постачальника ШІ, налаштованого в Налаштування → Скрапінг → Ключі API.

Звіти ROM

Що це робить

Перевіряє назви файлів ROM на відповідність стандартним конвенціям іменування та визначає потенційні проблеми. Відкрийте Інструменти ROM на бічній панелі, а потім вкладку Звіти ROM.

Типи звітів

ВкладкаЩо перевіряє
Нестандартні назвиROM з назвами файлів, що не відповідають конвенціям іменування. Показує поточну назву файлу, виявлені проблеми та пропоновану виправлену назву.
Невідповідності назвROM, де назва файлу не відповідає скрапленій назві метаданих. Показує поточну назву файлу порівняно зі скрапленою назвою, регіоном, роком і розробником.

Що перевіряється

  • Неприпустимі символи в назвах файлів (: ? * / " < > | \)
  • Відсутні або неправильні теги регіону (наприклад, (USA), (Europe))
  • Відсутні теги року
  • Невідповідності назви файлу та назви в базі даних

Звіти можна сортувати за системою, назвою файлу та типом проблеми. Використовуйте їх, щоб підтримувати бібліотеку ROM організованою та послідовно іменованою.

Інструменти ROM

Доступ до центру інструментів ROM з бічної панелі. Кожен інструмент виконується як фонове завдання з оновленням прогресу в реальному часі, підтримкою паузи/відновлення та журналюванням.

Сканер архівів

Розпаковує архіви ROM (ZIP, 7Z, RAR) з опціями для:

  • Рекурсивного сканування підпапок
  • Видалення небажаних файлів після розпакування
  • Автоматичної генерації плейлистів M3U для багатодискових ігор

Потребує: 7z або unzip

Конвертер CHD

Конвертує образи дисків (ISO, BIN/CUE, GDI) у стиснутий формат CHD. Значно економить сховище, зберігаючи повну сумісність з емуляторами.

Потребує: chdman (з mame-tools)

Перевірка CHD

Перевіряє цілісність файлів CHD за допомогою перевірки хешів. Виявляє пошкоджені або неповні конвертації.

Потребує: chdman

Пошук дублікатів

Знаходить дублікати ROM за хешем або назвою файлу, з опціями пріоритезації за тегами регіону. У режимі за назвою файлу пов'язані регіональні версії однієї гри не вважаються дублікатами; у режимі за хешем ідентичні файли вважаються ними завжди.

Без зовнішніх залежностей

Регіональні версії

Лише для редакторів. RetroDB пропонує ігри, схожі на одну гру з різних регіонів: та сама гра в IGDB або ScreenScraper, та сама назва з іншим тегом регіону або збіжна регіональна назва. Зніміть позначку з ігор, які сюди не належать, і натисніть "Пов'язати позначені ігри" або натисніть "Не версії", щоб цю групу більше ніколи не пропонували. Нічого не пов'язується, доки ви не підтвердите. Спершу запустіть Заповнення альтернативних назв у розділі Обслуговування: воно заповнює ідентифікатори IGDB і ScreenScraper, які використовують пропозиції.

Без зовнішніх залежностей

Назви MAME

Лише для адміністраторів. MAME знаходить гру за точною назвою файлу, тому зберігайте короткі назви, як-от dyger.zip. Виберіть список MAME (DAT, що відповідає вашим ROM, або вивід mame -listxml) і натисніть "Назвати ігри MAME". Кожна гра отримує справжню назву, рік і виробника, а файли залишаються без змін. Назву, яку ви змінили самі, збережено. Додайте catver.ini, щоб фільтрувати список за категорією. Набори BIOS приховано зі списку, але вони залишаються на диску, бо їх потребують інші ігри. Після цього виконайте скрапінг, щоб скрапери могли знайти кожну гру.

Потребує: файлу списку MAME

Масове заповнення ШІ

Лише для редакторів. Запускає Заповнення ШІ для цілої системи за тими полями, які ви ввімкнете (див. Заповнення ШІ → Багато ігор одразу).

Потребує: постачальника ШІ в Налаштування → Скрапінг

Організатор багатодискових ігор

Організовує багатодискові ігри в підпапки та генерує плейлисти M3U для емуляторів, які їх підтримують. Корисно для таких систем, як PlayStation і Saturn.

Без зовнішніх залежностей

Видалення дублікатів скріншотів

Знаходить і видаляє дублікати скріншотів у вашій бібліотеці ігор, щоб звільнити місце в сховищі.

  • Точний хеш (MD5) — Визначає лише ідентичні файли
  • Візуальна схожість — Порівняння за перцептивним хешем із налаштовуваним порогом (1–20, менше значення = суворіша відповідність)

Сканує поступово з живою статистикою, що показує кількість сканованих ігор, кількість дублікатів і місце, яке можна звільнити. Результати згруповано за грою та системою. Ви можете обрати, який файл зберегти в кожній групі дублікатів, або скористатися "Select Largest", щоб автоматично зберегти версію з найвищою роздільною здатністю.

Без зовнішніх залежностей

Зміна розміру зображень

Стандартизує медіа ігор до узгоджених цільових розмірів. Дивіться Стандартизація зображень для повних деталей.

Без зовнішніх залежностей (масштабування ШІ на основі Python)

Заповнення альтернативних назв

Проходить кожну скраплену гру й отримує її альтернативні назви з IGDB / TGDB / ScreenScraper, позначені регіоном, з якого походить кожна назва. Назви, які у вас уже є, отримують свій регіон. Корисно після імпортування великого каталогу або міграції з іншого інструмента, який не зберігав регіональні/японські/додаткові назви. Виконується у фоновому режимі; прогрес показується на картці інструмента.

Потребує принаймні одного ключа API скрапера (IGDB / TGDB / ScreenScraper)

Виправити регіони коробок та інструкцій

Старіші скрапінги ScreenScraper брали першу коробку, 3D-коробку та інструкцію з алфавітного списку регіонів, тож гра для США могла показувати європейську коробку або мати португальську інструкцію. Цей інструмент знову шукає кожну з цих ігор. Якщо для гри краще підходить інший регіон, він завантажує той файл і видаляє старий. Коробки та інструкції з будь-яких інших регіонів залишаються без змін, як і ігри, файл яких уже підходить. Щоб зупинити, натисніть картку ще раз; наступний запуск продовжить із рештою.

Виправити регіони за назвами файлів

Назва файлу ROM показує, яка це копія, тому тег на кшталт (USA) тепер визначає її регіон, і ШІ не запитують. Старіші скрапінги дозволяли ШІ вгадувати першим, тож файл (USA) міг бути вказаний як Японія. Цей інструмент присвоює таким іграм регіон із назви їхнього файлу. Він змінює лише регіони, заповнені ШІ, зокрема й той, який ви згодом вручну виправили так, що він відрізняється від назви файлу.

Залежності не потрібні

Упорядкувати дати виходу

Старіші скрапінги зберігали дату, відому лише за роком, як 1 січня або 31 грудня, ніби день був відомий. Цей інструмент обрізає такі дати до року або місяця, щоб пізніший скрапінг міг заповнити справжню. Дата, яку не заповнював жоден скрапінг, залишається як є.

Залежності не потрібні

Перевірити збережений час проходження

Старіші пошуки могли зберегти час проходження продовження або іншої гри з тією самою назвою на іншій системі. Цей інструмент надсилає такі збіги на сторінку перегляду HowLongToBeat, і жодна гра не змінюється, доки ви не вирішите. Там «Схвалити» зберігає час, а «Відхилити» очищає його. Деякі збіги правильні: HowLongToBeat не перелічує кожну систему, на якій вийшла гра.

Залежності не потрібні

Упорядкувати жанри, перспективи та режими

Джерела називають одне й те саме по-різному, тож один жанр міг з'являтися і як RPG, і як Role Playing Game, а фільтр пропускав ігри. Тепер скрапінги використовують один набір назв — ті, що в списках фільтрів. Цей інструмент перетворює те, що зберегли старіші скрапінги. Слова, яким немає місця в цих списках, як-от Arcade чи Indie, видаляються. Слова, що належать до іншого поля, як-от FPV, переносяться туди, якщо це поле порожнє. Кількість гравців, що суперечить режимам гри, виправляється, а старі значення 1 з RAWG очищуються, щоб їх могла заповнити справжня кількість. Значення, яке ви самі додали до списку, залишається. Після цього запустіть масовий скрапінг із Заповнити відсутнє, щоб заповнити все, що залишилося порожнім.

Залежності не потрібні

Очистити зображення RAWG з обкладинок

RAWG не має обкладинок. Старіші скрапінги зберігали його фонове зображення, часто скріншот, як обкладинку, а оскільки скрапінг заповнює лише порожні обкладинки, це зображення заважало справжній. Цей інструмент видаляє такі зображення й залишає обкладинки порожніми. Обкладинки з інших джерел і весь fanart залишаються. Ці ігри не показуватимуть обкладинки, доки скрапінг її не знайде, тож після цього запустіть масовий скрапінг із Заповнити відсутнє.

Залежності не потрібні

Масовий пошук HLTB

Запускає пошук HowLongToBeat для кожної гри, якій бракує оцінки часу проходження. Кожна відповідність оцінюється за назвою + платформою + роком випуску; відповідності з високою впевненістю зберігаються автоматично. Усе, що нижче порогу впевненості (або з конфліктуючими платформами), відкладається для перегляду людиною.

Шукає кожну гру на сайті HowLongToBeat, тому потрібен доступ до інтернету

Очікування перегляду HLTB

Черга перегляду для неоднозначних відповідностей, виявлених масовим пошуком HLTB. Кожен рядок очікування показує вихідну гру поряд із кандидатом HLTB (назва, платформа, рік випуску, впевненість). Схваліть, відхиліть або оберіть іншу відповідність для кожного рядка. Картка інструмента перегляду з'являється в центрі інструментів ROM лише за наявності принаймні однієї відповідності, що очікує.

  • Вкладки фільтрів для відповідностей з низькою впевненістю, альтернативною назвою та невідповідністю платформи.
  • Схвалення записує оцінку часу проходження; Відхилення відкидає кандидата й підтримує чистоту черги пошуку.

Налаштування інструментів

Налаштуйте шляхи, розташування інструментів, типи архівів і параметри, спільні для всіх інструментів ROM.

Порада: Усі інструменти ROM підтримують паузу/відновлення та виконуються у фоновому режимі. Прогрес і результати журналюються та доступні для перегляду в переглядачі журналів. Статус інструмента (доступний чи потребує встановлення) показується на картці кожного інструмента.

Нормалізація

Що це робить

Нормалізує значення жанру та режиму гри до узгоджених канонічних форм. Це відбувається автоматично під час скрапінгу та заповнення ШІ, а також може застосовуватися вручну до вашої наявної бібліотеки.

Чому це важливо

Різні скрапери використовують різні назви для однієї й тієї самої речі. Нормалізація забезпечує узгодженість у всій вашій бібліотеці:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Власні правила

Ви можете додати власні правила нормалізації в Налаштування → Дані → Нормалізація. Власні правила перевизначають вбудовані відповідності, дозволяючи вам визначити власні бажані назви жанрів і режимів. Правила зберігаються в базі даних.

Попередній перегляд і застосування

Перед застосуванням нормалізації ви можете переглянути, які ігри будуть змінені та які зміни буде внесено. Це дозволяє переглянути зміни перед їх внесенням до вашої бібліотеки.

Назви, написані двома способами

Кнопки Франшиза, Видавець і Розробник показують назви, написані з різними великими літерами, наприклад Doom і DOOM. Вибирається написання, яке має найбільше ігор; виберіть інше, якщо хочете, і натисніть Застосувати. Пізніший скрапінг або заповнення ШІ, що приносить назву з іншими великими літерами, використовує написання вашої бібліотеки.

У розділах Видавець і Розробник список Назви, які можуть бути однією компанією показує назви на кшталт Eidos і Eidos Interactive. Нічого не позначено, бо схожі назви можуть належати різним компаніям: Atari Games і Atari, Inc. — дві різні. У рядку виберіть назву, яку залишити, позначте назви тієї самої компанії та натисніть Об'єднати. Позначені назви змінюються на залишену і у Видавці, і в Розробнику, а пізніший скрапінг або заповнення ШІ, що приносить об'єднану назву, використовує залишену.

Стандартизація зображень

Що це робить

Стандартизує всі медіа ігор до узгоджених цільових розмірів для однорідного вигляду всієї вашої бібліотеки. Зображення в межах 80–120% від цільового розміру пропускаються.

Як це працює

  • Збільшення масштабу — Зображення, менші за цільовий розмір, збільшуються за допомогою Real-ESRGAN x4 (суперроздільна здатність на основі ШІ через ONNX Runtime) для якісного збільшення, а потім змінюються до точного цільового розміру
  • Зменшення масштабу — Зображення, більші за цільовий розмір, зменшуються за допомогою фільтрації Lanczos для чітких результатів
  • Смуга порогу — Зображення в межах 80–120% від цільового розміру залишаються без змін, щоб уникнути зайвої повторної обробки

Як запустити

  1. Перейдіть в Налаштування → Система → Обслуговування або Інструменти ROM → Зміна розміру зображень
  2. Натисніть "Почати", щоб почати масову стандартизацію
  3. Завдання виконується у фоновому режимі зі спливаючим сповіщенням, що показує поточний файл і статистику
  4. Зображення також автоматично стандартизуються під час скрапінгу (нові завантаження стандартизуються негайно)

Підтримка обладнання

Модель Real-ESRGAN автоматично визначає ваше обладнання та використовує найкращого доступного постачальника:

  • CUDA — Прискорення на GPU NVIDIA
  • ROCm — Прискорення на GPU AMD (з автоматичним перевизначенням версії gfx для серії RX 6000)
  • CoreML — Прискорення для Apple Silicon
  • CPU — Резервний варіант для систем без підтримки GPU

Файл моделі ONNX завантажується автоматично з Hugging Face під час першого використання та кешується локально.

Сканування бібліотеки

  • Сканувати бібліотеку — Сканує ваші папки ROM на наявність нових ігор. Визначає папки систем і підтримувані типи файлів за допомогою списків розширень ES-DE systeminfo.txt. Також доступно з панелі приладів.

Операції очищення

  • Очистити відсутні ROM — Видаляє записи бази даних для ігор, файли ROM яких більше не існують на диску. Корисно після реорганізації або видалення файлів ROM.
  • Очищення осиротілих медіа — Знаходить і видаляє файли зображень на диску (обкладинки, скріншоти, fanart), які не мають відповідного посилання в базі даних. Попередній перегляд перед видаленням для підтвердження.
  • Очистити скраплені дані — Прибирає все, що скрапінг записав у скраплені ігри, разом з посиланнями на їхні зображення й відео, щоб можна було скрапити знову з нуля. Ігри залишаються, а їхні назви повертаються до імен файлів (заблокована назва залишається). Файли зображень і відео лишаються на диску, якщо не позначити Також видалити файли зображень і відео. Попередній перегляд показує, скільки ігор це зачепить.
  • Очистити імпорти CLZ — Видаляє всі записи імпорту CLZ Games (записи лише з метаданими без файлів ROM).

Оптимізація бази даних

Резервне копіювання та відновлення

Створення резервних копій

  1. Перейдіть в Налаштування → Бібліотека → Резервне копіювання
  2. Натисніть "Create Backup"
  3. Резервна копія зберігається в папці backups/ з іменем файлу, що містить мітку часу

Що входить до резервної копії

Резервна копія включає всю базу даних SQLite (roms.db), яка містить усі метадані ігор, облікові записи користувачів, налаштування, дані трофеїв, прогрес досягнень, теги, списки та елементи списку бажань.

Що НЕ входить до резервної копії

Медіафайли (обкладинки, скріншоти, fanart, відео, посібники) НЕ включені до резервної копії бази даних, оскільки їх можна повторно завантажити за допомогою скрапінгу. Розгляньте окреме резервне копіювання папки static/images/, якщо у вас є власні завантаження.

Відновлення

  1. Знайдіть резервну копію у списку резервних копій
  2. Натисніть "Restore"
  3. Підтвердіть дію
Попередження: Відновлення резервної копії перезаписує вашу поточну базу даних. Створіть свіжу резервну копію перед відновленням старішої!

Оновлення RetroDB

Версія 4.0 — остання вебверсія RetroDB. Нові версії будуть застосунком для Windows, Linux і macOS, а також застосунком для Android. Вони відкриють вашу наявну бібліотеку. До того часу версія 4.0 отримуватиме лише виправлення безпеки та виправлення помилок, через які втрачаються дані.

Як оновити

  1. Завантажте новий випуск RetroDB
  2. Створіть резервну копію цих файлів (вони містять ваші особисті дані):
    • config.py (ваші шляхи та ключі API)
    • data/settings.json (ваші налаштування інтерфейсу)
    • data/scraper_settings.json (ваша конфігурація скраперів)
    • data/rom_tools_config.json (ваші налаштування інструментів ROM)
    • папку database/ (базу даних вашої бібліотеки ігор та збережені токени входу PSN/Xbox)
  3. Розпакуйте нову версію поверх наявної установки
  4. Запустіть python install.py, щоб встановити нові залежності
  5. Перезапустіть сервер

Файли, які можна безпечно перезаписати

Усі файли вихідного коду (.py, .html, .css, .js) можна безпечно перезаписати. Інсталятор не перезапише ваші особисті файли конфігурації.

Файли, які слід зберегти

Ніколи не видаляйте та не перезаписуйте: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Міграції бази даних

RetroDB автоматично обробляє зміни схеми бази даних під час запуску. Нові стовпці та таблиці додаються за потреби без втрати даних. Вам не потрібно робити нічого особливого — просто запустіть нову версію, і база даних оновиться автоматично.

Усунення несправностей

Проблеми згруповано за функціями. Введіть слово з повідомлення, яке ви бачите, у поле пошуку вгорі цієї сторінки, щоб перейти до нього. Більшість повідомлень також залишає рядок у розділі Переглядач журналів (лише для адміністраторів), де сказано більше.

Довгі завдання

Завдання, схоже, зависло

Масовий скрапінг, синхронізація досягнень, оновлення PSN, зміна розмірів зображень і запуски Заповнення ШІ показують сповіщення про прогрес у кутку. Його кнопки призупиняють, зупиняють або скасовують завдання. Масовий скрапінг зупиняється між двома іграми, тому гра, що обробляється, спершу завершується; це може тривати хвилину. Якщо завдання все ще виконується, перезапустіть RetroDB: Налаштування → Система → Керування сервером → Перезапустити сервер.

Банер "Interrupted Jobs" на панелі керування

Тут показано завдання, яке виконувалося або чекало, коли RetroDB зупинився. Відновити продовжує його з місця, де воно востаннє зберегло свій стан. Відхилити скидає його. Відновити все і Відхилити все роблять те саме з усіма завданнями у списку.

Додавання ігор

"Шлях до ROM не налаштовано"

Укажіть папку, у якій лежать ваші папки систем, у Налаштування → Бібліотека → Шляхи → Шлях до бібліотеки ROM, потім натисніть Сканувати бібліотеку.

Сканування не знаходить нових ігор, або якоїсь системи немає

  • У папці кожної системи потрібен файл ES-DE systeminfo.txt, що перелічує її розширення файлів. Папка без нього пропускається; Переглядач журналів показує для неї No extensions found. Папкам PS3 він не потрібен.
  • Файли мають лежати безпосередньо в папці системи. Файли у вкладених папках пропускаються, окрім PS3.
  • Файл, розширення якого немає в списку, пропускається.
  • Переміщений або перейменований файл додається як нова гра. Налаштування → Система → Очистити відсутні ROM видаляє старий запис.

Скрапінг

"No results found. Try a different search term."

  • Скоротіть назву в полі пошуку або спробуйте англійську назву.
  • Переконайтеся, що джерела ввімкнено й вони показують Онлайн у Налаштування → Скрапінг → Скрапер.
  • Джерело, що досягло свого ліміту, нічого не повертає до часу, який воно назвало (див. нижче).

Дані або зображення належать іншій грі

  • Масовий скрапінг шукає за назвою файлу ROM, тому погано названий файл знаходить не ту гру. Перейменуйте файл або проскрапте гру на її власній сторінці з кращою пошуковою назвою й виберіть правильний результат.
  • У вікні «Редагувати гру» поставте позначку Зберігати цю назву під час скрапінгу, щоб наступні скрапінги не чіпали назву.
  • Для багатьох ігор виберіть Суворо в Налаштування → Скрапінг → Скрапер → Фільтр збігів для масового скрапінгу.

Скрапінг не замінює поганого зображення

Скрапінг заповнює лише порожні зображення, а знімки екрана лише додаються. Видаліть зображення у вікні «Редагувати гру», потім проскрапте знову. Масовий Повторний скрапінг замінює зображення, якщо не поставлено позначку Зберегти наявні медіафайли. Знімок екрана, який ви видалили, більше не додається.

"… повідомляє, що ліміт вичерпано" або "… відхилив ключ API"

RetroDB перестає звертатися до цієї служби до часу, указаного в повідомленні. Якщо ключ відхилено, виправте його в Налаштування → Скрапінг → Ключі API й натисніть Зберегти ключі API; збереження також одразу знімає всі такі паузи. Перезапуск теж їх знімає.

Джерело показує причину замість "Онлайн"

Причина називає проблему, наприклад "No API key" або "Invalid API key". Введіть або виправте ключ у Налаштування → Скрапінг → Ключі API (лише для адміністраторів) і натисніть Зберегти ключі API. Збережений ключ показується зірочками; не чіпайте поле, щоб залишити його, або очистіть його й введіть новий ключ.

Масовий скрапінг

Масовий скрапінг завис

Натисніть Скасувати у вікні «Масовий скрапінг»; клацніть сповіщення про прогрес, щоб відкрити його. Гра, що обробляється, спершу завершується. Якщо воно все ще виконується, див. Завдання, схоже, зависло.

Більшість ігор "Пропущено"

  • Заповнити відсутнє пропускає гру, яку масовий скрапінг завершив за останні 24 години.
  • Гра, скрапінг якої не знайшов нічого нового, також вважається пропущеною.
  • Щоб проскрапити їх знову зараз, скористайтеся Повторний скрапінг; поставте позначку Зберегти наявні медіафайли, щоб зберегти ваші зображення.

Багато ігор "Невдало"

«Невдало» зазвичай означає, що жоден результат не був достатньо близьким, щоб його зберегти. Виберіть Вільно в Налаштування → Скрапінг → Скрапер → Фільтр збігів для масового скрапінгу та перевірте назви файлів. Переглядач журналів перелічує кожну гру, для якої не знайдено збігу.

"Скрапінг для … уже виконується"

Ця система вже скрапиться в тому самому режимі. Дочекайтеся завершення або скасуйте його. Скрапінг іншої системи стає в чергу й починається сам.

Заповнення ШІ

"ШІ не повернув даних. Перевірте ключ API та налаштування провайдера."

У Налаштування → Скрапінг → Ключі API виберіть Постачальник метаданих ШІ, введіть його ключ, натисніть Зберегти ключі API, потім Перевірити збережений ключ ШІ. Якщо служба ШІ відмовила, повідомлення натомість називає причину, наприклад, закінчилися кошти.

"ШІ не знайшов порожніх полів для заповнення"

Це не помилка: у грі немає порожніх полів, які Заповнення ШІ могло б заповнити.

Масове Заповнення ШІ зупинилося саме

Воно зупиняється після трьох ігор поспіль, що не отримали відповіді. Перевірте ключ кнопкою Перевірити збережений ключ ШІ, потім запустіть його знову. Ігри, які вже заповнено, зберігають отримане.

Зображення

Після скрапінгу бракує зображень

Зображення, яке не вдалося завантажити, пропускається без повідомлення; причину показує Переглядач журналів. Переконайтеся, що RetroDB може записувати до своєї папки медіа (static/images/, якщо ви її не переносили). У Linux або macOS команда chmod -R u+rwX static/images/ дає вашому обліковому запису право запису, не позначаючи зображення як програми.

Масштабування, схоже, не працює

  • Перше масштабування завантажує модель Real-ESRGAN, тому потрібен доступ до інтернету.
  • GPU потребує робочих драйверів (CUDA для NVIDIA, ROCm для AMD). Якщо GPU не спрацював, масштабування переходить на CPU.
  • Якщо масштабування взагалі не може працювати, RetroDB натомість збільшує зображення простим способом (Lanczos). Причину показує logs/upscale_worker.log.

Запуск ігор

Гра відкривається на іншому комп'ютері

Грати запускає емулятор на комп'ютері, де працює RetroDB, а не на пристрої, на якому ви натиснули кнопку.

"Програму емулятора не знайдено в PATH"

На сторінці «Емулятори» в розділі Зареєстровані емулятори відредагуйте емулятор і впишіть, де лежить програма, у поле Розташування програми. Або додайте теку, де вона лежить, у Теки емуляторів. Для RetroArch натисніть Автовизначення на картці RetroArch, потім Зберегти.

"Для системи … не налаштовано емулятор" або "Емулятор … вимкнено"

Виберіть емулятор для системи в розділі Прив'язка до систем на сторінці «Емулятори» або ввімкніть емулятор у розділі Зареєстровані емулятори. Якщо для гри задано емулятор, якого більше немає, очистьте цей вибір у її вікні «Редагувати гру».

"… ядро RetroArch для неї не задано" або "Ядро RetroArch не знайдено"

На сторінці «Емулятори» перевірте, що картка RetroArch указує на папку з вашими ядрами (Автовизначення заповнює її), потім натисніть Зберегти. Установіть відсутнє ядро власним завантажувачем ядер RetroArch. Або виберіть для системи інший емулятор у розділі Прив'язка до систем.

"Файл ROM не знайдено" або "Шлях до ROM поза налаштованими папками сканування"

Файл було переміщено або видалено після останнього сканування, або він лежить поза вашою папкою ROM. Поверніть його до папки системи й проскануйте бібліотеку знову.

"Ця гра вже запущена"

Закрийте вікно емулятора або погодьтеся на пропозицію закрити його й почати знову.

"Не вдалося завантажити ядро для …"

Кнопка «Грати» в RetroDB завантажує відсутнє ядро під час першого запуску, якщо на сторінці «Емулятори» не вимкнено Завантажувати відсутнє ядро після натискання «Грати». Перевірте підключення до інтернету й натисніть «Грати» знову або натисніть Встановити ядра для моїх систем на сторінці «Емулятори».

Чити

"Для цієї гри читів не знайдено."

Завантажте пакет читів для емулятора на картці «Чити» сторінки «Емулятори» або імпортуйте туди теку власних читів. Чити працюють у плеєрі, DuckStation, PCSX2 і MAME. Для MAME імпортуйте збірку читів з mamecheat.co.uk.

Увімкнений чит нічого не робить

Чити застосовуються під час наступного натискання «Грати». Увімкнений чит вимикає хардкорний режим RetroAchievements, поки ви граєте.

"Запустіть … один раз, щоб він створив свої налаштування, потім грайте знову."

DuckStation або PCSX2 ще не створив свою теку налаштувань. Запустіть емулятор один раз окремо, потім натисніть «Грати» знову.

Досягнення та трофеї

Синхронізація RetroAchievements зависла або чекає

Одночасно виконується одне завдання RetroAchievements; решта чекає в черзі в сповіщенні про прогрес. Його кнопка зупинки завершує поточне завдання, а в кожного завдання, що чекає, є кнопка Видалити з черги.

"RetroAchievements не налаштовано"

Збережіть ім'я користувача RetroAchievements і ключ веб-API у Налаштування → Обліковий запис → Мій профіль → Налаштування RetroAchievements.

"RetroAchievements не виконав вхід"

Для входу під час гри потрібен ваш пароль RetroAchievements, а не ключ API. Вхід набуває чинності під час наступного натискання «Грати».

"Ігор не знайдено. Перевірте, що ваш профіль Steam і дані про ігри встановлено як публічні."

На сайті Steam установіть для вашого профілю та даних про його ігри значення «Публічні». Ваш ключ Steam і 17-значний Steam ID вводяться в Налаштування → Обліковий запис → Мій профіль → Steam.

"OpenXBL не прийняв цей ключ"

  • Скопіюйте ключ ще раз із xbl.io і вставте його в Налаштування → Обліковий запис → Мій профіль → Xbox.
  • «Досягнуто погодинного ліміту OpenXBL» означає, що ключ уже використав свої 150 запитів цієї години. Синхронізуйте знову пізніше; почнеться з ігор, які ще не синхронізовано.

"Помилка автентифікації PSN"

  • Sony більше не приймає ваш збережений токен NPSSO. Отримайте новий за кроками в Налаштування → Обліковий запис → Мій профіль → PlayStation Network, потім натисніть Зберегти мій профіль.
  • RetroDB сам підтримує вхід, доки Sony приймає токен. Щоб замінити токен, який ще працює, спершу вийдіть із PlayStation.

Синхронізація трофеїв PSN зависла

У оновлення PSN у сповіщенні про прогрес є кнопки зупинки. У повної синхронізації трофеїв їх немає; її завершує перезапуск RetroDB.

Усі Трофеї колекціонера показуються як незароблені

Натисніть Оновити прогрес на сторінці «Трофеї колекціонера». Відкриття сторінки їх не рахує.

"Не знайдено збігу HowLongToBeat для …"

Введіть у поле пошуку назву, яку використовує HowLongToBeat, і знайдіть знову. Якщо HowLongToBeat повідомив про забагато запитів, RetroDB чекає 15 хвилин, перш ніж запитати знову, і до цього часу пошук нічого не знаходить.

Музей та інструменти ROM

"Провайдера ШІ не налаштовано"

Музей пише свої сторінки за допомогою провайдера ШІ, указаного в Налаштування → Скрапінг → Ключі API. Налаштуйте його, потім згенеруйте знову.

Генерація музею зависла

Натисніть Скасувати під індикатором прогресу на сторінці «Музей».

"chdman не знайдено. Установіть інструменти MAME."

Установіть інструменти MAME, до яких входить chdman, або вкажіть його розташування в Інструменти ROM → Налаштування.

"Ці результати сканування застаріли. Проскануйте знову, потім видаляйте."

Запустіть сканування знову, потім видаляйте з нових результатів.

Облікові записи та вхід

"Забагато спроб входу. Спробуйте пізніше."

Після п'яти неправильних паролів за п'ять хвилин зачекайте п'ять хвилин і спробуйте знову.

Забутий пароль

Скидання електронною поштою немає. Адміністратор задає новий пароль у Налаштування → Обліковий запис → Керування користувачами. Якщо єдиний адміністратор забув свій, відновіть резервну копію, створену, коли пароль був відомий.

"You do not have permission to access this feature"

Ваша роль не включає цю функцію. Адміністратор може змінити вашу роль у Налаштування → Обліковий запис → Керування користувачами.

База даних, резервні копії та оновлення

Помилки бази даних

  1. Створіть резервну копію, якщо можливо (Налаштування → Бібліотека → Резервне копіювання)
  2. Спробуйте Налаштування → Система → Обслуговування → Оптимізувати базу даних. Це може не вдатися, поки завдання пише в базу; дочекайтеся завершення завдань і спробуйте знову.
  3. Перевірте права доступу до файлів у папці database/
  4. Останній засіб: відновіть з резервної копії

"Виконується фонове завдання. Дочекайтеся його завершення перед відновленням."

Дайте завданню завершитися або зупиніть його зі сповіщення про прогрес, потім відновлюйте. Після відновлення перезапустіть RetroDB.

"Ця копія RetroDB — це git-checkout. Оновіть її командою git pull."

Засіб оновлення встановлюється лише поверх завантаженого випуску. Копія, створена через git, оновлюється командою git pull.

Оновлення не вдалося

Невдале завантаження нічого не встановлює; натисніть Завантажити оновлення знову. Невдале встановлення саме повертає стару версію й пояснює причину. Подробиці є в logs/update.log.

Сторінки та швидкість

Сторінка повільна або не відповідає

  • Великі колекції можуть завантажуватися довше — нескінченне прокручування завантажує партіями по 100
  • Спробуйте оновити сторінку, щоб очистити накопичену пам'ять
  • Перевірте консоль браузера на наявність помилок JavaScript
  • Спробуйте перейти на тему з легшим ефектом полотна (наприклад, Amber або Elite)
  • Ефекти полотна автоматично визначають обладнання; менш потужні пристрої використовують резервний варіант на CPU зі зниженою частотою кадрів

Поради щодо продуктивності

  • Тримайте свій браузер оновленим для найкращої продуктивності
  • Закривайте інші вкладки браузера під час роботи з дуже великими колекціями
  • Використовуйте фільтри систем, щоб зменшити кількість ігор, що відображаються одночасно
  • Періодично запускайте оптимізацію бази даних після великих операцій (скрапінг, очищення, імпорт)

Безпека та відмова від відповідальності

Найкращі практики безпеки

  • Змініть типовий пароль — Типовий пароль адміністратора (admin) слід змінити одразу після першого входу. Використовуйте надійний пароль довжиною щонайменше 12 символів.
  • Використовуйте зворотний проксі-сервер HTTPS — RetroDB сам по собі не надає TLS/SSL. Розмістіть його за зворотним проксі-сервером (наприклад, Nginx, Caddy, Traefik) з увімкненим HTTPS, щоб шифрувати трафік між клієнтами та сервером.
  • Обмежте мережевий доступ — Уникайте відкриття прямого доступу до RetroDB з публічного інтернету. Використовуйте VPN або обмежте доступ вашою локальною мережею. Якщо потрібен віддалений доступ, використовуйте зворотний проксі-сервер з автентифікацією.
  • Регулярно робіть резервні копії — Використовуйте вбудовану функцію резервного копіювання в Налаштуваннях для створення періодичних резервних копій бази даних. Зберігайте резервні копії в місці, окремому від застосунку.
  • Тримайте RetroDB оновленим — Регулярно перевіряйте наявність нових випусків. Виправлення безпеки та вдосконалення включені до оновлень.
  • Захищайте свої ключі API — Ключі API зберігаються в data/scraper_settings.json. Переконайтеся, що цей файл не є публічно доступним. Ніколи не діліться своїм config.py або файлами токенів.

Вбудовані функції безпеки

  • Хешування паролів — Паролі хешуються за допомогою PBKDF2 (ніколи не зберігаються у відкритому вигляді)
  • Обмеження швидкості входу — Захист від перебору паролів на кінцевій точці входу
  • Перевірка шляхів — Усі файлові операції використовують допоміжні функції safe_path та safe_filename для запобігання атакам обходу каталогів
  • Параметризовані запити — Усі запити до бази даних використовують параметризовані вирази для запобігання SQL-ін'єкціям
  • Захист від XSS — Модальні діалоги використовують безпечну побудову DOM; введені користувачем дані екрануються
  • Захист від бомб декомпресії зображень — Максимальна кількість пікселів зображення обмежена для запобігання вичерпанню пам'яті через шкідливі зображення
