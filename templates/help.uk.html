Встановлення

Системні вимоги

  • Python 3.8+ з pip
  • Веб-браузер (Chrome, Firefox, Safari, Edge)
  • Операційна система: Linux, Windows 10/11 або macOS

Швидке встановлення

  1. Розпакуйте ZIP-архів RetroDB у папку на свій вибір
  2. Відкрийте термінал/командний рядок у цій папці
  3. Запустіть: python install.py
  4. Запустіть сервер:
    • Linux: ./start.sh
    • Windows: подвійний клік на start.bat
    • macOS: подвійний клік на start.command
  5. Відкрийте http://localhost:5000 у браузері

Графічний інсталятор

У Linux можна також запустити ./setup.sh, щоб відкрити майстер графічного встановлення. Він автоматично перевіряє наявність Python/pip/tkinter, а потім проведе вас через усі кроки налаштування з візуальним журналом прогресу.

Що робить install.py

  • Перевіряє наявність Python 3.8+ і pip
  • Встановлює залежності Python з requirements.txt
  • Створює config.py з файлу-прикладу
  • Створює необхідні папки (базу даних, журнали, папки медіа)
  • Збирає пакети CSS і JS

Початок роботи

Первинне налаштування

Під час першого запуску RetroDB показує Майстер налаштування, який проведе вас через:

  1. Обліковий запис адміністратора — Створіть ім'я користувача та пароль
  2. Шлях до бібліотеки — Вкажіть папку з ROM
  3. Інтеграція з ES-DE — За бажанням прив'яжіть списки ігор та медіа ES-DE
  4. Ключі API — За бажанням додайте ключі API скраперів

Після завершення роботи майстра натисніть "Сканувати бібліотеку" на панелі приладів, щоб знайти ваші ROM.

Швидкий початок роботи

  1. Скануйте бібліотеку, щоб імпортувати ROM
  2. Переглядайте ігри за системою або всі ігри в бібліотеці
  3. Скрапте метадані окремо або скористайтеся масовим скрапінгом
  4. Організовуйте ігри за допомогою тегів, списків і списку бажань
  5. Відстежуйте прогрес за допомогою статусу проходження та досягнень

Структура бібліотеки ROM

RetroDB очікує, що ваші ROM організовані у папках систем усередині шляху до бібліотеки:

ROM Library/
  nes/
    Super Mario Bros. (USA).nes
  snes/
    Chrono Trigger (USA).sfc
  psx/
    Final Fantasy VII (USA)/
      Final Fantasy VII (USA) (Disc 1).chd
      Final Fantasy VII (USA) (Disc 2).chd

Кожна папка системи повинна містити файл ES-DE systeminfo.txt, який визначає підтримувані розширення файлів. RetroDB читає цей файл під час сканування, щоб визначити, які файли є коректними ROM для кожної системи.

Порада: Якщо ви вже скрапили дані за допомогою ES-DE, RetroDB може імпортувати ці дані! Налаштуйте шляхи ES-DE в Налаштування → Інтеграція з ES-DE, або під час роботи майстра налаштування.

Примітки щодо платформ

Linux

  • Протестовано на Ubuntu, Fedora, openSUSE та Arch Linux
  • Інструменти ROM потребують: sudo apt install p7zip-full unrar mame-tools (Debian/Ubuntu) або еквівалент для вашого дистрибутива
  • Якщо використовується системний Python, інсталятор автоматично обробляє --break-system-packages
  • Підтримується прискорення ROCm GPU для відеокарт AMD (масштабування зображень Real-ESRGAN)

Windows

  • Завантажте Python з python.org (позначте "Add to PATH" під час встановлення)
  • Інструменти ROM: встановіть 7-Zip, WinRAR та MAME (для chdman)
  • Використовуйте start.bat для запуску або виконайте python app.py з командного рядка

macOS

  • Python 3 можна встановити через Homebrew: brew install python3
  • Інструменти ROM: brew install p7zip unrar rom-tools
  • Подвійний клік на start.command у Finder для запуску
  • Підтримується прискорення CoreML для Apple Silicon (масштабування зображень Real-ESRGAN)

  • Теми перевизначають CSS-змінні кольорів — усі елементи інтерфейсу адаптуються автоматично
  • Ефекти полотна включають автоматичне визначення рівня обладнання (високий/середній/низький) з апаратним прискоренням GPU за наявності та резервним варіантом на CPU для менш потужних пристроїв
  • Ефекти призупиняються, коли вкладка не видима, для економії ресурсів

Панель приладів

Оцінка стану колекції

Кругова шкала прогресу показує загальний стан вашої колекції у відсотках, з кольоровим кодуванням за якістю:

  • Зелений (80%+) — Відмінне покриття метаданих
  • Блакитний (60–79%) — Гарне покриття з деякими прогалинами
  • Помаранчевий (40–59%) — Помірне покриття, варто розглянути масовий скрапінг
  • Червоний (<40%) — Значні прогалини в метаданих

Нижче міні-шкали розбивки показують повноту обкладинок, повноту описів і покриття досягнень.

Огляд статистики

Картки з швидким переглядом, що показують:

  • Усього систем — Кількість платформ у вашій бібліотеці
  • Усього ігор — Загальна кількість ігор (без урахування бонусних дисків)
  • Відсутні метадані — Ігри, які ще не скраплено
  • Завершено — Ігри зі скрапленими метаданими

Розділи останньої активності

Прокручувані розділи, що показують вашу останню активність (кожен з'являється лише за наявності відповідних ігор):

  • Зараз граю — Ігри, позначені як "В процесі"
  • Нещодавно додані — Останні ігри, додані до бібліотеки
  • Нещодавно переглянуті — Ігри, які ви нещодавно відкривали
  • Нещодавно скраплені — Ігри з нещодавно отриманими метаданими

Швидкі дії

  • Сканувати бібліотеку — Сканувати папки ROM на наявність нових ігор
  • Випадкова гра — Обрати випадкову гру з вашої бібліотеки

Статус API

Показує статус з'єднання всіх налаштованих скраперів та API. Офлайн або неправильно налаштовані API показують банер попередження з посиланням на Налаштування.

Відновлення завдань

Якщо RetroDB перезапускається під час виконання фонових завдань (масовий скрапінг, синхронізація RA, зміна розміру зображень тощо), перервані завдання з'являються в банері відновлення. Варіанти:

  • Відновити — Перезапустити окреме перерване завдання
  • Відновити все — Перезапустити всі перервані завдання
  • Відхилити — Прибрати окреме завдання зі списку відновлення
  • Відхилити все — Прибрати всі перервані завдання

Огляд систем

Сітка систем

Сторінка "Системи" показує всі платформи у вашій бібліотеці у вигляді карток в адаптивній сітці масонрі. Кожна картка показує:

  • Логотип системи (налаштовується в Налаштування → Персоналізація → Логотипи)
  • Кількість ROM та кількість нескраплених
  • Значок типу системи — Консоль, Портативна, Комп'ютер, Аркада або Рушій
  • Значки можливостей — Підтримка RetroAchievements, Локальні трофеї (RPCS3)

Модальне вікно характеристик системи

Натисніть кнопку інформації на будь-якій картці системи, щоб переглянути детальні апаратні характеристики:

  • Зображення обладнання (фото консолі/системи)
  • Виробник і дата випуску
  • CPU, GPU, RAM, VRAM
  • Роздільна здатність, глибина кольору, звуковий чип
  • Тип носія (картридж, диск тощо)

Фільтрація та пошук

  • Текстовий пошук — Фільтрація за назвою системи або назвою папки
  • Фільтр за типом — Консоль, Портативна, Комп'ютер, Аркада, Рушій
  • Фільтр за можливостями — Підтримка RetroAchievements, Локальні трофеї
  • Панель результатів фільтрації показує "X із Y систем"
  • Фільтри зберігаються між перезавантаженнями сторінки через сховище сеансу

Список ігор за системою

Натисніть на будь-яку картку системи, щоб переглянути її ігри. Список ігор за системою має ті самі можливості, що й повна сторінка бібліотеки — нескінченне прокручування, пошук, усі опції фільтрації, масовий вибір і сортування. Заголовок системи показує назву системи, кількість ігор і значок типу системи.

Посібник з налаштування ключів API

Ключі API необов'язкові, але дозволяють отримати розширені метадані та додаткові можливості. Налаштуйте їх в Налаштування → Скрапінг → Ключі API.

Скрапери метаданих

TheGamesDB

  1. Перейдіть на api.thegamesdb.net/key.php
  2. Запросіть ключі API (безкоштовно, схвалюється вручну) — ви отримаєте Public та Private ключ
  3. Введіть обидва ключі в Налаштування → Ключі API → TheGamesDB
  4. Public-ключ (ліміт запитів на IP) використовується як основний ключ для скрапінгу
  5. Private-ключ (спільний місячний пул) використовується як резервний варіант, якщо публічний ключ не спрацював

IGDB (через Twitch)

  1. Створіть обліковий запис Twitch на twitch.tv
  2. Перейдіть на dev.twitch.tv/console

Налаштування

Налаштування організовані в 6 вкладок, кожна з кількома підрозділами.

Вкладка "Обліковий запис"

  • Мій профіль — Завантаження/видалення аватара, відображуване ім'я, інформація про роль, зміна пароля
  • RetroAchievements — Ім'я користувача та ключ API для інтеграції з RA
  • PSN — Кукі NPSSO для синхронізації трофеїв PlayStation Network
  • Часовий пояс — Встановіть часовий пояс для відображення дат у застосунку
  • Користувачі — Керування користувачами: додавання, редагування, видалення користувачів і призначення ролей (лише для адміністратора)

Вкладка "Бібліотека"

  • Шляхи — Шлях до бібліотеки ROM, розташування бази даних
  • Відображення — Вибір теми, стиль обкладинки (2D/3D), бажана система вікових рейтингів, кількість елементів на сторінці
  • Іменування ROM — Розташування артикля (провідний/кінцевий "The"), список опцій регіонів, регіон за замовчуванням, конвенції іменування
  • Резервне копіювання — Створення та відновлення резервних копій бази даних

Вкладка "Скрапінг"

  • ES-DE — Шляхи до списку ігор і медіа ES-DE для локального імпорту даних
  • Скрапер — Увімкнення/вимкнення окремих скраперів, упорядкування пріоритету перетягуванням, налаштування обмеження швидкості для кожного скрапера
  • Ключі API — Усі облікові дані скраперів (TGDB, IGDB, RAWG, ScreenScraper), вибір постачальника ШІ та вибір моделі (Gemini, OpenAI, Claude)

Вкладка "Дані"

  • Статистика — Огляд статистики бібліотеки (всього ігор, систем, використання сховища)
  • Трофеї — Налаштування шляху до трофеїв RPCS3 для локального сканування трофеїв PS3
  • Випадаючі списки — Налаштування опцій регіону та інших значень випадаючих списків, що використовуються в застосунку
  • Нормалізація — Правила нормалізації жанрів і режимів — додавайте власні відповідності для стандартизації результатів скраперів

Вкладка "Персоналізація"

  • Сповіщення — Налаштування тайм-ауту сповіщень (успіх, інформація, попередження, помилка — кожен налаштовується окремо)
  • Контролери — Керування бібліотекою контролерів, встановлення контролерів за замовчуванням для кожної системи, додавання власних контролерів. Контролери за замовчуванням перевизначають скраплені/ШІ-значення під час отримання метаданих.
  • Логотипи — Налаштування логотипів систем — імпорт логотипів систем або оновлення до типових

Вкладка "Система"

  • Обслуговування — Оптимізація бази даних (VACUUM/ANALYZE), очищення осиротілих медіа, очищення відсутніх ROM, очищення скраплених даних, очищення імпортів CLZ, масова стандартизація зображень
  • Сервер — Конфігурація сервера (хост, порт, режим налагодження)
  • Журналювання — Налаштування рівня журналювання для різних категорій
  • Усунення несправностей — Очищення застряглого масового скрапінгу, черги синхронізації RA, оновлення PSN, генерації музею, перезапуск сервера
Порада: Вимкнені скрапери не будуть викликати попередження "API офлайн" на панелі приладів. Якщо ви не використовуєте скрапер, вимкніть його в Налаштування → Скрапінг → Скрапер, а не видаляйте ключ API.

Гібридний скрапінг

RetroDB автоматично поєднує дані з кількох джерел для максимального покриття метаданих:

  • Текстові метадані з джерела з найвищим пріоритетом
  • Зображення та медіа з другорядних джерел, якщо основне джерело їх не має
  • Автоматичне заповнення прогалин серед скраперів для максимального покриття
  • Назва для сортування генерується автоматично з назви гри під час скрапінгу

Робота з медіа

  • Поля медіа (обкладинка, 3D-обкладинка, скріншоти, fanart, відео, посібник) ніколи не замінюються під час звичайного скрапінгу — заповнюються лише коли порожні
  • Скріншоти завжди додаються, ніколи не замінюються
  • Щоб повторно завантажити медіа, спочатку очистіть наявне зображення в модальному вікні редагування, а потім скрапте повторно
  • Режим Повторний повний скрапінг перевизначає це і замінює все
  • Застарілі посилання на медіа (файл видалено, але назва файлу все ще в базі даних) автоматично очищуються перед скрапінгом, щоб можна було завантажити нові медіа
  • Завантажені зображення автоматично стандартизуються до цільових розмірів (дивіться Стандартизація зображень)

Пріоритет скраперів

Налаштуйте, які скрапери запускаються першими та які увімкнено/вимкнено, в Налаштування → Скрапінг → Скрапер. Перетягніть, щоб змінити порядок пріоритету. Вимкнені скрапери не будуть використовуватися під час скрапінгу та не викликатимуть попереджень про статус API на панелі приладів.

Обмеження швидкості

Кожен скрапер має налаштовувані обмеження швидкості для запобігання обмеженню з боку API. Типові затримки встановлені консервативно. Зменшуйте затримки на власний ризик — перевищення лімітів швидкості API може призвести до тимчасового блокування відповідним сервісом.

Масовий скрапінг

Початок масового скрапінгу

  1. Перейдіть на будь-яку сторінку системи або бібліотеки
  2. Натисніть "Select", щоб увійти в режим вибору
  3. Виберіть ігри окремо або скористайтеся швидким вибором:
    • Вибрати все — Усі видимі ігри
    • Вибрати нескраплені — Лише ігри без метаданих
  4. Оберіть режим: Заповнити відсутнє або Повторний повний скрапінг
  5. Натисніть "Scrape Selected"

Керування

  • Пауза / Продовжити — Призупинити або продовжити скрапінг
  • Скасувати — Зупинити повністю
  • У фоні — Згорнути та продовжити перегляд, поки триває скрапінг

Спливаюче сповіщення

Під час роботи у фоні постійне спливаюче сповіщення показує прогрес на всіх сторінках:

  • Назва поточної гри, кількість прогресу та статистика результатів (успіх, помилка, пропущено)
  • Керування паузою/скасуванням доступне з будь-якої сторінки
  • Натисніть на сповіщення, щоб повернутися до вікна скрапінгу

Система черги

Декілька масових скрапінгів автоматично стають у чергу:

  • Почніть новий скрапінг, поки виконується інший — він стає в чергу
  • Черга показується у сповіщенні з кількістю завдань, що очікують
  • Завдання обробляються автоматично по черзі
  • Використовуйте менеджер черги для перегляду, зміни порядку або скасування завдань у черзі

Опції скрапінгу

  • Заповнити лише відсутнє — Заповнювати лише порожні поля метаданих, зберігаючи наявні дані
  • Повторний повний скрапінг — Замінити всі поля, включно з медіа (завантажує нові зображення та відео)
  • Перевіряти RetroAchievements — Також перевіряти наявність наборів досягнень RetroAchievements під час скрапінгу

Відновлення завдань

Якщо RetroDB перезапускається під час виконання завдання, перервані завдання з'являються в банері відновлення на панелі приладів. Натисніть "Resume" для окремих завдань або "Resume All", щоб перезапустити їх усі. Спливаюче сповіщення про прогрес з'являється одразу після відновлення.

Заповнення ШІ

Що це робить

Заповнення ШІ використовує велику мовну модель (Gemini, OpenAI або Claude), щоб інтелектуально заповнити відсутні або неповні метадані гри. Це розумніше за звичайний скрапінг, оскільки використовує контекстні знання про гру для надання точних даних, яких можуть не мати скрапери.

Як використовувати

  1. Відкрийте модальне вікно деталей гри (або повну сторінку деталей)
  2. Натисніть "AI Fill" (потребує налаштованого ключа API ШІ в Налаштуваннях)
  3. ШІ аналізує назву гри та систему, а потім заповнює відсутні поля
  4. Перегляньте результати — зміни зберігаються автоматично

Що може надати заповнення ШІ

  • Жанр, опис, розробника, видавця, дату випуску
  • Кількість гравців, режими гри (одиночна гра, багатокористувацька, кооператив тощо)
  • Інформацію про кампанію та структуру гри
  • Усі 8 систем вікових рейтингів (ESRB, PEGI, CERO, USK, ACB, FPB, GRAC, ClassInd)
  • Регіон, франшизу, схожі ігри
  • Підтримку контролерів, тип збереження
  • Перспективу (від першої особи, вигляд зверху, платформер з горизонтальним прокручуванням тощо), вимірність (2D, 3D)
  • Інформацію про видання, оцінки критиків і користувачів

Логіка розумного заповнення

  • Порожні поля заповнюються завжди
  • Наявні дані користувача ніколи не перезаписуються
  • Схожі ігри завжди оновлюються (дані ШІ надійніші для цього поля)
  • Перехресно зіставлені рейтинги — Якщо відома одна система рейтингів, порожні рейтинги в інших системах автоматично заповнюються за допомогою перехресного зіставлення рівнів зрілості
  • Назва для сортування генерується автоматично при заповненні
  • Поле Кількість гравців нормалізує діапазони (наприклад, "1-4" стає 4)

Нормалізація жанрів

Заповнення ШІ використовує канонічні форми жанрів із назвами через дефіс:

  • First-Person-Shooter, Shoot-em-up, Beat-em-up
  • Hack-n-Slash, Board-Card, Real-Time Strategy

Вимоги

Потрібно налаштувати принаймні один ключ API постачальника ШІ в Налаштування → Скрапінг → Ключі API. Найдешевший рівень моделі (Gemini Flash Lite, GPT-4o Mini або Claude Haiku) добре працює для метаданих.

Фільтрація та пошук

Пошук

Пошук фільтрує ігри за назвою (та назвою для сортування). Натисніть /, щоб перевести фокус на поле пошуку. Результати оновлюються в реальному часі з затримкою 300 мс.

Фільтр за джерелом

Фільтруйте ігри за джерелом імпорту:

  • Файли ROM — Ігри з вашої бібліотеки ROM
  • Імпорти CLZ — Фізичні ігри, імпортовані з CLZ
  • Імпорти Steam — Ігри, імпортовані зі Steam
  • Імпорти Xbox — Ігри, імпортовані з Xbox
  • Імпорти PSN — Ігри, імпортовані з PlayStation Network

Кнопки фільтрів

Кожен фільтр відкриває модальне вікно з усіма унікальними значеннями у вашій бібліотеці з підрахунком. Фільтри підтримують два режими:

  • Включити (IS) — Показувати лише ігри, що відповідають обраному значенню
  • Виключити (IS NOT) — Приховувати ігри, що відповідають обраному значенню

Перемикайтеся між режимами включення та виключення за допомогою перемикача в модальному вікні фільтра.

Ігри завантажуються партіями по 100 під час прокручування. Нові сторінки завантажуються автоматично, коли ви наближаєтеся до кінця. Зміна фільтрів або пошуку миттєво скидає та перезавантажує результати.

Збереження стану

Ваші поточні фільтри, пошуковий запит і положення прокручування зберігаються в сховищі сеансу. Вони відновлюються, коли ви повертаєтеся на сторінку або оновлюєте її.

Деталі гри

Модальне вікно деталей гри

Клацання на будь-яку картку гри відкриває модальне вікно деталей з кешованим швидким переглядом. Модальне вікно показує:

  • Обкладинку (2D і 3D), фон fanart
  • Опис та інформацію про випуск
  • Значки розробника, видавця, жанру
  • Кількість гравців, режими гри, структуру гри
  • Зображення вікового рейтингу (з вашої бажаної системи, з резервним перехресним зіставленням)
  • Галерею скріншотів з навігацією клавіатурою (← →)
  • Відео трейлера (якщо доступне)
  • Оцінки часу проходження HLTB (основна історія, основна + додатковий контент, повне проходження)
  • Статус і прогрес RetroAchievements
  • Схожі ігри (клікабельні посилання)
  • Деталі підтримки контролерів
  • Теги, призначені грі
  • Розмір файлу та шлях до ROM

Повна сторінка деталей гри

Натисніть на посилання назви гри або перейдіть із хлібних крихт, щоб переглянути повну сторінку деталей гри. Додаткові можливості на повній сторінці включають:

  • Заголовок з фоном fanart з навігацією хлібними крихтами
  • Значки платформи імпорту — Показує CLZ Import, Steam Import, Xbox Import або PSN Import з логотипами платформ, де застосовно
  • Індикатор бонусного диска — Показує значок і посилання "Part of:" на батьківську гру з мініатюрою
  • Кнопка видалення — Видалити гру з бази даних (з підтвердженням)
  • Кнопка очищення — Очистити всі скраплені метадані, зберігаючи запис ROM

Модальне вікно редагування

Натисніть Edit (або клавішу e), щоб відкрити модальне вікно редагування, організоване в розділи:

  • Ідентичність — Назва, назва для сортування (генерується автоматично, але редагована), франшиза, видання
  • Інформація про випуск — Дата випуску, регіон (з налаштовуваного випадаючого списку)
  • Ігровий процес — Жанр (теги з множинним вибором), режими, структура гри, кількість гравців, розробник, видавець
  • Технічні дані — Контролери (множинний вибір), тип збереження, перспектива (множинне значення), вимірність (множинне значення)
  • Вікові рейтинги — Усі 8 систем рейтингів з офіційними зображеннями рейтингів та автоматичним перехресним зіставленням. Зміна одного рейтингу автоматично заповнює порожні рейтинги в інших системах.
  • Оцінки — Оцінка критиків, оцінка користувачів
  • Опис — Текст опису гри
  • Власні зображення — Завантаження власної обкладинки (2D), 3D-обкладинки та fanart. Очистіть наявні зображення, щоб дозволити повторний скрапінг.
  • Відео / Трейлер — Завантаження або посилання на відеотрейлер

Швидкі дії

  • Edit — Відкрити модальне вікно редагування (e)
  • Scrape — Отримати метадані з джерел скрапінгу (s)
  • AI Fill — Заповнити відсутні поля за допомогою ШІ (потребує ключа API ШІ)
  • Check for RA — Пошук набору досягнень RetroAchievements
  • HLTB Lookup — Знайти оцінки часу проходження з HowLongToBeat

Статус проходження

Відстежуйте прогрес за допомогою цих статусів (показані як значки на картках ігор):

  • Не розпочато — Ще не грали
  • В процесі — Наразі граєте
  • Зіграно — Грали, але не завершили
  • Завершено — Завершили основну гру
  • 100% — Завершили все

Порівняння ігор

Що це робить

Порівняння метаданих двох ігор поруч у вигляді таблиці. Корисно для перевірки якості метаданих, виявлення дублікатів або порівняння версій однієї гри для різних систем.

Як використовувати

  1. Перейдіть у розділ Порівняння (доступний зі сторінки бібліотеки)
  2. Знайдіть та оберіть першу гру
  3. Знайдіть та оберіть другу гру
  4. Перегляньте таблицю порівняння — відмінності виділено

Поля для порівняння

Система, розробник, видавець, дата випуску, жанр, франшиза, регіон, кількість гравців, режими, перспектива, вимірність, усі 8 вікових рейтингів, користувацький рейтинг, оцінка критиків, оцінки часу проходження, підтримка контролерів, тип збереження, розмір файлу, схожі ігри, опис та інше.

Колекції (Теги, Списки, Список бажань)

Теги

Створюйте власні кольорові теги для організації ігор. Теги працюють як ярлики — кожна гра може мати кілька тегів, а кожен тег може містити кілька ігор.

  • Створюйте теги з власними назвами та кольорами на сторінці Теги
  • Призначайте теги іграм через модальне вікно деталей гри
  • Натисніть на будь-який тег, щоб переглянути всі ігри з цим тегом
  • Редагуйте або видаляйте теги на сторінці керування тегами

Іменовані списки

Створюйте кураторські списки ігор із власним порядком. Списки схожі на плейлисти — ви керуєте точним порядком ігор.

  • Створюйте списки з назвою, описом та іконкою на сторінці Списки
  • Додавайте ігри до списків через модальне вікно деталей гри або сторінку списку
  • Перетягуйте, щоб змінити порядок ігор у списку
  • Сортуйте за власним порядком або за алфавітом

Список бажань

Відстежуйте ігри, які ви хочете придбати, фізично чи цифрово.

  • Додавайте ігри вручну з назвою, системою, нотатками та пріоритетом (1–5)
  • Елементи списку бажань можуть бути прив'язані до наявних ігор у бібліотеці, якщо їх знайдено
  • Сортуються за пріоритетом (найвищий спочатку), потім за датою додавання
Порада: Використовуйте теги для наскрізних ярликів (наприклад, "Улюблені", "Кооп на дивані", "Черга") і списки для конкретних кураторських колекцій (наприклад, "Топ-10 ігор SNES", "Ігри для стрімів").

Імпорт ігор

Імпортуйте колекції ігор із зовнішніх джерел. Доступ через Імпорт ігор на бічній панелі. Усі типи імпорту об'єднано на одній сторінці з вкладками.

Імпорт з CLZ Games

Імпортуйте вашу фізичну колекцію ігор із CLZ Games.

  1. Експортуйте вашу колекцію CLZ Games у PDF
  2. Перейдіть в Імпорт ігор → вкладка CLZ
  3. Завантажте PDF-файл
  4. Перегляньте розпізнані ігри
  5. Оберіть, які ігри імпортувати

Імпорти CLZ відстежуються окремо від ігор ROM (з використанням префікса clz_import/), що дозволяє каталогізувати як фізичні, так і цифрові колекції. Імпорти CLZ можна повністю очистити в Налаштування → Система → Обслуговування.

Імпорт зі Steam

Імпортуйте вашу бібліотеку ігор Steam та відстежуйте досягнення.

  1. Налаштуйте ключ Steam Web API та Steam ID у Налаштуваннях
  2. Перейдіть в Імпорт ігор → вкладка Steam
  3. Натисніть "Fetch Library", щоб отримати ваші ігри Steam
  4. Оберіть ігри для імпорту (дублікати виявляються автоматично)
  5. Імпортовані ігри позначаються їхнім Steam App ID для відстеження досягнень

Імпорт з Xbox

Імпортуйте вашу бібліотеку ігор Xbox через обліковий запис Microsoft.

  1. Перейдіть в Імпорт ігор → вкладка Xbox
  2. Натисніть "Sign In", щоб автентифікуватися через обліковий запис Microsoft (потік OAuth2)
  3. Історію ваших назв Xbox буде отримано автоматично
  4. Оберіть ігри для імпорту з виявленням дублікатів
  5. Імпортовані ігри позначаються їхнім Xbox Title ID для відстеження досягнень

Токени Xbox кешуються в data/xbox_tokens.json і оновлюються автоматично.

Імпорт з PSN

Імпортуйте вашу бібліотеку ігор PlayStation Network.

  1. Перейдіть в Імпорт ігор → вкладка PSN
  2. Введіть ваш кукі NPSSO (дивіться Трофеї → Автентифікація PSN для того, як його отримати)
  3. Натисніть "Fetch Library", щоб отримати ваші ігри PSN
  4. Оберіть ігри для імпорту

Після імпортування

  • Імпортовані ігри з'являються у вашій бібліотеці зі значками, специфічними для платформи
  • Використовуйте масовий скрапінг для отримання метаданих для імпортованих ігор
  • Відстеження досягнень/трофеїв автоматично прив'язується до вихідної платформи
  • Імпортовані ігри можна фільтрувати в бібліотеці за допомогою фільтра джерела
Порада: Після імпортування ігор з будь-якої платформи ви можете скрапити для них метадані за допомогою масового скрапінгу, так само як і для ігор ROM. Імпортовані ігри також можуть відстежувати досягнення з відповідних платформ.

RetroAchievements

Налаштування

  1. Створіть обліковий запис на retroachievements.org
  2. Згенеруйте ключ API в налаштуваннях профілю
  3. Введіть ім'я користувача та ключ API в Налаштування → Обліковий запис → RetroAchievements

Сторінка досягнень

  • Вкладки систем — Перегляд досягнень за платформою (запам'ятовує останню переглянуту вкладку)
  • Навігація за алфавітом — Перейдіть до ігор за першою літерою в межах кожної вкладки системи
  • Оновити прогрес — Синхронізувати прогрес досягнень з RetroAchievements
  • Загальна статистика — Отримані досягнення та бали за всіма системами
  • Прогрес по кожній грі — Перегляд відсотка завершення для кожної гри зі смугами прогресу

Черга синхронізації

Кілька синхронізацій систем можуть стояти в черзі:

  • Натисніть "Refresh Progress" на будь-якій системі, щоб почати або поставити синхронізацію в чергу
  • Якщо синхронізація вже виконується, нові запити ставляться в чергу автоматично
  • Черга обробляється автоматично після завершення поточної синхронізації
  • Спливаюче сповіщення показує поточний прогрес і кількість у черзі

Пошук ігор з досягненнями

  • Фільтр бібліотеки — Використовуйте фільтр "Has RA", щоб показувати лише ігри з досягненнями
  • Check for RA — У модальних вікнах деталей гри натисніть, щоб знайти набір досягнень
  • Масовий скрапінг — Увімкніть опцію "Check RA", щоб знаходити досягнення під час скрапінгу
  • Завдання оновлення RA — Скануйте всі ігри системи, щоб визначити, які підтримують RA

Деталі на рівні гри

Натисніть на будь-яку гру на сторінці досягнень, щоб побачити детальну інформацію про досягнення для цієї гри, включно з назвами окремих досягнень, описами, кількістю балів і статусом отримання.

Примітка: "Refresh Progress" синхронізує ваш прогрес для ігор, які вже прив'язані до RetroAchievements. Щоб знайти НОВІ набори досягнень, використовуйте "Check for RA" у модальних вікнах деталей гри або увімкніть цю опцію під час масового скрапінгу.

Досягнення Steam

Налаштування

  1. Імпортуйте ігри Steam через Імпорт ігор → Steam
  2. Переконайтеся, що ваш ключ Steam Web API налаштовано в Налаштуваннях

Сторінка досягнень

Переглядайте всі ваші ігри Steam з прогресом досягнень одним поглядом:

  • Загальна статистика — Усього ігор Steam, отримані досягнення, відсоток завершення
  • Прогрес по кожній грі — Смуги завершення для кожної гри

Деталі досягнень для кожної гри

Натисніть на будь-яку гру Steam, щоб побачити її окремі досягнення:

  • Значки, назви та описи досягнень
  • Статус розблоковано/заблоковано з мітками часу розблокування
  • Глобальний відсоток гравців, які розблокували кожне досягнення

Синхронізація

  • Синхронізуйте досягнення однієї гри з її сторінки деталей
  • Масова синхронізація всіх ігор Steam зі сторінки досягнень
  • Синхронізація виконується як фонове завдання з прогресом у спливаючому сповіщенні

Досягнення Xbox

Налаштування

  1. Імпортуйте ігри Xbox через Імпорт ігор → Xbox
  2. Автентифікація виконується через Xbox OAuth під час імпорту

Сторінка досягнень

  • Загальна статистика — Усього ігор Xbox, отримані досягнення, отриманий/загальний gamerscore, відсоток завершення
  • Прогрес по кожній грі — Отриманий gamerscore для кожної гри зі смугами прогресу

Деталі досягнень для кожної гри

Натисніть на будь-яку гру Xbox, щоб побачити її окремі досягнення:

  • Значки досягнень з окремими значеннями gamerscore
  • Статус розблоковано/заблоковано з мітками часу розблокування
  • Значки gamerscore на кожному досягненні

Синхронізація

  • Синхронізуйте одну гру або всі ігри Xbox масово
  • Виконується як фонове завдання зі спливаючими сповіщеннями
  • Загальний gamerscore оновлюється автоматично після кожної синхронізації

How Long to Beat

Використання

  1. Відкрийте модальне вікно деталей будь-якої гри
  2. Натисніть "Lookup HLTB"
  3. Оберіть правильну відповідність зі списку результатів
  4. Оцінки часу проходження зберігаються для гри

Категорії часу

  • Основна історія — Час завершення основної гри
  • Основна + додатковий контент — З додатковим контентом
  • Повне проходження — 100% усього

Де з'являються дані HLTB

  • Модальне вікно деталей гри — Оцінки часу проходження показані в інформації про гру
  • Повна сторінка деталей гри — Та сама інформація про час проходження
  • Аналітика → вкладка "Час проходження" — Аналіз часу проходження для всієї колекції
  • Порівняння ігор — Порівняння часу проходження поруч
Порада: Дані HLTB також показуються в Аналітиці на вкладці "Час проходження", даючи вам оцінки для всієї вашої колекції.

Трофеї PS3 / PSN

Локальні трофеї RPCS3

Відстежуйте трофеї, отримані в іграх PS3 через емулятор RPCS3.

  1. Встановіть шлях до трофеїв RPCS3 в Налаштування → Дані → Трофеї
  2. Натисніть "Scan Trophies", щоб імпортувати отримані трофеї
  3. Переглядайте списки трофеїв та деталі окремих трофеїв у розділі Трофеї RPCS3

RPCS3 читає дані трофеїв XML з вашої користувацької папки RPCS3 та автоматично зіставляє ігри з вашою бібліотекою.

Трофеї через API PSN

Синхронізуйте дані трофеїв PlayStation Network з вашого облікового запису PSN.

  1. Отримайте свій кукі NPSSO (див. нижче)
  2. Введіть його в Налаштування → Обліковий запис → PSN
  3. Ваша бібліотека трофеїв PSN буде отримана через API PlayStation
  4. Переглядайте прогрес трофеїв для кожної гри з підрахунком отримано/усього
  5. Деталі окремих трофеїв включають опис, рідкість і мітки часу розблокування

Автентифікація PSN (кукі NPSSO)

PSN використовує спеціальний автентифікаційний кукі, який називається токеном NPSSO. Щоб його отримати:

  1. Відкрийте веб-браузер і увійдіть на store.playstation.com
  2. Після входу перейдіть за адресою: https://ca.account.sony.com/api/v1/ssocookie
  3. На сторінці відобразиться JSON, що містить ваш токен NPSSO
  4. Скопіюйте значення npsso і вставте його в Налаштування → Обліковий запис → PSN

Після автентифікації RetroDB безпечно кешує токени доступу у власній базі даних (для кожного користувача) і автоматично оновлює їх — вам не потрібно вставляти NPSSO знову перед кожною синхронізацією. Сеанс залишається дійсним приблизно два місяці, і тепер RetroDB також автоматично оновлює його у фоновому режимі, тож за звичайного використання свіжий NPSSO знадобиться вкрай рідко.

Деталі трофеїв

  • Типи трофеїв: бронза, срібло, золото, платина
  • Значки трофеїв завантажуються та кешуються локально
  • Відсоток завершення для кожної гри
  • Мітки часу розблокування для кожного отриманого трофея

Масова синхронізація

Синхронізуйте всі трофеї ігор PSN одразу через фонове завдання. Прогрес показується у спливаючому сповіщенні. Обмеження швидкості (2,5 с між запитами) запобігає обмеженню з боку API PSN.

Музей

Що це таке

Інтерактивна енциклопедія ігрових систем, організована за поколіннями. Дізнайтеся про історію, характеристики та примітні ігри для кожної платформи у вашій колекції.

Головна сторінка

Головна сторінка Музею показує хронологію ігрових систем, згрупованих за поколіннями (1–9 покоління, портативні, аркадні, комп'ютери). Кожна картка системи показує зображення обладнання та кількість ігор з вашої бібліотеки.

Сторінки деталей системи

Натисніть на будь-яку систему, щоб переглянути її сторінку музею, яка включає:

  • Зображення обладнання — Фото консолі/системи
  • Технічні характеристики — CPU, GPU, RAM, роздільна здатність, тип носія
  • Історія — Згенерована ШІ розповідь про розробку системи, її запуск і спадщину
  • Топ-10 ігор — Найпримітніші тайтли системи (за оцінками критиків і пропозиціями ШІ)
  • Галерея контролерів — Зображення контролерів системи з описами

Генерація контенту ШІ

Контент Музею генерується за допомогою ШІ (Gemini, OpenAI або Claude). Ви можете генерувати контент для:

  • Однієї системи — Натисніть "Generate" на сторінці музею будь-якої системи
  • Масової генерації — Генеруйте контент для всіх систем одразу з головної сторінки (виконується як фонове завдання з прогресом у спливаючому сповіщенні)

Зображення контролерів

Зображення контролерів можна додати через:

  • Пошук зображень — Шукайте фото контролерів за допомогою Bing Image Search. Результати ранжуються за релевантністю (назва контролера + виробник + варіації системи).
  • Ручне завантаження — Завантажте власні зображення контролерів
  • Видалення фону — Автоматичне видалення фону за допомогою локального ШІ (бібліотека rembg) для прозорих зображень контролерів на будь-якому фоні
  • Поширення зображень — Коли знайдено зображення контролера, воно автоматично поширюється на той самий контролер в інших системах (спорідненні контролери)
  • Масове отримання — Отримати зображення для всіх контролерів системи одразу

Усі зображення контролерів стандартизуються до цільового розміру та зберігаються у форматі WebP.

Порада: Для генерації контенту потрібен ключ API ШІ. Музей використовує того ж постачальника ШІ, налаштованого в Налаштування → Скрапінг → Ключі API.

Звіти ROM

Що це робить

Перевіряє назви файлів ROM на відповідність стандартним конвенціям іменування та визначає потенційні проблеми. Доступ через Звіти ROM на бічній панелі.

Типи звітів

ВкладкаЩо перевіряє
Нестандартні назвиROM з назвами файлів, що не відповідають конвенціям іменування. Показує поточну назву файлу, виявлені проблеми та пропоновану виправлену назву.
Невідповідності назвROM, де назва файлу не відповідає скрапленій назві метаданих. Показує поточну назву файлу порівняно зі скрапленою назвою, регіоном, роком і розробником.

Що перевіряється

  • Неприпустимі символи в назвах файлів (: ? * / " < > | \)
  • Відсутні або неправильні теги регіону (наприклад, (USA), (Europe))
  • Відсутні теги року
  • Невідповідності назви файлу та назви в базі даних

Звіти можна сортувати за системою, назвою файлу та типом проблеми. Використовуйте їх, щоб підтримувати бібліотеку ROM організованою та послідовно іменованою.

Інструменти ROM

Доступ до центру інструментів ROM з бічної панелі. Кожен інструмент виконується як фонове завдання з оновленням прогресу в реальному часі, підтримкою паузи/відновлення та журналюванням.

Сканер архівів

Розпаковує архіви ROM (ZIP, 7Z, RAR) з опціями для:

  • Рекурсивного сканування підпапок
  • Видалення небажаних файлів після розпакування
  • Автоматичної генерації плейлистів M3U для багатодискових ігор

Потребує: 7z або unzip

Конвертер CHD

Конвертує образи дисків (ISO, BIN/CUE, GDI) у стиснутий формат CHD. Значно економить сховище, зберігаючи повну сумісність з емуляторами.

Потребує: chdman (з mame-tools)

Перевірка CHD

Перевіряє цілісність файлів CHD за допомогою перевірки хешів. Виявляє пошкоджені або неповні конвертації.

Потребує: chdman

Пошук дублікатів

Знаходить дублікати ROM за хешем або назвою файлу, з опціями пріоритезації за тегами регіону.

Без зовнішніх залежностей

Організатор багатодискових ігор

Організовує багатодискові ігри в підпапки та генерує плейлисти M3U для емуляторів, які їх підтримують. Корисно для таких систем, як PlayStation і Saturn.

Без зовнішніх залежностей

Видалення дублікатів скріншотів

Знаходить і видаляє дублікати скріншотів у вашій бібліотеці ігор, щоб звільнити місце в сховищі.

  • Точний хеш (MD5) — Визначає лише ідентичні файли
  • Візуальна схожість — Порівняння за перцептивним хешем із налаштовуваним порогом (1–20, менше значення = суворіша відповідність)

Сканує поступово з живою статистикою, що показує кількість сканованих ігор, кількість дублікатів і місце, яке можна звільнити. Результати згруповано за грою та системою. Ви можете обрати, який файл зберегти в кожній групі дублікатів, або скористатися "Select Largest", щоб автоматично зберегти версію з найвищою роздільною здатністю.

Без зовнішніх залежностей

Зміна розміру зображень

Стандартизує медіа ігор до узгоджених цільових розмірів. Дивіться Стандартизація зображень для повних деталей.

Без зовнішніх залежностей (масштабування ШІ на основі Python)

Заповнення альтернативних назв

Сканує бібліотеку на предмет ігор, у яких поле альтернативні назви порожнє, і заповнює його з IGDB / TGDB / ScreenScraper. Корисно після імпортування великого каталогу або міграції з іншого інструмента, який не зберігав регіональні/японські/додаткові назви. Виконується у фоновому режимі; прогрес показується на картці інструмента.

Потребує принаймні одного ключа API скрапера (IGDB / TGDB / ScreenScraper)

Масовий пошук HLTB

Запускає пошук HowLongToBeat для кожної гри, якій бракує оцінки часу проходження. Кожна відповідність оцінюється за назвою + платформою + роком випуску; відповідності з високою впевненістю зберігаються автоматично. Усе, що нижче порогу впевненості (або з конфліктуючими платформами), відкладається для перегляду людиною.

Без зовнішніх залежностей (використовує вбудований офлайн-набір даних HLTB)

Очікування перегляду HLTB

Черга перегляду для неоднозначних відповідностей, виявлених масовим пошуком HLTB. Кожен рядок очікування показує вихідну гру поряд із кандидатом HLTB (назва, платформа, рік випуску, впевненість). Схваліть, відхиліть або оберіть іншу відповідність для кожного рядка. Картка інструмента перегляду з'являється в центрі інструментів ROM лише за наявності принаймні однієї відповідності, що очікує.

  • Вкладки фільтрів для відповідностей з низькою впевненістю, альтернативною назвою та невідповідністю платформи.
  • Схвалення записує оцінку часу проходження; Відхилення відкидає кандидата й підтримує чистоту черги пошуку.

Налаштування інструментів

Налаштуйте шляхи, розташування інструментів, типи архівів і параметри, спільні для всіх інструментів ROM.

Порада: Усі інструменти ROM підтримують паузу/відновлення та виконуються у фоновому режимі. Прогрес і результати журналюються та доступні для перегляду в переглядачі журналів. Статус інструмента (доступний чи потребує встановлення) показується на картці кожного інструмента.

Нормалізація

Що це робить

Нормалізує значення жанру та режиму гри до узгоджених канонічних форм. Це відбувається автоматично під час скрапінгу та заповнення ШІ, а також може застосовуватися вручну до вашої наявної бібліотеки.

Чому це важливо

Різні скрапери використовують різні назви для однієї й тієї самої речі. Нормалізація забезпечує узгодженість у всій вашій бібліотеці:

  • platform → Platformer
  • fps, first person shooter → First-Person-Shooter
  • shoot 'em up, shmup → Shoot-em-up
  • beat 'em up, brawler → Beat-em-up
  • hack and slash → Hack-n-Slash
  • rts, real time strategy → Real-Time Strategy
  • board game, card game → Board-Card

Власні правила

Ви можете додати власні правила нормалізації в Налаштування → Дані → Нормалізація. Власні правила перевизначають вбудовані відповідності, дозволяючи вам визначити власні бажані назви жанрів і режимів. Правила зберігаються в базі даних.

Попередній перегляд і застосування

Перед застосуванням нормалізації ви можете переглянути, які ігри будуть змінені та які зміни буде внесено. Це дозволяє переглянути зміни перед їх внесенням до вашої бібліотеки.

Стандартизація зображень

Що це робить

Стандартизує всі медіа ігор до узгоджених цільових розмірів для однорідного вигляду всієї вашої бібліотеки. Зображення в межах 80–120% від цільового розміру пропускаються.

Як це працює

  • Збільшення масштабу — Зображення, менші за цільовий розмір, збільшуються за допомогою Real-ESRGAN x4 (суперроздільна здатність на основі ШІ через ONNX Runtime) для якісного збільшення, а потім змінюються до точного цільового розміру
  • Зменшення масштабу — Зображення, більші за цільовий розмір, зменшуються за допомогою фільтрації Lanczos для чітких результатів
  • Смуга порогу — Зображення в межах 80–120% від цільового розміру залишаються без змін, щоб уникнути зайвої повторної обробки

Як запустити

  1. Перейдіть в Налаштування → Система → Обслуговування або Інструменти ROM → Зміна розміру зображень
  2. Натисніть "Start", щоб почати масову стандартизацію
  3. Завдання виконується у фоновому режимі зі спливаючим сповіщенням, що показує поточний файл і статистику
  4. Зображення також автоматично стандартизуються під час скрапінгу (нові завантаження стандартизуються негайно)

Підтримка обладнання

Модель Real-ESRGAN автоматично визначає ваше обладнання та використовує найкращого доступного постачальника:

  • CUDA — Прискорення на GPU NVIDIA
  • ROCm — Прискорення на GPU AMD (з автоматичним перевизначенням версії gfx для серії RX 6000)
  • CoreML — Прискорення для Apple Silicon
  • CPU — Резервний варіант для систем без підтримки GPU

Файл моделі ONNX завантажується автоматично з Hugging Face під час першого використання та кешується локально.

Обслуговування

Операції обслуговування доступні в Налаштування → Система → Обслуговування. Вони допомагають підтримувати вашу бібліотеку чистою та оптимізованою.

Сканування бібліотеки

  • Сканувати бібліотеку — Сканує ваші папки ROM на наявність нових ігор. Визначає папки систем і підтримувані типи файлів за допомогою списків розширень ES-DE systeminfo.txt. Також доступно з панелі приладів.

Операції очищення

  • Очистити відсутні ROM — Видаляє записи бази даних для ігор, файли ROM яких більше не існують на диску. Корисно після реорганізації або видалення файлів ROM.
  • Очищення осиротілих медіа — Знаходить і видаляє файли зображень на диску (обкладинки, скріншоти, fanart), які не мають відповідного посилання в базі даних. Попередній перегляд перед видаленням для підтвердження.
  • Очистити скраплені дані — Видаляє всі скраплені метадані з ігор, зберігаючи записи файлів ROM. Корисно для початку роботи зі скрапінгом з чистого аркуша. Попередній перегляд показує уражені ігри перед виконанням.
  • Очистити імпорти CLZ — Видаляє всі записи імпорту CLZ Games (записи лише з метаданими без файлів ROM).

Оптимізація бази даних

  • Оптимізувати базу даних — Виконує SQLite VACUUM та ANALYZE для звільнення сховища від видалених записів і оновлення статистики планувальника запитів. Рекомендується після великих видалень або операцій очищення.

Резервне копіювання та відновлення

Створення резервних копій

  1. Перейдіть в Налаштування → Бібліотека → Резервне копіювання
  2. Натисніть "Create Backup"
  3. Резервна копія зберігається в папці backups/ з іменем файлу, що містить мітку часу

Що входить до резервної копії

Резервна копія включає всю базу даних SQLite (roms.db), яка містить усі метадані ігор, облікові записи користувачів, налаштування, дані трофеїв, прогрес досягнень, теги, списки та елементи списку бажань.

Що НЕ входить до резервної копії

Медіафайли (обкладинки, скріншоти, fanart, відео, посібники) НЕ включені до резервної копії бази даних, оскільки їх можна повторно завантажити за допомогою скрапінгу. Розгляньте окреме резервне копіювання папки static/images/, якщо у вас є власні завантаження.

Відновлення

  1. Знайдіть резервну копію у списку резервних копій
  2. Натисніть "Restore"
  3. Підтвердіть дію
Попередження: Відновлення резервної копії перезаписує вашу поточну базу даних. Створіть свіжу резервну копію перед відновленням старішої!

Оновлення RetroDB

Як оновити

  1. Завантажте новий випуск RetroDB
  2. Створіть резервну копію цих файлів (вони містять ваші особисті дані):
    • config.py (ваші шляхи та ключі API)
    • data/settings.json (ваші налаштування інтерфейсу)
    • data/scraper_settings.json (ваша конфігурація скраперів)
    • data/rom_tools_config.json (ваші налаштування інструментів ROM)
    • папку database/ (базу даних вашої бібліотеки ігор та збережені токени входу PSN/Xbox)
  3. Розпакуйте нову версію поверх наявної установки
  4. Запустіть python install.py, щоб встановити нові залежності
  5. Перезапустіть сервер

Файли, які можна безпечно перезаписати

Усі файли вихідного коду (.py, .html, .css, .js) можна безпечно перезаписати. Інсталятор не перезапише ваші особисті файли конфігурації.

Файли, які слід зберегти

Ніколи не видаляйте та не перезаписуйте: config.py, database/roms.db, data/settings.json, data/scraper_settings.json, data/rom_tools_config.json.

Міграції бази даних

RetroDB автоматично обробляє зміни схеми бази даних під час запуску. Нові стовпці та таблиці додаються за потреби без втрати даних. Вам не потрібно робити нічого особливого — просто запустіть нову версію, і база даних оновиться автоматично.

Усунення несправностей

Поширені проблеми

"No extensions found for system"

Папці системи потрібен коректний файл ES-DE systeminfo.txt, який визначає підтримувані розширення файлів ROM. Переконайтеся, що структура папок ROM відповідає стандартам ES-DE.

"API Connection Failed"

  • Перевірте своє інтернет-з'єднання
  • Перевірте ключі API в Налаштування → Скрапінг → Ключі API
  • Зачекайте, якщо досягнуто ліміту швидкості (деякі API мають денні/годинні обмеження)
  • Перевірте, чи увімкнено скрапер (вимкнені скрапери показують "Disabled" у статусі на панелі приладів)
  • Перевірте переглядач журналів на наявність детальних повідомлень про помилки

"Bulk Scrape Stuck"

Перейдіть в Налаштування → Система → Усунення несправностей → "Clear Stuck Bulk Scrape". Це скидає стан завдання без впливу на ваші дані.

"RA Sync Queue Stuck"

Очистіть чергу синхронізації RetroAchievements в Налаштування → Система → Усунення несправностей.

"PSN Sync Stuck"

Очистіть завдання оновлення PSN в Налаштування → Система → Усунення несправностей.

"Museum Generation Stuck"

Очистіть завдання генерації музею в Налаштування → Система → Усунення несправностей.

"Database Errors"

  1. Створіть резервну копію, якщо можливо (Налаштування → Бібліотека → Резервне копіювання)
  2. Спробуйте Налаштування → Система → Обслуговування → Optimize Database
  3. Перевірте права доступу до файлів у папці database/
  4. Останній засіб: відновіть з резервної копії або видаліть базу даних і скануйте повторно

"Images Not Saving"

Перевірте права запису на папки медіа: chmod -R 755 static/images/

"Page Slow or Unresponsive"

  • Великі колекції можуть завантажуватися довше — нескінченне прокручування завантажує партіями по 100
  • Спробуйте оновити сторінку, щоб очистити накопичену пам'ять
  • Перевірте консоль браузера на наявність помилок JavaScript
  • Спробуйте перейти на тему з легшим ефектом полотна (наприклад, Amber або Elite)
  • Ефекти полотна автоматично визначають обладнання; менш потужні пристрої використовують резервний варіант на CPU зі зниженою частотою кадрів

Банер "Interrupted Jobs" на панелі приладів

Якщо RetroDB перезапускається під час виконання завдань, вони з'являються в банері відновлення. Натисніть "Resume" для окремих завдань або "Resume All", щоб перезапустити їх. Натисніть "Dismiss" або "Dismiss All", щоб прибрати їх.

"PSN Authentication Failed"

  • Термін дії токенів NPSSO закінчується — згенеруйте новий на ca.account.sony.com/api/v1/ssocookie
  • Переконайтеся, що ви увійшли на store.playstation.com перед переходом за адресою кукі
  • RetroDB кешує ваш сеанс PSN приблизно на два місяці і тепер автоматично оновлює його у фоновому режимі; якщо він усе ж закінчився, просто вставте свіжий NPSSO в Налаштування → Обліковий запис → PSN

"Xbox Authentication Failed"

  • Повторно автентифікуйтеся, натиснувши "Sign In" на вкладці Імпорт ігор → Xbox
  • Токени Xbox кешуються в data/xbox_tokens.json і оновлюються автоматично

"Image Upscaling Errors"

  • Модель ONNX Real-ESRGAN завантажується під час першого використання — переконайтеся в наявності доступу до інтернету
  • Прискорення GPU потребує сумісних драйверів (CUDA для NVIDIA, ROCm для AMD)
  • Якщо GPU не спрацював, система автоматично переходить до обробки на CPU

Поради щодо продуктивності

  • Тримайте свій браузер оновленим для найкращої продуктивності
  • Закривайте інші вкладки браузера під час роботи з дуже великими колекціями
  • Використовуйте фільтри систем, щоб зменшити кількість ігор, що відображаються одночасно
  • Періодично запускайте оптимізацію бази даних після великих операцій (скрапінг, очищення, імпорт)
  • Ефекти теми полотна автоматично визначають обладнання; менш потужні пристрої використовують резервний варіант на CPU

Безпека та відмова від відповідальності

Найкращі практики безпеки

  • Змініть типовий пароль — Типовий пароль адміністратора (admin) слід змінити одразу після першого входу. Використовуйте надійний пароль довжиною щонайменше 8 символів.
  • Використовуйте зворотний проксі-сервер HTTPS — RetroDB сам по собі не надає TLS/SSL. Розмістіть його за зворотним проксі-сервером (наприклад, Nginx, Caddy, Traefik) з увімкненим HTTPS, щоб шифрувати трафік між клієнтами та сервером.
  • Обмежте мережевий доступ — Уникайте відкриття прямого доступу до RetroDB з публічного інтернету. Використовуйте VPN або обмежте доступ вашою локальною мережею. Якщо потрібен віддалений доступ, використовуйте зворотний проксі-сервер з автентифікацією.
  • Регулярно робіть резервні копії — Використовуйте вбудовану функцію резервного копіювання в Налаштуваннях для створення періодичних резервних копій бази даних. Зберігайте резервні копії в місці, окремому від застосунку.
  • Тримайте RetroDB оновленим — Регулярно перевіряйте наявність нових випусків. Виправлення безпеки та вдосконалення включені до оновлень.
  • Захищайте свої ключі API — Ключі API зберігаються в data/scraper_settings.json. Переконайтеся, що цей файл не є публічно доступним. Ніколи не діліться своїм config.py або файлами токенів.

Вбудовані функції безпеки

  • Хешування паролів — Паролі адміністратора хешуються за допомогою PBKDF2 (ніколи не зберігаються у відкритому вигляді)
  • Обмеження швидкості входу — Захист від перебору паролів на кінцевій точці входу
  • Перевірка шляхів — Усі файлові операції використовують допоміжні функції safe_path та safe_filename для запобігання атакам обходу каталогів
  • Параметризовані запити — Усі запити до бази даних використовують параметризовані вирази для запобігання SQL-ін'єкціям
  • Захист від XSS — Модальні діалоги використовують безпечну побудову DOM; введені користувачем дані екрануються
  • Захист від бомб декомпресії зображень — Максимальна кількість пікселів зображення обмежена для запобігання вичерпанню пам'яті через шкідливі зображення
